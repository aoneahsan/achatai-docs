# Moving from One-Time Secret to AChat

**One-Time Secret gives you a one-time link for a secret, with an expiry and an optional passphrase.** A password that should vanish after one read belongs there. Reach for AChat when there's more than one thing to send, or the other side needs to answer.

Last checked 2026-11-07. The full comparison: [AChat and One-Time Secret](https://achat.aoneahsan.com/compare/one-time-secret).

## When one read isn't enough

A typical case: you're setting up a machine for someone, and there's a password, a licence key and a question about which account to use. That's a link per secret, or one room on AChat.

1. On the machine with the details, choose **Continue anonymously**, then **Create room** ([anonymous rooms](/features/anonymous-chats)).
2. Give the room a password, so only the person you give it to can read it ([passwords and encryption](/features/passwords-and-encryption)). Send the password by a different route from the link.
3. Paste the password, the key and your question; a file can go in too ([file sharing](/features/file-sharing)). They can reply in the same room.
4. When you're done, delete what you sent. Anything left is deleted after a set number of days, 10 by default.

## What their pages said

One-Time Secret's page confirms a passphrase option. We couldn't find a statement on whether it needs an account, carries files as well as text, or lets the other side reply, so those rows are left out.

| Feature | AChat | One-Time Secret |
|---|---|---|
| Protect it with a password | Yes | Yes (<a href="https://onetimesecret.com/" target="_blank" rel="noopener noreferrer nofollow">their page</a>) |

On AChat, none of those needs an account: rooms take text and files, and the other side can reply. In a room without a password, anyone with the link can read it.
