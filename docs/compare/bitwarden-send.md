# Moving from Bitwarden Send to AChat

**Bitwarden Send shares files and passwords from Bitwarden, with end-to-end encryption and control over how long each Send lasts.** If you already use Bitwarden, keep using Send. AChat fills the gap where there's no password manager on the machine in front of you.

Checked 2026-11-07. See [AChat and Bitwarden Send](https://achat.aoneahsan.com/compare/bitwarden-send) for the side-by-side.

## On a machine without your vault

A borrowed laptop, a library computer, a client's PC: you can't, or shouldn't, sign in to your password manager there.

1. In that machine's browser, open AChat and choose **Continue anonymously**. You type no account details ([anonymous rooms](/features/anonymous-chats)).
2. Join the room you made earlier from your own device, or create one now and open its link on your phone.
3. Make sure the room has a password ([passwords and encryption](/features/passwords-and-encryption)).
4. Send what you need across, text or a file ([file sharing](/features/file-sharing)), and copy it out.
5. Delete the messages before you walk away. Close the tab too.

## What Bitwarden's page said

Bitwarden's page confirms Send carries text and files. It didn't state whether the recipient needs an account, whether you can add a password, or whether the other side can reply, so those rows are left out.

| Feature | AChat | Bitwarden Send |
|---|---|---|
| Send both text and files | Yes | Yes (<a href="https://bitwarden.com/products/send/" target="_blank" rel="noopener noreferrer nofollow">their page</a>) |

On AChat, the person at the other end needs no account and can write back, and the room can have a password. Anonymous means no account, not invisible: the machine still connects to AChat's servers.
