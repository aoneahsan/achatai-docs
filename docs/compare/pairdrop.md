# Moving from PairDrop to AChat

**PairDrop sends files and text peer to peer on your local network, or over the internet through paired devices and temporary public rooms.** When both machines are on at the same time, it's the direct route. AChat helps when the other machine comes online later and the message still has to be there.

Last checked 2026-11-07. Side by side: [AChat and PairDrop](https://achat.aoneahsan.com/compare/pairdrop).

## When the other machine isn't on yet

Say you're leaving work and want a file on your home computer tonight. Nothing is waiting on the other end now, so a peer-to-peer send can't land.

1. On the work machine, open AChat, **Continue anonymously**, and create a room ([anonymous rooms](/features/anonymous-chats)).
2. Add a password, so only you can open it later ([passwords and encryption](/features/passwords-and-encryption)).
3. Drop the file and any notes in ([file sharing](/features/file-sharing)). Copy the room link somewhere you'll have at home.
4. At home, open the link, enter the password, and take the file.
5. Delete it, or leave it. Messages go after a set number of days.

## The facts, side by side

| Feature | AChat | PairDrop |
|---|---|---|
| No account needed | Yes | Yes (<a href="https://github.com/schlagmichdoch/PairDrop" target="_blank" rel="noopener noreferrer nofollow">their page</a>) |
| Send both text and files | Yes | Yes (<a href="https://github.com/schlagmichdoch/PairDrop" target="_blank" rel="noopener noreferrer nofollow">their page</a>) |
| Protect it with a password | Yes | Not stated on the pages we checked |
| The other side can reply | Yes | Not stated on the pages we checked |

AChat's servers hold the room until its messages expire, which is what lets it wait for you. With no password, anyone with the link can read it.
