# Moving from FilePizza to AChat

**FilePizza does peer-to-peer file transfers in your browser.** When you want a file to go directly from one browser to another, use it. AChat is for when the other side won't be online at the same moment.

Last checked 2026-11-07. The full comparison: [AChat and FilePizza](https://achat.aoneahsan.com/compare/filepizza).

## Leaving it for later

A browser-to-browser transfer needs both ends there at once. An AChat room holds the file until the other side turns up.

1. Open a room from **Continue anonymously** ([anonymous rooms](/features/anonymous-chats)). Nobody signs up.
2. Lock it with a password ([passwords and encryption](/features/passwords-and-encryption)).
3. Attach the file and close your tab; it stays in the room ([file sharing](/features/file-sharing)).
4. Send the link and password. The other person collects it whenever they're on, and can leave you a reply.
5. It's deleted after the room's set number of days. Delete it sooner if you like.

## What FilePizza's page said

FilePizza's page confirms files, which we've marked "partly" for text and files. It didn't state whether an account is needed, whether a password can be added, or whether the other side can reply, so those rows are left out.

| Feature | AChat | FilePizza |
|---|---|---|
| Send both text and files | Yes | Partly (<a href="https://github.com/kern/filepizza" target="_blank" rel="noopener noreferrer nofollow">their page</a>) |

AChat covers all three: no account, an optional password, and replies. In a room without a password, anyone with the link can read it.

We found no price to list. AChat's prices sit on its [pricing page](https://achat.aoneahsan.com/pricing). To check FilePizza, open the <a href="https://file.pizza/" target="_blank" rel="noopener noreferrer nofollow">FilePizza website</a>.
