# Moving from CometChat to AChat

**CometChat is chat for developers, free for up to 100 users on its Build plan.** If your developers are adding chat to your own app, stay with it. AChat is for when you'd rather paste a snippet and let visitors talk with no account.

Last checked 2026-11-07. Side by side: [AChat and CometChat](https://achat.aoneahsan.com/compare/cometchat).

## Past the 100-user line

The Build plan covers up to 100 users. If what you built on it is really a public room for visitors, here's the swap.

1. Separate the two uses. In-app chat between your own users stays on CometChat.
2. For the public part, create a room or choose an open community channel on the [widget page](https://achat.aoneahsan.com/widget) ([embeddable widget](/features/embeddable-widget)).
3. Set the layout, then copy the code into your page.
4. Visitors pick a display name in the room. Nobody needs an account.
5. If the room should be private to a group, give it a password and send that separately.

## CometChat's pages

CometChat's pricing page confirms a free plan with no end date. The pages we checked didn't state whether it offers a ready-made chat to add to a page, or whether you can run it on your own servers, so those rows are left out.

| Feature | AChat | CometChat |
|---|---|---|
| Free plan with no end date | Yes | Yes (<a href="https://www.cometchat.com/pricing" target="_blank" rel="noopener noreferrer nofollow">their page</a>) |

AChat runs hosted only. Its widget is a ready-made room, not an agent inbox or an SDK.
