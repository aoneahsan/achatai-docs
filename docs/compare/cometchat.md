# Moving from CometChat to AChat

**Chat for developers, free for up to 100 users on its Build plan.** Choose CometChat if your developers are adding chat to your own app. Choose AChat if you want to paste a snippet and let visitors talk with no account.

Last checked 2026-11-07. The full comparison is on [AChat and CometChat](https://achat.aoneahsan.com/compare/cometchat).

## How to move across

1. Decide whether AChat's widget fits. It shows an anonymous room or an open community channel, so visitors talk to each other. It doesn't replace CometChat if an agent has to answer each visitor.
2. Build it on the [widget page](https://achat.aoneahsan.com/widget), then paste the code into your page ([embeddable widget](/features/embeddable-widget)).
3. List the websites allowed to show it. Until you add one, any website can.
4. Add a password if the room shouldn't be readable by everyone on the page.

## How they differ

| Feature | AChat | CometChat |
|---|---|---|
| Free plan with no end date | Yes | Yes (<a href="https://www.cometchat.com/pricing" target="_blank" rel="noopener noreferrer nofollow">their page</a>) |
| Ready-made chat to add to a page | Yes | Not stated on the pages we checked |
| Run it on your own servers | No | Not stated on the pages we checked |

The AChat widget shows an anonymous room or an open community channel. It isn't an agent inbox or a developer SDK, and anyone on the page can read the room unless it has a password.
