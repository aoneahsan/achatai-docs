# Moving from tawk.to to AChat

**tawk.to is free live chat for websites; paying removes its branding.** If your team answers customers and wants a help centre and ticketing alongside, tawk.to does that and AChat doesn't. AChat's widget is a room. Visitors talk to each other there, without waiting for someone on a support team.

Last checked 2026-11-07. The side-by-side is on [AChat and tawk.to](https://achat.aoneahsan.com/compare/tawk-to).

## Is this a replacement, or a second widget?

Usually the second. Support questions still need someone answering them, so keep tawk.to on your contact or help pages. Put AChat where visitors would talk among themselves: an event page, a course, a fan site.

1. Open the [widget page](https://achat.aoneahsan.com/widget) and pick a room ID, 8 to 20 lowercase letters, numbers and dashes. The room is created the first time someone opens the widget ([embeddable widget](/features/embeddable-widget)).
2. Choose **In the page** for a chat at a fixed size, or **Chat button** for a button in a corner that opens the chat in a panel.
3. Watch the preview, then copy the code into the page.
4. Keep the room with an account, then list up to 20 websites allowed to show it. Until a site is listed, any website can show your room.
5. Set a password if the room shouldn't be readable by everyone who visits.
