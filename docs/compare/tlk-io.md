# Moving from tlk.io to AChat

**tlk.io is a web chat room at a URL, with no signup, that you can embed on your own site.** For one throwaway room with nothing to read first, it's hard to beat. AChat rooms start the same way and go further when you need them to: a password, files, or someone keeping the room.

Last checked 2026-11-07. Side by side: [AChat and tlk.io](https://achat.aoneahsan.com/compare/tlk-io).

## The same habit, one more choice

A tlk.io room is a URL you send round. An AChat room is too.

1. Open AChat, choose **Continue anonymously**, then **Create room**. You get the room and its link to send ([anonymous rooms](/features/anonymous-chats)).
2. If the room isn't for everyone who might guess the link, set a password when you create it. The password also encrypts the room's messages ([passwords and encryption](/features/passwords-and-encryption)).
3. Drop files into the room as well as messages ([file sharing](/features/file-sharing)).
4. Each message is deleted after a set number of days, 10 by default. If the room should last, someone with an account [keeps it](/features/keep-chats-and-accounts).
5. Had tlk.io embedded on your site? The [widget page](https://achat.aoneahsan.com/widget) does the same for an AChat room.

## Their page and ours

| Feature | AChat | tlk.io |
|---|---|---|
| No account needed | Yes | Yes (<a href="https://tlk.io/" target="_blank" rel="noopener noreferrer nofollow">their page</a>) |
| Send both text and files | Yes | Not stated on the pages we checked |
| Protect it with a password | Yes | Not stated on the pages we checked |
| The other side can reply | Yes | Yes (<a href="https://tlk.io/" target="_blank" rel="noopener noreferrer nofollow">their page</a>) |

In a room with no password, anyone with the link can read it. No account doesn't mean invisible: your device still connects to AChat's servers.
