# Moving from Sendbird to AChat

**In-app chat priced by monthly active users, with a free trial.** Choose Sendbird if chat is part of your own product and you have a budget for it. Choose AChat if a room on a page is enough and you'd rather not pay to start.

Last checked 2026-11-07. The full comparison is on [AChat and Sendbird](https://achat.aoneahsan.com/compare/sendbird).

## How to move across

1. Decide whether AChat's widget fits. It shows an anonymous room or an open community channel, so visitors talk to each other. It doesn't replace Sendbird if an agent has to answer each visitor.
2. Build it on the [widget page](https://achat.aoneahsan.com/widget), then paste the code into your page ([embeddable widget](/features/embeddable-widget)).
3. List the websites allowed to show it. Until you add one, any website can.
4. Add a password if the room shouldn't be readable by everyone on the page.

## How they differ

| Feature | AChat | Sendbird |
|---|---|---|
| Free plan with no end date | Yes | No (<a href="https://sendbird.com/pricing/chat" target="_blank" rel="noopener noreferrer nofollow">their page</a>) |
| Ready-made chat to add to a page | Yes | Not stated on the pages we checked |
| Run it on your own servers | No | Not stated on the pages we checked |

The AChat widget shows an anonymous room or an open community channel. It isn't an agent inbox or a developer SDK, and anyone on the page can read the room unless it has a password.
