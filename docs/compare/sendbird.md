# Moving from Sendbird to AChat

**Sendbird is in-app chat priced by monthly active users, with a free trial.** If chat is part of your own product and you have a budget for it, Sendbird is built for that. AChat suits a smaller ask: a room on a page, where you'd rather not pay to start.

Last checked 2026-11-07. Compared in full on [AChat and Sendbird](https://achat.aoneahsan.com/compare/sendbird).

## Before the trial turns into a bill

Sendbird's plans start at $349 a month billed yearly. If your trial showed that all you needed was a place for visitors to talk, try this first.

1. Write down what the trial was for. If it was messaging between your own signed-in users, keep evaluating Sendbird; AChat's widget isn't an SDK for that.
2. If it was a public room, build one on the [widget page](https://achat.aoneahsan.com/widget) on AChat's free plan ([embeddable widget](/features/embeddable-widget)).
3. Paste the code where the trial's chat sat.
4. Turn on **Offer sign-in** if visitors should be able to keep the room. Sign-in opens in a new tab, and chatting never needs it.
5. Add a password if the room should stay among people you invite.

## Sendbird, as their pricing page has it

Their pricing page says there's no free plan with no end date. The pages we checked didn't state whether Sendbird offers a ready-made chat to add to a page or a version to run on your own servers, so those rows aren't shown.

| Feature | AChat | Sendbird |
|---|---|---|
| Free plan with no end date | Yes | No (<a href="https://sendbird.com/pricing/chat" target="_blank" rel="noopener noreferrer nofollow">their page</a>) |

AChat is hosted only, and its widget is a ready-made room, not an SDK or an agent inbox.
