# Moving from Crisp to AChat

**A shared inbox for customer messages, priced per workspace.** Choose Crisp if a team answers customer messages from one inbox. Choose AChat if you want an open room on your page, with no seats to count.

Last checked 2026-11-07. The full comparison is on [AChat and Crisp](https://achat.aoneahsan.com/compare/crisp).

## How to move across

1. Decide whether AChat's widget fits. It shows an anonymous room or an open community channel, so visitors talk to each other. It doesn't replace Crisp if an agent has to answer each visitor.
2. Build it on the [widget page](https://achat.aoneahsan.com/widget), then paste the code into your page ([embeddable widget](/features/embeddable-widget)).
3. List the websites allowed to show it. Until you add one, any website can.
4. Add a password if the room shouldn't be readable by everyone on the page.

## How they differ

| Feature | AChat | Crisp |
|---|---|---|
| Free plan with no end date | Yes | Yes (<a href="https://crisp.chat/en/pricing/" target="_blank" rel="noopener noreferrer nofollow">their page</a>) |
| Ready-made chat to add to a page | Yes | Not stated on the pages we checked |
| Run it on your own servers | No | Not stated on the pages we checked |

The AChat widget shows an anonymous room or an open community channel. It isn't an agent inbox or a developer SDK, and anyone on the page can read the room unless it has a password.
