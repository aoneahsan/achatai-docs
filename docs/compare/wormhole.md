# Moving from Wormhole to AChat

**Wormhole shares files with end-to-end encryption, up to 10 GB, by a link that expires.** Large files belong on Wormhole. AChat is for when you also want to talk in the same place, or need to send a password and a small file together.

Checked 2026-11-07. The comparison is on [AChat and Wormhole](https://achat.aoneahsan.com/compare/wormhole).

## Big files there, small ones here

Keep Wormhole for the video export or the disk image. AChat's file size limit comes from your plan, and AChat shows it before you attach, so check that first ([file sharing](/features/file-sharing)).

1. Create a room with **Continue anonymously**, then **Create room** ([anonymous rooms](/features/anonymous-chats)).
2. Set a password, so the room's messages are encrypted with it ([passwords and encryption](/features/passwords-and-encryption)).
3. Send the small things: the config file, the Wi-Fi password, a note on what it's for.
4. If something's too big, send a Wormhole link into the room and talk about it there.
5. Messages are deleted after the room's set number of days, unless someone with an account keeps it.

## What Wormhole's page said

Wormhole's page confirms files, and we've marked text and files as "partly". It didn't state whether you need an account, can add a password, or can get a reply, so those rows are left out.

| Feature | AChat | Wormhole |
|---|---|---|
| Send both text and files | Yes | Partly (<a href="https://wormhole.app/" target="_blank" rel="noopener noreferrer nofollow">their page</a>) |

In an AChat room you need no account, can set a password, and get answers back. Without a password, anyone with the link can read the room.

We found no price to list for Wormhole. What AChat costs is on the [pricing page](https://achat.aoneahsan.com/pricing). Check it yourself on the <a href="https://wormhole.app/" target="_blank" rel="noopener noreferrer nofollow">Wormhole website</a>.
