# Files, voice notes & media

**Share a file of any type within your plan's allowance, record a voice note, or paste an image straight into the message box.**

## Allowances

Two limits come from your [plan](/features/plans-and-pricing):

- **File size:** how large each file can be.
- **Files per chat:** how much file storage each chat can hold.

AChat shows both before you attach, and so does **Account**, then **Storage**. When a chat reaches its limit, new files in it are refused; messaging carries on.

## Voice notes

Record a voice note from the message box, up to the length AChat shows. Slide up to lock the recording and keep your hands free. If you hit the limit, recording stops so you can listen before you send.

## Photos, videos and pasted images

- Paste or drop an image into the message box to attach it, with an optional caption.
- Videos play in the chat.
- **Chat info**, then **Media**, collects the photos, videos and files shared in a chat. Hidden and cleared messages' files leave it too.

## Uploads

Uploads show real progress and can be cancelled. An upload survives a page reload, and a cancelled upload is removed.

## Encryption

Files in personal chats and private groups are end-to-end encrypted with the chat. See [Passwords & encryption](/features/passwords-and-encryption) for the other chat types.
