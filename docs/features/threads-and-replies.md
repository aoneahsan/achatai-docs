# Threads & replies

**Reply in a thread so a plan doesn't get lost while everyone else keeps chatting.**

## Reply or thread

- **Reply** quotes a message in the main conversation.
- **Thread** opens a side conversation on one message, in a panel beside the chat. **Show in chat** jumps back to the message it started from.

Threads work in chats, rooms and community channels.

## Deleting in a thread

- Delete one reply on its own, and it goes to the chat's Trash.
- Delete the message a thread starts from, and it goes to Trash with all its replies. Anyone in the chat can restore them from Trash.

See [Manage messages](/features/manage-messages) for Trash.
