# Appearance, language & shortcuts

**Theme, colour, text size and motion live in one Appearance panel, so a change shows everywhere at once.**

## Appearance

Open the Appearance panel to change the theme, colour, text size or motion. Each choice applies on every page.

## Language

AChat's interface comes in English, Spanish, French, German and Arabic. Choose it at the end of the Appearance panel; each language appears under its own name. Arabic reads right to left.

## Keyboard shortcuts

Press **?** anywhere outside a text field to see the full list. Shortcuts show **Ctrl**, or **⌘** on Apple devices.

| Keys | Action |
|---|---|
| Ctrl+K | Find a chat or page |
| Enter | Send |
| Shift+Enter | New line |
| ↑ in an empty message box | Edit your last message |
| Ctrl+Shift+S | Mark the selected text as a spoiler |
| Esc | Close a menu or dialog, cancel a reply or an edit |
| Ctrl+Shift+F | Focus mode on or off |
| Ctrl+Shift+H | Hide the screen now |
| ↑ / ↓, Home / End | Move through the chat list |
| Alt+↑ / Alt+↓ | Previous or next chat |
| Shift+F10 | Chat actions |

## Focus mode

Turn **Focus mode** on from a chat's menu or with Ctrl+Shift+F. Press **Esc** to leave it.

## Accessibility

- The shortcuts above cover the chat list, a chat and the message box.
- Changes such as a sent message or a restored draft are announced to screen readers.
- Text size and motion come from Appearance.
- [Read aloud](/features/writing-messages#read-aloud) plays a message with an on-device voice.
