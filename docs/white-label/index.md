# White-label & licensing

**AChat can run under another organisation's name.** With a white-label licence, the AChat team hosts AChat, deploys it at your domain and puts your name, logo and colours on it. You offer it to your own people. If you'd rather own the code, you can buy AChat outright instead.

Current prices are on the [licence prices page](https://achat.aoneahsan.com/white-label/pricing) and the [buyout page](https://achat.aoneahsan.com/white-label/buyout). They aren't repeated here, so they're only ever stated in one place.

## The two paths

| | White-label licence | Source buyout |
|---|---|---|
| Who runs it | The AChat team hosts and deploys it | You do, from the source code |
| Source code | Not included | Every repository that builds the web and Android app |
| Exclusive | No: others can license AChat too | Yes: the AChat team stops selling it |
| Updates | Six months included, then renewals | Six months included, then renewals |
