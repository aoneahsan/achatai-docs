# 2026-11-17 · eatthis (delta)

- **Prerendered SPAs inherit the PWA head for free when the prerender copies the built shell.** Eat This's
  `src/build/prerender.ts` replaces only title/description/canonical in `dist/index.html`, so the manifest link and iOS
  meta reached every prerendered page with no extra code. Probe for other projects: `grep -c 'rel="manifest"'` on
  one deep prerendered page; a prerender that writes its own head from a template will miss it.
- **pricing.md is a pay surface for the payment-copy law.** A "final and non-refundable" line there broke the rule
  (refund words only in Terms and Privacy). Probe: `curl -s <origin>/pricing.md | grep -ci refund` → 0.
- **Pages deploys propagate unevenly for a few seconds**: `/sw.js` already new while a query-string page URL still
  served the previous HTML. Re-read the bundle hash after ~15 s before calling a deploy mismatched.
