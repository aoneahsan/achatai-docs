واجهة برمجة AChat

أرسل مفتاح وصول بوصفه رمز Bearer إلى https://vhkerwyxmhaxfyjbvsha.supabase.co/functions/v1/api/v1 فتحصل على JSON. يمكن قراءة ملفك الشخصي وإعداداتك ومنشورات حالتك وقائمة المحظورين وتغييرها؛ أما جهات الاتصال والمحادثات ورسائل الغرف المفتوحة والمجتمعات والقنوات فللقراءة فقط. ولا يوجد في الواجهة أي شيء مشفّر من الطرف إلى الطرف إطلاقًا.

المرجع المقروء آليًا هو openapi.json ‏(OpenAPI 3.1)، ومتاح أيضًا بصيغة openapi.md. ولا يحتاج أي منهما إلى مفتاح.

العنوان الأساسي والمفتاح​

export ACHAT_API="https://vhkerwyxmhaxfyjbvsha.supabase.co/functions/v1/api/v1"
export ACHAT_KEY="achat_pat_…"   # from Account › Other apps

curl -s "$ACHAT_API/token" -H "Authorization: Bearer $ACHAT_KEY"

يجيب /token عمّا هي بيانات الاعتماد وما الذي يحق لها فعله، وهي أسرع طريقة لفحص مفتاح جديد:

{
  "data": {
    "kind": "pat",
    "user_id": "6f0d2a4e-1b7c-4e39-8d52-0a9c3f71b2e8",
    "client_id": null,
    "scopes": ["blocks:read", "profile:read", "status:read", "status:write"]
  }
}

قيمة kind هي pat لمفتاح الوصول وoauth لتطبيق ربطته، مثل مساعد. وتقبل الواجهة كليهما.

الغلاف​

كل رد هو JSON بإحدى الصيغ الثلاث التالية.

الردالصيغة
سجل واحد{ "data": { … } }
قائمة{ "data": [ … ], "meta": { "next_cursor": "…" or null, "limit": 20 } }
خطأ{ "error": { "code": "…", "message": "…", "details": { … }, "correlation_id": "req_…" } }

يرد الحذف بـ 204 دون جسم. والحقل الذي لا يملك AChat له قيمة يعود بـ null.

الأخطاء​

HTTPcodeمتى
400invalid_requestاستعلام خاطئ، أو مؤشر خاطئ، أو جسم يخالف قواعد الحقول (يذكر details.issues كل حقل)
401invalid_tokenالمفتاح مفقود أو خاطئ أو منتهٍ أو مُزال
403scope_requiredالمفتاح يفتقر إلى الإذن؛ ويذكره details.scope
404not_foundلا شيء على هذا العنوان لهذا المفتاح، بما في ذلك سجل شخص آخر
405method_not_allowedالمورد لا يقبل هذه الطريقة، مثل POST إلى جهات الاتصال
409conflictرفضت قاعدة في AChat التغيير؛ وتقول الرسالة أيها بكلمات بسيطة
413payload_too_largeالجسم كبير جدًا
429rate_limitedطلبات كثيرة جدًا؛ راجع الحدود
500internalالخطأ منا. أرسل correlation_id إلى فريق AChat عبر صفحة التواصل

الرسالة مكتوبة لإنسان ولا تحمل أبدًا تتبع مكدس أو SQL أو سرًا. ودون أي مفتاح:

{
  "error": {
    "code": "invalid_token",
    "message": "The credential is missing, invalid, expired or revoked.",
    "correlation_id": "req_011342b96e465843"
  }
}

الصفحات والترتيب والتصفية​

تُرجع القوائم 20 سجلًا افتراضيًا و50 كحد أقصى (من limit=1 إلى limit=50). وحين يوجد المزيد، يحمل meta.next_cursor مؤشرًا: أرسله مجددًا بوصفه cursor مع الاستعلام نفسه لتحصل على الصفحة التالية، وتوقف حين يصبح null. المؤشر مرتبط بالاستعلام الذي جاء منه؛ فإن غيّرت الترتيب أو أحد المرشحات رفضه AChat، فابدأ من جديد دونه.

يقبل sort القيم التي يذكرها كل مورد أدناه؛ و- في البداية تعني الأحدث أولًا. وتُكتب المرشحات بصيغة field.op=value:

curl -s "$ACHAT_API/status?kind.eq=text&created_at.gte=2026-11-21T00:00:00Z&sort=-created_at" \
  -H "Authorization: Bearer $ACHAT_KEY"

الحدود​

يحق لكل مفتاح أو اتصال 120 طلبًا في الدقيقة. وفوق ذلك تحدد خطتك عدد الطلبات التي يحق للحساب كله إجراؤها يوميًا، محسوبة من منتصف الليل بتوقيت UTC عبر كل المفاتيح والمساعدين (5,000 في Free افتراضيًا؛ راجع ما تسمح به خطتك). يحمل كل رد ratelimit-limit وratelimit-remaining وratelimit-reset (الثواني المتبقية حتى يُعاد ضبط أضيق الحدود)؛ ويضيف 429 الترويسة retry-after بالثواني. وتظل الطلبات تُحتسب أثناء رفضك، لذا تمهّل بدل الإعادة في حلقة.

الملف الشخصي​

ملفك الشخصي: سجل واحد، معرّفه id هو معرّفك. وusername للقراءة فقط هنا، لأن اسم المستخدم الجديد يمر بمسار المطالبة في التطبيق. اقرأ بـ profile:read، وغيّر بـ profile:write.

الحقلالنوعملاحظات
iduuidمعرّفك
usernameنص، حتى 24للقراءة فقط
nameنص، من 1 إلى 100الاسم الذي يراه الآخرون
hueعدد صحيح من 0 إلى 359لون صورتك الرمزية حين لا توجد صورة
created_atتاريخ ووقت
# Read it (a list of one)
curl -s "$ACHAT_API/profile" -H "Authorization: Bearer $ACHAT_KEY"

# Change the name and colour
curl -s -X PATCH "$ACHAT_API/profile/6f0d2a4e-1b7c-4e39-8d52-0a9c3f71b2e8" \
  -H "Authorization: Bearer $ACHAT_KEY" -H "Content-Type: application/json" \
  -d '{"name": "Mariam K.", "hue": 212}'

تُغيَّر صورتك في التطبيق، لا هنا.

الإعدادات​

إعداداتك: سجل واحد، على /preferences. اقرأ بـ preferences:read، وغيّر بـ preferences:write.

الحقلالقيم
presence_visibilityeveryone أو contacts أو nobody: من يرى إن كنت متصلًا
read_receiptstrue أو false
languageen أو zh-Hans أو hi أو es أو ar أو fr أو pt-BR أو ru أو ja أو ur أو de، أو null حين لا تُحدد لغة
notify_soundstrue أو false
notify_previewname أو none: هل يعرض الإشعار من كتب
notify_mute_alltrue أو false
show_matureللقراءة فقط: يتبع العمر الذي صرّحت به في التطبيق
id، updated_atللقراءة فقط
curl -s "$ACHAT_API/preferences" -H "Authorization: Bearer $ACHAT_KEY"

curl -s -X PATCH "$ACHAT_API/preferences/6f0d2a4e-1b7c-4e39-8d52-0a9c3f71b2e8" \
  -H "Authorization: Bearer $ACHAT_KEY" -H "Content-Type: application/json" \
  -d '{"presence_visibility": "contacts", "read_receipts": false}'

معرّف id لسجل الإعدادات هو معرّفك نفسه، كمعرّف ملفك الشخصي وuser_id الذي يُرجعه /token.

منشورات الحالة​

منشورات حالتك خلال آخر 24 ساعة. اقرأ بـ status:read؛ وانشر بـ status:write؛ واحذف بـ status:delete.

الحقلملاحظات
id، created_at، expires_atللقراءة فقط
kindtext أو photo أو video؛ للقراءة فقط
textكلمات المنشور النصي، حتى 700 حرف؛ ويسري طول الحالة في خطتك
bg_hueلون خلفية المنشور النصي، من 0 إلى 359؛ وإن أغفلته يُستخدم لون صورتك الرمزية
captionتعليق الصورة أو الفيديو؛ للقراءة فقط
audience_modecontacts أو except أو only؛ للقراءة فقط
audience_countعدد من يصلهم المنشور؛ للقراءة فقط

المرشحات: kind.eq وcreated_at.gte وcreated_at.lt. الترتيب: -created_at (الافتراضي) أو created_at.

# Post a text status
curl -s -X POST "$ACHAT_API/status" \
  -H "Authorization: Bearer $ACHAT_KEY" -H "Content-Type: application/json" \
  -d '{"text": "Back online after the move. Same username.", "bg_hue": 160}'

# Delete one
curl -s -X DELETE "$ACHAT_API/status/STATUS_ID" -H "Authorization: Bearer $ACHAT_KEY"

تنشر الواجهة نصًا فقط؛ أما الصور والفيديوهات فتحتاج إلى الرفع من التطبيق. يذهب المنشور الجديد إلى الجمهور الذي تحدده إعدادات الحالة في تطبيقك، مع حد النشر الخاص بالتطبيق (30 في الساعة)، الذي يرد بـ 409 مع السبب عند بلوغه. والحالة ليست مشفّرة من الطرف إلى الطرف، لا في التطبيق ولا هنا.

الأشخاص المحظورون​

الأشخاص الذين حظرتهم، باسم المستخدم والاسم اللذين يعرضونهما. اقرأ بـ blocks:read؛ واحظر بـ blocks:write؛ وارفع الحظر بـ blocks:delete. وid هنا هو معرّف الشخص المحظور.

الحقلملاحظات
idمعرّف الشخص المحظور
usernameاسمه. لحظر شخص، أرسله
nameالاسم الذي يعرضه؛ للقراءة فقط
created_atمتى حظرته

الترتيب: -created_at (الافتراضي) أو created_at.

# Block someone by username
curl -s -X POST "$ACHAT_API/blocks" \
  -H "Authorization: Bearer $ACHAT_KEY" -H "Content-Type: application/json" \
  -d '{"username": "night_owl_42"}'

# Unblock them
curl -s -X DELETE "$ACHAT_API/blocks/BLOCKED_PERSON_ID" -H "Authorization: Bearer $ACHAT_KEY"

يعمل الحظر كما في التطبيق: لا يعود الشخص قادرًا على مراسلتك أو رؤية حالتك، وينتهي الاتصال بينكما.

جهات الاتصال​

للقراءة فقط، بـ contacts:read. يحمل كل سجل اسم الشخص الآخر: id (معرّفه) وusername وname وhue وchat_id (محادثتك المباشرة معه، أو null) وcreated_at. الترتيب: -created_at أو created_at.

curl -s "$ACHAT_API/contacts?limit=50" -H "Authorization: Bearer $ACHAT_KEY"

طلبات الاتصال التي تنتظرك ليست موردًا؛ ويمكن لخادمك أن يعلم بها عبر webhook ‏contact_request.received.

المحادثات​

المحادثات التي تنتمي إليها، للقراءة فقط، بـ chats:read.

الحقلملاحظات
id، created_at
kinddirect أو group أو anonymous_room أو channel
title، topicnull حين لا يكون للمحادثة ذلك
end_to_endtrue حين تكون الرسائل مشفّرة من الطرف إلى الطرف ولا تُقرأ هنا أبدًا
has_passwordtrue للغرفة ذات كلمة المرور
last_message_at، joined_atnull حين لا يوجد

المرشح: kind.eq. الترتيب: -created_at أو created_at.

curl -s "$ACHAT_API/chats?kind.eq=anonymous_room" -H "Authorization: Bearer $ACHAT_KEY"

تظهر المحادثة المباشرة أو المجموعة أو الغرفة ذات كلمة المرور في القائمة، باسمها ووقت آخر رسالة فيها، أما رسائلها فلا تظهر أبدًا.

الرسائل​

الرسائل في الغرف المفتوحة والقنوات التي تنتمي إليها، كما كتبها الناس: للقراءة فقط، بـ chats:read. الغرف ذات كلمة المرور والمحادثات المباشرة والمجموعات ليست هنا، ولا رسائل العرض لمرة واحدة، ولا الرسائل التي أزالها مشرف، ولا المرفقات أو التفاعلات أو الاستطلاعات.

الحقلملاحظات
id، created_at
chat_idالغرفة المفتوحة أو القناة
kindtext أو link
bodyالرسالة كما كُتبت
sender_nameالاسم المعروض الذي أُرسلت به
reply_to_idالرسالة التي ترد عليها، أو null
edited_atnull إن لم تُعدَّل قط

المرشحات: chat_id.eq وcreated_at.gte وcreated_at.lt. الترتيب: -created_at أو created_at.

curl -s "$ACHAT_API/messages?chat_id.eq=CHAT_ID&created_at.gte=2026-11-21T00:00:00Z" \
  -H "Authorization: Bearer $ACHAT_KEY"

المجتمعات​

المجتمعات التي أنت عضو فيها، للقراءة فقط، بـ communities:read: id وname وabout وtopic (general أو tech أو gaming أو study أو creative أو support أو local أو random) وjoin_mode (open أو account) وmember_count وrole الخاص بك (owner أو admin أو member) وjoined_at. الترتيب: name (الافتراضي) أو -joined_at.

curl -s "$ACHAT_API/communities" -H "Authorization: Bearer $ACHAT_KEY"

القنوات​

القنوات التي تستطيع رؤيتها في مجتمعاتك، للقراءة فقط، بـ communities:read: id وcommunity_id وchat_id (اقرأ رسائلها عبر الرسائل) وname وtopic وaccess (open أو private) وposition. المرشح: community_id.eq. الترتيب: position.

curl -s "$ACHAT_API/channels?community_id.eq=COMMUNITY_ID" -H "Authorization: Bearer $ACHAT_KEY"

الحذف من تطبيق متصل​

الحذف بمفتاح وصول يحدث فورًا ويرد بـ 204. أما الحذف الذي يطلبه تطبيق ربطته فلا يحدث هكذا أبدًا: يرد بـ 202 وينتظرك.

{
  "data": {
    "status": "pending_confirmation",
    "confirm_url": "https://achat.aoneahsan.com/developers/confirm/…",
    "expires_at": "2026-11-21T10:24:00.000Z"
  }
}

تفتح الرابط، وترى ما سيذهب، وتقول نعم أو لا في AChat خلال 10 دقائق. راجع الحذف ينتظرك.
