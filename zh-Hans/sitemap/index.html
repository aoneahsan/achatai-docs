概览

  • 简介

    AChat 是一款用于私人聊天、群组、社区和匿名房间的消息应用，支持网页和 Android。它能做什么，以及它不承诺什么。

  • 常见问题

    关于 AChat 的直接回答：账号、加密、匿名房间、消息保留多久、套餐、位置记录、删除账号和支持的平台。

  • 更新日志

    AChat 的发布历史：加入私人聊天、群组、社区和动态的重建版本，以及匿名聊天早期的各个版本。

入门

  • 安装与访问

    在浏览器里使用 AChat，或从 Google Play 获取 Android 应用。匿名房间不需要账号；私人聊天需要 Google 登录和一个用户名。

  • 快速开始

    开始你的第一次 AChat 对话：通过用户名和朋友聊，或通过链接进入匿名房间，并保存好恢复密钥。

功能

  • 私人聊天与联系人

    通过用户名、邀请链接或二维码添加联系人，处理消息请求和屏蔽，并选择谁能看到你是否在线、是否发送已读回执。

  • 设备与恢复密钥

    把另一台设备关联到你的 AChat 账户，比对安全码，移除丢失的设备，并用恢复密钥找回你的历史。

  • 匿名房间

    AChat 的匿名房间如何在没有账号的情况下运作：房间 ID、显示名称、密码、消息保留多久，以及匿名不代表什么。

  • 密码与加密

    哪些 AChat 聊天是端到端加密的，房间密码保护什么，以及限制：开放房间、社区和动态不是端到端加密的。

  • 群组与社区

    给彼此认识的人用的端到端加密私密群组，以及有频道、话题、角色、举报和封禁的社区。哪些需要账号。

  • 动态

    发布一条 24 小时后消失的动态给联系人看，选择谁能看到，并了解动态不是端到端加密的。

  • 保留的房间与你的账户

    让匿名 AChat 房间保留超过默认的历史期限、释放它，以及管理你的账户：用户名、数据导出和删除账户。

  • 话题与回复

    回复一条消息，或在话题里回复，让一段旁支对话集中在一处。话题可用于聊天、群组、房间和社区频道。

  • 文件、语音消息和媒体

    在套餐的文件额度内，在 AChat 里分享任意类型的文件、照片、视频和语音消息，并查看聊天里的媒体都汇集在哪里。

  • 管理消息

    编辑、删除、清空、转发、置顶和恢复 AChat 消息；每个聊天的回收站；阅后消失和阅后即焚；投票；归档聊天、消息和回复；保存聊天副本。

  • 写消息

    AChat 里的草稿、剧透、数学公式、提及、贴纸、听写、设备上的翻译和朗读，以及其中哪些会离开你的设备。

  • 搜索与离线历史

    AChat 的搜索在你的设备上进行，范围是设备上保存的消息。打开过的聊天离线也能读，离线时写的消息会在发件箱里等待。

  • 可嵌入的小组件

    把 AChat 的匿名房间或社区频道放到你的网站上，嵌在页面里或做成聊天按钮，并选择哪些网站可以显示它。

  • 通知与邮件

    AChat 的通知需要你主动开启，而且从不包含消息正文。AChat 会给你的 Google 邮箱发哪些邮件，以及何时发。

  • 外观、语言和快捷键

    一个外观面板管理主题、颜色、文字大小和动效；十一种界面语言，包括阿拉伯语和乌尔都语；AChat 的键盘快捷键和专注模式。

  • 这台设备上的隐私

    保护共用或借来的设备的 AChat 设置：隐私屏幕、中性标签页标题、自动清空剪贴板，以及从这台设备清除。

  • 设备和位置记录

    有些 AChat 聊天会记录设备和位置。会记录什么、谁能看到、保留多久，以及聊天如何在你进入前先征得同意。

  • 套餐与价格

    AChat 的 Free、Pro 和 Team / Family 套餐，它们改变的四项额度，银行卡或银行转账付款如何进行，以及推荐如何赚取套餐月份。

  • 页面导览和“AChat 如何运作”

    聊天、功能、套餐与价格、社区和账户页面上的页面导览，以及六步的“AChat 如何运作”页面。

  • 口述、草稿助手和帮我跟上

    “口述”把录音变成输入框里的文字，“草稿助手”改写、缩短或翻译你自己的草稿，“帮我跟上”为你一个人总结开放房间。

概念

  • AChat 是怎么运作的

    AChat 里的两种身份——账号和匿名显示名——有哪些聊天类型、消息存放在哪里，以及每种内容保留多久。

  • 安全与加密模型

    AChat 的端到端加密涵盖什么、不涵盖什么，密钥、关联设备和恢复密钥是怎么配合的，以及任何应用都无法消除的限制。

  • 管理员监督

    AChat 的管理员能看到和做什么、不能看到和做什么——聊天详情但从不看消息、举报、停用、房间限制、套餐授予——以及操作日志。

  • 数据、隐私与删除

    AChat 收集什么、哪些服务会处理、每类数据保留多久、你能控制什么，以及删除账号会移除什么。

开发者

  • 面向开发者的 AChat

    从脚本、AI 助手或你自己的服务器访问你的 AChat 账户：带访问密钥的 API、供 Claude 和 ChatGPT 使用的助手连接、签名的 Webhook 和两步登录。加密聊天永远不会离开 AChat。

  • 访问密钥

    在 账户 › 其他应用 中创建 AChat 访问密钥，选择它能读取、更改或删除什么，以及何时失效。密钥何时能再次显示，如何无缝更换，以及如何移除。

  • AChat API

    AChat 的 REST API：基础 URL、Authorization 请求头、响应信封、错误码、游标分页和限制，以及每个资源附带可用的 curl 示例，从你的资料、动态到开放房间的消息。

  • 连接 Claude、ChatGPT、Claude Code 或 Cursor

    通过 AChat 的 MCP 地址把 AI 助手连接到你的 AChat 账户。Claude、ChatGPT、Claude Code 和 Cursor 的设置方法，你要批准什么，为什么删除总要等你点头，以及如何断开。

  • Webhook

    AChat Webhook：添加 https 地址，选择事件，并用 Node 或 Python 验证每次投递的 Standard Webhooks 签名。每个事件及其载荷、重试时间表、暂停，以及什么会让地址被关闭。

  • 两步登录

    在 AChat 上用 Google 登录之后，再加一个身份验证器应用给出的六位验证码。如何设置、十个恢复码、记住浏览器 7 天、手机丢了怎么办，以及 AChat 团队能为你做和不能做的事。

  • 开发者更新日志

    AChat 的 API、助手连接、Webhook 和两步登录的变更，最新的在前，从 2026-11-21 的开放平台开始。

白标与授权

  • 白标与授权

    以你自己的名义运行由 AChat 团队托管的 AChat，或直接买断它的源代码。每条路径包含什么，以及价格在哪里。

  • 每个平台你能得到什么

    AChat 白标许可目前覆盖的平台：网页应用，以及移动应用（Android，iOS 按需提供）。

  • 设置你的副本

    购买 AChat 白标授权后会发生什么：授权邮件、你的域名、你的名称、标志和配色，以及上线。

  • 更新与续期

    每份 AChat 白标授权和买断都包含六个月的 AChat 更新。更新涵盖什么、不续期会怎样，以及如何续期。

  • 验证许可

    如何通过许可密钥或域名，检查一个以其他名称运行的 AChat 副本是否获得许可，以及每种结果的含义。

  • 白标常见问题

    关于 AChat 白标许可和买断的解答：源代码、独占、定制工作、iOS、通过 Wise 转账付款，以及买断后的分成。
