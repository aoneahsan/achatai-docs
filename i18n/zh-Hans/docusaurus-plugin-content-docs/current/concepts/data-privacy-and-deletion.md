# 数据、隐私与删除

**本页概括 AChat 的[隐私页面](https://achat.aoneahsan.com/zh-Hans/privacy)，以隐私页面为准。两者不一致时，以隐私页面为准。** AChat 团队位于巴基斯坦拉合尔，负责运营 AChat，并决定如何处理它持有的数据。

## AChat 收集什么

- **账号：** 来自你 Google 账号的姓名、邮箱和头像，以及你的用户名。AChat 从不问你的手机号。
- **匿名房间：** 你在每个房间选的显示名、你在那里发的消息，以及在那个房间里使用的设备 ID。
- **聊天：** 你的消息、文件、语音消息和动态，以及每个聊天里有谁。
- **联系人：** 你接受的人、请求，以及你屏蔽的人。
- **位置：** 只在开启了[设备与位置记录](/features/location-history)的聊天里，并且要你同意之后。
- **举报：** 你举报时选择的消息。
- **付款：** 你选的套餐，以及 AChat 团队确认付款所需的信息，比如付款编号。银行卡支付时，AChat 保存订阅的状态、套餐、周期、席位、金额和日期，从不接收你的卡号、账单姓名或地址。
- **联系表单：** 你的姓名、邮箱和留言。
- **错误报告和使用统计：** 不含消息内容、密码、密钥或精确位置。
- **屏幕录制：** 两个公开页面的遮盖录制，从不录制聊天。

## 还有谁会处理

| 服务 | 提供方 | 接收什么 |
|---|---|---|
| 登录 | Google | 你的姓名、邮箱和头像来自这里 |
| 错误报告 | Sentry | 出了什么问题，不含消息内容、密码、密钥或精确位置 |
| 使用统计 | Amplitude，以及开启后的 Google Analytics 4 | AChat 的使用情况，同样的排除项 |
| 屏幕录制 | Microsoft Clarity | 只有两个页面的遮盖录制：加入 AChat 和保留房间。文字和图片都被隐藏。聊天、房间、联系人和动态从不录制 |
| 推送通知 | OneSignal，以及 Android 上的 Google Firebase Cloud Messaging | 一个推送令牌，以及每条提醒的聊天名或发送者名，从不含消息内容 |
| 银行卡支付（当你用银行卡付款时） | Polar Software, Inc.（[隐私政策](https://polar.sh/legal/privacy)） | 你账号的邮箱和一个 AChat 账号 ID，在付款页面打开时发送。你的姓名、账单国家或地址和卡信息由 Polar 在自己的页面上收集 |
| 托管、数据库、文件存储和邮件 | 列在[隐私页面](https://achat.aoneahsan.com/zh-Hans/privacy)上 | 你的账号、聊天、文件，以及 AChat 发送的账号邮件 |

AChat 不显示广告网络的广告，也不出售你的个人数据。它可能会向你展示 AChat 团队做的其他应用。

## 保留多久

| 内容 | 保留多久 |
|---|---|
| 私人聊天和群组里的消息 | 直到有人删除，或者到聊天的阅后即焚时间 |
| 匿名房间里的消息 | 每条发送后保留设定的天数（默认 10 天），或者到保留截止日期 |
| 回收站里的聊天和消息 | 设定的天数（默认 30 天），之后永久删除 |
| 动态 | 24 小时 |
| 位置记录 | 直到聊天从回收站被永久删除或到期 |
| 你的资料和用户名 | 直到你删除账号 |
| 屏幕录制 | 30 天，Microsoft 保留的一小部分样本最长 9 个月。热力图和团队标为收藏的录制保留 9 个月 |
| 联系留言、举报、付款记录、错误报告和统计、备份 | 设定的时间，列在隐私页面上 |
| 保存在设备上的聊天 | 直到你在那台设备上退出登录或清理空间 |
| 你下载的导出文件 | 你保留这个文件多久就多久 |

## 你能控制什么

- **导出：** 一个包含你的资料、联系人和这台设备能读的聊天的文件，在你的设备上生成。
- **在线状态和已读回执：** 参见[私人聊天与联系人](/features/personal-chats-and-contacts)。
- **动态的可见范围：** 默认是你接受的联系人，可以单独包含或排除某些人。
- **其他应用：** 除非你创建了访问密钥或批准了连接，AChat 之外的任何东西都触及不到你的账号，而且你随时可以移除它们。端到端加密的消息永远无法被访问。参见[面向开发者的 AChat](/developers)。
- **使用统计和屏幕录制：** 对所有人开启；没有关闭开关。AChat 会说明一次：你第一次打开时，屏幕底部会出现一条提示栏。统计不含消息内容、密码、密钥和精确位置；录制只涵盖两个公开页面，文字和图片都被隐藏。
- **更正或删除：** 修改你的资料或用户名，或删除账号。其他事项，请通过[联系页面](https://achat.aoneahsan.com/zh-Hans/contact)写信给 AChat 团队。

## 删除账号

删除立即生效且无法恢复。你发出的消息会留在收到的人那里，标为来自已删除的账号。步骤和细节：[保留的房间与你的账号](/features/keep-chats-and-accounts#delete-your-account)。

## 收不回来的东西

任何已经被读过、复制、保存或导出的内容。之后改设置或政策都收不回来。

## 年龄

使用 AChat 需要年满 16 岁。
