# 管理员监督

**AChat 的管理面板显示聊天详情，从不显示消息，举报人选择随举报一起发送的内容除外。** 每一次管理员改动都记入操作日志，任何人都不能编辑或删除，管理员也不行。

## 管理员能看到什么

- **聊天：** 只有人数、日期和设置。加密聊天只列出它的详情。
- **举报：** 关于用户、房间和社区。管理员只能看到举报人选择发送的内容，从看不到是谁举报的。
- **私密的位置记录：** 管理员打不开。

## 管理员能做什么 {#what-admins-can-do}

| 操作 | 效果 |
|---|---|
| 移除被举报的消息 | 对聊天里的所有人移除。只有 AChat 管理员能恢复 |
| 限制房间 | 新的人无法通过链接打开或加入。已在里面的成员可以继续聊天 |
| 停用账号 | 在管理员解除前，此人无法登录或发送消息。聊天会保留，可以通过联系页面申请复核 |
| 授予套餐或额度 | 给某个账号设置套餐或自定义额度，带有自己的结束日期 |
| 将房间标记为可永久保留 | 让仅限已标记房间的永久保留授予涵盖这个房间 |
| 为某人设置永久保留 | 决定此人能否永久保留房间：**不允许**、**仅已标记的房间**、**任何房间** 或 **每个房间，自动**。除了“不允许”，其他选项都需要填写原因。更改它从不会缩短已经永久保留的房间 |
| 将社区标为成人内容 | 更改社区的 18+ 标记 |
| 应请求删除账号 | 针对无法登录的人，依据该账号 Google 邮箱发来的请求 |

管理员还会手动确认银行转账付款，并处理联系收件箱。

对于[银行卡支付](/features/plans-and-pricing#card)，管理员可以开启或关闭新的银行卡销售、把 Polar 产品对应到套餐和周期、设置套餐的年付价格，以及设置续费失败后套餐还保留多久。关闭银行卡销售不会结束大家已有的订阅。每项改动都记入操作日志。

## 管理员设置的限额

管理员在管理面板里设置 AChat 的各项限额，比如回收站保留多久、匿名房间消息保留多久。其中两项限定每台设备上的[搜索](/features/search-and-history)范围：**搜索的聊天数**，即搜索最多涵盖的聊天数（先置顶的，再按最近）；**搜索的消息数**，即每个聊天中最多涵盖的消息数，从最新开始。每个字段只接受允许范围内的整数。

## 群组和社区内部的管理

先由管理这个空间的人处理。群组管理员可以移除成员、删除任何消息；社区管理员处理举报和封禁。参见[群组与社区](/features/groups-and-communities)。

## 操作日志

每一次管理员改动都会显示是谁、在什么时候做的。永久保留的改动会显示改动前后的设置。任何人都不能编辑或删除记录。聊天的设备和位置记录不在这个日志里。

## 复核

如果你认为某次停用或封禁有误，请通过[联系页面](https://achat.aoneahsan.com/zh-Hans/contact)请 AChat 团队复核。最终决定由团队作出，申请复核并不保证任何结果。
