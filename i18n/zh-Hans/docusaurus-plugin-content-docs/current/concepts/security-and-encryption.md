# 安全与加密模型

**AChat 承诺对私人聊天、私密群组和设了密码的房间进行端到端加密。对社区及其频道、开放房间和动态，不做这个承诺。**

## 这里的端到端加密指什么

- 这些聊天里的消息只能在聊天成员的设备上读到。
- AChat 以服务器和管理员都读不了的形式保存它们。
- AChat 不保存你的消息密钥副本，所以既读不了，也恢复不了你的记录。
- 推送通知只带聊天名或发送者名，从不带消息内容。
- 搜索只查看已经在你设备上的消息。
- 其他应用也读不了。访问密钥、AI 助手或 Webhook 只能看到加密聊天的名称和成员，从看不到消息。参见[面向开发者的 AChat](/developers#what-other-apps-can-reach)。

## 密钥、设备和恢复

- **关联设备** 各自保存你的密钥。批准一台设备，它就能读你的聊天（包括历史记录），并以你的身份发消息。关联时请比对安全码。
- **移除设备** 会让新消息不再发到它那里，并让它退出登录。它已经存下的内容仍留在上面。
- **群组成员变化时会换新密钥**，所以离开的人读不到新消息。
- **恢复密钥** 由你自己保管。只靠 Google 登录恢复不了记录。如果恢复密钥和所有关联设备都丢了，谁也恢复不了。

## 房间密码

设了密码的房间会在你的设备上用这个密码加密消息。连续输错太多次，需要等一会儿才能再试。你设置的密码会在你的设备上检查强度并给出建议。

## 私密的位置记录

在私人聊天、私密群组或设了密码的房间里，[设备与位置记录](/features/location-history)是端到端加密的。只有输入了该聊天审计密码（或房间密码）的成员才能看到，AChat 的管理员打不开。

## 加密做不到的事

- **读到消息的人都能复制它。** 聊天里的人可以复制、保存或截图任何内容，包括打开时的阅后即焚和仅看一次的消息。之后删除影响不到这些副本。
- **开放的聊天就是开放的。** 有开放房间链接的人都能读。社区及其频道不是端到端加密的。
- **匿名不等于无法追踪。** 你的设备像访问任何网站一样连接 AChat 的服务器，托管方会记录 IP 地址等连接信息。
- **丢失且未锁定的设备是个风险。** 拿到它的人能打开上面存的东西。[本设备上的隐私](/features/privacy-on-this-device)介绍了隐私屏和“从此设备清除”。
- **已经被看到的内容收不回来。** 之后改设置或政策，都收不回已经被读过、复制、保存或导出的内容。

## 管理与加密

只有当加密聊天里有人举报一条消息并随举报一起发送时，AChat 的版主才会看到它。参见[管理员监督](/concepts/admin-oversight)。
