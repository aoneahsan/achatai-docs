# AChat 是怎么运作的

**在 AChat 里，你可以用两种方式加入聊天：一个账号（Google 登录加用户名），或者在匿名房间里，用一个不需要账号的显示名。** 两者从不关联：即使你也有账号，AChat 也不会把你的匿名消息和它联系起来。

## 聊天类型

| 聊天 | 谁在里面 | 需要账号 | 端到端加密 |
|---|---|---|---|
| 私人聊天 | 你和一位联系人 | 是 | 是 |
| 私密群组 | 你邀请的联系人，或管理员批准的人 | 是 | 是 |
| 匿名房间 | 有链接（设了密码的还要有密码）的任何人 | 否 | 仅在设了密码时 |
| 社区频道 | 社区成员 | 取决于社区 | 否 |
| 动态 | 你接受的联系人 | 是 | 否 |

## 消息存放在哪里

- **在 AChat 的服务器上：** 每个聊天的消息，这样每台设备都能取到。端到端加密的消息以服务器和 AChat 管理员都读不了的形式保存。
- **在你的设备上：** 你打开过的聊天和文件，这样加载快、离线也能打开，还有等待发送的消息发件箱。搜索就在这里进行，范围是设备上已有的内容。
- **你的密钥：** 在你关联的设备上，并可以用恢复密钥找回。AChat 不保存副本。

## 内容保留多久

| 内容 | 保留多久 |
|---|---|
| 私人聊天和群组 | 直到有人删除，除非这个聊天设置了阅后即焚（1 分钟、1 小时或 1 天） |
| 匿名房间消息 | 每条从发送起保留设定的天数（默认 10 天），或者有人保留了房间的话，保留到那个日期 |
| 回收站 | 设定的天数（默认 30 天），绝不超过聊天本身的记录时长 |
| 动态 | 24 小时 |
| 位置记录 | 直到聊天从回收站被永久删除或到期 |

[隐私页面](https://achat.aoneahsan.com/zh-Hans/privacy)列出了其他所有内容，[数据、隐私与删除](/concepts/data-privacy-and-deletion)做了概括。

## 发送一条消息

1. 你写下它。它先进入发件箱，所以断网或刷新页面都不会丢。
2. AChat 发送它，并一直重试直到被接收，不会发两次。
3. 消息下方的标签从 **正在发送**（离线时是 **等待发送**）变成 **已发送**，表示已经送达。

## 平台

同一个 AChat 运行在浏览器和 Android 上，支持十一种语言。不支持语音或视频通话。
