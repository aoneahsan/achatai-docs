# 页面导览和“AChat 如何运作”

**不离开 AChat 就能学会它的两种方式：当前页面的简短导览，以及介绍整个应用的六步页面。**

## 页面导览

**浏览这个页面** 是标题栏里的路标按钮，就在 外观 前面。它出现在 聊天、功能、套餐与价格、社区和账户 页面上。在手机上它位于同一条顶栏里；在 账户 和 社区 页面上，它在页面标题的末尾。

第一次打开这些页面时，会有一条简短的提示指向这个按钮：*刚来？快速浏览一下这个页面。* 每个页面只显示一次，而且这一次会记在你的账户上，所以第二台设备不会再显示。几秒后它会自动消失。

导览每次突出页面的一个部分，并说明它是做什么的。

| 控件 | 作用 |
|---|---|
| **下一步**、**上一步** | 前进或后退一步；方向键也一样 |
| **所有步骤** | 列出每一步，可以跳到任意一步 |
| **跳过导览**、关闭按钮、Esc | 立即结束导览 |

在手机上，每一步以从屏幕底部弹出的面板显示；如果突出的部分靠下，则从顶部弹出。以 `?tour=3` 结尾的导览链接会打开第 3 步。

## AChat 如何运作

[AChat 如何运作](https://achat.aoneahsan.com/zh-Hans/how-achat-works) 共六步，每一步都配有发生那件事的界面：和你认识的人聊天、无需账号的房间、群组和社区、动态、断网时会怎样，以及套餐。用 **下一步** 和 **上一步**、方向键，或在手机上滑动来切换；`?step=3` 会打开第 3 步。

你可以从公开页面底部的 **帮助** 栏、网站地图、**账户** 页面顶部，以及登录前的 聊天 界面打开它。
