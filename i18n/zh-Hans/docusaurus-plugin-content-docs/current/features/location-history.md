# 设备和位置记录

**一个聊天可以开启设备和位置记录。在你进入之前，它会说明记录什么、谁能看到。你拒绝的话，这个聊天就保持关闭。** 你的其他聊天不受影响。

## 记录什么

聊天会在你进入时、打开期间每 5 分钟、以及你每次回来时记录一次。每条记录包含：

- 你的精确位置，以及设备给出的精度
- 日期和时间
- 只在这个聊天里使用的设备 ID
- 你的浏览器和操作系统，以及你的语言和时区

记录从不显示你的 IP 地址，也不显示能把你在不同聊天间关联起来的 ID。位置由你的设备上报，所以实际位置可能偏差更大。

## 谁能看到

| 聊天 | 谁能看到记录 |
|---|---|
| 公开聊天 | 现在或以后能打开这个聊天的任何人。他们可以复制看到的内容 |
| 私人聊天或私密群组 | 只有输入了聊天 **审计密码** 的成员。记录是端到端加密的；AChat 的管理员打不开 |
| 带密码的房间 | 只有输入了房间密码的成员，同样端到端加密 |

如果聊天里的每个人都忘了审计密码，这个聊天的私密位置记录就永久丢失了。

## 保留多久

只要聊天还在就一直保留。只有当聊天从回收站被永久删除或过期时，记录才会结束。关闭记录会停止新的记录，但不会删除以前的。

## 年龄

这类聊天面向声明自己达到最低年龄的人，聊天会在你进入前显示这个年龄。AChat 不核实这份声明。

## 限制

- 开启了位置记录的聊天需要联网才能打开。
- 它不能在其他网站的[小组件](/features/embeddable-widget)里打开；请在 AChat 里打开。
- 如果浏览器暂停了这个标签页，记录也会暂停，你回来时聊天会请求一条新记录。
- 离开聊天会停止新的记录。你以前的记录会保留。
- 开启记录会让聊天对所有人（包括你）关闭，直到每个人同意并分享自己的位置。
