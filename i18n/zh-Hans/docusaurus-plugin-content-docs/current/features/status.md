# 动态

**动态是给你接受的联系人看的更新，24 小时后消失。** 发动态需要账号。

## 谁能看到

默认是你接受的联系人。发布前，你可以只分享给其中一部分人，或排除特定的人。无论怎么选，只有你接受为联系人的人才能看到。

## 查看、回复和删除

- 你能看到谁看过你的动态。
- 对动态的回复会出现在你和那个人的私人聊天里。
- 删除动态会立即对所有人移除。已经看过的人已经看到了。

## 限制

动态不是端到端加密的，所以 AChat 的服务器能读取。访问规则会把每条动态的其他可见者限制在你选的范围内。
