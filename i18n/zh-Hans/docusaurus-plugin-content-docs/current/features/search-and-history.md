# 搜索与离线历史

**搜索在你的设备上进行，范围是设备上保存的消息，所以你的搜索词也只留在设备上。**

## 搜索

- 打开 **搜索** 在所有聊天中查找。结果按聊天分组。
- 它覆盖这台设备上已有的消息。回收站、已归档的聊天、你已离开的群组，以及暂时关闭的聊天都不在搜索范围内。
- 搜索最多覆盖一定数量的聊天，先是置顶的，再是最近的，每个聊天里覆盖一定数量的最新消息。这两个数字由 AChat 的管理员设定，搜索页面会告诉你它覆盖了多少个聊天。
- **Ctrl+K**（或 **⌘K**）可以找到一个聊天或页面。

## 离线

- 打开过的聊天和文件会保存在设备上，加载更快，离线也能打开。
- 离线时写的消息会在 **发件箱** 里显示 **等待发送**，连接恢复后按顺序发出。消息只有送达后才会显示 **已发送**。
- 如果有些消息发不出去，你可以重试，或丢弃不再需要的。
- 开启了设备和位置记录的聊天需要联网才能打开。

## 保存在这台设备上的

**账户** 里的 **存储** 会显示设备上保存了什么。**清除保存的副本** 会删除保存的聊天和文件；联网后打开时会重新下载，发件箱不受影响。

退出登录会从设备上删除你的聊天，以及仍在等待发送的消息。见[设备与恢复密钥](/features/devices-and-recovery)。
