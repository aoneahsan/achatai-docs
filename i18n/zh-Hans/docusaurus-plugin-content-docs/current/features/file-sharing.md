# 文件、语音消息和媒体

**在套餐额度内分享任意类型的文件，录一条语音消息，或把图片直接粘贴进输入框。**

## 额度

有两项限制来自你的[套餐](/features/plans-and-pricing)：

- **文件大小：** 每个文件最大能多大。
- **每个聊天的文件：** 每个聊天能存多少文件。

AChat 会在你添加附件前显示这两项，**账户** 里的 **存储** 也会显示。聊天达到上限后，新文件会被拒绝；消息照常收发。

## 语音消息

在输入框里录一条语音消息，最长不超过 AChat 显示的时长。向上滑动可以锁定录音，解放双手。达到上限时录音会停止，让你发送前先听一遍。

## 照片、视频和粘贴的图片

- 把图片粘贴或拖进输入框即可添加附件，可以加说明。
- 视频在聊天里直接播放。
- **聊天信息** 里的 **媒体** 汇集了聊天中分享过的照片、视频和文件。被隐藏和清空的消息里的文件也会从这里移除。

## 上传

上传会显示真实进度，也可以取消。页面重新加载后上传会继续，取消的上传会被移除。

## 加密

私人聊天和私密群组里的文件随聊天一起端到端加密。其他类型的聊天见[密码与加密](/features/passwords-and-encryption)。
