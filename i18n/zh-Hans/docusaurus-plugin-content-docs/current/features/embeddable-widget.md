# 可嵌入的小组件

**选择一个房间或频道，选好外观，然后把代码复制到你的页面里。** 在[小组件页面](https://achat.aoneahsan.com/zh-Hans/widget)上制作，复制前会用演示消息显示预览。

## 能嵌入什么

| 对象 | 条件 |
|---|---|
| 匿名房间 | 任意房间 ID：8 到 20 个小写字母、数字和连字符。第一次有人打开小组件时会创建新房间 |
| 社区频道 | 只限标为 **允许匿名** 的社区里使用显示名称的频道 |

私密群组和需要账号的频道不能显示在其他网站上。

## 布局和选项

- **嵌在页面中：** 在你粘贴代码的位置，以固定尺寸显示聊天。
- **聊天按钮：** 角落里的一个按钮，点开后在面板里打开聊天。
- **紧凑**、**隐藏聊天标题栏** 和 **提供登录**（访客可以登录来保留房间；聊天本身从不需要登录，登录会在新标签页打开）。

## 允许的网站

最多列出 20 个允许显示这个聊天的网站。在你添加之前，任何网站都能显示它。

- 对房间来说，只有保留它的人能修改列表。在有人保留之前，谁都不能限制一个房间。
- 对频道来说，只有社区的管理员可以。

不在列表上的网站会显示一条提示和一个链接，让人改在 AChat 里打开聊天。

## 访客需要知道的

- 任何访问带小组件页面的人都能读这个房间、在里面发言，除非房间有密码。消息遵循房间自己的历史保留规则。
- 登录、麦克风和位置在别的网站里不可用。记录位置的聊天只能在 AChat 里打开。
- 网站的浏览器设置可能让 AChat 记不住访客，所以他们下次可能需要重新选一个显示名称。
