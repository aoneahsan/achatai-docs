# 写消息

**输入框会保存你的草稿，排版剧透和数学公式，还能听写。翻译和朗读在你的设备上进行。**

## 草稿

没发出的草稿会留在对应的聊天里，并显示在聊天列表中。丢弃草稿可以撤销。

## 格式

| 输入 | 得到 |
|---|---|
| `\|\|text\|\|` | 剧透，点一下才显示 |
| `$formula$` | 句子里的数学公式 |
| `$$formula$$` | 单独一行的数学公式 |
| `@username` 或 `@all` | 提及。提到你的消息会有轮廓，**提到你的消息** 里会列出它们 |

画不出来的公式会按输入原样显示。

## 格式工具栏

输入框上方有：**粗体**、**斜体**、**删除线**、**代码**、**链接**、**代码块**、**项目符号列表**、**编号列表** 和 **引用**。宽屏上工具栏一开始就显示；手机上用 **格式**（Aa）显示或隐藏。没有格式的消息会以纯文本发送。粘贴的文字只保留这几种格式。用旧版 AChat 编辑器写的消息也会显示原有格式。

常见语言的代码块在显示时会高亮。话题回复框的工具和聊天输入框一样。

## 输入时的建议

输入 `@` 和名字开头，可以从聊天里选一个人，或选 `@all`。在空输入框开头输入 `/` 可以使用命令：`/shrug` 加上 ¯\\_(ツ)_/¯，`/clear` 清空草稿，`/export` 打开 **保存副本**。其他以 `/` 开头的内容会按原样发送。

## 全屏和长消息

**全屏书写** 让输入框占满整个窗口；按 Esc 返回。长消息几行后会折叠，带有 **显示更多**。

## 链接

消息里的网址是一个会在新标签页打开的链接。**显示链接预览**（账户 › 偏好设置 › 这台设备）会加上一张带页面标题和图片的卡片。它默认关闭。开启后，由 AChat 自己的服务器读取页面并转发图片，所以被链接的网站永远看不到你的设备；在端到端加密的聊天里，这意味着链接会离开你的设备。

## 贴纸和表情

AChat 自带七款贴纸，所以不用下载任何东西。你的版本不认识的贴纸会显示为不可用。

## 听写

**听写** 通过浏览器的语音服务，把语音变成输入框里的文字。有些浏览器会把你的声音发给它们的服务商去转成文字，AChat 会在开始听之前告诉你。不能听写的地方，你可以打字或录一条语音消息。

## 翻译

在你的设备上 **翻译** 一条消息。某些语言需要浏览器先下载一个语言包，它会留在设备上。不能翻译的地方，消息不会被发送到任何地方。

## 朗读 {#read-aloud}

**朗读** 用你设备上的声音播放一条消息。没有设备内置声音的浏览器不提供这个功能。即使在静音的聊天里也会播放。

## 未读消息

一条分隔线标出新消息从哪里开始，还有一个按钮可以跳过去。
