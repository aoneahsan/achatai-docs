# 群组与社区

**群组是给已经彼此认识的人用的。社区有频道和话题，每个社区都会说明你需要账号还是可以匿名加入。**

## 群组

群组把你联系人里的人拉进一个端到端加密的聊天，所以群组需要账号。

- 在 **群组** 里 **创建** 群组，然后邀请联系人或分享邀请链接。
- **通过链接加入：** 通过链接申请加入的人需要管理员批准。重置链接会让旧链接失效。
- **新成员** 能看到加入之后发送的消息。之前的消息不会自动共享。
- **离开或被移出** 后就收不到新消息。已经在那个人设备上的消息会留在那里。见[你已离开的群组](#groups-youve-left)。

| 角色 | 能做 |
|---|---|
| 所有者 | 管理员能做的一切，并选择管理员。可以让别人成为所有者 |
| 管理员 | 批准申请、移除成员、删除任何消息、为所有人清空消息 |
| 成员 | 聊天、回复、回应、离开 |

管理员删除的消息会进入群组的回收站，只有管理员能恢复。

### 你已离开的群组 {#groups-youve-left}

你离开或被移出的群组，会留在打开过它的设备的聊天列表里。打开它可以读到那台设备上已有的消息，顶部有横幅说明你已离开或被移出。它是只读的：没有输入框，消息也没有回复、回应或其他操作。新消息不会到达，这些群组也不在[搜索](/features/search-and-history)范围内。

## 社区

浏览 **社区** 目录，或打开某个社区的链接。

- **访问方式：** 每个社区要么是 **需要账号**，要么是 **允许匿名**。匿名加入会使用显示名称；这并不保证没人能认出你。
- **频道：** 社区里有频道，频道里有话题。私密频道只有被加入的人能读。
- **社区链接 ID：** 8 到 20 个小写字母、数字和连字符，由创建者选定。
- **成人：** 用于成人话题的 18+ 标记，绝不是露骨内容。成人社区只对声明自己年满 18 岁的人显示，而且始终需要账号。AChat 不核实这份声明，AChat 管理员可以修改这个标记。

社区及其频道不是端到端加密的。

## 管理

- 管理员创建频道、管理私密频道，并处理举报和封禁。只有所有者能选择管理员。
- **举报：** 你选中的消息会发给社区的管理员和 AChat 的审核员。你选择一个理由：垃圾信息、骚扰或霸凌、色情内容、威胁或暴力，或其他。审核队列从不显示是谁举报的。
- **封禁：** 被封禁的人在管理员解除封禁前，不能阅读或发表该社区任何频道的内容。他们之前的消息会保留，除非管理员删除。如果你认为封禁有误，可以通过联系页面请 AChat 团队复查。
- 管理员或审核员删除的消息会进入该空间的回收站，只有它的管理员能恢复。

社区会保留举报、封禁和删除的管理记录。

## 等待加入加密群组

群组是端到端加密的，所以每个新成员都要由所有者或管理员的设备添加。你接受邀请后，群组会以 **等待中** 显示在 **群组** 里，直到那台设备上线，AChat 会在你加入后告诉你。只要所有者或管理员的设备上打开着 AChat，它就会添加等待的人。
