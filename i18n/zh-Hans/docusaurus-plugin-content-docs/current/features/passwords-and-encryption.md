# 密码与加密

**私人聊天、私密群组及其中的文件都是端到端加密的，所以每条消息只能在聊天成员的设备上读取。** 带密码的房间会用这个密码在你的设备上加密消息。

## 哪些是加密的

| 聊天 | 端到端加密？ |
|---|---|
| 私人聊天 | 是，连同文件 |
| 私密群组 | 是，连同文件 |
| 带密码的匿名房间 | 是，用房间密码加密 |
| 开放的匿名房间 | 否。任何有链接的人都能读 |
| 社区及其频道 | 否 |
| 动态 | 否。AChat 的服务器能读取；访问规则限制其他还有谁能看到每条动态 |

AChat 以服务器和管理员都无法读取的形式存储端到端加密的消息。AChat 不保存你的消息密钥副本。

## 房间密码

- 每个人都需要密码才能加入和阅读房间。
- 把密码和链接分开发送。
- 连续输错太多次，需要等几分钟才能再试。
- 新密码会显示强度指示。它在你的设备上检查，密码不会被发送到任何地方去检查。

## 群组和成员变化

群组成员变化时，群组会换新的安全密钥，所以离开的人读不到新消息。加入的人能看到加入之后发送的消息；之前的消息不会自动共享。

## 检查已关联的设备

在 **账户** 的 **设备** 里，你可以比对两台设备之间的安全码。如果不一致，移除你不信任的那台。见[设备与恢复密钥](/features/devices-and-recovery)。

## 限制

- 聊天里的任何人都能复制、保存或截图消息。加密保护的是传输中和服务器上的消息，而不是别人读过之后的。
- 搜索只查看已经在你设备上的消息。
- 推送通知从不包含消息正文。
- 恢复密钥和所有已关联的设备都丢了，意味着你的历史无法恢复，你自己和 AChat 团队都做不到。

完整的模型见[安全与加密](/concepts/security-and-encryption)。
