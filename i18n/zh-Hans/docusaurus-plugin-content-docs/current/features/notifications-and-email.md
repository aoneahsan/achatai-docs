# 通知与邮件

**在你允许之前通知都是关闭的，而且从不包含消息本身。**

## 通知

- 在 **账户** 的 **偏好设置** 里用 **允许通知** 开启。只有你选择了这一项，AChat 才会向设备申请权限。
- 每条提醒只带聊天或发送者的名字，从不带消息正文。
- **静音通知** 让一个聊天安静下来。全部静音会停止声音和提醒；消息照常到达。
- 允许和收到是两回事：如果设备允许通知但还没收到，AChat 会告诉你，并让你再试一次。

## 邮件

AChat 只会就你的账户给你的 Google 邮箱发邮件：

| 邮件 | 何时 |
|---|---|
| 欢迎 | 你注册之后 |
| 关联了新设备 | 有设备关联到你的账户 |
| 恢复密钥已更换 | 你的恢复密钥被更换 |
| 保留房间提醒 | 保留房间的日期快到了 |
| 套餐邀请 | 有人邀请你加入 Team / Family 套餐 |
| 付款请求已收到、已确认或未确认 | 你为套餐付款之后 |
| 联系表单回执 | 你通过联系页面发消息之后 |
| 账户已删除 | 你的账户被删除之后 |

匿名房间不发送任何邮件。

## AChat 在另一个标签页时

有消息到达而 AChat 的标签页没有显示时，你会听到消息提示音（如果通知设置里的 **声音** 开着且这个聊天没有静音），标签页标题会计数新消息，直到你回来。聊天列表会立即更新。
