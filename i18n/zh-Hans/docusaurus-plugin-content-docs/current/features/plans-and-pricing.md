# 套餐与价格

**付费提高的是额度，而不是功能。** Free 没有截止日期，覆盖私人聊天、群组、社区和匿名房间。当前价格和额度见[价格页面](https://achat.aoneahsan.com/zh-Hans/pricing)。

## 套餐

| 套餐 | 适合 |
|---|---|
| **Free** | 和你常联系的人日常聊天。无需付款 |
| **Pro** | 一个人，更高的额度 |
| **Team / Family** | 给家庭或团队的共享席位。每位成员的聊天仍归自己所有 |

Pro 和 Team / Family 会提高四项额度：文件大小、每个聊天的文件、能保留多少个房间，以及能保留多久。每个套餐的额度由 AChat 团队设定。

套餐也决定其他应用能在多大程度上访问你的账户：访问密钥、每天的 API 请求、Webhook 地址和已连接的助手。见[你的套餐允许什么](/developers#what-your-plan-allows)。

## 付款

在网页上登录账户后付款。在价格页面选择套餐，然后选择付款方式：**银行转账**，或在可用时选择 **银行卡**。

### 银行转账

1. 通过银行转账付款，并附上结账页面付款信息里显示的编号。
2. 提交付款请求。AChat 团队会手动把每笔付款和编号对上，确认之前你的套餐会显示为等待中。

在价格页面或 **账户** 里 **取消**：你的套餐会一直有效到已付费周期结束，不会再要求续费付款。

### 银行卡 {#card}

银行卡付款由销售该套餐的 Polar（Polar Software, Inc.）收取。你在 Polar 运营的页面上输入卡号，AChat 永远不会收到你的卡号。

1. 选择 **付款周期**：**按月** 或 **按年**。没有年付价格的套餐按月付款。
2. 进入 Polar 的页面并在那里付款。根据你所在的国家，Polar 的页面上可能会加上税费。
3. 你会回到 AChat，Polar 确认付款后你的套餐就会变更。

银行卡付款是订阅：在你取消之前，每月或每年都会从你的卡上扣款。Polar 自己的[条款](https://polar.sh/legal/terms)也适用于银行卡付款。

### 你的订阅

用银行卡付费的套餐会显示在 **账户** 的 **你的订阅** 下，包括套餐、周期、席位以及续费或结束日期。

| 操作 | 作用 |
|---|---|
| **银行卡和收据** | 打开 Polar 的页面，在那里更换银行卡和查看收据 |
| **更改席位** | 更改 Team / Family 套餐的席位数。不能低于正在使用的席位 |
| **更换套餐** | 更换套餐或周期。Polar 会计算已付费周期剩余部分的差价，Polar 确认后变更生效 |
| **取消订阅** | 你保留套餐到已付费周期结束，之后不再续费 |
| **恢复订阅** | 在结束日期之前，让订阅在同一天重新续费 |

**如果续费付款没有成功**，付费周期结束后你还能保留套餐一小段时间，之后会转到你原本应有的套餐，直到付款成功。Polar 会继续尝试扣款，如果尝试次数用完，订阅就会结束。

**在 Android 应用里** 没有银行卡付款。用银行卡付费的套餐在那里只显示为你的套餐，设为不续费后会显示结束日期。银行卡订阅的其他一切都在网页上管理。

### 套餐结束时

- **付费套餐结束时**，你会回到 Free。什么都不会被删除，所有内容都还能读，你也能继续发消息。在回到 Free 的限额以内之前，超出限额的聊天里的新文件以及新的保留房间会被拒绝。
- 删除账户会立即结束付费套餐。如果你用银行卡付款，会先在 Polar 取消订阅，所以不会再扣款。如果无法确认这一点，账户就不会被删除。

## Team / Family

- 一个人作为 **付款人**，为最低数量的席位付款，并通过用户名邀请其他人。可以设为 Team 或 Family；两者的套餐和额度相同。
- 付款并不能让任何人读取其他成员的消息、聊天或位置。付款人只管理席位和续费，仅此而已。
- 用银行卡时，Team / Family 按席位付费：付款人选择席位数，从套餐的最低数开始。
- 你同一时间只能属于一个 Team / Family 群组。
- 付款人可以让另一位成员成为付款人，或者结束群组。每个人都保留套餐到付费周期结束，然后回到各自原来的套餐，什么都不会被删除。用银行卡付费的套餐则在 **你的订阅** 下管理。

## 推荐

分享你的邀请链接。有人通过它创建 AChat 账号并验证了邮箱后，你会得到积分和徽章。确认的推荐还会增加套餐月份，任意 12 个月内有上限；超过后积分和徽章仍会继续累计。只有新账号才算。如果你已经有该套餐或更高的套餐，赚到的月份会在当前套餐结束时开始。
