# 外观、语言和快捷键

**主题、颜色、文字大小和动效都在一个外观面板里，所以一处修改，处处生效。**

## 外观

打开外观面板可以修改主题、颜色、文字大小或动效。每个选择都会应用到所有页面。

## 语言

AChat 的界面有十一种语言：英语、中文、印地语、西班牙语、阿拉伯语、法语、葡萄牙语、俄语、日语、乌尔都语和德语。在外观面板的最后选择；每种语言都以它自己的名字显示。阿拉伯语和乌尔都语从右往左阅读，中文、印地语、日语和乌尔都语各有自己的字体。

## 键盘快捷键

在文本框以外的任何地方按 **?** 打开列表。大多数按键都能在那里修改。快捷键显示为 **Ctrl**，在 Apple 设备上显示为 **⌘**。下表列出每个快捷键的原始按键。

| 按键 | 操作 |
|---|---|
| Ctrl+K | 查找聊天或页面 |
| Enter | 发送 |
| Shift+Enter | 换行 |
| 在空输入框中按 ↑ | 编辑你的上一条消息 |
| Ctrl+Shift+S | 把选中的文字标为剧透 |
| Esc | 关闭菜单或对话框，取消回复或编辑 |
| Ctrl+Shift+F | 开关专注模式 |
| Ctrl+Shift+H | 立即遮住屏幕 |
| ↑ / ↓、Home / End | 在聊天列表中移动 |
| Alt+↑ / Alt+↓ | 上一个或下一个聊天 |
| Shift+F10 | 聊天操作 |

### 修改按键

在列表里，按快捷键旁边的 **更改**，然后按下新的按键。**Esc** 取消。**重置** 让一个快捷键恢复原始按键，**全部重置** 让所有快捷键恢复，并提供撤销。

- 一个按键组合只属于一个快捷键。如果按键已被占用，AChat 会说出是哪个快捷键占用了它，并链接过去。
- Esc、方向键、Home、End 和 Shift+F10 是标准按键。它们不能修改，因为菜单、对话框和列表依赖它们。
- 浏览器会保留一些组合给自己，比如 Ctrl+W，所以 AChat 无法使用它们。
- 登录时，你的按键设置会随账户同步到你登录的每台设备。未登录时，只保存在这个浏览器里。

## 专注模式

从聊天的菜单或用 Ctrl+Shift+F 打开 **专注模式**。按 **Esc** 退出。

## 无障碍

- 上面的快捷键覆盖聊天列表、聊天和输入框。
- 发出消息或恢复草稿等变化会告知屏幕阅读器。
- 文字大小和动效来自外观设置。
- [朗读](/features/writing-messages#read-aloud) 用设备上的声音播放一条消息。

## 侧边面板

聊天 页面上的每个侧边面板（房间、聊天信息、共享媒体、回收站、话题等）都会占聊天区域的 60% 宽度打开。拖动它的边缘，或聚焦边缘后用方向键调整；双击恢复到 60%。每个面板的宽度会保存在这台设备上，登录时也保存在你的账户里。

## 把外观存成文件

外观面板里的 **保存为文件** 会把每个外观选择存进一个小文件；**从文件加载** 会应用一个这样的文件。

## 按键

按键 1 到 6 用快捷回应来回应最新的消息。**聊天中使用 Vim 风格按键**（在快捷键对话框里）加入 j 和 k 来滚动，G 跳到最新消息，g g 跳到已加载的最早消息。每个快捷键都可以修改。
