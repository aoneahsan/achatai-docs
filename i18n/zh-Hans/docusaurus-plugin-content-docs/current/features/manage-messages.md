# 管理消息

**每个消息操作在你确认前都会说明它改变什么、对谁生效，而且大多数都能撤销。**

## 消息操作

| 操作 | 作用 |
|---|---|
| 回应 | 加上一个表情回应 |
| 回复 / 话题 | 引用一条消息，或在它上面开启[话题](/features/threads-and-replies) |
| 编辑 | 修改你自己的消息，加密聊天里也可以 |
| 转发 | 把副本发到另一个聊天。在加密聊天里，会为目标聊天重新加密 |
| 置顶 | 把一条消息置顶到聊天顶部 |
| 复制链接 | 指向那一条消息的链接，只对聊天里的人打开 |

## 删除和回收站

- **仅为我删除** 只为你删掉一条消息。
- **为所有人删除** 适用于你自己的消息，会把消息移到这个聊天的 **回收站**。
- 聊天里的任何人都能从回收站恢复消息，或永久删除它。
- 回收站会保留一定天数（默认 30 天），然后永久删除。不会超过聊天自己的历史期限，也不会超过消息自己的消失计时。

在端到端加密的聊天里，为所有人删除的消息也会在每台设备下次加载这个聊天时，从设备为离线阅读和搜索保存的副本中移除。它仍可以从回收站恢复。一旦被永久删除，保存的副本也会消失，关联设备或恢复历史时也不会回来。

被删除的聊天也会在回收站里等着，你可以把它找回来。

## 清空消息

- **仅为我清空** 只对你隐藏聊天里的所有消息。其他人都还保留着，新消息也照常到达。清空后立刻会出现 **撤销**，能把消息找回来。它只能用一次，而且有时间限制；不可用时什么都不变，这个聊天对你仍是清空状态。
- **为所有人清空** 把所有消息作为一个批次移到聊天的回收站，名为“已清空的消息”，聊天里的任何人都能用 **全部恢复** 恢复。在群组里，只有所有者和管理员能这么做。

别人已经保存、转发或截图的副本会留在他们那里。

## 阅后消失 {#disappearing-messages}

按聊天设置：**关闭**、**1 分钟**、**1 小时** 或 **1 天**。它适用于聊天里所有人的新消息；已经发出的消息保持自己的计时。有人修改时，聊天里会出现一行说明，每条消息都会显示倒计时。

在消息消失之前，聊天里的任何人仍然可以复制、保存或截图。

## 阅后即焚

为你的下一条消息开启 **阅后即焚**。它在打开前一直被遮住，打开后显示几秒并倒计时，然后从那台设备上消失。你能看到它是否被打开过。打开期间它仍然可能被复制或截图。如果因为连接问题没打开，它不会被用掉：遮罩还在，你可以在短时间内再试。

## 投票

发起投票，大家在聊天里投票。投票显示每个选项有多少人选，而不是谁选的，每人只能选一个。发起人可以结束投票：之后谁都不能再投，结果保留，领先的选项会被标出。结束的投票可以重新打开。

## 归档和私密归档 {#archive-and-private-archive}

- **归档** 把聊天从你的列表里隐藏，但不删除。其他人那边什么都不变。
- 在菜单里 **归档一条消息或回复**。你自己的消息会对所有人隐藏，直到你取消归档；别人的只对你隐藏。归档主消息会带着它的话题一起归档。如果别人回复了你的消息，他们的回复会留在“消息已归档”下面，在你取消归档之前话题不接受新回复。
- **选择** 多条消息、回复或聊天（从菜单，或在手机上长按），然后一起归档或取消归档。在你按下“归档”之前，操作栏会说明谁将看不到它们。
- 每一层都有自己的视图：列表里的 **已归档的聊天**，从聊天菜单或聊天信息打开的 **已归档的消息**，以及从话题打开的 **已归档的回复**。那里的内容不会自己过期，只有你能取消你归档的内容。设了消失计时的消息到时间仍会离开。
- **私密归档**（匿名房间，需要账号）：从此只有你的账户能打开这个房间，即使有链接或密码也不行，房间会变成只读。你不能对别人保留的房间这样做。

## 保存副本

把聊天保存为网页（.html）或 Markdown（.md）。文件包含你现在在那台设备上能读到的消息，拿到文件的任何人都能读。

## 给消息加星标

**加星标** 只在这台设备上标记一条消息；不会发送任何东西。加了星标的消息会显示一颗星，**搜索这个聊天** 可以只显示加了星标的消息。

## 举报消息

**举报** 会把别人的消息连同理由一起发给 AChat 的审核员。作者不会被告知是谁举报的。在端到端加密的聊天里，AChat 的服务器读不了消息，所以你设备上显示的文字会随举报一起发送，对话框会事先说明。

## 搜索这个聊天

**搜索这个聊天**（Ctrl 或 ⌘ + F，或聊天的“更多”菜单）在这台设备已加载的消息里查找文字，包括端到端加密的消息，因为搜索在你的设备上进行。**搜索更早的消息** 会加载更多。什么都不会被发送出去。

## 从聊天保存副本

**保存副本**（Ctrl 或 ⌘ + E，或聊天的“更多”菜单）把聊天保存为你设备上的一个文件。
