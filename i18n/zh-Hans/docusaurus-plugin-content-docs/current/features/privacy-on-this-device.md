# 这台设备上的隐私

**这些设置只作用于这台设备，无论是否登录。它们不会改变和你聊天的人那边的任何东西。**

## 设置

| 设置 | 作用 | 限制 |
|---|---|---|
| **隐私屏幕** | 你切换到其他标签页或应用时，以及 90 秒没有操作后，把 AChat 模糊处理 | 按任意键或轻点一下即可重新显示聊天 |
| **中性标签页标题** | 你在其他标签页时，这个标签页叫“新标签页”，显示一个普通图标 | 浏览器历史仍会显示 AChat |
| **清除复制的链接和密钥** | 复制邀请链接、房间链接或恢复密钥 45 秒后，会从剪贴板中清除 | 有些键盘和系统会保留自己的剪贴板历史，这里管不到 |

你也可以用键盘快捷键立即遮住屏幕。

## 从这台设备清除

在聊天的菜单里，**从这台设备清除** 会把这个聊天在这台设备上保存的内容删除，然后关闭它：

- 你还没发送的草稿
- 保存在这台设备上的房间密码
- 你为它的位置记录做的密码校验
- 在这台设备上显示过的翻译
- 它在这台设备搜索里的条目

它不会为任何人删除这个聊天或其中的消息。其他设备和其他人的副本都还在，再次打开聊天会重新加载消息。

AChat 收集什么、谁会收到，见[数据、隐私与删除](/concepts/data-privacy-and-deletion)。
