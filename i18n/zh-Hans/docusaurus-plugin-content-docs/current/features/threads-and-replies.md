# 话题与回复

**在话题里回复，计划就不会在大家继续聊天时被淹没。**

## 回复还是话题

- **回复** 在主对话里引用一条消息。
- **话题** 针对一条消息开启旁支对话，显示在聊天旁边的面板里。**在聊天中显示** 会跳回它开始的那条消息。

话题可用于聊天、房间和社区频道。

## 在话题里删除

- 单独删除一条回复，它会进入聊天的回收站。
- 删除话题开始的那条消息，它会连同所有回复一起进入回收站。聊天里的任何人都能从回收站恢复它们。

回收站的说明见[管理消息](/features/manage-messages)。
