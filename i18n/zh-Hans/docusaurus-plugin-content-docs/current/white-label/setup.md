# 设置你的副本

**付款后，由 AChat 团队完成设置，并就每一部分写信给你。** 你这边什么都不用安装。

1. **授权邮件。** 你的授权密钥和证书会发到你购买时用的邮箱。两者都要保存：续期时需要密钥。
2. **你的域名。** 告诉 AChat 团队你的副本要运行在哪个地址，比如 `chat.yourname.com`。域名仍归你所有，所以如果连接它需要你那边添加 DNS 记录，团队会把要添加的那条记录发给你。
3. **你的名称、标志和配色。** 发过来，它们就会用到每个界面上。
4. **上线。** 你的副本在你的域名上运行后，会提供它的授权文件，任何人都能[查验](/white-label/verify-a-licence)。

你通过银行转账付款到 AChat 团队的 Wise 账户，并在付款页面上提交转账编号。授权在 AChat 团队确认转账后签发，绝不会从你返回的那个页面签发。
