# 验证许可

**任何人都可以检查一个以其他名称运行的 AChat 副本。** 打开[验证许可](https://achat.aoneahsan.com/zh-Hans/verify-license)，输入这个副本的许可密钥或域名。验证由我们的许可服务完成。

## 按域名

每个获得许可的副本都会在自己的域名下、`/.well-known/` 里提供一个许可文件。按域名检查会读取这个文件，并检查其中写的密钥。

| 结果 | 含义 |
|---|---|
| 许可有效 | 文件写明了这个域名的许可，而且有效 |
| 其他域名 | 文件写的是签发给另一个域名的许可 |
| 不是有效许可 | 文件写的许可并不存在 |
| 没有许可文件 | 这个域名没有提供许可文件 |
| 没有响应 | 无法访问这个域名 |

## 按密钥

按密钥检查会告诉你许可是有效、仍在设置中，还是已被吊销，并显示它的公开信息：许可给了谁、它的域名、平台和日期。它从不显示邮箱或价格。

## 许可未生效的副本

它会显示“这个许可未生效”而不是应用本身，并附上指向这个检查的链接。里面的任何内容都不会被删除。
