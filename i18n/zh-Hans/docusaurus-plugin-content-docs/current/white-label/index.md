# 白标与授权

**AChat 可以以另一个组织的名义运行。** 有了白标许可，AChat 团队托管 AChat，把它部署在你的域名上，并放上你的名称、标志和配色。你把它提供给自己的人使用。如果你更想拥有代码，也可以直接买断 AChat：买断价格，加上 AChat 只要有收入就按其总收入的 7% 支付的分成。

当前价格在[许可价格页面](https://achat.aoneahsan.com/zh-Hans/white-label/pricing)和[买断页面](https://achat.aoneahsan.com/zh-Hans/white-label/buyout)上。这里不再重复，这样价格只在一个地方说明。

## 两条路径

| | 白标许可 | 源代码买断 |
|---|---|---|
| 谁来运行 | AChat 团队托管并部署 | 你自己，用源代码 |
| 源代码 | 不包含 | 构建网页和 Android 应用的所有代码仓库 |
| 独占 | 否：其他人也能获得 AChat 授权 | 是：AChat 团队停止出售 |
| 更新 | 包含六个月，之后续期 | 包含六个月，之后续期 |
| 购买之后 | 想要更多更新就续期 | 按 AChat 总收入的 7% 支付分成，每季度支付 |

## 使用你这份副本的人能得到什么

你的副本就是运行在 achat.aoneahsan.com 上的同一个 AChat，只是挂上你的名字。第一天就有：

- **私人聊天和私密群组**，端到端加密，支持关联设备，并有能找回历史的恢复密钥。
- **匿名房间**，不需要账号，可选的密码同时会加密房间。消息在设定的天数后删除，默认 10 天。
- **社区**，有频道、话题、举报、封禁和管理记录。
- **状态**，给联系人看的更新，24 小时后消失。
- **十一种界面语言**，阿拉伯语和乌尔都语从右往左显示。

限制也一样：没有语音或视频通话；社区、开放房间和状态不是端到端加密的。
