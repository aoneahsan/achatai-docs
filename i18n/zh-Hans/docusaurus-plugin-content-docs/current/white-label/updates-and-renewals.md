# 更新与续期

**每份授权和买断都包含从付款当天起六个月的 AChat 更新。** 更新是指 AChat 团队对 AChat 本身做的修复或改进，并同步到你的副本。只为你做的改动属于定制工作。

## 续期

续期可增加三、六或十二个月。它从你当前的结束日期开始；如果那个日期已经过去，就从今天开始。请在[更新页面](https://achat.aoneahsan.com/zh-Hans/white-label/updates)用你的授权密钥和授权签发到的邮箱续期；价格就列在那里。

## 不续期的话

你的副本会继续运行在它收到的最后一个版本上。什么都不会被关掉。
