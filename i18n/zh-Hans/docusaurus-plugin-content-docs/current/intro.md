# 简介

**AChat 是一款和你选择的人保持联系的消息应用：私人聊天、群组、社区，还有不想用账号时的匿名房间。** 它可以在浏览器里打开 [achat.aoneahsan.com](https://achat.aoneahsan.com)，也有 [Android](https://play.google.com/store/apps/details?id=com.aoneahsan.achat) 版，支持十一种语言：英语、中文、印地语、西班牙语、阿拉伯语、法语、葡萄牙语、俄语、日语、乌尔都语和德语。

不需要交出手机号。你用 Google 登录，选一个用户名，朋友通过这个用户名、邀请链接或二维码找到你。匿名房间完全不需要账号。

## 它不承诺什么

- **匿名不等于无法追踪。** 匿名房间不需要账号，但你的设备仍会连接 AChat 的服务器，和访问任何网站一样。
- **不是所有内容都端到端加密。** AChat 承诺对私人聊天、私密群组和设了密码的房间进行端到端加密。对社区及其频道、开放房间和动态，不做这个承诺。参见[安全与加密](/concepts/security-and-encryption)。
- **不能打电话。** AChat 只用来发消息，不支持语音或视频通话。
- **有些聊天会记录位置。** 聊天可以开启设备和位置记录，并在你进入前告诉你它记录什么。参见[设备与位置记录](/features/location-history)。
- **已经被看到的内容收不回来。** 聊天里的任何人都可以复制、保存或截图一条消息，之后删除也影响不到这些副本。
