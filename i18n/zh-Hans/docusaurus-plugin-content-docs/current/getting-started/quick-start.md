# 快速开始

**挑一个你本来就在聊的人，发一句你好。第一步就这么简单。** AChat 打开就是聊天页，每段对话都从那里开始。

## 和认识的人聊天

1. 打开 [achat.aoneahsan.com](https://achat.aoneahsan.com/zh-Hans)，选择 **使用账户**，然后 **使用 Google 继续**。
2. 选一个用户名。朋友就是靠它找到你。
3. AChat 显示 **恢复密钥** 时把它保存好。如果所有设备都丢了，这是找回记录的唯一办法，而且 AChat 只显示一次。参见[设备与恢复密钥](/features/devices-and-recovery)。
4. 打开 **联系人**，通过用户名、邀请链接或二维码添加某人。
5. 对方接受后，打开聊天发一条消息。

消息下方的标签先显示 **正在发送**，送达后显示 **已发送**。

## 不用账号聊天

1. 选择 **匿名继续**，然后 **创建房间**，或者用别人发给你的链接或 ID **加入房间**。
2. 选一个 1–24 个字符的显示名。房间里的其他人只看得到这个，而且房间从不显示你是否在线或最后在线时间。
3. 分享房间链接。拿到链接的人都能加入，除非房间设了密码。

房间里的每条消息从发送起保留设定的天数，默认 10 天。有账号的人可以把[房间保留](/features/keep-chats-and-accounts)更久。

## 断网的时候

打开过的聊天仍然可读，新消息会显示 **等待发送**，直到你重新联网。
