# 安装与访问

**在较新的浏览器里打开 [achat.aoneahsan.com](https://achat.aoneahsan.com/zh-Hans)，或从 [Google Play](https://play.google.com/store/apps/details?id=com.aoneahsan.achat) 安装 Android 应用。** 两者是同一个 AChat，聊天也一样。

## 网页版

AChat 可以在手机、平板或电脑上的任何较新浏览器里运行，什么都不用安装。

在手机上，AChat 的页面排得像一个应用：主要操作始终在拇指够得着的地方，页面链接放在 **更多链接** 下面。在电脑上，或者把浏览器窗口拉窄时，你看到的是网页布局。

## Android

在 [Google Play](https://play.google.com/store/apps/details?id=com.aoneahsan.achat) 上获取。AChat 使用相机（扫码）、麦克风（语音消息和听写）、通知或位置（只在开启了设备和位置记录的聊天里）之前，Android 都会先问你。

## iPhone 和 iPad

没有 iOS 应用。请在 Safari 里使用网页版 AChat。

## 两种加入方式

| | 匿名房间 | 账号 |
|---|---|---|
| 需要什么 | 一个房间链接和一个显示名 | 一个 Google 账号和一个用户名 |
| 得到什么 | 那个房间，用你选的显示名 | 私人聊天、联系人、群组、社区、动态、保留的房间、套餐 |
| 手机号 | 从不要求 | 从不要求 |

用户名由 3–24 个字母、数字、点或下划线组成，以后可以更改。如果你有账号，AChat 不会把你在匿名房间里的消息和账号关联起来。

## 可以先试试吗？

可以。[演示](https://achat.aoneahsan.com/zh-Hans/demo)会带你用虚构的人物完成四个小任务，你在那里输入的任何内容都不会离开页面。

## 谁可以使用 AChat

你需要年满 16 岁。如果发现账号属于更年轻的人，账号会被关闭。
