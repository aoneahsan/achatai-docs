# 从 Chatwoot 搬到 AChat

**Chatwoot 是开源客服平台，可以自行托管，也可以按客服人数付费。** 在自己的服务器上运行客服是留下的好理由；AChat 不能自行托管。它适合你不想运行任何东西、而且访客是在彼此交谈而不是找客服的时候。

核对于 2026-11-22。对比见 [AChat 与 Chatwoot](https://achat.aoneahsan.com/zh-Hans/compare/chatwoot)。

## 停用一个自行托管的实例

如果你的 Chatwoot 服务器主要承载访客闲聊，维护成本可能比这个房间本身更高。

1. 先从 Chatwoot 导出你需要的一切。AChat 不导入任何内容。
2. 在[小组件页面](https://achat.aoneahsan.com/zh-Hans/widget)上做一个房间或选一个开放的社区频道（[可嵌入小组件](/features/embeddable-widget)）。没有服务器、数据库或更新需要你照看。
3. 把代码贴到原来运行 Chatwoot 小组件的地方。
4. 用账号保留这个房间，这样它能超过默认的历史保留期，你也能列出允许显示它的网站。
5. 等新房间运行一段时间之后，再关掉你的实例。
