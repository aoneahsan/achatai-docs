# 从 WhatsApp 搬到 AChat

**WhatsApp 和你的手机号绑定，并通过 Google 或它自己的云存储备份聊天。** 如果你联系的人都已经在那里，而且你打电话和发消息一样频繁，那就留下。AChat 适合那些你更愿意通过用户名、链接或二维码联系的人，全程不需要手机号。

以下事实核对于 2026-11-22。价格和功能的并排对比见 [AChat 与 WhatsApp](https://achat.aoneahsan.com/zh-Hans/compare/whatsapp)。

## 把人带过来

在 WhatsApp 上，有你号码的人就能找到你。在 AChat 上，你给出用户名之前谁都找不到你，所以搬家是一个人一个人地进行。

1. 用 Google [登录 AChat](/getting-started/quick-start) 并选一个用户名。不会要你的手机号。
2. 在 **联系人** 里复制你的邀请链接，粘贴到你想带过来的人的 WhatsApp 聊天里。打开它的人都能给你发联系人请求（[私人聊天与联系人](/features/personal-chats-and-contacts)）。
3. AChat 一显示恢复密钥就保存它（[设备与恢复密钥](/features/devices-and-recovery)）。它取代 WhatsApp 的备份：没有已关联的设备时，它是找回历史的唯一办法。
4. 把 WhatsApp 的历史留在原处。AChat 不导入其他应用的聊天，所以旧消息只能在 WhatsApp 里读。
5. 通话继续用 WhatsApp。AChat 没有语音或视频通话。

## WhatsApp 的页面怎么说

| 功能 | AChat | WhatsApp |
|---|---|---|
| 不用手机号注册 | 是 | 否（<a href="https://www.whatsapp.com/security" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |
| 个人聊天端到端加密 | 是 | 我们查看的页面上没有说明 |
| 换新设备后记录能找回 | 部分 | 部分（<a href="https://faq.whatsapp.com/481135090640375" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |

我们这边的“部分”是这个意思：另一台已关联的设备或你的恢复密钥能找回你的加密历史。两者都没了，谁都无法恢复，包括我们。
