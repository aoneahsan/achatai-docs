# 从 Telegram 搬到 AChat

**Telegram 是云端消息应用：你用手机号登录，聊天在每台设备上都在。** 端到端加密只有秘密聊天才有。如果“到处都有”对你比这更重要，Telegram 更合适。AChat 默认对私人聊天和私密群组做端到端加密，从不要求手机号。代价是你的历史跟着设备走，而不是跟着云端走。

核对于 2026-11-22。并排对比页面是 [AChat 与 Telegram](https://achat.aoneahsan.com/zh-Hans/compare/telegram)。

## 发第一条消息之前

要改掉的习惯是“在哪儿登录都什么都在”。第一天就把设备设置好，趁你还有一台登录着的设备。

1. 在你最常用的设备上[登录 AChat](/getting-started/quick-start)，选一个用户名。Telegram 用户习惯用户名，所以你分享用户名的方式完全一样。
2. 在 **账户** 的 **设备** 里关联你的另一部手机、平板或电脑（[设备与恢复密钥](/features/devices-and-recovery)）。新设备扫描已登录设备上的码。
3. 把恢复密钥保存在这些设备以外的地方。所有已关联的设备都没了时，靠它恢复历史。
4. 通过用户名添加你的 Telegram 联系人（[私人聊天与联系人](/features/personal-chats-and-contacts)）。
5. 在 **群组** 里重建你在意的群组，等大家成为你的联系人后再邀请。公开的 Telegram 频道更接近 AChat 的[社区](/features/groups-and-communities)，社区不是端到端加密的。

你的 Telegram 历史留在 Telegram 里。AChat 不导入其他应用的聊天。

## 逐项对比

| 功能 | AChat | Telegram |
|---|---|---|
| 不用手机号注册 | 是 | 否（<a href="https://telegram.org/faq" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |
| 私人聊天端到端加密 | 是 | 部分（<a href="https://telegram.org/faq" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |
| 新设备上找回历史 | 部分 | 是（<a href="https://telegram.org/faq" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |

那个“部分”就是取舍所在。另一台已关联的设备或你的恢复密钥能找回历史。两者都没有时，谁都无法恢复，包括 AChat 团队。AChat 也没有语音或视频通话。
