# 从 Intercom 搬到 AChat

**Intercom 是按席位计价的客服软件，它的 AI 客服 Fin 按结果收费。** 想让 AI 先回答的客服团队应该留在 Intercom。AChat 不能替代其中任何一项。它提供的是页面上的一个房间，适合你本来就不需要客服台的时候。

核对于 2026-11-22。对比见 [AChat 与 Intercom](https://achat.aoneahsan.com/zh-Hans/compare/intercom)。

## 一个房间就够的地方

诚实的检验是：你的团队里有没有人在读 Intercom 的对话。如果有，就继续为席位付费。

1. 列出出现 Intercom 的页面。标出那些访客主要彼此交谈、或团队里没人回复的页面。
2. 为这些页面在[小组件页面](https://achat.aoneahsan.com/zh-Hans/widget)上做一个房间或开放频道（[可嵌入小组件](/features/embeddable-widget)）。
3. 如果想让它从页面角落打开，选 **聊天按钮**。
4. 贴上代码，团队工作的地方继续留着 Intercom。
5. 让有账号的人保留这个房间，这样你就能限制哪些网站显示它。

## Intercom 的页面没有说的

我们在 Intercom 的页面上查了：没有截止日期的免费套餐、可直接加到页面的现成聊天、在自己的服务器上运行。三项都没有说明，所以这里没有功能表。<a href="https://www.intercom.com" target="_blank" rel="noopener noreferrer nofollow">Intercom 网站</a> 也许有答案。

我们这边，AChat 有免费套餐、现成的小组件，不支持自行托管。小组件不是客服收件箱，除非设了密码，页面上的任何人都能读这个房间。
