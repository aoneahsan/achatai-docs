# 从 Discord 搬到 AChat

**Discord 是社区聊天，Nitro 是付费升级，用于更大的上传等。** 活在语音频道里的大型社区属于 Discord；AChat 没有语音。AChat 适合应该让访客不用账号就能进来的社区，或希望一对一聊天端到端加密的人。

最后核对于 2026-11-22。并排对比：[AChat 与 Discord](https://achat.aoneahsan.com/zh-Hans/compare/discord)。

## 从服务器到社区

Discord 服务器和 AChat 社区几乎一一对应：社区包含频道，频道包含话题。

1. [登录](/getting-started/quick-start)并从 **社区** 创建一个社区（[群组与社区](/features/groups-and-communities)）。选一个链接 ID，8 到 20 个小写字母、数字和连字符。
2. 选择它的进入方式。**允许匿名** 让访客不用账号、用显示名称加入。**需要账号** 只让登录的人进入。
3. 重建你真正在用的文字频道。只该让部分成员读到的频道，设为私密。
4. 指定管理员。他们创建频道、处理举报和封禁；只有所有者决定谁是管理员。
5. 在 Discord 公告里发布社区链接，给搬家留点时间。
6. 可选：从[小组件页面](https://achat.aoneahsan.com/zh-Hans/widget)把一个用显示名称的频道放到你的网站上。

社区不是端到端加密的。私人聊天（[私人聊天与联系人](/features/personal-chats-and-contacts)）和私密群组是，它们的历史只能通过已关联的设备或恢复密钥回来（[设备与恢复密钥](/features/devices-and-recovery)）。Discord 的历史不会导入。

## Discord 的页面告诉了我们什么

我们在 Discord 的页面上查了对每个即时通讯应用都会比较的三件事：不用手机号注册、私人聊天端到端加密、新设备上的历史。它们一项都没有说明，所以这里没有功能表。请到 <a href="https://discord.com" target="_blank" rel="noopener noreferrer nofollow">Discord 网站</a> 自行核对。
