# 从 Signal 搬到 AChat

**Signal 免费、没有广告、端到端加密，能在手机和电脑上用。** 背后是一家非营利组织，它支持语音和视频通话，而 AChat 不支持。人们通常出于另外两个原因来看 AChat：它能在浏览器里打开，以及丢了手机后恢复密钥能找回你的历史。Signal 说没有旧设备时不支持恢复。

最后核对于 2026-11-22。完整对比：[AChat 与 Signal](https://achat.aoneahsan.com/zh-Hans/compare/signal)。

## 在 Signal 旁边装上 AChat

试用不需要放弃 Signal。大多数人会两个一起用一阵子。

1. 在电脑的浏览器里打开 AChat 并[登录](/getting-started/quick-start)。不用安装任何东西，也不需要先配对手机。选一个用户名；不会要手机号。
2. AChat 显示恢复密钥时把它记下来，因为它只显示一次（[设备与恢复密钥](/features/devices-and-recovery)）。这正是 Signal 给不了你的那部分，所以像对待家门钥匙一样对待它。
3. 和 Signal 上的朋友当面时，互相扫二维码。否则就在你们的 Signal 聊天里发你的邀请链接（[私人聊天与联系人](/features/personal-chats-and-contacts)）。
4. 关联自己的第二台设备时比对安全码。码一致，说明就是你想关联的那台设备。

通话留在 Signal 上。旧的 Signal 消息也留在那里，因为 AChat 不导入其他应用的聊天。

## 区别在哪里

| 功能 | AChat | Signal |
|---|---|---|
| 不用手机号注册 | 是 | 我们查看的页面上没有说明 |
| 个人聊天端到端加密 | 是 | 是（<a href="https://signal.org/" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |
| 换新设备后记录能找回 | 部分 | 部分（<a href="https://support.signal.org/hc/en-us/articles/360007059752-Backup-and-Restore-Messages" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |

两边都写“部分”，原因不同。在 AChat 上，它指已关联的设备或恢复密钥。两者都丢了，谁都无法恢复你的历史，包括我们。
