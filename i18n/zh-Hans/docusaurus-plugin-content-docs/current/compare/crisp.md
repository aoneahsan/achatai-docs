# 从 Crisp 搬到 AChat

**Crisp 是处理客户消息的共享收件箱，按工作区计价。** 如果一个团队要在同一个收件箱里回答客户，那是 Crisp 的活，AChat 不做。AChat 给你的是页面上的一个开放房间，不用数席位。

核对于 2026-11-22。并排对比见 [AChat 与 Crisp](https://achat.aoneahsan.com/zh-Hans/compare/crisp)。

## 当收件箱超出了你的需要

只有当你发现 Crisp 里的对话其实是访客想彼此交谈、而不是找客服时，AChat 才合适。

1. 看看到底是谁在往你的 Crisp 收件箱里写。如果大多数消息需要你的团队回复，就到此为止。
2. 如果不是，就在[小组件页面](https://achat.aoneahsan.com/zh-Hans/widget)上做一个房间。来自标记为 **允许匿名** 的社区的开放频道也行（[可嵌入小组件](/features/embeddable-widget)）。
3. 如果常客应该能保留这个房间，就打开 **提供登录**。聊天本身从不需要登录。
4. 把代码贴到原来放 Crisp 小组件的地方，或放在它旁边。
5. 有人保留了这个房间之后，他可以列出允许显示它的网站。在那之前，任何网站都可以。

## Crisp 的页面怎么说

Crisp 的价格页面确认有一个没有截止日期的免费套餐。我们查看的页面没有说明 Crisp 是否提供可直接加到页面的现成聊天，或能在自己服务器上运行的版本，所以这两行已略去。

| 功能 | AChat | Crisp |
|---|---|---|
| 没有截止日期的免费套餐 | 是 | 是（<a href="https://crisp.chat/en/pricing/" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |

AChat 只提供托管版本，所以无法在你自己的服务器上运行。除非设了密码，访问页面的任何人都能读这个房间。
