# 从 LiveChat 搬到 AChat

**LiveChat 是按用户计价的在线聊天，有 14 天试用。** 它是为逐一回答访客的客服做的。如果你的网站就是这样运作，那就留着它。AChat 适合今天就在页面上放点免费的东西，没有会到期的试用。

最后核对于 2026-11-22。并排对比页面：[AChat 与 LiveChat](https://achat.aoneahsan.com/zh-Hans/compare/livechat)。

## 如果你的试用快到期了

也许你开始试用 LiveChat 后发现访客根本不需要客服。下面是在试用结束前把房间准备好的方法。

1. 打开[小组件页面](https://achat.aoneahsan.com/zh-Hans/widget)，选一个匿名房间或开放的社区频道（[可嵌入小组件](/features/embeddable-widget)）。
2. 在预览里试试两种布局，预览会用示例消息填满房间，方便你判断大小。
3. 复制代码，替换 LiveChat 的代码片段。
4. 访客选一个显示名称就能聊。没有人排队，因为根本没有队列。
5. 设个密码，房间就只有拿到密码的人能读。
