# 从 Wire 搬到 AChat

**Wire 在每个套餐上都对消息做端到端加密，按人数计价，5 人以内的团队免费。** 如果你在为企业团队采购，它就是为你做的。AChat 是用来和亲友聊天的，外加谁都能凭链接加入的匿名房间。

核对于 2026-11-22。对比页面是 [AChat 与 Wire](https://achat.aoneahsan.com/zh-Hans/compare/wire)。

## 从一个小 Wire 团队到 AChat

这一节写给在 5 人上限内使用 Wire for Free 的家人或朋友圈。

1. 每个人都[登录 AChat](/getting-started/quick-start)并选一个用户名。不会要手机号。
2. 通过用户名或邀请链接互相添加为联系人（[私人聊天与联系人](/features/personal-chats-and-contacts)）。
3. 你们中的一人创建一个[群组](/features/groups-and-communities)并邀请其他人。它是端到端加密的，就像你们的 Wire 对话一样。
4. 每个人保存自己的恢复密钥（[设备与恢复密钥](/features/devices-and-recovery)）。别人无法替你恢复历史。
5. 对圈子以外的人，用链接分享一个[匿名房间](/features/anonymous-chats)，而不是把他们加进来。

Wire 的对话留在 Wire。AChat 不导入其他应用的聊天。

## 按 Wire 价格页面的说法

Wire 的价格页面确认了端到端加密。它没有说明能否不用手机号注册，也没有说明新设备上能否找回历史，所以这两行已略去。

| 功能 | AChat | Wire |
|---|---|---|
| 私人聊天端到端加密 | 是 | 是（<a href="https://wire.com/en/pricing" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |

AChat 从不要手机号。它的历史通过已关联的设备或恢复密钥回来，两者都没有时谁都无法恢复，包括我们。AChat 没有语音或视频通话。
