# 从 Element 搬到 AChat

**Element 向组织销售聊天：免费的 Community 版，加上按席位或按部署计价的 Enterprise 和 Sovereign 方案。** 如果你在为一个组织运营聊天、想要自己的部署，这一页不适合你；AChat 无法在你自己的服务器上运行。它是为另一种情况准备的：你用 Element 和亲友保持联系，更想直接在浏览器里开始，什么都不用设置。

核对于 2026-11-22。完整对比见 [AChat 与 Element](https://achat.aoneahsan.com/zh-Hans/compare/element)。

## 搬一个私人圈子

1. 在任意较新的浏览器里打开 [achat.aoneahsan.com](https://achat.aoneahsan.com) 并[登录](/getting-started/quick-start)。什么都不用设置。选一个用户名；不会要手机号。
2. 保存你的恢复密钥（[设备与恢复密钥](/features/devices-and-recovery)）。它只显示一次。
3. 通过用户名、邀请链接或二维码，添加你聊得最多的那几个人（[私人聊天与联系人](/features/personal-chats-and-contacts)）。
4. 把每个小的 Element 房间变成一个 AChat [群组](/features/groups-and-communities)。群组是端到端加密的。通过链接加入的人要等管理员批准。
5. 更大、开放的房间更适合做成带频道的社区。社区不是端到端加密的。

Element 的消息历史留在 Element。AChat 不导入其他应用的聊天。

## Element 的价格页面怎么说

我们读了 Element 的价格页面。它说可以不用手机号注册。关于私人聊天的端到端加密、或在新设备上找回历史，它都没有说明，所以我们略去了这几行。

| 功能 | AChat | Element |
|---|---|---|
| 不用手机号注册 | 是 | 是（<a href="https://element.io/en/pricing" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |

在 AChat 上，私人聊天是端到端加密的。已关联的设备或恢复密钥能找回你的历史，没有它们谁都无法恢复，包括我们。没有语音或视频通话。

| 套餐 | 价格 | 来源 |
|---|---|---|
| Community | 免费 | <a href="https://element.io/en/pricing" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a> |
| Enterprise | 未说明 | <a href="https://element.io/en/pricing" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a> |

AChat 自己的套餐见[价格页面](https://achat.aoneahsan.com/zh-Hans/pricing)。Element 的：<a href="https://element.io" target="_blank" rel="noopener noreferrer nofollow">Element 网站</a>。
