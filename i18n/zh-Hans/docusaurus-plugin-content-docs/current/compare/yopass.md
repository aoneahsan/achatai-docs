# 从 Yopass 搬到 AChat

**Yopass 生成一次性机密链接，在你的浏览器里加密，开源，可免费自行托管。** 如果机密应该在查看一次后自毁，或者你想自己托管这个工具，就留在 Yopass；AChat 不能自行托管。AChat 适合一段一直开着、直到你处理完的对话。

核对于 2026-11-22。对比见 [AChat 与 Yopass](https://achat.aoneahsan.com/zh-Hans/compare/yopass)。

## 让对话一直开着

Yopass 链接被读过就关闭了。如果对方回来说“不行啊”，你就得重来。在 AChat 房间里，他们就在你停下的地方回复。

1. 选择 **匿名继续**，然后 **创建房间**（[匿名房间](/features/anonymous-chats)）。
2. 设一个密码。有密码的房间里的消息会用它在你的设备上加密（[密码与加密](/features/passwords-and-encryption)）。
3. 发送需要的内容，文字或文件（[文件分享](/features/file-sharing)），然后分开发送链接和密码。
4. 一直待到问题解决。然后删掉你的消息，或者让它们在房间设定的天数后过期。

## Yopass 的页面怎么说

Yopass 的页面确认能发文字和文件。它没有说明是否需要账号、能否加密码、对方能否回复，所以这几行已略去。

| 功能 | AChat | Yopass |
|---|---|---|
| 文字和文件都能发 | 是 | 是（<a href="https://yopass.se/" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |

AChat 房间不需要账号，可以设密码，对方也能回复。没有密码时，任何拿到链接的人都能读这个房间。
