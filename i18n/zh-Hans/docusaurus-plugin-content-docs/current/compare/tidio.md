# 从 Tidio 搬到 AChat

**Tidio 是带 AI 客服 Lyro 的客户聊天，按对话数计价。** 如果你想要一个客服来回答客户，那是 Tidio。AChat 适合人们来彼此交谈的页面，而且你不想去数对话数。

最后核对于 2026-11-22。完整对比：[AChat 与 Tidio](https://achat.aoneahsan.com/zh-Hans/compare/tidio)。

## 把回答机器人换成一个房间

在 AChat 上没有人代你回答。访客彼此回答，所以只有在这正是目的的地方才行得通。

1. 挑出访客彼此聊天、而不是找你聊天的页面。其余页面留着 Tidio。
2. 在[小组件页面](https://achat.aoneahsan.com/zh-Hans/widget)上选一个匿名房间或开放的社区频道，再选布局（[可嵌入小组件](/features/embeddable-widget)）。
3. 如果房间放在一个窄栏里，打开 **紧凑** 或 **隐藏聊天标题栏**。
4. 把代码贴到这些页面里。
5. 如果只该让特定访客读到，给房间设个密码。

## Tidio，来自它的价格页面

Tidio 的价格页面确认有一个没有截止日期的免费套餐。我们查看的页面没有提到可直接加到页面的现成聊天，也没有提到在自己的服务器上运行，所以这两行没有列出。

| 功能 | AChat | Tidio |
|---|---|---|
| 没有截止日期的免费套餐 | 是 | 是（<a href="https://www.tidio.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |

AChat 小组件不是客服收件箱，也不是开发者 SDK，而且不能自行托管。
