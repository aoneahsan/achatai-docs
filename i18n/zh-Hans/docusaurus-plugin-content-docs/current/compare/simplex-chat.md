# 从 SimpleX Chat 搬到 AChat

**SimpleX Chat 完全没有用户标识符，连随机的都没有。** 如果这正是你看重的，这里没有什么能胜过它。AChat 有意走了另一条路：别人通过用户名找到你。在此之上，还有可以凭链接分享或放到网站上的匿名房间。

最后核对于 2026-11-22。完整对比：[AChat 与 SimpleX Chat](https://achat.aoneahsan.com/zh-Hans/compare/simplex-chat)。

## 选一个你愿意被人找到的名字

在 SimpleX 上，每个联系人都从一次性链接开始。在 AChat 上，你递出去的是用户名，所以花点心思想一想。

1. [登录](/getting-started/quick-start)并选一个 3 到 24 个字符的用户名，可用字母、数字、点或下划线。随时可以改。改了之后，旧名字就可以被别人使用。
2. 用你习惯的方式分享它：邀请链接或二维码（[私人聊天与联系人](/features/personal-chats-and-contacts)）。你还没接受的人发来的消息在 **消息请求** 里等着。
3. 保存恢复密钥（[设备与恢复密钥](/features/devices-and-recovery)）。没有已关联的设备时，它是找回历史的唯一办法。
4. 对不该碰到你用户名的对话，改用[匿名房间](/features/anonymous-chats)。[小组件页面](https://achat.aoneahsan.com/zh-Hans/widget)能把房间放到你的网站上。

聊天留在 SimpleX 里。AChat 不从其他应用导入。

## 按他们的说法

| 功能 | AChat | SimpleX Chat |
|---|---|---|
| 不用手机号注册 | 是 | 是（<a href="https://simplex.chat/" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |
| 个人聊天端到端加密 | 是 | 是（<a href="https://simplex.chat/faq/" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |
| 换新设备后记录能找回 | 部分 | 是（<a href="https://simplex.chat/faq/" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |

在 AChat 上，历史只能通过已关联的设备或恢复密钥回来，没有它们谁都无法恢复，包括 AChat 团队。AChat 没有语音或视频通话。
