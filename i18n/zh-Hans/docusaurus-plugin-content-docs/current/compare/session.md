# 从 Session 搬到 AChat

**Session 创建账号时不绑定任何属于你的标识符，通过洋葱路由发送消息，并在新设备上用恢复密码找回你的 Account ID。** 对那些在意这一点的对话，继续用 Session。AChat 账号用 Google 登录。加上 AChat 的理由是带频道和话题的社区，以及大家凭链接加入的房间。

核对于 2026-11-22。并排对比：[AChat 与 Session](https://achat.aoneahsan.com/zh-Hans/compare/session)。

## 带什么过来，留下什么

合理的分法是：把群体的公开讨论搬过来，私密对话留在原处。

1. 从一个房间开始，它不需要账号（[快速开始](/getting-started/quick-start)）。**匿名继续**，创建一个房间，分享它的链接（[匿名房间](/features/anonymous-chats)）。
2. 如果这个群体需要一个能长期存在的地方，由有账号的人创建一个[社区](/features/groups-and-communities)，设为 **允许匿名**，这样成员仍能用显示名称加入。社区不是端到端加密的，所以适合公开讨论。
3. 如果你确实创建了账号，会得到一个恢复密钥。它的作用类似 Session 的恢复密码之于你的 ID，但在这里它恢复的是你的消息历史（[设备与恢复密钥](/features/devices-and-recovery)）。把它存在设备以外。
4. 用用户名添加你想继续一对一聊天的人（[私人聊天与联系人](/features/personal-chats-and-contacts)）。

Session 的内容都不会导入。
