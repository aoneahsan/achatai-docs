# 从 Threema 搬到 AChat

**Threema 不要手机号也不要邮箱，并分别备份你的 ID 和聊天。** 如果注册时不交出任何个人数据是你选择它的原因，那就留着它。AChat 账号用 Google 登录，所以没那么“空白”。AChat 多出来的是任何人凭链接就能加入的房间，以及可以放到网站上的聊天。

核对于 2026-11-22。并排对比见 [AChat 与 Threema](https://achat.aoneahsan.com/zh-Hans/compare/threema)。

## 两种进入方式

先决定你想给 AChat 多少信息，因为这决定了你从哪里开始。

**什么都不给。** 选择 **匿名继续**，创建一个房间（[匿名房间](/features/anonymous-chats)）。你为这个房间选一个显示名称，然后分享它的链接。如果只该让特定的人读到，就给它设个密码。

**一个账号。** [用 Google 登录](/getting-started/quick-start)并选一个用户名，别人就是通过它找到你的，很像 Threema ID。然后：

1. 保存你的恢复密钥。Threema 会备份 ID；在 AChat 上，能找回历史的是恢复密钥或另一台已关联的设备（[设备与恢复密钥](/features/devices-and-recovery)）。
2. 把你的用户名或邀请链接发给 Threema 上的联系人（[私人聊天与联系人](/features/personal-chats-and-contacts)）。
3. 如果你有网站，在[小组件页面](https://achat.aoneahsan.com/zh-Hans/widget)上为它做一个房间。

你的 Threema 聊天不会搬过来。AChat 不导入其他应用的聊天。
