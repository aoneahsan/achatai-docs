# 从 CometChat 搬到 AChat

**CometChat 是给开发者用的聊天，Build 套餐最多 100 位用户免费。** 如果你的开发者在给你自己的应用加聊天，那就留着它。AChat 适合你更想贴一段代码、让访客不用账号就交谈的时候。

最后核对于 2026-11-22。并排对比：[AChat 与 CometChat](https://achat.aoneahsan.com/zh-Hans/compare/cometchat)。

## 超过 100 位用户之后

Build 套餐最多覆盖 100 位用户。如果你在它上面做的其实是一个给访客的公开房间，下面是替换方法。

1. 把两种用途分开。你自己用户之间的应用内聊天留在 CometChat。
2. 对公开的部分，在[小组件页面](https://achat.aoneahsan.com/zh-Hans/widget)上创建一个房间或选一个开放的社区频道（[可嵌入小组件](/features/embeddable-widget)）。
3. 设好布局，然后把代码复制到你的页面里。
4. 访客在房间里选一个显示名称。谁都不需要账号。
5. 如果房间只该对一个群体开放，就设个密码，并单独发给他们。

## CometChat 的页面

CometChat 的价格页面确认有一个没有截止日期的免费套餐。我们查看的页面没有说明它是否提供可直接加到页面的现成聊天，或能否在自己的服务器上运行，所以这两行已略去。

| 功能 | AChat | CometChat |
|---|---|---|
| 没有截止日期的免费套餐 | 是 | 是（<a href="https://www.cometchat.com/pricing" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |

AChat 只提供托管版本。它的小组件是现成的房间，不是客服收件箱，也不是 SDK。
