# 从 tlk.io 搬到 AChat

**tlk.io 是一个网址上的网页聊天室，不用注册，可以嵌到你自己的网站上。** 对于一个用完即弃、不用先读任何东西的房间，它很难被超越。AChat 房间的开始方式一样，在你需要时走得更远：密码、文件，或有人保留房间。

最后核对于 2026-11-22。并排对比：[AChat 与 tlk.io](https://achat.aoneahsan.com/zh-Hans/compare/tlk-io)。

## 同样的习惯，多一个选择

tlk.io 房间是一个你发给大家的网址。AChat 房间也是。

1. 打开 AChat，选择 **匿名继续**，然后 **创建房间**。你会得到房间和要发出去的链接（[匿名房间](/features/anonymous-chats)）。
2. 如果房间不是给每个可能猜到链接的人的，就在创建时设个密码。密码还会加密房间的消息（[密码与加密](/features/passwords-and-encryption)）。
3. 除了消息，也可以把文件放进房间（[文件分享](/features/file-sharing)）。
4. 每条消息在设定的天数后删除，默认 10 天。如果房间应该长期存在，就由有账号的人[保留它](/features/keep-chats-and-accounts)。
5. 以前在网站上嵌入过 tlk.io？[小组件页面](https://achat.aoneahsan.com/zh-Hans/widget)能为 AChat 房间做同样的事。
