# 从 Chatzy 搬到 AChat

**Chatzy 为你邀请的人提供免费私密聊天室，不用注册。** 如果你依赖它自己的控制来决定谁能进来，就继续用它。AChat 对“谁能进来”的回答是密码，而这个密码同时会加密房间的消息。AChat 房间也能放文件。

核对于 2026-11-22。对比见 [AChat 与 Chatzy](https://achat.aoneahsan.com/zh-Hans/compare/chatzy)。

## 重建一个私密房间

1. 在 AChat 中选择 **匿名继续**，然后 **创建房间**。谁都不用注册（[匿名房间](/features/anonymous-chats)）。
2. 创建时设一个密码。没有它，谁都无法加入或阅读。消息会用这个密码在每个人的设备上加密（[密码与加密](/features/passwords-and-encryption)）。
3. 链接用一条消息发，密码用另一条消息发，或者换一种途径发。
4. 每个人选一个显示名称，1 到 24 个字符，在该房间内唯一。
5. 需要时在房间里分享文件（[文件分享](/features/file-sharing)）。

消息在设定的天数后删除，默认 10 天，除非有账号的人[保留房间](/features/keep-chats-and-accounts)。
