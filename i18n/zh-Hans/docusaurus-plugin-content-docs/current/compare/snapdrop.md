# 从 Snapdrop 搬到 AChat

**Snapdrop 是不需要账号的文件传输，由 LimeWire 存储，不登录每次最多 4 GB。** 不用注册就能传大文件是它的长处。AChat 适合你除了文件还想发消息、并想给房间加密码的时候。

核对于 2026-11-22。对比见 [AChat 与 Snapdrop](https://achat.aoneahsan.com/zh-Hans/compare/snapdrop)。

## 文件，加上关于它们的几句话

1. 在搬一次大传输之前，先看看你的 AChat 套餐允许的文件大小。AChat 会在你附加前显示它（[文件分享](/features/file-sharing)）。超过的部分，Snapdrop 仍是合适的工具。
2. 在发送的电脑上打开 AChat，开一个房间，不需要账号（[匿名房间](/features/anonymous-chats)）。
3. 给它加个密码（[密码与加密](/features/passwords-and-encryption)）。
4. 发送文件，并在同一个房间里写下每个文件是做什么用的。
5. 另一台电脑上的人打开链接，输入密码，下载，缺什么还可以回复。

## 怎么对得上

| 功能 | AChat | Snapdrop |
|---|---|---|
| 不需要账户 | 是 | 是（<a href="https://snapdrop.net/" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |
| 文字和文件都能发 | 是 | 部分（<a href="https://snapdrop.net/" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |
| 可用密码保护 | 是 | 我们查看的页面上没有说明 |
| 对方可以回复 | 是 | 我们查看的页面上没有说明 |

AChat 消息会在房间设定的天数后删除，除非有账号的人保留房间。匿名指不需要账号，不是隐身。
