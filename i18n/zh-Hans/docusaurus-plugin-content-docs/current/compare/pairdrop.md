# 从 PairDrop 搬到 AChat

**PairDrop 在你的局域网里点对点发送文件和文字，或通过已配对的设备和临时公共房间经互联网发送。** 两台机器同时开着时，它是最直接的路。当另一台机器晚些才上线、而消息仍得在那里等着时，AChat 能帮上忙。

最后核对于 2026-11-22。并排对比：[AChat 与 PairDrop](https://achat.aoneahsan.com/zh-Hans/compare/pairdrop)。

## 当另一台机器还没开机时

比如你要下班了，想今晚在家里的电脑上拿到一个文件。现在另一头没有任何东西在等着，所以点对点发送落不了地。

1. 在单位的电脑上打开 AChat，**匿名继续**，创建一个房间（[匿名房间](/features/anonymous-chats)）。
2. 加一个密码，这样之后只有你能打开它（[密码与加密](/features/passwords-and-encryption)）。
3. 把文件和任何备注放进去（[文件分享](/features/file-sharing)）。把房间链接复制到你在家能看到的地方。
4. 到家后打开链接，输入密码，取走文件。
5. 删掉它，或者留着。消息会在设定的天数后删除。
