# 从 tawk.to 搬到 AChat

**tawk.to 是给网站用的免费在线聊天；付费可以去掉它的品牌标识。** 如果你的团队要回答客户，还想同时有帮助中心和工单，tawk.to 能做到，AChat 不能。AChat 的小组件是一个房间。访客在那里彼此交谈，不用等客服团队的人。

最后核对于 2026-11-22。并排对比在 [AChat 与 tawk.to](https://achat.aoneahsan.com/zh-Hans/compare/tawk-to)。

## 是替代，还是第二个小组件？

通常是第二个。客服问题仍然需要有人回答，所以联系或帮助页面上继续留着 tawk.to。把 AChat 放在访客会彼此聊天的地方：活动页面、课程、粉丝网站。

1. 打开[小组件页面](https://achat.aoneahsan.com/zh-Hans/widget)，选一个房间 ID，8 到 20 个小写字母、数字和连字符。第一次有人打开小组件时，房间就会创建（[可嵌入小组件](/features/embeddable-widget)）。
2. 选 **嵌在页面中** 得到固定大小的聊天，或选 **聊天按钮** 在角落放一个按钮，点开后聊天在面板里出现。
3. 看着预览，然后把代码复制到页面里。
4. 用账号保留这个房间，然后列出最多 20 个允许显示它的网站。在列出网站之前，任何网站都能显示你的房间。
5. 如果房间不该被每个访客读到，就设个密码。

| 功能 | AChat | tawk.to |

| 没有截止日期的免费套餐 | 是 | 是（<a href="https://www.tawk.to/pricing/" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |
| 可直接加到页面的现成聊天 | 是 | 是（<a href="https://www.tawk.to/pricing/" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |
| 可在自己的服务器上运行 | 否 | 我们查看的页面上没有说明 |

AChat 小组件背后没有客服收件箱，它也不是开发者 SDK。除非设了密码，页面上的任何人都能读这个房间。
