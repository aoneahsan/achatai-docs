# 从 Bitwarden Send 搬到 AChat

**Bitwarden Send 从 Bitwarden 分享文件和密码，端到端加密，每个 Send 保留多久由你控制。** 如果你已经在用 Bitwarden，就继续用 Send。AChat 填补的是眼前这台电脑上没有密码管理器的空当。

核对于 2026-11-22。并排对比见 [AChat 与 Bitwarden Send](https://achat.aoneahsan.com/zh-Hans/compare/bitwarden-send)。

## 在没有你密码库的电脑上

借来的笔记本、图书馆的电脑、客户的电脑：你在那里不能、也不该登录你的密码管理器。

1. 在那台电脑的浏览器里打开 AChat，选择 **匿名继续**。你不用输入任何账号信息（[匿名房间](/features/anonymous-chats)）。
2. 加入你之前用自己设备建好的房间，或者现在新建一个，再用手机打开它的链接。
3. 确认房间有密码（[密码与加密](/features/passwords-and-encryption)）。
4. 把需要的东西传过去，文字或文件（[文件分享](/features/file-sharing)），再复制出来。
5. 离开前删掉这些消息。标签页也关掉。

## Bitwarden 的页面怎么说

Bitwarden 的页面确认 Send 能发文字和文件。它没有说明接收者是否需要账号、能否加密码、对方能否回复，所以这几行已略去。

| 功能 | AChat | Bitwarden Send |
|---|---|---|
| 文字和文件都能发 | 是 | 是（<a href="https://bitwarden.com/products/send/" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |

在 AChat 上，另一头的人不需要账号，可以回复，房间也可以设密码。匿名指不需要账号，不是隐身：这台电脑仍然会连接 AChat 的服务器。

我们查看的页面上没有列出价格。AChat 的费用在[价格页面](https://achat.aoneahsan.com/zh-Hans/pricing)。请到 <a href="https://bitwarden.com/products/send/" target="_blank" rel="noopener noreferrer nofollow">Bitwarden Send 网站</a> 核对 Bitwarden Send。
