# 从 Pastebin 搬到 AChat

**Pastebin 让你粘贴文字并分享链接，可加密码，也有阅后即焚选项。上传文件是 PRO 功能。** 对于应该在同一个地址放上几个月的长文本，Pastebin 是更好的去处。当你还需要发文件，或希望对方回复时，就用 AChat。

最后核对于 2026-11-22。并排对比页面：[AChat 与 Pastebin](https://achat.aoneahsan.com/zh-Hans/compare/pastebin)。

## 先弄清它能保存多久

最大的区别是时间。AChat 会在设定的天数后删除房间里的每条消息，默认 10 天。在粘贴下个月还要用的东西之前，先考虑到这一点。

1. 选择 **匿名继续** 和 **创建房间**（[匿名房间](/features/anonymous-chats)）。
2. 如果这段内容不是给每个拿到链接的人的，就加个密码（[密码与加密](/features/passwords-and-encryption)）。
3. 粘贴文字。把日志文件或截图附在旁边（[文件分享](/features/file-sharing)）。
4. 发送链接。打开它的人可以直接在你的内容下面回答。
5. 需要放更久？登录并[保留房间](/features/keep-chats-and-accounts)，最长到你的套餐允许的日期。
