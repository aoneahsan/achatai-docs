# 从 FilePizza 搬到 AChat

**FilePizza 在你的浏览器里做点对点文件传输。** 想让文件从一个浏览器直接到另一个浏览器时，就用它。AChat 适合对方不会在同一时刻在线的时候。

最后核对于 2026-11-22。完整对比：[AChat 与 FilePizza](https://achat.aoneahsan.com/zh-Hans/compare/filepizza)。

## 留着以后取

浏览器到浏览器的传输需要两头同时在。AChat 房间会一直保存文件，直到对方出现。

1. 从 **匿名继续** 打开一个房间（[匿名房间](/features/anonymous-chats)）。谁都不用注册。
2. 用密码锁上它（[密码与加密](/features/passwords-and-encryption)）。
3. 附上文件，然后关掉你的标签页；文件会留在房间里（[文件分享](/features/file-sharing)）。
4. 发送链接和密码。对方随时上线来取，还能给你留言回复。
5. 它会在房间设定的天数后删除。你也可以早点删掉。

## FilePizza 的页面怎么说

FilePizza 的页面确认能发文件，所以我们把“文字和文件”标为“部分”。它没有说明是否需要账号、能否加密码、对方能否回复，所以这几行已略去。

| 功能 | AChat | FilePizza |
|---|---|---|
| 文字和文件都能发 | 是 | 部分（<a href="https://github.com/kern/filepizza" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |

这三项 AChat 都有：不需要账号、可选密码、可以回复。没有密码的房间，任何拿到链接的人都能读。

我们没有找到可列出的价格。AChat 的价格在它的[价格页面](https://achat.aoneahsan.com/zh-Hans/pricing)。要核对 FilePizza，请打开 <a href="https://file.pizza/" target="_blank" rel="noopener noreferrer nofollow">FilePizza 网站</a>。
