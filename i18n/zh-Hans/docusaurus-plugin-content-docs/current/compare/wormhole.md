# 从 Wormhole 搬到 AChat

**Wormhole 用会过期的链接分享文件，端到端加密，最大 10 GB。** 大文件就该放在 Wormhole。AChat 适合你还想在同一个地方交谈，或需要把一个密码和一个小文件一起发出去的时候。

核对于 2026-11-22。对比在 [AChat 与 Wormhole](https://achat.aoneahsan.com/zh-Hans/compare/wormhole)。

## 大文件放那边，小的放这边

视频导出或磁盘镜像留给 Wormhole。AChat 的文件大小上限取决于你的套餐，并会在你附加前显示出来，所以先看一下（[文件分享](/features/file-sharing)）。

1. 用 **匿名继续** 创建房间，然后点 **创建房间**（[匿名房间](/features/anonymous-chats)）。
2. 设一个密码，让房间的消息用它加密（[密码与加密](/features/passwords-and-encryption)）。
3. 发送小东西：配置文件、Wi-Fi 密码、一句说明它用来做什么。
4. 如果有东西太大，把 Wormhole 链接发进房间，在那里讨论。
5. 消息在房间设定的天数后删除，除非有账号的人保留它。

## Wormhole 的页面怎么说

Wormhole 的页面确认能发文件，所以我们把“文字和文件”标为“部分”。它没有说明是否需要账号、能否加密码、能否收到回复，所以这几行已略去。

| 功能 | AChat | Wormhole |
|---|---|---|
| 文字和文件都能发 | 是 | 部分（<a href="https://wormhole.app/" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |

在 AChat 房间里，你不需要账号，可以设密码，也能收到回答。没有密码时，任何拿到链接的人都能读这个房间。

我们没有找到 Wormhole 可列出的价格。AChat 的费用在[价格页面](https://achat.aoneahsan.com/zh-Hans/pricing)。请自己到 <a href="https://wormhole.app/" target="_blank" rel="noopener noreferrer nofollow">Wormhole 网站</a> 核实。
