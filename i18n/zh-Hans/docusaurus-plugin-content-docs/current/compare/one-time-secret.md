# 从 One-Time Secret 搬到 AChat

**One-Time Secret 为一条机密给你一个一次性链接，带有效期和可选的口令。** 读一次就该消失的密码就该放在那里。当要发的不止一样，或对方需要回答时，就用 AChat。

最后核对于 2026-11-22。完整对比：[AChat 与 One-Time Secret](https://achat.aoneahsan.com/zh-Hans/compare/one-time-secret)。

## 当读一次不够时

一个典型场景：你在帮别人设置一台电脑，有一个密码、一个许可证密钥，还有一个关于用哪个账号的问题。那是每条机密一个链接，或者 AChat 上的一个房间。

1. 在存着这些信息的电脑上，选择 **匿名继续**，然后 **创建房间**（[匿名房间](/features/anonymous-chats)）。
2. 给房间设个密码，这样只有你给了密码的人能读（[密码与加密](/features/passwords-and-encryption)）。密码要和链接走不同的途径。
3. 贴上密码、密钥和你的问题；文件也能放进去（[文件分享](/features/file-sharing)）。对方可以在同一个房间里回复。
4. 完事后，删掉你发的内容。剩下的会在设定的天数后删除，默认 10 天。

## 他们的页面怎么说

One-Time Secret 的页面确认有口令选项。我们没找到关于是否需要账号、是否能同时发文件和文字、对方能否回复的说明，所以这几行已略去。

| 功能 | AChat | One-Time Secret |
|---|---|---|
| 可用密码保护 | 是 | 是（<a href="https://onetimesecret.com/" target="_blank" rel="noopener noreferrer nofollow">他们的页面</a>） |

在 AChat 上，这些都不需要账号：房间能发文字和文件，对方也能回复。没有密码的房间，任何拿到链接的人都能读。
