# 从 Stream Chat 搬到 AChat

**Stream Chat 是供开发者做进自己应用里的聊天，月活跃用户 1,000 以内免费。** 如果你的开发者要把聊天做进你自己的产品，并想掌控每个部分，Stream 就是那类合适的工具。AChat 是相反的取舍：你贴一段代码就有能用的聊天，不需要开发者参与。

核对于 2026-11-22。并排对比在 [AChat 与 Stream Chat](https://achat.aoneahsan.com/zh-Hans/compare/stream-chat)。

## 当 SDK 超出了这件事的需要

团队有时为最后只是一个页面上的一个公开房间，用上了聊天 SDK。如果你正是这种情况，这只需几分钟，而不是一个冲刺周期。

1. 凡是聊天和你自己的用户与数据绑定的地方，都留着 Stream。AChat 小组件不是开发者 SDK，所以它不会架在你自己的用户账号之上。
2. 对公开房间，打开[小组件页面](https://achat.aoneahsan.com/zh-Hans/widget)，选一个房间 ID 或开放的社区频道（[可嵌入小组件](/features/embeddable-widget)）。
3. 选好布局和选项；小组件页面会替你写好代码。
4. 把代码片段复制到你的页面模板里。
5. 有人保留了房间后，他可以列出允许显示它的域名，最多 20 个。

| 功能 | AChat | Stream Chat |
