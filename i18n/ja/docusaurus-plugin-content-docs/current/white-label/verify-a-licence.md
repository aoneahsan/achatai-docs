# ライセンスを確認

**別の名前で動いている AChat のコピーは、誰でも確認できます。** [ライセンスを確認](https://achat.aoneahsan.com/ja/verify-license)を開き、そのコピーのライセンスキーかドメインを入力してください。確認は私たちのライセンスサービスが行います。

## ドメインで

ライセンスを受けたコピーは、自分のドメインの `/.well-known/` の下にライセンスファイルを置いています。ドメインでの確認はそのファイルを読み、そこに書かれたキーを確かめます。

| 結果 | 意味 |
|---|---|
| 有効なライセンス | ファイルにこのドメインのライセンスが書かれていて、有効です |
| 別のドメイン | ファイルに書かれているのは、別のドメインに発行されたライセンスです |
| 有効なライセンスではありません | ファイルに書かれたライセンスは存在しません |
| ライセンスファイルがありません | このドメインはファイルを置いていません |
| 応答がありません | ドメインにつながりませんでした |

## キーで

キーでの確認では、ライセンスが有効か、セットアップ中か、取り消されたかがわかり、公開されている詳細（誰に対するライセンスか、ドメイン、プラットフォーム、日付）が表示されます。メールアドレスや料金は表示されません。

## ライセンスが有効でないコピー

アプリの代わりに「このライセンスは有効ではありません」と表示し、この確認へのリンクを出します。中身は何も削除されません。
