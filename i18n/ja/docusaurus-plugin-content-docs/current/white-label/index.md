# ホワイトラベルとライセンス

**AChat は別の組織の名前で動かせます。** ホワイトラベルライセンスでは、AChat チームが AChat をホストし、あなたのドメインに置き、あなたの名前、ロゴ、色を付けます。あなたはそれを自分の人たちに提供します。コードを所有したい場合は、AChat をまるごと買い取ることもできます。買い取り価格に加え、AChat が収益を上げ続けるかぎり、その総収益の 7% のロイヤリティがかかります。

現在の料金は[ライセンス料金のページ](https://achat.aoneahsan.com/ja/white-label/pricing)と[買い取りのページ](https://achat.aoneahsan.com/ja/white-label/buyout)にあります。料金を 1 か所だけで示すため、ここには繰り返しません。

## 2 つの道

| | ホワイトラベルライセンス | ソースの買い取り |
|---|---|---|
| 運用するのは | AChat チームがホストし、デプロイします | あなたが、ソースコードから |
| ソースコード | 含まれません | ウェブアプリと Android アプリを作るすべてのリポジトリ |
| 独占 | いいえ：ほかの人も AChat のライセンスを受けられます | はい：AChat チームは販売をやめます |
| アップデート | 6 か月分付き、その後は更新 | 6 か月分付き、その後は更新 |
| 購入のあと | もっとアップデートがほしければ更新 | AChat の総収益の 7% のロイヤリティを四半期ごとに |
