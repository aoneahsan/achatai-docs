# アップデートと更新

**どのライセンスと買い取りにも、支払った日から 6 か月分の AChat のアップデートが付きます。** アップデートとは、AChat チームが AChat 自体に加えた修正や改善を、あなたのコピーにも届けることです。あなただけのための変更はカスタム開発です。

## 更新する

更新では 3 か月、6 か月、12 か月のいずれかを追加します。現在の終了日から、その日がすでに過ぎていれば今日から始まります。[アップデートのページ](https://achat.aoneahsan.com/ja/white-label/updates)で、ライセンスキーとライセンスの発行先のメールアドレスを使って更新してください。料金はそこに載っています。

## 更新しない場合

あなたのコピーは、最後に受け取ったバージョンのまま動き続けます。止められるものは何もありません。
