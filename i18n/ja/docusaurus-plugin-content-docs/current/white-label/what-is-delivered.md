# プラットフォームごとに得られるもの

**ライセンスは支払ったプラットフォームが対象で、AChat が今提供しているのは 2 つです。** 拡張機能、デスクトップアプリ、パッケージは提供していません。AChat 自体にそれがないからです。

## ウェブアプリ

あなた自身のアドレスで、ブラウザで動く AChat です。個人チャット、グループ、コミュニティ、ステータス、匿名ルームがあり、すべての画面にあなたの名前が入ります。achat.aoneahsan.com で動いているものと同じアプリですが、切り離されています。あなたのコピーを使う人は AChat のアカウントを持たず、そのチャットが AChat のものと混ざることはありません。

## モバイルアプリ（Android と iOS）

あなたの名前の Android アプリを、あなた自身のストアアカウントから公開します。iOS 版は、Apple の開発者アカウントを用意するか費用を負担していただければ、同じアプリから作ります。ストアの開発者アカウントはあなたが選ぶ費用なので、あなたのものです。

## どのコピーでも同じこと

暗号化は AChat と同じように働きます。個人チャット、プライベートグループ、パスワード付きのルームはエンドツーエンド暗号化され、コミュニティ、オープンなルーム、ステータスはされません。何が守られ、何が守られないかは[セキュリティと暗号化のモデル](/concepts/security-and-encryption)をご覧ください。

あなたのコピーにはあなたの名前が入るので、使う人が読むのは AChat ではなく、あなたのプライバシーポリシーと利用規約です。

## 含まれないもの

あなただけのための変更です。それは[カスタム開発](https://achat.aoneahsan.com/ja/white-label/custom-work)で、別に見積もり、別に支払います。
