# コピーのセットアップ

**支払いのあと、セットアップは AChat チームが行い、それぞれの段階についてご連絡します。** あなたの側でインストールするものはありません。

1. **ライセンスのメール。** ライセンスキーと証明書が、購入に使ったメールアドレスに届きます。両方保管してください。更新のときにキーが必要です。
2. **あなたのドメイン。** コピーを動かすアドレス（例：`chat.yourname.com`）を AChat チームに伝えてください。ドメインはあなたのものなので、接続にあなた側の DNS レコードが必要なら、追加すべきレコードをそのまま送ります。
3. **あなたの名前、ロゴ、色。** 送っていただければ、すべての画面に反映します。
4. **公開。** コピーがあなたのドメインで動き出すと、ライセンスファイルを公開し、誰でも[確認](/white-label/verify-a-licence)できます。

支払いは AChat チームの Wise 口座への銀行振込で、支払いページから振込の参照番号を送ります。ライセンスは AChat チームが振込を確認してから発行され、戻ってきたページから発行されることはありません。
