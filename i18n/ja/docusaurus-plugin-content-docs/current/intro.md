# はじめに

**AChat は、自分で選んだ人とつながり続けるためのメッセージアプリです。個人チャット、グループ、コミュニティ、そしてアカウントを使いたくないときの匿名ルーム。** ブラウザなら [achat.aoneahsan.com](https://achat.aoneahsan.com) で、[Android](https://play.google.com/store/apps/details?id=com.aoneahsan.achat) でも使え、英語、中国語、ヒンディー語、スペイン語、アラビア語、フランス語、ポルトガル語、ロシア語、日本語、ウルドゥー語、ドイツ語の 11 言語に対応しています。

電話番号を渡す必要はありません。Google でログインしてユーザー名を決めれば、友だちはそのユーザー名、招待リンク、QR コードであなたを見つけます。匿名ルームにはアカウントがまったくいりません。

## 約束していないこと

- **匿名でも追跡できないわけではありません。** 匿名ルームにアカウントはいりませんが、どのウェブサイトとも同じように、デバイスは AChat のサーバーに接続します。
- **すべてがエンドツーエンド暗号化されているわけではありません。** AChat がエンドツーエンド暗号化を約束しているのは、個人チャット、非公開グループ、パスワードつきのルームです。コミュニティとそのチャンネル、オープンなルーム、ステータスについては約束していません。[セキュリティと暗号化](/concepts/security-and-encryption)をご覧ください。
- **通話はできません。** AChat はメッセージのためのアプリで、音声通話やビデオ通話はできません。
- **位置を記録するチャットもあります。** チャットはデバイスと位置の記録をオンにでき、入る前に何を記録するかを伝えます。[デバイスと位置の記録](/features/location-history)をご覧ください。
- **一度見られたものは取り消せません。** チャットにいる人は誰でもメッセージをコピー、保存、スクリーンショットでき、あとで削除してもそのコピーには届きません。

## 以前 AChat を使っていましたか？

AChat は作り直されました。匿名ルームのリンクはこれまでどおり開き、メッセージも保管したルームもそのままで、たまった延長日数も引き継がれます。知っている人との個人チャット、グループ、コミュニティ、ステータスは、匿名ルームと並ぶ新しい機能です。
