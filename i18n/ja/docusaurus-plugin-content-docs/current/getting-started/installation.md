# インストールとアクセス

**最新のブラウザで [achat.aoneahsan.com](https://achat.aoneahsan.com/ja) を開くか、[Google Play](https://play.google.com/store/apps/details?id=com.aoneahsan.achat) から Android アプリをインストールしてください。** どちらも同じ AChat で、チャットも同じです。

## ウェブ

AChat はスマホ、タブレット、パソコンの最新ブラウザで動きます。インストールは不要です。

スマホでは、AChat のページはアプリのように並びます。主な操作は親指の届くところにあり、ページへのリンクは **その他のリンク** の下にまとまっています。パソコンや幅を狭めたブラウザでは、ウェブのレイアウトになります。

## Android

[Google Play](https://play.google.com/store/apps/details?id=com.aoneahsan.achat) から入手できます。AChat がカメラ（コードの読み取り）、マイク（ボイスメッセージと音声入力）、通知、位置（デバイスと位置の記録がオンのチャットでだけ）を使う前に、Android が確認します。

## iPhone と iPad

iOS アプリはありません。Safari でウェブ版の AChat をお使いください。

## 2 つの参加方法

| | 匿名ルーム | アカウント |
|---|---|---|
| 必要なもの | ルームのリンクと表示名 | Google アカウントとユーザー名 |
| 使えるもの | そのルームを、自分で決めた表示名で | 個人チャット、連絡先、グループ、コミュニティ、ステータス、保管したルーム、プラン |
| 電話番号 | 求められません | 求められません |

ユーザー名は 3〜24 文字の英字、数字、ドット、アンダースコアで、あとから変えられます。アカウントがあっても、AChat は匿名ルームでのメッセージをアカウントに結びつけません。

## まず試せますか？

はい。[デモ](https://achat.aoneahsan.com/ja/demo)では架空の人たちと 4 つの短いタスクを体験でき、入力した内容はそのページから出ていきません。

## AChat を使える人

16 歳以上である必要があります。それより若い人のアカウントだとわかった場合は閉鎖されます。
