# クイックスタート

**ふだん話している人をひとり選んで、あいさつを送りましょう。最初の一歩はそれだけです。** AChat はチャットの画面で開き、すべての会話はそこから始まります。

## 知っている人とチャットする

1. [achat.aoneahsan.com](https://achat.aoneahsan.com/ja) を開き、**アカウントを使う**、続いて **Google で続ける** を選びます。
2. ユーザー名を決めます。友だちはそれであなたを見つけます。
3. AChat が **復元キー** を表示したら保存してください。すべてのデバイスをなくしたとき、履歴に戻る唯一の方法で、AChat は一度しか表示しません。[デバイスと復元キー](/features/devices-and-recovery)をご覧ください。
4. **連絡先** を開き、ユーザー名、招待リンク、QR コードで相手を追加します。
5. 相手が承認したら、チャットを開いてメッセージを送ります。

メッセージの下の表示は **送信中** になり、届くと **送信済み** に変わります。

## アカウントなしでチャットする

1. **匿名で続ける** を選び、**ルームを作成** するか、送ってもらったリンクや ID で **ルームに参加** します。
2. 1〜24 文字の表示名を決めます。ルームのほかの人に見えるのはそれだけで、ルームではオンラインかどうかや最終ログインは表示されません。
3. ルームのリンクを共有します。パスワードがない限り、リンクを持っている人は誰でも参加できます。

ルームのメッセージは、それぞれ送信から決められた日数（初期設定は 10 日）残ります。アカウントのある人は[ルームを保管](/features/keep-chats-and-accounts)してもっと長く残せます。

## 接続が切れたとき

開いたことのあるチャットは読めたままで、新しいメッセージは戻るまで **送信待ち** で待ちます。
