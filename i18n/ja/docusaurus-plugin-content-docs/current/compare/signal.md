# Signal から AChat へ

**Signal は無料で広告がなく、エンドツーエンド暗号化され、スマートフォンでもデスクトップでも動きます。** 非営利団体が支えていて、AChat にはない音声通話とビデオ通話があります。人が AChat を見るのはたいてい別の 2 つの理由からです。ブラウザで開けること、そしてスマートフォンをなくしても復元キーで履歴が戻ること。Signal は、古い端末がないと復元はサポートしていないとしています。

最終確認 2026-11-22。比較の全体は [AChat と Signal](https://achat.aoneahsan.com/ja/compare/signal)。

## Signal と並べて使い始める

試すのに Signal をやめる必要はありません。たいていの人はしばらく両方を使います。

1. パソコンのブラウザで AChat を開き、[ログイン](/getting-started/quick-start)します。インストールは不要で、先にスマートフォンとペアリングする必要もありません。ユーザー名を選びます。電話番号は聞かれません。
2. AChat が復元キーを表示したら書き留めます。表示は 1 回だけです（[端末と復元キー](/features/devices-and-recovery)）。これが Signal では得られない部分なので、家の鍵のように扱ってください。
3. Signal の相手と会っているときは、互いの QR コードを読み取ります。そうでなければ、Signal のチャットで招待リンクを送ります（[個人チャットと連絡先](/features/personal-chats-and-contacts)）。
4. 自分の 2 台目の端末をリンクするときは、セキュリティコードを照合します。一致すれば、リンクしたかった端末です。

通話は Signal のままで。古い Signal のメッセージも、AChat がほかのアプリのチャットを取り込まないので、そちらに残ります。

## どう違うか

| 機能 | AChat | Signal |
|---|---|---|
| 電話番号なしで登録 | はい | 確認したページに記載なし |
| 個人チャットのエンドツーエンド暗号化 | はい | はい（<a href="https://signal.org/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |
| 新しいデバイスで履歴が戻る | 一部 | 一部（<a href="https://support.signal.org/hc/en-us/articles/360007059752-Backup-and-Restore-Messages" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |

どちらも「一部」ですが、理由が違います。AChat では、リンクした端末か復元キーのことです。両方なくすと、私たちを含め誰も履歴を戻せません。
