# Discord から AChat へ

**Discord はコミュニティのチャットで、大きなアップロードなどのための有料アップグレードが Nitro です。** ボイスチャンネルで成り立っている大きなコミュニティは Discord が合っています。AChat にはボイスがありません。AChat が合うのは、訪問者をアカウントなしで迎えたいコミュニティや、1 対 1 のチャットをエンドツーエンド暗号化したい人です。

最終確認 2026-11-22。並べた比較：[AChat と Discord](https://achat.aoneahsan.com/ja/compare/discord)。

## サーバーからコミュニティへ

Discord のサーバーは、AChat のコミュニティにかなり素直に対応します。コミュニティがチャンネルを持ち、チャンネルがスレッドを持ちます。

1. [ログイン](/getting-started/quick-start)し、**コミュニティ** からコミュニティを作ります（[グループとコミュニティ](/features/groups-and-communities)）。リンク ID は小文字、数字、ハイフンで 8〜20 文字です。
2. 参加方法を選びます。**匿名で参加可** なら訪問者はアカウントなしに表示名で参加できます。**アカウントが必要** ならログインした人に限られます。
3. 実際に使っているテキストチャンネルを作り直します。一部のメンバーだけが読むべきチャンネルは非公開にします。
4. 管理者を決めます。管理者はチャンネルを作り、通報や追放を扱います。誰を管理者にするかはオーナーだけが決めます。
5. コミュニティのリンクを Discord のお知らせに投稿し、移行には少し時間をかけます。
6. 任意：[ウィジェットのページ](https://achat.aoneahsan.com/ja/widget)から、表示名で話せるチャンネルをサイトに置きます。

コミュニティはエンドツーエンド暗号化されていません。個人チャット（[個人チャットと連絡先](/features/personal-chats-and-contacts)）とプライベートグループは暗号化されていて、その履歴はリンクした端末か復元キーからだけ戻ります（[端末と復元キー](/features/devices-and-recovery)）。Discord の履歴は取り込まれません。
