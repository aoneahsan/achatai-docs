# CometChat から AChat へ

**CometChat は開発者向けのチャットで、Build プランは 100 ユーザーまで無料です。** 開発者が自社アプリにチャットを加えているなら、そのまま使ってください。AChat は、スニペットを貼って訪問者にアカウントなしで話してもらいたいときのためのものです。

最終確認 2026-11-22。並べた比較：[AChat と CometChat](https://achat.aoneahsan.com/ja/compare/cometchat)。

## 100 ユーザーを超えたら

Build プランは 100 ユーザーまでです。その上に作ったものが実は訪問者向けの公開ルームなら、次のように置き換えます。

1. 2 つの用途を分けます。自社ユーザーどうしのアプリ内チャットは CometChat に残します。
2. 公開部分については、[ウィジェットのページ](https://achat.aoneahsan.com/ja/widget)でルームを作るか、コミュニティの公開チャンネルを選びます（[埋め込みウィジェット](/features/embeddable-widget)）。
3. レイアウトを設定し、コードをページにコピーします。
4. 訪問者はルームで表示名を選びます。アカウントは誰にも要りません。
5. ルームをあるグループだけのものにするなら、パスワードを付けて別に伝えます。

## CometChat のページ

CometChat の料金ページは、期限のない無料プランを明記しています。確認したページには、ページに置ける既製のチャットがあるか、自分のサーバーで運用できるかは書かれていなかったので、その行は省いています。

| 機能 | AChat | CometChat |
|---|---|---|
| 期限のない無料プラン | はい | はい（<a href="https://www.cometchat.com/pricing" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |

AChat はホスト型のみです。ウィジェットは既製のルームで、担当者用の受信箱でも SDK でもありません。
