# FilePizza から AChat へ

**FilePizza はブラウザ内でピアツーピアのファイル転送を行います。** ファイルをブラウザからブラウザへ直接送りたいなら、それを使いましょう。AChat は、相手が同じ瞬間にオンラインでないときのためのものです。

最終確認 2026-11-22。比較の全体：[AChat と FilePizza](https://achat.aoneahsan.com/ja/compare/filepizza)。

## 後で受け取れるように置いておく

ブラウザ間の転送には、両端が同時にいる必要があります。AChat のルームは、相手が来るまでファイルを保持します。

1. **匿名で続ける** からルームを開きます（[匿名ルーム](/features/anonymous-chats)）。誰も登録しません。
2. パスワードで鍵をかけます（[パスワードと暗号化](/features/passwords-and-encryption)）。
3. ファイルを添付してタブを閉じます。ファイルはルームに残ります（[ファイル共有](/features/file-sharing)）。
4. リンクとパスワードを送ります。相手は都合のよいときに受け取り、返信も残せます。
5. ルームの決まった日数で削除されます。早めに消してもかまいません。

## FilePizza のページに書かれていたこと

FilePizza のページはファイルを扱うことを明記しているので、テキストとファイルは「一部」としました。アカウントが必要か、パスワードを付けられるか、相手が返信できるかは書かれていなかったので、その行は省いています。

| 機能 | AChat | FilePizza |
|---|---|---|
| テキストもファイルも送れる | はい | 一部（<a href="https://github.com/kern/filepizza" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |

AChat は 3 つともそろっています。アカウント不要、任意のパスワード、そして返信です。パスワードのないルームは、リンクを持つ誰でも読めます。

掲載できる料金は見つかりませんでした。AChat の料金は[料金のページ](https://achat.aoneahsan.com/ja/pricing)にあります。FilePizza を確かめるなら <a href="https://file.pizza/" target="_blank" rel="noopener noreferrer nofollow">FilePizza のサイト</a> を開いてください。
