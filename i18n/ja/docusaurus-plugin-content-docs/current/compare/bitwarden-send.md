# Bitwarden Send から AChat へ

**Bitwarden Send は Bitwarden からファイルとパスワードを共有します。エンドツーエンド暗号化で、各 Send をどれだけ残すかを決められます。** すでに Bitwarden を使っているなら、Send を使い続けてください。AChat が埋めるのは、目の前のマシンにパスワードマネージャーがないという隙間です。

2026-11-22 確認。並べた比較は [AChat と Bitwarden Send](https://achat.aoneahsan.com/ja/compare/bitwarden-send) をご覧ください。

## 保管庫のないマシンで

借りたノートパソコン、図書館のパソコン、取引先の PC。そこではパスワードマネージャーにログインできない、あるいはすべきではありません。

1. そのマシンのブラウザで AChat を開き、**匿名で続ける** を選びます。アカウント情報は何も入力しません（[匿名ルーム](/features/anonymous-chats)）。
2. 自分の端末で前もって作ったルームに入るか、今作ってそのリンクをスマートフォンで開きます。
3. ルームにパスワードが付いていることを確かめます（[パスワードと暗号化](/features/passwords-and-encryption)）。
4. 必要なもの、テキストやファイルを送り（[ファイル共有](/features/file-sharing)）、コピーして取り出します。
5. 離れる前にメッセージを削除します。タブも閉じましょう。

## Bitwarden のページに書かれていたこと

Bitwarden のページは、Send がテキストとファイルを扱うことを明記しています。受け取る人にアカウントが必要か、パスワードを付けられるか、相手が返信できるかは書かれていなかったので、その行は省いています。

| 機能 | AChat | Bitwarden Send |
|---|---|---|
| テキストもファイルも送れる | はい | はい（<a href="https://bitwarden.com/products/send/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |

AChat では、相手側の人にアカウントは要らず、返信もでき、ルームにはパスワードを付けられます。匿名はアカウント不要という意味で、見えないという意味ではありません。そのマシンは AChat のサーバーに接続しています。

確認したページに料金の記載はありませんでした。AChat の料金は[料金のページ](https://achat.aoneahsan.com/ja/pricing)にあります。Bitwarden Send は <a href="https://bitwarden.com/products/send/" target="_blank" rel="noopener noreferrer nofollow">Bitwarden Send のサイト</a> でご確認ください。
