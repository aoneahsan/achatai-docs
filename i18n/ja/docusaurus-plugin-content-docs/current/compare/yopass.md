# Yopass から AChat へ

**Yopass は使い捨ての秘密リンクを作るツールで、ブラウザ内で暗号化され、オープンソースで、無料でセルフホストできます。** 秘密を一度見たら消すべきなら、あるいはツールを自分でホストしたいなら、Yopass のままで。AChat はセルフホストできません。AChat は、片付くまで開いたままの会話のためのものです。

2026-11-22 確認。比較は [AChat と Yopass](https://achat.aoneahsan.com/ja/compare/yopass) をご覧ください。

## やり取りを開いたままにする

Yopass のリンクは読まれると閉じます。相手が「うまくいかなかった」と戻ってきたら、最初からやり直しです。AChat のルームなら、相手はあなたが止めたところで返信します。

1. **匿名で続ける**、次に **ルームを作成** を選びます（[匿名ルーム](/features/anonymous-chats)）。
2. パスワードを設定します。パスワード付きのルームのメッセージは、それを使って端末上で暗号化されます（[パスワードと暗号化](/features/passwords-and-encryption)）。
3. 必要なもの、テキストやファイルを送り（[ファイル共有](/features/file-sharing)）、リンクとパスワードは別々に送ります。
4. 片付くまでそこにいます。終わったらメッセージを削除するか、ルームの決まった日数で消えるのに任せます。

## Yopass のページに書かれていたこと

Yopass のページは、テキストとファイルを送れることを明記しています。アカウントが必要か、パスワードを付けられるか、相手が返信できるかは書かれていなかったので、その行は省いています。

| 機能 | AChat | Yopass |
|---|---|---|
| テキストもファイルも送れる | はい | はい（<a href="https://yopass.se/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |

AChat のルームはアカウント不要で、パスワードを付けられ、相手は返信できます。パスワードがなければ、リンクを持つ誰でもルームを読めます。

|---|---|---|
| オープンソース版 | 無料 | <a href="https://yopass.se/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a> |

AChat のプランは[料金のページ](https://achat.aoneahsan.com/ja/pricing)を。Yopass のものは <a href="https://yopass.se/" target="_blank" rel="noopener noreferrer nofollow">Yopass のサイト</a> にあります。
