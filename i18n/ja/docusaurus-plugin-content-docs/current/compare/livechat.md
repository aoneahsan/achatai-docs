# LiveChat から AChat へ

**LiveChat はユーザー単位で料金がかかるライブチャットで、14 日間の試用があります。** 担当者が訪問者に一人ずつ答えるために作られています。サイトがそういう運用なら、そのまま使ってください。AChat は、期限切れになる試用なしで、今日から無料でページに置けるものが欲しいときのためのものです。

最終確認 2026-11-22。並べた比較のページ：[AChat と LiveChat](https://achat.aoneahsan.com/ja/compare/livechat)。

## 試用期間が終わりそうなら

LiveChat の試用を始めてみたら、訪問者には担当者がまったく要らなかった、ということもあるでしょう。試用が終わる前にルームを用意する方法です。

1. [ウィジェットのページ](https://achat.aoneahsan.com/ja/widget)を開き、匿名ルームかコミュニティの公開チャンネルを選びます（[埋め込みウィジェット](/features/embeddable-widget)）。
2. プレビューで両方のレイアウトを試します。プレビューはデモのメッセージでルームを埋めるので、大きさを判断できます。
3. コードをコピーし、LiveChat のスニペットと置き換えます。
4. 訪問者は表示名を選んで話します。待ち行列がないので、誰も並びません。
5. パスワードを付ければ、渡した人だけがルームを読めます。

## LiveChat のページに書かれていなかったこと

私たちが読んだ LiveChat のページには、期限のない無料プラン、ページに置ける既製のチャット、自分のサーバーで運用できる版があるかどうかが書かれていませんでした。そのため機能の表はありません。<a href="https://www.livechat.com" target="_blank" rel="noopener noreferrer nofollow">LiveChat のサイト</a> でご確認ください。

AChat には無料プランと既製のウィジェットがあり、ホスト型のみです。ウィジェットは担当者用の受信箱でも開発者向け SDK でもありません。
