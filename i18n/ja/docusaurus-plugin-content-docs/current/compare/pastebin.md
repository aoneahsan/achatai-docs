# Pastebin から AChat へ

**Pastebin はテキストを貼り付けてリンクを共有でき、パスワードと読んだら消える設定があります。ファイルのアップロードは PRO の機能です。** 同じアドレスに何か月も置いておくべき長いテキストなら、Pastebin のほうが向いています。ファイルも送りたいときや、相手からの返事が欲しいときは AChat を使います。

最終確認 2026-11-22。並べた比較のページ：[AChat と Pastebin](https://achat.aoneahsan.com/ja/compare/pastebin)。

## まず、どれだけ残るかを知る

大きな違いは時間です。AChat はルームの各メッセージを決まった日数、標準で 10 日後に削除します。来月も必要なものを貼る前に、それを考えておきましょう。

1. **匿名で続ける** と **ルームを作成** を選びます（[匿名ルーム](/features/anonymous-chats)）。
2. リンクを持つ全員向けでないなら、パスワードを付けます（[パスワードと暗号化](/features/passwords-and-encryption)）。
3. テキストを貼ります。ログファイルやスクリーンショットも一緒に添付します（[ファイル共有](/features/file-sharing)）。
4. リンクを送ります。開いた人は、あなたが貼った内容のすぐ下で答えられます。
5. もっと長く必要なら、ログインしてプランが許す日付まで[ルームを保持](/features/keep-chats-and-accounts)します。

## 並べて

| 機能 | AChat | Pastebin |
|---|---|---|
| アカウント不要 | はい | はい（<a href="https://pastebin.com/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |
| テキストもファイルも送れる | はい | 一部（<a href="https://pastebin.com/pro" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |
| パスワードで保護 | はい | はい（<a href="https://pastebin.com/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |
| 相手が返信できる | はい | 確認したページに記載なし |

パスワードがなければ、ルームのリンクを持つ誰でも読めます。アカウント不要は、見えないということではありません。

| プラン | 料金 | 出典 |
|---|---|---|
| ゲストまたは無料 | 無料 | <a href="https://pastebin.com/pro" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a> |
| PRO | 記載なし | <a href="https://pastebin.com/pro" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a> |

AChat の料金は[料金のページ](https://achat.aoneahsan.com/ja/pricing)にあります。Pastebin は <a href="https://pastebin.com/" target="_blank" rel="noopener noreferrer nofollow">Pastebin のサイト</a> でご確認ください。
