# TalkJS から AChat へ

**TalkJS は製品に追加できる既製のチャット UI で、開発モードでは無料で使えます。** チャットが自社製品の中にあり、自社のユーザーアカウントと結びついているなら、TalkJS のほうが合っています。AChat は無料プランで公開でき、使う訪問者にアカウントはまったく要りません。

2026-11-22 確認。比較のページは [AChat と TalkJS](https://achat.aoneahsan.com/ja/compare/talkjs) です。

## 開発モードから公開ルームへ

TalkJS は開発モードで作っているあいだは無料です。試作したのがユーザーどうしのチャットではなく公開ルームなら、AChat が無料プランで公開まで運べます。

1. 試作が何に依存しているかを確認します。自社のユーザー ID に結びついた会話は TalkJS に残します。AChat のウィジェットは開発者向け SDK ではなく、あなたのユーザーを知らないからです。
2. 開かれたルームなら、[ウィジェットのページ](https://achat.aoneahsan.com/ja/widget)でルーム ID を選びます（[埋め込みウィジェット](/features/embeddable-widget)）。訪問者は表示名で参加します。
3. TalkJS のチャットがあった場所に置くなら **ページの中**、隅のパネルにするなら **チャットボタン** を選びます。
4. コードをページにコピーします。
5. アカウントでルームを保持し、表示を許可するサイトを登録します。
