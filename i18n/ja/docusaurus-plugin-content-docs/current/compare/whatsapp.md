# WhatsApp から AChat へ

**WhatsApp は電話番号と結びついていて、チャットは Google か WhatsApp 自身のクラウドにバックアップされます。** 話す相手が全員すでにそこにいて、メッセージと同じくらい通話もするなら、そのままでいいでしょう。AChat は、電話番号をどこにも出さず、ユーザー名、リンク、QR コードでつながりたい相手のためのものです。

以下は 2026-11-22 に確認した事実です。料金と機能を並べた比較は [AChat と WhatsApp](https://achat.aoneahsan.com/ja/compare/whatsapp) にあります。

## 人を連れてくる

WhatsApp では、あなたの番号を知っている人ならあなたを見つけられます。AChat では、ユーザー名を教えるまで誰にも見つけられないので、移るのは一人ずつです。

1. Google で [AChat にログイン](/getting-started/quick-start)し、ユーザー名を選びます。電話番号は聞かれません。
2. **連絡先** で招待リンクをコピーし、連れてきたい人との WhatsApp のチャットに貼り付けます。開いた人は誰でも連絡先リクエストを送れます（[個人チャットと連絡先](/features/personal-chats-and-contacts)）。
3. AChat が復元キーを表示したら、すぐに保存します（[端末と復元キー](/features/devices-and-recovery)）。これが WhatsApp のバックアップの代わりです。リンクした端末がひとつも残っていないとき、履歴を取り戻す唯一の手段になります。
4. WhatsApp の履歴はそのままに。AChat はほかのアプリのチャットを取り込まないので、古いメッセージは WhatsApp でしか読めません。
5. 通話は WhatsApp で。AChat には音声通話もビデオ通話もありません。

## WhatsApp のページに書かれていること

| 機能 | AChat | WhatsApp |
|---|---|---|
| 電話番号なしで登録 | はい | いいえ（<a href="https://www.whatsapp.com/security" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |
| 個人チャットのエンドツーエンド暗号化 | はい | 確認したページに記載なし |
| 新しいデバイスで履歴が戻る | 一部 | 一部（<a href="https://faq.whatsapp.com/481135090640375" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |

こちらの「一部」の意味はこうです。リンクしたほかの端末か復元キーがあれば、暗号化された履歴が戻ります。両方なくすと、私たちを含め誰も復元できません。
