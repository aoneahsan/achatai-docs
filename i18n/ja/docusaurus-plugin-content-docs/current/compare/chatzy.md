# Chatzy から AChat へ

**Chatzy は、招待した人のための無料の非公開チャットルームを、登録なしで提供しています。** 誰が入れるかを Chatzy 独自の管理に頼っているなら、そのまま使ってください。「誰が入れるか」に対する AChat の答えはパスワードで、そのパスワードはルームのメッセージの暗号化にも使われます。AChat のルームにはファイルも置けます。

2026-11-22 確認。比較は [AChat と Chatzy](https://achat.aoneahsan.com/ja/compare/chatzy) にあります。

## 非公開ルームを作り直す

1. AChat で **匿名で続ける**、次に **ルームを作成** を選びます。誰も登録は要りません（[匿名ルーム](/features/anonymous-chats)）。
2. 作るときにパスワードを設定します。それがなければ、誰も参加も閲覧もできません。メッセージはそのパスワードを使って各自の端末で暗号化されます（[パスワードと暗号化](/features/passwords-and-encryption)）。
3. リンクとパスワードは別々のメッセージで、または別の手段で送ります。
4. 各自が 1〜24 文字の表示名を選びます。ルーム内で重複はできません。
5. 必要なときはルームでファイルを共有します（[ファイル共有](/features/file-sharing)）。

メッセージは決まった日数、標準で 10 日後に消えます。アカウントを持つ人が[ルームを保持](/features/keep-chats-and-accounts)すれば別です。

## 行ごとに

| 機能 | AChat | Chatzy |
|---|---|---|
| アカウント不要 | はい | はい（<a href="https://www.chatzy.com/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |
| テキストもファイルも送れる | はい | 確認したページに記載なし |
| パスワードで保護 | はい | 一部（<a href="https://www.chatzy.com/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |
| 相手が返信できる | はい | はい（<a href="https://www.chatzy.com/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |

ルームのパスワードは、それを持たない人を入れません。ここでの匿名はアカウント不要という意味で、見えないという意味ではありません。
