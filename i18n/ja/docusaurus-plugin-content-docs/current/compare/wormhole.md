# Wormhole から AChat へ

**Wormhole は、期限切れになるリンクでファイルを共有します。エンドツーエンド暗号化で、最大 10 GB です。** 大きなファイルは Wormhole に置きましょう。AChat は、同じ場所で話もしたいときや、パスワードと小さなファイルを一緒に送りたいときのためのものです。

2026-11-22 確認。比較は [AChat と Wormhole](https://achat.aoneahsan.com/ja/compare/wormhole) にあります。

## 大きいものはあちら、小さいものはこちら

動画の書き出しやディスクイメージは Wormhole に任せます。AChat のファイルサイズ上限はプランで決まり、添付する前に表示されるので、先に確認してください（[ファイル共有](/features/file-sharing)）。

1. **匿名で続ける**、次に **ルームを作成** でルームを作ります（[匿名ルーム](/features/anonymous-chats)）。
2. パスワードを設定し、ルームのメッセージがそれで暗号化されるようにします（[パスワードと暗号化](/features/passwords-and-encryption)）。
3. 小さなものを送ります。設定ファイル、Wi-Fi のパスワード、何に使うかのメモなどです。
4. 大きすぎるものがあれば、Wormhole のリンクをルームに送り、そこで話します。
5. メッセージはルームの決まった日数で削除されます。アカウントを持つ人が保持すれば別です。

## Wormhole のページに書かれていたこと

Wormhole のページはファイルを扱うことを明記しているので、テキストとファイルは「一部」としました。アカウントが必要か、パスワードを付けられるか、返信をもらえるかは書かれていなかったので、その行は省いています。

| 機能 | AChat | Wormhole |
|---|---|---|
| テキストもファイルも送れる | はい | 一部（<a href="https://wormhole.app/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |

AChat のルームならアカウント不要で、パスワードを設定でき、返事も受け取れます。パスワードがなければ、リンクを持つ誰でもルームを読めます。

Wormhole について掲載できる料金は見つかりませんでした。AChat の料金は[料金のページ](https://achat.aoneahsan.com/ja/pricing)にあります。<a href="https://wormhole.app/" target="_blank" rel="noopener noreferrer nofollow">Wormhole のサイト</a> でご自身で確かめてください。
