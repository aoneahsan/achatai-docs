# PairDrop から AChat へ

**PairDrop は、ローカルネットワーク内でピアツーピアにファイルとテキストを送ります。ペアリングした端末や一時的な公開ルームを通じて、インターネット越しにも送れます。** 両方のマシンが同時に動いているなら、それがいちばん直接的な道です。相手のマシンが後からオンラインになり、そのときまでメッセージが残っていてほしい場合に AChat が役立ちます。

最終確認 2026-11-22。並べた比較：[AChat と PairDrop](https://achat.aoneahsan.com/ja/compare/pairdrop)。

## 相手のマシンがまだ動いていないとき

たとえば職場を出るところで、今夜自宅のパソコンでファイルを使いたいとします。今は向こう側で待っているものがないので、ピアツーピアの送信は届きません。

1. 職場のマシンで AChat を開き、**匿名で続ける** でルームを作ります（[匿名ルーム](/features/anonymous-chats)）。
2. パスワードを付けて、後で自分だけが開けるようにします（[パスワードと暗号化](/features/passwords-and-encryption)）。
3. ファイルとメモを入れます（[ファイル共有](/features/file-sharing)）。ルームのリンクは、自宅で見られる場所にコピーしておきます。
4. 自宅でリンクを開き、パスワードを入れて、ファイルを取ります。
5. 削除するか、そのままにします。メッセージは決まった日数で消えます。

## 事実を並べて

| 機能 | AChat | PairDrop |
|---|---|---|
| アカウント不要 | はい | はい（<a href="https://github.com/schlagmichdoch/PairDrop" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |
| テキストもファイルも送れる | はい | はい（<a href="https://github.com/schlagmichdoch/PairDrop" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |
| パスワードで保護 | はい | 確認したページに記載なし |
| 相手が返信できる | はい | 確認したページに記載なし |

AChat のサーバーは、メッセージの期限が来るまでルームを保持します。だからあなたを待てるのです。パスワードがなければ、リンクを持つ誰でも読めます。

確認したページに料金の記載はありませんでした。AChat のプランは[料金のページ](https://achat.aoneahsan.com/ja/pricing)を。PairDrop 自身のサイトは <a href="https://pairdrop.net/" target="_blank" rel="noopener noreferrer nofollow">PairDrop のサイト</a> です。
