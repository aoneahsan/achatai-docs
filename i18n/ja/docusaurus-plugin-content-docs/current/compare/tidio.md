# Tidio から AChat へ

**Tidio は Lyro という AI エージェントのいる顧客チャットで、会話数で料金が決まります。** 顧客に答えるエージェントが欲しいなら、それは Tidio です。AChat は、人が互いに話しに来るページ向けで、会話数を数えたくないときのものです。

最終確認 2026-11-22。比較の全体：[AChat と Tidio](https://achat.aoneahsan.com/ja/compare/tidio)。

## 応答ボットをルームに替える

AChat では、誰かが代わりに答えることはありません。訪問者どうしが答え合うので、それが目的の場所でだけ成り立ちます。

1. 訪問者があなたとではなく互いに話しているページを選びます。それ以外は Tidio のままにします。
2. [ウィジェットのページ](https://achat.aoneahsan.com/ja/widget)で匿名ルームかコミュニティの公開チャンネルを選び、次にレイアウトを選びます（[埋め込みウィジェット](/features/embeddable-widget)）。
3. ルームが細い列に収まるなら、**コンパクト** か **チャットのヘッダーを隠す** をオンにします。
4. そのページにコードを貼ります。
5. 特定の訪問者だけが読むべきなら、ルームにパスワードを付けます。

## Tidio の料金ページから

Tidio の料金ページは、期限のない無料プランを明記しています。確認したページには、ページに置ける既製のチャットや、自分のサーバーでの運用には触れていなかったので、その行は載せていません。

| 機能 | AChat | Tidio |
|---|---|---|
| 期限のない無料プラン | はい | はい（<a href="https://www.tidio.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |

AChat のウィジェットは担当者用の受信箱でも開発者向け SDK でもなく、セルフホストもできません。
