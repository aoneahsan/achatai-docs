# tlk.io から AChat へ

**tlk.io は URL ひとつのウェブチャットルームで、登録不要、自分のサイトに埋め込めます。** 先に何も読まずに使い捨てのルームを 1 つ、という用途ならなかなか勝てません。AChat のルームも同じように始まり、必要なときにはもっと先へ進めます。パスワード、ファイル、誰かがルームを保持することです。

最終確認 2026-11-22。並べた比較：[AChat と tlk.io](https://achat.aoneahsan.com/ja/compare/tlk-io)。

## 同じ習慣に、選択肢がひとつ増える

tlk.io のルームは、みんなに送る URL です。AChat のルームもそうです。

1. AChat を開き、**匿名で続ける**、次に **ルームを作成** を選びます。ルームと、送るためのリンクができます（[匿名ルーム](/features/anonymous-chats)）。
2. リンクを推測できる誰にでも開かれていてはいけないルームなら、作るときにパスワードを設定します。パスワードはルームのメッセージの暗号化にも使われます（[パスワードと暗号化](/features/passwords-and-encryption)）。
3. メッセージだけでなくファイルもルームに置けます（[ファイル共有](/features/file-sharing)）。
4. 各メッセージは決まった日数、標準で 10 日後に削除されます。ルームを残すなら、アカウントを持つ人が[保持します](/features/keep-chats-and-accounts)。
5. サイトに tlk.io を埋め込んでいましたか？ [ウィジェットのページ](https://achat.aoneahsan.com/ja/widget)で AChat のルームも同じようにできます。

## 先方のページとこちら

| 機能 | AChat | tlk.io |
|---|---|---|
| アカウント不要 | はい | はい（<a href="https://tlk.io/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |
| テキストもファイルも送れる | はい | 確認したページに記載なし |
| パスワードで保護 | はい | 確認したページに記載なし |
| 相手が返信できる | はい | はい（<a href="https://tlk.io/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |

パスワードのないルームは、リンクを持つ誰でも読めます。アカウント不要は見えないという意味ではありません。端末は AChat のサーバーに接続しています。
