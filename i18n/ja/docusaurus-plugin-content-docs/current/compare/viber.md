# Viber から AChat へ

**Viber は無料の通話とメッセージを提供し、チャットは端末間で同期されます。** 通話が文字と同じくらい大事なら、Viber は残しましょう。AChat には通話がまったくありません。メッセージを移す人は、電話番号を絡めたくないか、誰でもリンクから参加できるルームが欲しいからです。

最終確認 2026-11-22。比較は [AChat と Viber](https://achat.aoneahsan.com/ja/compare/viber) をご覧ください。

## 両方を使う

Viber は通話用にスマートフォンに残します。メッセージは少しずつ移します。

1. 誰かが登録する前に、ルームを試します。**匿名で続ける** でルームを作り、そのリンクを Viber のチャットに貼ります（[匿名ルーム](/features/anonymous-chats)）。みんな表示名を選んで話せます。アカウントも電話番号も要りません。
2. 残るチャットが欲しくなったら、Google で[ログイン](/getting-started/quick-start)してユーザー名を選びます。
3. 復元キーを保存し、**アカウント** の **デバイス** からほかの端末をリンクします（[端末と復元キー](/features/devices-and-recovery)）。Viber はチャットを同期しますが、AChat が履歴を端末に届けるのは、リンクしたときかキーを使ったときだけです。
4. ルームの人たちに、ユーザー名であなたを追加してもらいます（[個人チャットと連絡先](/features/personal-chats-and-contacts)）。

Viber の履歴は移りません。AChat はほかのアプリのチャットを取り込みません。

## Viber のページからわかること

私たちが読んだかぎり、Viber のページには、電話番号なしで登録できるかどうかも、個人チャットがエンドツーエンド暗号化されるかどうかも書かれていませんでした。その行は省いています。

| 機能 | AChat | Viber |
|---|---|---|
| 新しいデバイスで履歴が戻る | 一部 | 一部（<a href="https://www.viber.com/en/faq/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |

AChat の「一部」は、リンクした端末か復元キーのことです。両方なくすと、私たちを含め誰も履歴を戻せません。

| プラン | 料金 | 出典 |
|---|---|---|
| 通話とメッセージ | 無料 | <a href="https://www.viber.com/en/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a> |

AChat の料金は[料金のページ](https://achat.aoneahsan.com/ja/pricing)にあります。Viber を確かめるなら <a href="https://www.viber.com" target="_blank" rel="noopener noreferrer nofollow">Viber のサイト</a> へ。
