# Telegram から AChat へ

**Telegram はクラウド型のメッセンジャーです。電話番号でログインすれば、チャットはどの端末にもそのままあります。** エンドツーエンド暗号化はシークレットチャットだけです。どこでも全部あることのほうが大事なら、Telegram が合っています。AChat は個人チャットとプライベートグループを標準でエンドツーエンド暗号化し、電話番号を求めることはありません。その代わり、履歴はクラウドではなく端末についていきます。

2026-11-22 確認。並べた比較は [AChat と Telegram](https://achat.aoneahsan.com/ja/compare/telegram) にあります。

## 最初のメッセージの前に

捨てるべき習慣は「どこでログインしても全部ある」です。ログインした端末が手元にあるうちに、初日に端末を設定しましょう。

1. いちばんよく使う端末で [AChat にログイン](/getting-started/quick-start)し、ユーザー名を選びます。Telegram の人はユーザー名に慣れているので、共有の仕方も同じです。
2. **アカウント** の **デバイス** から、もう一台のスマートフォン、タブレット、パソコンをリンクします（[端末と復元キー](/features/devices-and-recovery)）。新しい端末が、ログイン中の端末のコードを読み取ります。
3. 復元キーは、それらの端末以外の場所に保存します。リンクした端末がすべてなくなったとき、履歴を戻すのはこれです。
4. Telegram の連絡先をユーザー名で追加します（[個人チャットと連絡先](/features/personal-chats-and-contacts)）。
5. 大事なグループは、相手が連絡先になってから招待して、**グループ** から作り直します。公開の Telegram チャンネルは AChat の[コミュニティ](/features/groups-and-communities)に近く、こちらはエンドツーエンド暗号化されていません。

Telegram の履歴は Telegram に残ります。AChat はほかのアプリのチャットを取り込みません。

## 項目ごとに

| 機能 | AChat | Telegram |
|---|---|---|
| 電話番号なしで登録 | はい | いいえ（<a href="https://telegram.org/faq" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |
| 個人チャットのエンドツーエンド暗号化 | はい | 一部（<a href="https://telegram.org/faq" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |
| 新しい端末で履歴が戻る | 一部 | はい（<a href="https://telegram.org/faq" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |

その「一部」がトレードオフです。リンクしたほかの端末か復元キーがあれば履歴は戻ります。どちらもなければ、AChat チームを含め誰も復元できません。AChat には音声通話もビデオ通話もありません。
