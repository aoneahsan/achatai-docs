# Session から AChat へ

**Session はあなたに結びつく識別子なしでアカウントを作り、オニオンルーティングでメッセージを送り、新しい端末ではリカバリーパスワードから Account ID を戻します。** それが大事な会話は、Session のままで。AChat のアカウントは Google でログインします。AChat を加える理由は、チャンネルとスレッドのあるコミュニティと、リンクから参加できるルームです。

2026-11-22 確認。並べた比較：[AChat と Session](https://achat.aoneahsan.com/ja/compare/session)。

## 持ってくるもの、残すもの

無理のない分け方は、グループのオープンな話を移し、個人的な会話はそのまま残すことです。

1. アカウントの要らないルームから始めます（[クイックスタート](/getting-started/quick-start)）。**匿名で続ける** でルームを作り、リンクを共有します（[匿名ルーム](/features/anonymous-chats)）。
2. グループに長く続く場所が要るなら、アカウントを持つ人が[コミュニティ](/features/groups-and-communities)を作り、**匿名で参加可** にします。メンバーは表示名のまま参加できます。コミュニティはエンドツーエンド暗号化されていないので、オープンな話向きです。
3. アカウントを作れば、復元キーが手に入ります。Session のリカバリーパスワードが ID に果たす役目に近いですが、こちらで戻るのはメッセージの履歴です（[端末と復元キー](/features/devices-and-recovery)）。端末の外に保存してください。
4. 1 対 1 で話し続けたい人をユーザー名で追加します（[個人チャットと連絡先](/features/personal-chats-and-contacts)）。

Session からは何も取り込まれません。

## 機能ごとに

| 機能 | AChat | Session |
|---|---|---|
| 電話番号なしで登録 | はい | はい（<a href="https://getsession.org/faq" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |
| 個人チャットのエンドツーエンド暗号化 | はい | はい（<a href="https://getsession.org/faq" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |
| 新しいデバイスで履歴が戻る | 一部 | 一部（<a href="https://getsession.org/faq" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |

復元キーとリンクしたすべての端末をなくすと、私たちを含め誰も AChat の履歴を戻せません。AChat には音声通話もビデオ通話もありません。

Session の掲載できる料金は見つかりませんでした。AChat の料金は[料金のページ](https://achat.aoneahsan.com/ja/pricing)に。<a href="https://getsession.org" target="_blank" rel="noopener noreferrer nofollow">Session のサイト</a> でご自身で確かめてください。
