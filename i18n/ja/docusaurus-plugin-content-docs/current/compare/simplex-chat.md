# SimpleX Chat から AChat へ

**SimpleX Chat にはユーザー識別子がまったくありません。ランダムなものさえありません。** それが目的なら、ここにそれを超えるものはありません。AChat はあえて逆を行きます。人はユーザー名であなたを見つけます。その上に、リンクで共有したりサイトに置いたりできる匿名ルームがあります。

最終確認 2026-11-22。比較の全体：[AChat と SimpleX Chat](https://achat.aoneahsan.com/ja/compare/simplex-chat)。

## 見つけられてもいい名前を選ぶ

SimpleX では、連絡先はどれも使い捨てのリンクから始まります。AChat で手渡すのはユーザー名なので、少し考えてから決めましょう。

1. [ログイン](/getting-started/quick-start)し、英字、数字、ドット、アンダースコアで 3〜24 文字のユーザー名を選びます。いつでも変えられます。変えると、古い名前はほかの人が使えるようになります。
2. 慣れた方法で渡します。招待リンクか QR コードです（[個人チャットと連絡先](/features/personal-chats-and-contacts)）。まだ承認していない人からのメッセージは **メッセージリクエスト** で待っています。
3. 復元キーを保存します（[端末と復元キー](/features/devices-and-recovery)）。リンクした端末が残っていないとき、履歴が戻る唯一の方法です。
4. ユーザー名に触れさせたくない会話には、代わりに[匿名ルーム](/features/anonymous-chats)を使います。[ウィジェットのページ](https://achat.aoneahsan.com/ja/widget)でサイトに置けます。

チャットは SimpleX に残ります。AChat はほかのアプリから取り込みません。

## 記載どおりに

| 機能 | AChat | SimpleX Chat |
|---|---|---|
| 電話番号なしで登録 | はい | はい（<a href="https://simplex.chat/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |
| 個人チャットのエンドツーエンド暗号化 | はい | はい（<a href="https://simplex.chat/faq/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |
| 新しい端末で履歴が戻る | 一部 | はい（<a href="https://simplex.chat/faq/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |

AChat では、履歴が戻るのはリンクした端末か復元キーからだけで、それがなければ AChat チームを含め誰も戻せません。AChat には音声通話もビデオ通話もありません。

確認したページに料金の記載はありませんでした。AChat の料金は[料金のページ](https://achat.aoneahsan.com/ja/pricing)に。先方の料金は <a href="https://simplex.chat" target="_blank" rel="noopener noreferrer nofollow">SimpleX Chat のサイト</a> にあります。
