# Chatwoot から AChat へ

**Chatwoot はオープンソースのカスタマーサポート基盤で、セルフホストするか、担当者単位で料金を払います。** 自分のサーバーでサポートを運用することは、残る十分な理由です。AChat はセルフホストできません。AChat は、何も運用したくなく、訪問者が担当者ではなく互いに話しているときのためのものです。

2026-11-22 確認。比較は [AChat と Chatwoot](https://achat.aoneahsan.com/ja/compare/chatwoot) をご覧ください。

## セルフホストのインスタンスを畳む

Chatwoot のサーバーがおもに訪問者の雑談を載せているなら、保守の手間のほうがルームより重いかもしれません。

1. まず Chatwoot から必要なものをすべてエクスポートします。AChat には何も取り込まれません。
2. [ウィジェットのページ](https://achat.aoneahsan.com/ja/widget)でルームを作るか、コミュニティの公開チャンネルを選びます（[埋め込みウィジェット](/features/embeddable-widget)）。面倒を見るサーバーもデータベースも更新もありません。
3. Chatwoot のウィジェットが動いていた場所にコードを貼ります。
4. アカウントでルームを保持します。標準の履歴期間を超えて残り、表示を許可するサイトも登録できます。
5. 新しいルームがしばらく動いてから、インスタンスを停止します。
