# Threema から AChat へ

**Threema は電話番号もメールも求めず、ID とチャットを別々にバックアップします。** 登録時に個人情報を一切渡さないことが選んだ理由なら、そのまま使い続けてください。AChat のアカウントは Google でログインするので、そこまで何もなしではありません。AChat が加えるのは、誰でもリンクで参加できるルームと、サイトに置けるチャットです。

2026-11-22 確認。並べた比較は [AChat と Threema](https://achat.aoneahsan.com/ja/compare/threema) をご覧ください。

## 入り方は 2 つ

まず AChat にどこまで渡すかを決めましょう。それで始める場所が変わります。

**何も渡さない。** **匿名で続ける** を選び、ルームを作ります（[匿名ルーム](/features/anonymous-chats)）。そのルーム用の表示名を選び、リンクを共有します。特定の人だけが読むべきなら、パスワードを付けます。

**アカウントを作る。** [Google でログイン](/getting-started/quick-start)してユーザー名を選びます。人はそれであなたを見つけるので、Threema ID とよく似ています。それから：

1. 復元キーを保存します。Threema は ID をバックアップしますが、AChat では履歴を戻すのは復元キーか、リンクしたほかの端末です（[端末と復元キー](/features/devices-and-recovery)）。
2. Threema の連絡先に、ユーザー名か招待リンクを送ります（[個人チャットと連絡先](/features/personal-chats-and-contacts)）。
3. サイトを運営しているなら、[ウィジェットのページ](https://achat.aoneahsan.com/ja/widget)でサイト用のルームを作ります。

Threema のチャットは移りません。AChat はほかのアプリのチャットを取り込みません。
