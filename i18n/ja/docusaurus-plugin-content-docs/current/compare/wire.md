# Wire から AChat へ

**Wire はすべてのプランでメッセージをエンドツーエンド暗号化し、1 人あたりで料金を設定し、5 人までのチームは無料です。** ビジネスチーム向けに買うなら、まさにそのための製品です。AChat は友人や家族とのチャット用で、誰でもリンクで参加できる匿名ルームもあります。

2026-11-22 確認。比較のページは [AChat と Wire](https://achat.aoneahsan.com/ja/compare/wire) です。

## 小さな Wire チームから AChat へ

5 人の上限内で Wire for Free を使っている家族や友人グループ向けです。

1. 一人ひとりが [AChat にログイン](/getting-started/quick-start)し、ユーザー名を選びます。電話番号は聞かれません。
2. ユーザー名か招待リンクで、互いを連絡先に追加します（[個人チャットと連絡先](/features/personal-chats-and-contacts)）。
3. 誰か一人が[グループ](/features/groups-and-communities)を作り、ほかの人を招待します。Wire の会話と同じく、エンドツーエンド暗号化されています。
4. それぞれが自分の復元キーを保存します（[端末と復元キー](/features/devices-and-recovery)）。ほかの誰もあなたの代わりに履歴を戻せません。
5. 輪の外の人には、追加する代わりに[匿名ルーム](/features/anonymous-chats)をリンクで共有します。

Wire の会話は Wire に残ります。AChat はほかのアプリのチャットを取り込みません。

## Wire の料金ページによると

Wire の料金ページはエンドツーエンド暗号化を明記しています。電話番号なしで登録できるか、新しい端末で履歴が戻るかは書かれていないので、その行は省いています。

| 機能 | AChat | Wire |
|---|---|---|
| 個人チャットのエンドツーエンド暗号化 | はい | はい（<a href="https://wire.com/en/pricing" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |

AChat は電話番号を求めません。履歴はリンクした端末か復元キーから戻り、どちらもなければ私たちを含め誰も戻せません。AChat には音声通話もビデオ通話もありません。

| プラン | 料金 | 出典 |
|---|---|---|
| Wire for Free | 無料 | <a href="https://wire.com/en/pricing" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a> |
| Wire for SMB | 1 人あたり月 €7.45（年払い） | <a href="https://wire.com/en/pricing" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a> |
| Wire for SMB | 1 人あたり月 €8.94（月払い） | <a href="https://wire.com/en/pricing" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a> |

AChat のプランは[料金のページ](https://achat.aoneahsan.com/ja/pricing)に。Wire のものは <a href="https://wire.com" target="_blank" rel="noopener noreferrer nofollow">Wire のサイト</a> にあります。
