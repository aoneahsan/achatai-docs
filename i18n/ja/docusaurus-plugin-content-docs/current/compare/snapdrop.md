# Snapdrop から AChat へ

**Snapdrop はアカウント不要のファイル転送で、LimeWire が保管し、アカウントなしで 1 回最大 4 GB です。** 登録なしで大きなファイルを送れるのが強みです。AChat は、ファイルに加えてメッセージも送りたいときや、ルームにパスワードを付けたいときのためのものです。

2026-11-22 確認。比較は [AChat と Snapdrop](https://achat.aoneahsan.com/ja/compare/snapdrop) にあります。

## ファイルと、それについての一言

1. 大きな転送を移す前に、AChat のプランで送れるファイルサイズを確認します。AChat は添付する前に表示します（[ファイル共有](/features/file-sharing)）。それを超えるなら、Snapdrop が今でも合った道具です。
2. 送る側のマシンで AChat を開き、ルームを始めます。アカウントは不要です（[匿名ルーム](/features/anonymous-chats)）。
3. パスワードを付けます（[パスワードと暗号化](/features/passwords-and-encryption)）。
4. ファイルを送り、それぞれ何のためのものかを同じルームに書きます。
5. もう一方のマシンの人はリンクを開き、パスワードを入れてダウンロードし、足りないものがあれば返信できます。

## 並べてみると

| 機能 | AChat | Snapdrop |
|---|---|---|
| アカウント不要 | はい | はい（<a href="https://snapdrop.net/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |
| テキストもファイルも送れる | はい | 一部（<a href="https://snapdrop.net/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |
| パスワードで保護 | はい | 確認したページに記載なし |
| 相手が返信できる | はい | 確認したページに記載なし |

AChat のメッセージはルームの決まった日数で削除されます。アカウントを持つ人がルームを保持すれば別です。匿名はアカウント不要という意味で、見えないという意味ではありません。
