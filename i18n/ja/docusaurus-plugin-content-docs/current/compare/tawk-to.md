# tawk.to から AChat へ

**tawk.to はサイト向けの無料ライブチャットで、有料にするとブランド表示を外せます。** チームが顧客に答え、ヘルプセンターやチケット管理も一緒に欲しいなら、それは tawk.to の仕事で、AChat にはできません。AChat のウィジェットはルームです。訪問者はそこで、サポートの担当者を待たずに互いに話します。

最終確認 2026-11-22。並べた比較は [AChat と tawk.to](https://achat.aoneahsan.com/ja/compare/tawk-to) にあります。

## 置き換えか、2 つ目のウィジェットか

たいていは 2 つ目です。サポートの質問には今も答える人が必要なので、お問い合わせやヘルプのページには tawk.to を残しましょう。AChat は、訪問者どうしが話す場所に置きます。イベントのページ、講座、ファンサイトなどです。

1. [ウィジェットのページ](https://achat.aoneahsan.com/ja/widget)を開き、小文字、数字、ハイフンで 8〜20 文字のルーム ID を選びます。ルームは、誰かが初めてウィジェットを開いたときに作られます（[埋め込みウィジェット](/features/embeddable-widget)）。
2. 決まった大きさのチャットなら **ページの中**、隅のボタンからパネルでチャットを開くなら **チャットボタン** を選びます。
3. プレビューを見てから、コードをページにコピーします。
4. アカウントでルームを保持し、表示を許可するサイトを最大 20 件まで登録します。サイトを登録するまでは、どのサイトでもあなたのルームを表示できます。
5. 訪問者全員に読まれてはいけないルームなら、パスワードを設定します。

## 両方を同じ行で

| 機能 | AChat | tawk.to |
|---|---|---|
| 期限のない無料プラン | はい | はい（<a href="https://www.tawk.to/pricing/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |
| ページに置ける既製のチャット | はい | はい（<a href="https://www.tawk.to/pricing/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |
| 自分のサーバーで運用 | いいえ | 確認したページに記載なし |

AChat のウィジェットの裏に担当者用の受信箱はなく、開発者向け SDK でもありません。パスワードがなければ、ページにいる誰でもルームを読めます。

| プラン | 料金 | 出典 |
|---|---|---|
| ライブチャット | 無料 | <a href="https://www.tawk.to/pricing/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a> |
| ブランド表示の削除 | 月 $29 | <a href="https://www.tawk.to/pricing/" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a> |

AChat のプランは[料金のページ](https://achat.aoneahsan.com/ja/pricing)に。tawk.to のものは <a href="https://www.tawk.to" target="_blank" rel="noopener noreferrer nofollow">tawk.to のサイト</a> でご確認ください。
