# Sendbird から AChat へ

**Sendbird は月間アクティブユーザーで料金が決まるアプリ内チャットで、無料トライアルがあります。** チャットが自社製品の一部で、そのための予算があるなら、Sendbird はそのために作られています。AChat はもっと小さな要望向けです。ページにルームを 1 つ置き、始めるのにお金を払いたくない場合です。

最終確認 2026-11-22。全体の比較は [AChat と Sendbird](https://achat.aoneahsan.com/ja/compare/sendbird)。

## トライアルが請求に変わる前に

Sendbird のプランは年払いで月 $349 からです。トライアルで、必要なのは訪問者が話す場所だけだとわかったなら、まずこちらを試してください。

1. トライアルの目的を書き出します。自社のログイン済みユーザーどうしのメッセージなら、Sendbird の評価を続けてください。AChat のウィジェットはそのための SDK ではありません。
2. 公開ルームだったなら、AChat の無料プランで[ウィジェットのページ](https://achat.aoneahsan.com/ja/widget)から作ります（[埋め込みウィジェット](/features/embeddable-widget)）。
3. トライアルのチャットがあった場所にコードを貼ります。
4. 訪問者がルームを保持できるようにするなら、**ログインを提供** をオンにします。ログインは新しいタブで開き、チャットするだけなら不要です。
5. 招待した人のあいだに留めたいルームなら、パスワードを付けます。

## Sendbird の料金ページによると

料金ページには、期限のない無料プランはないと書かれています。確認したページには、ページに置ける既製のチャットや、自分のサーバーで運用できる版があるかは書かれていなかったので、その行は載せていません。

| 機能 | AChat | Sendbird |
|---|---|---|
| 期限のない無料プラン | はい | いいえ（<a href="https://sendbird.com/pricing/chat" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |

AChat はホスト型のみで、ウィジェットは既製のルームです。SDK でも担当者用の受信箱でもありません。
