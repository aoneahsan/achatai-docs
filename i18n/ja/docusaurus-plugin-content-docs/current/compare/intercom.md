# Intercom から AChat へ

**Intercom は席数で料金が決まるカスタマーサービスのソフトウェアで、AI エージェントの Fin は成果ごとに課金されます。** AI に先に答えさせたいサポートチームは Intercom に残るべきです。AChat はそのどれも置き換えません。AChat が出せるのはページ上のルームで、そもそもサポートデスクが要らなかった場合のためのものです。

2026-11-22 確認。比較は [AChat と Intercom](https://achat.aoneahsan.com/ja/compare/intercom) をご覧ください。

## ルームで足りる場所

正直な見分け方は、チームの誰かが Intercom の会話を読んでいるかどうかです。読んでいるなら、席の料金を払い続けてください。

1. Intercom が出ているページを書き出します。訪問者がおもに互いに話しているページや、チームの誰も返信していないページに印を付けます。
2. それらのページ用に、[ウィジェットのページ](https://achat.aoneahsan.com/ja/widget)でルームか公開チャンネルを作ります（[埋め込みウィジェット](/features/embeddable-widget)）。
3. ページの隅から開きたいなら **チャットボタン** を選びます。
4. コードを貼り、チームが働く場所には Intercom を残します。
5. アカウントを持つ人にルームを保持してもらうと、表示できるサイトを絞れます。

## Intercom のページに書かれていなかったこと

Intercom のページで、期限のない無料プラン、ページに置ける既製のチャット、自分のサーバーでの運用を確認しました。3 つとも書かれていなかったので、機能の表はありません。<a href="https://www.intercom.com" target="_blank" rel="noopener noreferrer nofollow">Intercom のサイト</a> に答えがあるかもしれません。

こちら側では、AChat には無料プランと既製のウィジェットがあり、セルフホストはできません。ウィジェットは担当者用の受信箱ではなく、パスワードがなければページにいる誰でもルームを読めます。
