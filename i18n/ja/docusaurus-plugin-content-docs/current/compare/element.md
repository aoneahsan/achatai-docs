# Element から AChat へ

**Element は組織にチャットを販売しています。無料の Community 版に加え、席数またはデプロイ単位で価格が決まる Enterprise と Sovereign があります。** 組織のチャットを運用していて自前のデプロイが欲しいなら、このページは当てはまりません。AChat は自分のサーバーでは動かせません。これは別のケース、つまり Element で友人や家族と連絡を取っていて、何も設定せずにブラウザから始めたい人のためのものです。

2026-11-22 確認。全体の比較は [AChat と Element](https://achat.aoneahsan.com/ja/compare/element)。

## 個人的な輪を移す

1. 最新のブラウザで [achat.aoneahsan.com](https://achat.aoneahsan.com) を開き、[ログイン](/getting-started/quick-start)します。設定は何も要りません。ユーザー名を選びます。電話番号は聞かれません。
2. 復元キーを保存します（[端末と復元キー](/features/devices-and-recovery)）。表示は 1 回だけです。
3. よく話す数人を、ユーザー名、招待リンク、QR コードで追加します（[個人チャットと連絡先](/features/personal-chats-and-contacts)）。
4. 小さな Element のルームは、それぞれ AChat の[グループ](/features/groups-and-communities)にします。グループはエンドツーエンド暗号化されます。リンクから参加した人は、管理者の承認を待ちます。
5. 大きく開かれたルームは、チャンネルのあるコミュニティのほうが合います。コミュニティはエンドツーエンド暗号化されていません。

Element のメッセージ履歴は Element に残ります。AChat はほかのアプリのチャットを取り込みません。

## Element の料金ページに書かれていること

Element の料金ページを読みました。電話番号なしで登録できると書かれています。個人チャットのエンドツーエンド暗号化や、新しい端末で履歴が戻るかについてはどちらとも書かれていなかったので、その行は省いています。

| 機能 | AChat | Element |
|---|---|---|
| 電話番号なしで登録 | はい | はい（<a href="https://element.io/en/pricing" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a>） |

AChat では、個人チャットはエンドツーエンド暗号化されます。リンクした端末か復元キーで履歴は戻り、それがなければ私たちを含め誰も戻せません。音声通話もビデオ通話もありません。

| プラン | 料金 | 出典 |
|---|---|---|
| Community | 無料 | <a href="https://element.io/en/pricing" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a> |
| Enterprise | 記載なし | <a href="https://element.io/en/pricing" target="_blank" rel="noopener noreferrer nofollow">先方のページ</a> |

AChat のプランは[料金のページ](https://achat.aoneahsan.com/ja/pricing)へ。Element のものは <a href="https://element.io" target="_blank" rel="noopener noreferrer nofollow">Element のサイト</a> へ。
