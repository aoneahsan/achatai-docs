# 開発者向けの AChat

**あなたの AChat アカウントには、アプリの外から、あなた自身が、あなたの条件でアクセスできます。** スクリプトでステータスを投稿したりブロックリストをそろえたり、Claude にどのオープンなルームに新しいメッセージがあったかを聞いたり、誰かが連絡先リクエストを送った瞬間にあなたのサーバーが知ったりできます。Free を含むすべてのプランにあり、どの経路も届くのは 1 つのアカウント、あなたのものだけです。

## どれが必要ですか？

| したいこと | 使うもの |
|---|---|
| 自分のスクリプトやサービスでアカウントを読んだり変えたりする | [アクセスキー](./access-keys.md)と [API](./api.md) |
| Claude、ChatGPT、Claude Code、Cursor にアカウントを扱わせる | [アシスタント接続](./assistants.md) |
| 何か変わったら、毎分問い合わせなくてもサーバーに知らせる | [Webhook](./webhooks.md) |
| Google ログインのあとにコードを求め、盗まれた Google アカウントだけでは入れないようにする | [2 段階ログイン](./two-step-sign-in.md) |

4 つともアプリの中にあります。キー、接続中のアプリ、Webhook は **アカウント › ほかのアプリ**、2 段階ログインは **アカウント › セキュリティ** です。

## ほかのアプリが届く範囲 {#what-other-apps-can-reach}

アプリが入れるのは、あなたが作ったキーか、あなたが承認した接続を通じてだけです。どちらでも、3 つのルールが守られます。

| | 対象 | AChat の外から |
|---|---|---|
| **あなたのもの** | プロフィール、設定、ステータスの投稿、ブロックリスト | 読み取りと変更。削除は別の権限で、チェックしないかぎりオフです |
| **ほかの人と共有するもの** | 連絡先、チャット、オープンなルームのメッセージ、コミュニティ、チャンネル | 読み取りのみ。どのアプリもそこに投稿、削除、招待はできません |
| **エンドツーエンド暗号化されたもの** | 個人チャット、グループ、パスワード付きのルーム | 一切なし。アプリに見えるのはチャットの名前とあなたが参加していることだけで、メッセージは見えません |

最後のルールは設定ではありません。個人チャット、グループ、パスワード付きのルームのメッセージはあなたの端末で鍵がかけられ、AChat のサーバーは読めないので、どのキーやアシスタントにも読めません。端末の鍵、復元キー、2 段階のコードも同じです。[セキュリティと暗号化](/concepts/security-and-encryption)をご覧ください。

## プランで使える量 {#what-your-plan-allows}

| | Free | Pro | Team / Family |
|---|---|---|---|
| 同時に持てるアクセスキー | 5 | 25 | 50 |
| 1 日の API とアシスタントのリクエスト | 5,000 | 50,000 | 100,000 |
| 同時に持てる Webhook のアドレス | 3 | 20 | 40 |
| 同時に持てるアシスタント接続 | 3 | 10 | 25 |

これは現在の初期値です。各プランの数値は AChat チームが決めるので、**アカウント › ほかのアプリ › プランに対する使用量** で、あなたに当てはまる値と今日の件数を確認できます。リクエストは UTC の午前 0 時から、アカウントのすべてのキーとアシスタントを合わせて数えます。どのプランでも、キーや接続ごとに 1 分あたり 120 リクエストまでなので、暴走したスクリプトは 1 日分を使い切る前に止まります。

## カレンダーフィードはありません

AChat にはカレンダーに入れるべき日付つきのものがないので、購読するカレンダーフィードはありません。
