# セキュリティと暗号化のモデル

**AChat がエンドツーエンド暗号化を約束しているのは、個人チャット、非公開グループ、パスワードつきのルームです。コミュニティとそのチャンネル、オープンなルーム、ステータスについては約束していません。**

## ここでいうエンドツーエンド暗号化とは

- それらのチャットのメッセージは、参加者のデバイスでしか読めません。
- AChat はそれを、サーバーも管理者も読めない形で保存します。
- AChat はあなたのメッセージキーのコピーを持たないので、履歴を読むことも復元することもできません。
- プッシュ通知に入るのはチャット名か送信者名だけで、本文は入りません。
- 検索するのは、すでにデバイスにあるメッセージだけです。
- ほかのアプリも読めません。アクセスキー、AI アシスタント、Webhook に見えるのは暗号化されたチャットの名前とメンバーだけで、メッセージは見えません。[開発者向け AChat](/developers#what-other-apps-can-reach)をご覧ください。

## キー、デバイス、復元

- **リンクしたデバイス** はそれぞれあなたのキーを持ちます。デバイスを承認すると、そのデバイスは履歴を含むチャットを読み、あなたとしてメッセージを送れます。リンクの確認にはセキュリティコードを比べてください。
- **デバイスを外す** と、新しいメッセージは届かなくなり、ログアウトされます。すでに保存された内容はそのデバイスに残ります。
- **グループはメンバーが変わると新しいキーになる** ので、抜けた人は新しいメッセージを読めません。
- **復元キー** はあなたが保管します。Google のログインだけでは履歴を復元できません。キーとすべてのリンクしたデバイスをなくすと、誰にも復元できません。

## ルームのパスワード

パスワードつきのルームは、そのパスワードを使ってメッセージをあなたのデバイスで暗号化します。続けて何度も間違えると、次に試すまで待つ必要があります。設定したパスワードは、デバイス上で強さを確認してアドバイスが出ます。

## 非公開の位置の記録

個人チャット、非公開グループ、パスワードつきのルームでは、[デバイスと位置の記録](/features/location-history)はエンドツーエンド暗号化されます。見られるのはチャットの監査パスワード（またはルームのパスワード）を入力したメンバーだけで、AChat の管理者には開けません。

## 暗号化にできないこと

- **メッセージを読んだ人はコピーできます。** チャットの参加者は、開いているあいだの消えるメッセージや 1 回だけ表示のメッセージも含め、何でもコピー、保存、スクリーンショットできます。あとで削除してもそのコピーには届きません。
- **オープンなチャットはオープンです。** オープンなルームのリンクを持つ人は誰でも読めます。コミュニティとそのチャンネルはエンドツーエンド暗号化されていません。
- **匿名でも追跡できないわけではありません。** デバイスはどのウェブサイトとも同じように AChat のサーバーに接続し、ホスト側は IP アドレスなどの接続情報を記録します。
- **ロックされていない端末をなくすのは危険です。** 手にした人は、そこに保存されたものを開けます。[このデバイスのプライバシー](/features/privacy-on-this-device)で、プライバシー画面と「このデバイスから消去」を説明しています。
- **一度見られたものは取り消せません。** あとから設定やポリシーを変えても、読まれ、コピーされ、保存され、書き出されたものは戻りません。

## モデレーションと暗号化

暗号化されたチャットのメッセージを AChat のモデレーターが見るのは、そのチャットの誰かが報告し、報告に添えて送ったときだけです。[管理者による監督](/concepts/admin-oversight)をご覧ください。
