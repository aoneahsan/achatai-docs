# データ、プライバシー、削除

**このページは AChat の[プライバシーのページ](https://achat.aoneahsan.com/ja/privacy)の要約で、正式なのはプライバシーのページです。内容が違う場合はプライバシーのページが優先されます。** AChat を運営し、扱うデータの取り扱いを決めているのは、パキスタンのラホールにある AChat チームです。

## AChat が集めるもの

- **アカウント：** Google アカウントの名前、メールアドレス、写真と、あなたのユーザー名。AChat が電話番号を聞くことはありません。
- **匿名ルーム：** ルームごとに決めた表示名、そこで送ったメッセージ、そのルームで使うデバイス ID。
- **チャット：** あなたのメッセージ、ファイル、ボイスメッセージ、ステータスと、各チャットの参加者。
- **連絡先：** 承認した人、リクエスト、ブロックした人。
- **位置：** [デバイスと位置の記録](/features/location-history)がオンのチャットで、あなたが同意したあとだけ。
- **報告：** 報告するときに選んだメッセージ。
- **支払い：** 選んだプランと、AChat チームが支払いを確認するのに必要なもの（受付番号など）。カード決済では、サブスクリプションの状態、プラン、期間、席数、金額、日付を保存し、カード番号や請求先の名前・住所は受け取りません。
- **問い合わせフォーム：** 名前、メールアドレス、メッセージ。
- **エラーレポートと利用分析：** メッセージの内容、パスワード、キー、正確な位置は含みません。
- **画面の録画：** 公開ページ 2 つのマスクした録画だけで、チャットは録画しません。

## ほかに扱うところ

| サービス | 提供元 | 受け取るもの |
|---|---|---|
| ログイン | Google | 名前、メールアドレス、写真はここから来ます |
| エラーレポート | Sentry | 何が起きたか。メッセージの内容、パスワード、キー、正確な位置は含みません |
| 利用分析 | Amplitude、およびオンにしたあとの Google Analytics 4 | AChat の使われ方。同じものは除きます |
| 画面の録画 | Microsoft Clarity | 2 つのページだけのマスクした録画：「AChat に参加」と「ルームの保管」。文字と画像は隠されます。チャット、ルーム、連絡先、ステータスは録画しません |
| プッシュ通知 | OneSignal、Android では Google Firebase Cloud Messaging | プッシュトークンと、通知ごとのチャット名か送信者名。本文は含みません |
| カード決済（カードで支払う場合） | Polar Software, Inc.（[プライバシーポリシー](https://polar.sh/legal/privacy)） | 支払いページを開くときに送られる、アカウントのメールアドレスと AChat のアカウント ID。名前、請求先の国や住所、カード情報は Polar が自分のページで集めます |
| ホスティング、データベース、ファイル保存、メール | [プライバシーのページ](https://achat.aoneahsan.com/ja/privacy)に記載 | アカウント、チャット、ファイル、AChat が送るアカウントのメール |

AChat は広告ネットワークの広告を表示せず、個人データを売りません。AChat チームが作ったほかのアプリを紹介することがあります。

## どれくらい保存するか

| 対象 | 期間 |
|---|---|
| 個人チャットとグループのメッセージ | 誰かが削除するか、チャットの消えるタイマーまで |
| 匿名ルームのメッセージ | それぞれ送信から決められた日数（初期設定は 10 日）、または保管期限まで |
| ゴミ箱のチャットとメッセージ | 決められた日数（初期設定は 30 日）、その後完全に削除 |
| ステータス | 24 時間 |
| 位置の記録 | チャットがゴミ箱から完全に削除されるか、期限が切れるまで |
| プロフィールとユーザー名 | アカウントを削除するまで |
| 画面の録画 | 30 日。Microsoft が残す一部のサンプルは最長 9 か月。ヒートマップと、チームがお気に入りにした録画は 9 か月 |
| 問い合わせ、報告、支払い記録、エラーレポートと分析、バックアップ | 決められた期間。プライバシーのページに記載 |
| デバイスに保存されたチャット | そのデバイスでログアウトするか、容量を空けるまで |
| ダウンロードした書き出しファイル | あなたがそのファイルを持っている限り |

## あなたが管理できること

- **書き出し：** プロフィール、連絡先、このデバイスで読めるチャットをまとめた 1 つのファイル。あなたのデバイスで作られます。
- **オンライン状態と既読表示：** [個人チャットと連絡先](/features/personal-chats-and-contacts)をご覧ください。
- **ステータスの公開範囲：** 初期設定は承認した連絡先で、人を個別に含めたり外したりできます。
- **ほかのアプリ：** アクセスキーを作るか接続を承認しない限り、AChat の外からアカウントに届くものはなく、どちらもいつでも外せます。エンドツーエンド暗号化されたメッセージには決して届きません。[開発者向け AChat](/developers)をご覧ください。
- **利用分析と画面の録画：** 全員オンで、オフにするスイッチはありません。最初に開いたとき、画面下部のお知らせバーで一度だけ伝えます。分析にはメッセージの内容、パスワード、キー、正確な位置は含まれず、録画は文字と画像を隠した公開ページ 2 つだけです。
- **修正と削除：** プロフィールやユーザー名を編集するか、アカウントを削除します。それ以外のことは、[お問い合わせページ](https://achat.aoneahsan.com/ja/contact)から AChat チームに連絡してください。

## アカウントの削除

削除はすぐに実行され、元に戻せません。送ったメッセージは受け取った人の手元に残り、削除されたアカウントからのものと表示されます。手順と詳細：[保管したルームとアカウント](/features/keep-chats-and-accounts#delete-your-account)。

## 取り消せないもの

すでに読まれ、コピーされ、保存され、書き出されたもの。あとから設定やポリシーを変えても戻りません。

## 年齢

AChat を使うには 16 歳以上である必要があります。
