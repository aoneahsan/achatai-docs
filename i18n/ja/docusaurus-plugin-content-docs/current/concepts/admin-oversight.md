# 管理者による監督

**AChat の管理パネルに表示されるのはチャットの詳細だけで、メッセージは表示されません。ただし報告者が報告に添えた内容は除きます。** 管理者の変更はすべて操作ログに残り、管理者を含め誰も編集・削除できません。

## 管理者に見えるもの

- **チャット：** 人数、日付、設定だけ。暗号化されたチャットは詳細だけが一覧に出ます。
- **報告：** 人、ルーム、コミュニティについてのもの。管理者に見えるのは報告者が送ることを選んだ内容だけで、誰が送ったかは見えません。
- **非公開の位置の記録：** 管理者には開けません。

## 管理者にできること {#what-admins-can-do}

| 操作 | 結果 |
|---|---|
| 報告されたメッセージを削除 | チャットの全員から削除されます。元に戻せるのは AChat の管理者だけ |
| ルームを制限 | 新しい人はリンクから開くことも参加することもできません。すでにいるメンバーはチャットを続けられます |
| アカウントを停止 | 管理者が解除するまで、その人はログインも送信もできません。チャットは保管され、問い合わせページから見直しを求められます |
| プランや上限を付与 | アカウントにプランやカスタム上限を設定します。それぞれに終了日があります |
| ルームを無期限保管の対象にする | 対象ルームに限られた無期限保管の付与が、そのルームにも及ぶようにします |
| ある人の無期限保管を設定 | その人がルームを無期限に保管できるかを選びます：**不可**、**指定されたルームのみ**、**どのルームでも**、**すべてのルーム、自動で**。不可以外は理由が必要です。変更しても、すでに無期限保管のルームが短くなることはありません |
| コミュニティを成人向けに指定 | コミュニティの 18+ の指定を変えます |
| 依頼に応じてアカウントを削除 | ログインできない人のために、そのアカウントの Google メールから届いた依頼で行います |

管理者は銀行振込の支払いを手作業で確認し、問い合わせ受信箱にも対応します。

[カード決済](/features/plans-and-pricing#card)については、新規のカード販売の開始・停止、Polar の商品とプラン・期間の対応づけ、プランの年額の設定、更新に失敗したあとプランを残す期間の設定ができます。カード販売を止めても、すでにあるサブスクリプションは終わりません。変更はそれぞれ操作ログに残ります。

## 管理者が決める上限

管理者は管理パネルで AChat の上限を決めます。ゴミ箱に残る期間や匿名ルームのメッセージが残る期間などです。そのうち 2 つが各デバイスの[検索](/features/search-and-history)の範囲を決めます。**検索するチャット** は検索の対象になるチャットの上限（ピン留めを先に、次に新しい順）、**検索するメッセージ** はチャットごとに対象になるメッセージの上限（新しい順）です。各欄には許された範囲の整数だけを入れられます。

## グループとコミュニティの中のモデレーション

まず動くのは、その場を運営している人たちです。グループの管理者はメンバーを外したり、どのメッセージでも削除したりできます。コミュニティの管理者は報告と参加禁止を扱います。[グループとコミュニティ](/features/groups-and-communities)をご覧ください。

## 操作ログ

管理者の変更はすべて、誰がいつ行ったかとともに表示されます。無期限保管の変更では、変更前と後の設定が表示されます。記録は誰も編集・削除できません。チャットのデバイスと位置の記録はこのログに含まれません。

## 見直し

停止や参加禁止が間違っていると思ったら、[お問い合わせページ](https://achat.aoneahsan.com/ja/contact)から AChat チームに見直しを依頼してください。最終的な判断はチームが行い、見直しを求めても結果は保証されません。
