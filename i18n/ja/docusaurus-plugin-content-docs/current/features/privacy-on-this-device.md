# この端末でのプライバシー

**これらの設定は、ログインしているかどうかに関係なく、この端末にだけ適用されます。チャット相手の側は何も変わりません。**

## 設定

| 設定 | すること | 限界 |
|---|---|---|
| **プライバシー画面** | ほかのタブやアプリに切り替えたときと、90 秒操作がないときに AChat をぼかします | いずれかのキーを押すかタップするとチャットがまた表示されます |
| **目立たないタブ名** | ほかのタブにいるあいだ、このタブは「新しいタブ」という名前で、普通のアイコンを表示します | ブラウザの履歴には AChat と残ります |
| **コピーしたリンクとキーを消去** | 招待リンク、ルームのリンク、復元キーをコピーしてから 45 秒後に、クリップボードから消去します | キーボードやシステムによっては独自のクリップボード履歴を持っていて、そこには届きません |

キーボードショートカットで画面をすぐ隠すこともできます。

## このデバイスから消す

チャットのメニューの **このデバイスから消す** は、そのチャットがこの端末に保存しているものを消してから、チャットを閉じます：

- 送っていない下書き
- この端末に保存したルームのパスワード
- 位置の記録のためのパスワード確認
- この端末で表示した翻訳
- この端末の検索にあるそのチャットの項目

誰にとってもチャットやメッセージが削除されるわけではありません。ほかの端末やほかの人は写しを持ち続け、チャットを開けばメッセージをまた読み込みます。

AChat が何を集め、誰が受け取るかは[データ、プライバシー、削除](/concepts/data-privacy-and-deletion)をご覧ください。
