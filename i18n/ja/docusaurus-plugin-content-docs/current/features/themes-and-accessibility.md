# 外観、言語、ショートカット

**テーマ、色、文字サイズ、動きは 1 つの外観パネルにまとまっているので、変更はすぐにどこにでも反映されます。**

## 外観

外観パネルを開くと、テーマ、色、文字サイズ、動きを変えられます。どの選択もすべてのページに適用されます。

## 言語

AChat の画面は 11 の言語で使えます：英語、中国語、ヒンディー語、スペイン語、アラビア語、フランス語、ポルトガル語、ロシア語、日本語、ウルドゥー語、ドイツ語。外観パネルの最後で選び、各言語はその言語自身の名前で表示されます。アラビア語とウルドゥー語は右から左に読み、中国語、ヒンディー語、日本語、ウルドゥー語にはそれぞれ専用の書体があります。

## キーボードショートカット

テキスト欄の外ならどこでも **?** を押すと一覧が開きます。ほとんどのキーはそこで変えられます。ショートカットは **Ctrl**、Apple の端末では **⌘** で表示されます。表は各ショートカットの元のキーです。

| キー | 操作 |
|---|---|
| Ctrl+K | チャットやページを探す |
| Enter | 送信 |
| Shift+Enter | 改行 |
| 空のメッセージ欄で ↑ | 最後のメッセージを編集 |
| Ctrl+Shift+S | 選んだ文章をネタバレにする |
| Esc | メニューやダイアログを閉じる、返信や編集を取り消す |
| Ctrl+Shift+F | 集中モードのオン・オフ |
| Ctrl+Shift+H | すぐに画面を隠す |
| ↑ / ↓、Home / End | チャット一覧を移動 |
| Alt+↑ / Alt+↓ | 前のチャット、次のチャット |
| Shift+F10 | チャットの操作 |

### キーを変える

一覧でショートカットの横の **変更** を押し、新しいキーを押します。**Esc** で取り消し。**リセット** は 1 つのショートカットを元のキーに、**すべてリセット** はすべてを元に戻し、元に戻す操作も出ます。

- 1 つのキーの組み合わせは 1 つのショートカットのものです。使われているキーなら、AChat はそれを使っているショートカットの名前を出し、そこへリンクします。
- Esc、矢印キー、Home、End、Shift+F10 は標準のキーです。メニュー、ダイアログ、一覧が頼っているので変えられません。
- ブラウザは Ctrl+W など一部の組み合わせを自分用に取っておくので、AChat では使えません。
- ログインしていれば、キーの設定はアカウントについていき、ログインするすべての端末で使えます。ログアウト中はこのブラウザにだけ保存されます。

## 集中モード

チャットのメニューか Ctrl+Shift+F で **集中モード** をオンにします。**Esc** で抜けます。

## アクセシビリティ

- 上のショートカットで、チャット一覧、チャット、メッセージ欄を操作できます。
- メッセージの送信や下書きの復元などの変化は、スクリーンリーダーに伝えられます。
- 文字サイズと動きは外観で決まります。
- [読み上げ](/features/writing-messages#read-aloud) は端末の音声でメッセージを再生します。

## サイドパネル

チャット 画面のサイドパネル（ルーム、チャット情報、共有メディア、ゴミ箱、スレッドなど）は、どれもチャット領域の 60% の幅で開きます。端をドラッグするか、端にフォーカスして矢印キーで調整し、ダブルクリックで 60% に戻ります。各パネルの幅はこの端末に、ログインしていればアカウントにも保存されます。

## 外観をファイルに

外観パネルの **ファイルとして保存** で、外観のすべての選択を小さなファイルに残せます。**ファイルから読み込む** でそれを適用します。

## キー

1〜6 のキーで、最新のメッセージにクイックリアクションを付けます。**チャットで Vim 風のキー**（ショートカットのダイアログ）をオンにすると、j と k でスクロール、G で最新のメッセージ、g g で読み込んだ最古のメッセージへ移れます。どのショートカットも変更できます。

## このデバイス

アカウント › 設定 › **このデバイス**：**チャット中は画面をつけたままにする**、**送信とリアクションで振動**（Android アプリ）、**リンクのプレビューを表示**、ブラウザが対応していれば **AChat をインストール**。
