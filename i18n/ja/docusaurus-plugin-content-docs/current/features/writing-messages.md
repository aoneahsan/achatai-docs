# メッセージを書く

**メッセージ欄は下書きを残し、ネタバレや数式を整え、音声入力もできます。翻訳と読み上げは端末上で動きます。**

## 下書き

送っていない下書きはそのチャットに残り、チャット一覧にも表示されます。下書きを捨てても元に戻せます。

## 書式

| 書き方 | 結果 |
|---|---|
| `\|\|text\|\|` | タップするまで隠れるネタバレ |
| `$formula$` | 文中の数式 |
| `$$formula$$` | 独立した行の数式 |
| `@username` または `@all` | メンション。自分へのメンションは枠で囲まれ、**あなたへのメンション** に一覧で出ます |

描けない数式は入力したまま表示されます。

## 書式ツールバー

メッセージ欄の上に：**太字**、**斜体**、**取り消し線**、**コード**、**リンク**、**コードブロック**、**箇条書き**、**番号つきリスト**、**引用**。広い画面では最初から表示され、スマートフォンでは **書式**（Aa）で表示・非表示を切り替えます。書式のないメッセージはプレーンテキストで送られます。貼り付けた文章は、これらの書式だけを残します。以前の AChat のエディターで書いたメッセージも書式つきで表示されます。

コードブロックは、表示するときによく使われる言語なら色分けされます。スレッドの返信欄にも、チャットの欄と同じツールがあります。

## 入力中の候補

`@` と名前の最初を打つと、チャットの人か `@all` を選べます。空の欄の先頭で `/` を打つとコマンド：`/shrug` は ¯\\_(ツ)_/¯ を入れ、`/clear` は下書きを消し、`/export` は **コピーを保存** を開きます。`/` で始まるほかの文字は、そのまま送られます。

## 全画面と長いメッセージ

**全画面で書く** でメッセージ欄がウィンドウ全体になり、Esc で戻ります。長いメッセージは数行で折りたたまれ、**もっと見る** が付きます。

## リンク

メッセージ内のウェブアドレスは、新しいタブで開くリンクになります。**リンクのプレビューを表示**（アカウント › 設定 › このデバイス）をオンにすると、ページのタイトルと画像のカードが付きます。初期設定ではオフです。オンにすると AChat 自身のサーバーがページを読んで画像を中継するので、リンク先のサイトがあなたの端末を見ることはありません。エンドツーエンド暗号化されたチャットでは、これはリンクが端末の外に出ることを意味します。

## スタンプと絵文字

AChat には 7 つのスタンプが入っているので、何もダウンロードしません。あなたのバージョンが知らないスタンプは、利用できないと表示されます。

## 音声入力

**音声入力** は、ブラウザの音声サービスを使って話した言葉をメッセージ欄のテキストにします。ブラウザによっては声をそのサービス提供元に送ってテキストにするので、AChat は聞き取る前にそう伝えます。音声入力が使えない場所では、入力するかボイスメモを録音できます。

## 翻訳

メッセージを端末上で **翻訳** します。言語によっては、ブラウザが先に言語パックをダウンロードし、それは端末に残ります。翻訳が使えない場所では、メッセージがどこかへ送られることはありません。

## 読み上げ

**読み上げ** は、端末の音声でメッセージを再生します。端末に音声がないブラウザでは表示されません。ミュートしたチャットでも再生されます。

## 未読のメッセージ

区切り線が新しいメッセージの始まりを示し、ボタンでそこへ移れます。
