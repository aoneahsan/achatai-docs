# ステータス

**ステータスは、承認した連絡先に向けた投稿で、24 時間で消えます。** ステータスにはアカウントが必要です。

## 見られる人

初期設定では承認した連絡先です。投稿する前に、その一部だけに見せたり、特定の人を外したりできます。どう選んでも、見られるのは連絡先として承認した人だけです。

## 閲覧、返信、削除

- 誰がステータスを見たかを確認できます。
- ステータスへの返信は、その人との個人チャットに届きます。
- ステータスを削除すると、すぐに全員から消えます。すでに見た人は見たあとです。

## 限界

ステータスはエンドツーエンド暗号化されていないので、AChat のサーバーは読めます。アクセスのルールで、ほかに見られる人をあなたが選んだ範囲に限っています。
