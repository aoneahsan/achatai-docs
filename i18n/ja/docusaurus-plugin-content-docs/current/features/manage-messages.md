# メッセージの管理

**どのメッセージ操作も、確定する前に何が誰に対して変わるかを伝え、ほとんどは元に戻せます。**

## メッセージの操作

| 操作 | すること |
|---|---|
| リアクション | 絵文字のリアクションを付けます |
| 返信 / スレッド | メッセージを引用するか、その[スレッド](/features/threads-and-replies)を開きます |
| 編集 | 自分のメッセージを変えます。暗号化されたチャットでもできます |
| 転送 | 別のチャットに写しを送ります。暗号化されたチャットでは、送り先のチャット用に暗号化し直されます |
| ピン留め | メッセージをチャットの一番上に固定します |
| リンクをコピー | その 1 件のメッセージへのリンクで、チャットの人にだけ開きます |

## 削除とゴミ箱

- **自分だけ削除** はメッセージを自分にとってだけ消します。
- **全員から削除** は自分のメッセージに使え、メッセージをそのチャットの **ゴミ箱** に移します。
- チャットの誰でも、チャットのゴミ箱からメッセージを元に戻したり、完全に削除したりできます。
- ゴミ箱は決まった日数（初期設定で 30 日）保管し、そのあと完全に削除します。チャット自体の保存期間や、メッセージ自体の消える時間より長くなることはありません。

エンドツーエンド暗号化されたチャットでは、全員から削除したメッセージは、各端末がオフラインの閲覧と検索のために保存していた写しからも、その端末が次にチャットを読み込むときに消えます。ゴミ箱からはまだ戻せます。完全に削除されると保存した写しも消え、端末をリンクしたり履歴を戻したりしても戻りません。

削除したチャットもゴミ箱で待っているので、取り戻せます。

## メッセージを消去する

- **自分だけ消去** は、チャットのすべてのメッセージを自分にだけ隠します。ほかの人はそのまま持っていて、新しいメッセージも届きます。消去した直後なら **元に戻す** でメッセージが戻ります。使えるのは 1 回だけで時間に限りがあり、使えなくなったら何も変わらず、チャットは自分にとって消去されたままです。
- **全員から消去** は、すべてのメッセージを「消去したメッセージ」という 1 つのまとまりとしてチャットのゴミ箱に移し、チャットの誰でも **すべて戻す** で元に戻せます。グループでは、これができるのはオーナーと管理者だけです。

ほかの人がすでに保存、転送、スクリーンショットした写しは、その人の手元に残ります。

## 消えるメッセージ

チャットごとの設定です：**オフ**、**1 分**、**1 時間**、**1 日**。チャットの全員の新しいメッセージに適用され、すでに送ったメッセージは元の時間のままです。誰かが変えるとチャットに 1 行表示され、各メッセージにカウントダウンが出ます。

消える前なら、チャットの誰でもメッセージをコピー、保存、スクリーンショットできます。

## 1 回だけ表示

次のメッセージで **一度だけ表示** をオンにします。開くまで隠れていて、開くとカウントダウンとともに数秒表示され、その端末から消えます。開かれたかどうかはわかります。開いているあいだは、コピーやスクリーンショットができてしまいます。接続の問題で開けなかった場合は使ったことにならず、隠れたまま、しばらくのあいだもう一度試せます。

## 投票

投票を送ると、みんながチャットで投票します。投票は各選択肢を何人が選んだかを示し、誰が選んだかは示さず、1 人 1 つだけ選べます。送った人は締め切れます。そのあとは誰も投票できず、結果は残り、一番多い選択肢に印が付きます。締め切った投票はまた開けます。

## アーカイブと非公開アーカイブ {#archive-and-private-archive}

- **アーカイブ** すると、チャットを削除せずに一覧から隠します。ほかの人には何も変わりません。
- メニューから **メッセージや返信をアーカイブ** できます。自分のメッセージはアーカイブを解除するまで全員から隠れ、ほかの人のものは自分にだけ隠れます。メインのメッセージをアーカイブするとスレッドも一緒です。あなたのメッセージにほかの人が返信していれば、その返信は「アーカイブされたメッセージ」の下に残り、解除するまでスレッドは新しい返信を受け付けません。
- 複数のメッセージ、返信、チャットを **選択**（メニューから、またはスマートフォンでは長押し）して、まとめてアーカイブしたり解除したりできます。「アーカイブ」を押す前に、誰に見えなくなるかをバーが示します。
- それぞれに専用の画面があります：一覧の **アーカイブしたチャット**、チャットのメニューやチャット情報からの **アーカイブしたメッセージ**、スレッドからの **アーカイブした返信**。そこにあるものが自然に期限切れになることはなく、アーカイブを解除できるのはアーカイブした本人だけです。消える時間が設定されたメッセージは、その時間が来れば消えます。
- **非公開アーカイブ**（匿名ルーム、アカウントが必要）：それ以降、リンクやパスワードがあっても、そのルームを開けるのはあなたのアカウントだけになり、読み取り専用になります。ほかの人が保管しているルームにはできません。

## コピーを保存

チャットをウェブページ（.html）か Markdown（.md）として保存できます。ファイルには、その端末で今読めるメッセージが入り、ファイルを受け取った誰でも読めます。

## メッセージにスターを付ける

**スター** はこの端末だけでメッセージに印を付け、何も送りません。スターを付けたメッセージには星が付き、**このチャットを検索** でスター付きのメッセージだけを表示できます。

## メッセージを報告する

**報告** は、ほかの人のメッセージを理由とともに AChat のモデレーターに送ります。作者には誰が報告したかは伝えられません。エンドツーエンド暗号化されたチャットでは AChat のサーバーがメッセージを読めないので、端末に表示されている言葉が報告と一緒に送られ、そのことはダイアログが先に伝えます。

## このチャットを検索

**このチャットを検索**（Ctrl または ⌘ + F、またはチャットの「その他」メニュー）は、この端末が読み込んだメッセージから言葉を探します。検索は端末上で動くので、エンドツーエンド暗号化されたメッセージも対象です。**以前のメッセージを検索** でさらに読み込みます。何もどこにも送られません。

## チャットからコピーを保存

**コピーを保存**（Ctrl または ⌘ + E、またはチャットの「その他」メニュー）で、チャットを端末上のファイルとして保存します。
