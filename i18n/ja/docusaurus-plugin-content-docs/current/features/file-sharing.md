# ファイル、ボイスメモ、メディア

**プランの範囲でどんな種類のファイルでも共有でき、ボイスメモを録音したり、画像を入力欄に直接貼り付けたりできます。**

## 容量

[プラン](/features/plans-and-pricing)で決まる上限が 2 つあります：

- **ファイルサイズ：** 1 つのファイルの大きさ。
- **チャットごとのファイル：** 1 つのチャットに保存できるファイルの量。

AChat は添付する前に両方を表示し、**アカウント** の **ストレージ** にも表示されます。チャットが上限に達すると、そのチャットへの新しいファイルは受け付けられませんが、メッセージのやり取りは続けられます。

## ボイスメモ

入力欄からボイスメモを録音できます。長さは AChat が表示する上限までです。上にスライドすると録音を固定でき、手を離せます。上限に達すると録音が止まり、送る前に聞き返せます。

## 写真、動画、貼り付けた画像

- 画像を入力欄に貼り付けるかドロップすると添付され、説明も付けられます。
- 動画はチャットの中で再生されます。
- **チャット情報** の **メディア** に、そのチャットで共有された写真、動画、ファイルがまとまります。非表示にしたメッセージや消去したメッセージのファイルもそこから消えます。

## アップロード

アップロードは実際の進み具合を表示し、取り消せます。ページを再読み込みしても続き、取り消したアップロードは削除されます。

## 暗号化

個人チャットとプライベートグループのファイルは、チャットと一緒にエンドツーエンド暗号化されます。ほかの種類のチャットについては[パスワードと暗号化](/features/passwords-and-encryption)をご覧ください。
