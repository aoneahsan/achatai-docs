# 検索とオフラインの履歴

**検索は端末にあるメッセージを対象に端末上で動くので、検索語も端末から出ません。**

## 検索

- **検索** を開くと、チャットをまたいで探せます。結果はチャットごとにまとまります。
- 対象はこの端末にすでにあるメッセージです。ゴミ箱、アーカイブしたチャット、退出したグループ、今は閉じているチャットは検索されません。
- 検索の対象は決まった数のチャットまでで、ピン留めしたものから、次に最近のものの順です。各チャットでは決まった数の新しいメッセージが対象です。どちらの数も AChat の管理者が決め、検索ページに対象のチャット数が表示されます。
- **Ctrl+K**（または **⌘K**）でチャットやページを探せます。

## オフライン

- 開いたチャットとファイルは端末に保存されるので、速く読み込め、オフラインでも開けます。
- オフラインで書いたメッセージは **送信トレイ** で **送信待ち** になり、接続が戻ると順番に送られます。**送信済み** になるのは届いてからです。
- 送れないメッセージがあれば、再試行したり、もう要らないものを破棄したりできます。
- 端末と位置の記録がオンのチャットは、開くのに接続が必要です。

## この端末に保存されているもの

**アカウント** の **ストレージ** で、端末に保存されているものがわかります。**保存したコピーを消去** すると保存したチャットとファイルが消え、オンラインで開くとまたダウンロードされます。送信トレイには影響しません。

ログアウトすると、チャットと、まだ送信待ちのメッセージが端末から消えます。[端末と復元キー](/features/devices-and-recovery)をご覧ください。
