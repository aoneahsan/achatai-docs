# 端末と位置の記録

**チャットは端末と位置の記録をオンにできます。入る前に、何を記録し誰が見られるかを表示します。断れば、そのチャットは閉じたままです。** ほかのチャットには影響しません。

## 記録するもの

入ったとき、開いているあいだ 5 分ごと、戻ってくるたびに記録します。各記録には次が含まれます：

- 正確な位置と、端末が示す精度
- 日時
- そのチャットでだけ使う端末 ID
- ブラウザとオペレーティングシステム、言語とタイムゾーン

記録に IP アドレスや、チャットをまたいであなたを結びつける ID が表示されることはありません。位置は端末が報告するので、実際の位置はもっとずれている可能性があります。

## 見られる人

| チャット | 記録を見られる人 |
|---|---|
| 公開チャット | 今もこれからも、そのチャットを開ける誰でも。見たものをコピーできます |
| 個人チャットやプライベートグループ | チャットの **監査パスワード** を入力したメンバーだけ。記録はエンドツーエンド暗号化され、AChat の管理者には開けません |
| パスワード付きのルーム | ルームのパスワードを入力したメンバーだけ。同じくエンドツーエンド暗号化されます |

チャットの全員が監査パスワードを忘れると、そのチャットの非公開の位置記録は二度と戻りません。

## 保存期間

チャットがあるかぎり保存されます。記録がなくなるのは、チャットがゴミ箱から完全に削除されるか、期限が切れたときだけです。記録をオフにすると新しい記録は止まりますが、以前の記録は消えません。

## 年齢

こうしたチャットは、決まった年齢以上だと申告した人向けで、その年齢は入る前に表示されます。AChat は申告を確認しません。

## 限界

- 位置の記録がオンのチャットは、開くのに接続が必要です。
- ほかのサイトの[ウィジェット](/features/embeddable-widget)の中では開けません。AChat で開いてください。
- ブラウザがタブを一時停止すると記録も止まり、戻ったときにチャットが新しい記録を求めます。
- チャットを出ると新しい記録は止まります。以前の記録は残ります。
- 記録をオンにすると、全員が同意して位置を共有するまで、あなたを含む全員にとってチャットが閉じます。
