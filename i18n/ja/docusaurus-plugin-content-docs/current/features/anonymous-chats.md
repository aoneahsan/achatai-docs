# 匿名ルーム

**匿名ルームにアカウントも電話番号も要りません。表示名を選んで、ルームのリンクを共有するだけです。** ルームにパスワードがなければ、リンクを持つ誰でも参加できます。

## ルームを作る、参加する

- **ルームを作成** で新しいルームと、共有するリンクができます。
- **ルームに参加** にはリンクかルーム ID を入れます。ルーム ID は小文字、数字、ハイフンで 8〜20 文字です。
- **表示名** を選びます。1〜24 文字で、そのルームでほかの人が使っていないものです。ルームのほかの人に見えるのはこれだけで、あとから変えられます。

ルームでは、オンラインかどうかも最終ログインも表示されません。

## ルームの保存期間

匿名ルームの各メッセージは、送られてから決まった日数（初期設定で 10 日）保存され、そのあと削除されます。アカウントを持つ人が[ルームを保管](/features/keep-chats-and-accounts)すると、履歴は代わりにルームの保管期限まで残ります。

チャットで[消えるメッセージ](/features/manage-messages#disappearing-messages)をオンにして、新しいメッセージをもっと早く消すこともできます。

## パスワード付きのルーム

ルームを作るときにパスワードを設定すると、ほかの人は参加にそれが必要になります。パスワード付きのルームは、そのパスワードを使ってあなたの端末でメッセージを暗号化します。パスワードはリンクとは別に伝えてください。

パスワードが何を守り、何を守らないかは[パスワードと暗号化](/features/passwords-and-encryption)をご覧ください。

## ここでの「匿名」の意味

アカウントも電話番号も要りません。ただし、見えなくなるという意味ではありません。

- あなたの端末は、ほかのサイトと同じように AChat のサーバーに接続します。
- AChat は、各ルームで選んだ表示名、そこで送ったメッセージ、そのルームで使う端末 ID を記録します。
- アカウントも持っていても、AChat は匿名のメッセージをアカウントと結びつけません。
- オープンなルーム（パスワードなし）では、リンクを持つ誰でもメッセージを読めます。

## 以前の AChat のルーム

作り直す前のルームのリンクも、メッセージ、パスワード、保管ルームとともにそのまま開きます。

パスワード付きのルームでは、同じパスワードを入力すれば、名前、返信、投票、ファイルを含む以前のメッセージが読めます。読めないメッセージには、その旨の 1 行が表示されます。

以前の AChat はパスワード付きのルームのメッセージを暗号化していましたが、ファイルは暗号化せず、推測できない公開リンクにそれぞれ保存していました。こうした以前のファイルはそのまま残しているので、そのファイルのリンクを持つ人なら誰でも開けます。
