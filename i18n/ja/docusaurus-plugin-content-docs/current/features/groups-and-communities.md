# グループとコミュニティ

**グループは、すでに知り合いの人たちのためのものです。コミュニティにはチャンネルとスレッドがあり、アカウントが必要か匿名で参加できるかを、それぞれが示します。**

## グループ

グループは連絡先の人たちを 1 つのエンドツーエンド暗号化されたチャットに集めるので、アカウントが必要です。

- **グループ** からグループを **作成** し、連絡先を招待するか招待リンクを共有します。
- **リンクで参加：** リンクから参加を申し込んだ人は、管理者が承認します。リンクをリセットすると、古いリンクは使えなくなります。
- **新しいメンバー** には、参加後に送られたメッセージが見えます。それ以前のメッセージは自動では共有されません。
- **退出や削除** で、新しいメッセージは届かなくなります。その人の端末にすでにあるメッセージは残ります。[退出したグループ](#groups-youve-left)をご覧ください。

| 役割 | できること |
|---|---|
| オーナー | 管理者ができることすべてと、管理者の選任。ほかの人をオーナーにもできます |
| 管理者 | 申請の承認、メンバーの削除、どのメッセージも削除、全員のメッセージを消去 |
| メンバー | チャット、返信、リアクション、退出 |

管理者が削除したメッセージはグループのゴミ箱に移り、元に戻せるのは管理者だけです。

### 退出したグループ {#groups-youve-left}

退出した、または外されたグループは、それを開いたことのある端末のチャット一覧に残ります。開くと、その端末にすでにあるメッセージを、退出したか外されたことを示す帯の下で読めます。読み取り専用で、メッセージ欄はなく、メッセージに返信、リアクションなどの操作もありません。新しいメッセージは届かず、こうしたグループは[検索](/features/search-and-history)の対象になりません。

## コミュニティ

**コミュニティ** の一覧を見るか、コミュニティのリンクを開きます。

- **参加方法：** 各コミュニティは **アカウントが必要** か **匿名で参加可** のどちらかです。匿名で参加すると表示名を使いますが、誰にも正体がわからないことを保証するものではありません。
- **チャンネル：** コミュニティにはチャンネルがあり、チャンネルにはスレッドがあります。プライベートなチャンネルは、追加された人しか読めません。
- **コミュニティのリンク ID：** 作成者が選ぶ、小文字、数字、ハイフンで 8〜20 文字。
- **成人向け：** 大人向けの話題のための 18+ の表示で、露骨な内容のためではありません。成人向けのコミュニティは 18 歳以上だと申告した人にだけ表示され、常にアカウントが必要です。AChat は申告を確認せず、AChat の管理者はこの表示を変更できます。

コミュニティとそのチャンネルはエンドツーエンド暗号化されていません。

## モデレーション

- 管理者はチャンネルを作り、プライベートなチャンネルを管理し、通報と追放に対応します。管理者を選べるのはオーナーだけです。
- **通報：** 選んだメッセージが、コミュニティの管理者と AChat のモデレーターに届きます。理由を選びます：スパム、嫌がらせやいじめ、性的な内容、脅しや暴力、その他。モデレーションの一覧に通報者が表示されることはありません。
- **追放：** 追放された人は、管理者が解除するまでそのコミュニティのどのチャンネルも読めず、投稿もできません。以前のメッセージは、管理者が削除しないかぎり残ります。追放が誤りだと思えば、お問い合わせページから AChat チームに見直しを頼めます。
- 管理者やモデレーターが削除したメッセージはその場所のゴミ箱に移り、元に戻せるのはそこの管理者だけです。

コミュニティには、通報、追放、削除のモデレーション履歴が残ります。

## 暗号化されたグループへの参加を待つ

グループはエンドツーエンド暗号化されているので、新しいメンバーはオーナーか管理者の端末が 1 人ずつ追加します。招待を受け入れると、その端末がオンラインになるまで、グループは **グループ** に **待機中** と表示され、参加できたら AChat がお知らせします。オーナーや管理者の端末は、AChat を開いているあいだ、待っている人を追加します。
