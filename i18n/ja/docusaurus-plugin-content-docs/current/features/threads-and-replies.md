# スレッドと返信

**スレッドで返信すれば、ほかの人たちがチャットを続けていても、予定の話が埋もれません。**

## 返信とスレッド

- **返信** はメインの会話の中でメッセージを引用します。
- **スレッド** は 1 つのメッセージについてわき道の会話を開き、チャットの横のパネルに表示します。**チャットで表示** で始まりのメッセージに戻れます。

スレッドはチャット、ルーム、コミュニティのチャンネルで使えます。

## スレッドでの削除

- 返信を 1 つだけ削除すると、チャットのゴミ箱に移ります。
- スレッドの始まりのメッセージを削除すると、すべての返信と一緒にゴミ箱に移ります。チャットの誰でもゴミ箱から元に戻せます。

ゴミ箱については[メッセージの管理](/features/manage-messages)をご覧ください。
