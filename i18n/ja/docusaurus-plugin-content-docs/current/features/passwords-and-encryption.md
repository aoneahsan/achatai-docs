# パスワードと暗号化

**個人チャット、プライベートグループ、そのファイルはエンドツーエンド暗号化されているので、各メッセージはその中の人たちの端末でしか読めません。** パスワード付きのルームは、そのパスワードを使ってあなたの端末でメッセージを暗号化します。

## 暗号化されるもの

| チャット | エンドツーエンド暗号化？ |
|---|---|
| 個人チャット | はい、ファイルも |
| プライベートグループ | はい、ファイルも |
| パスワード付きの匿名ルーム | はい、ルームのパスワードで暗号化 |
| オープンな匿名ルーム | いいえ。リンクを持つ誰でも読めます |
| コミュニティとそのチャンネル | いいえ |
| ステータス | いいえ。AChat のサーバーは読めます。ほかに誰が見られるかはアクセスのルールで限っています |

AChat は、エンドツーエンド暗号化されたメッセージを、サーバーにも管理者にも読めない形で保存します。AChat はメッセージの鍵の写しを持ちません。

## ルームのパスワード

- 参加して読むには、全員にパスワードが必要です。
- パスワードはリンクとは別に送ってください。
- 続けて何度も間違えると、数分待たないと再試行できません。
- 新しいパスワードには強度の目安が表示されます。確認はあなたの端末で行われ、パスワードを確認のためにどこかへ送ることはありません。

## グループとメンバーの変化

グループのメンバーが変わると、グループは新しいセキュリティの鍵を受け取るので、抜けた人は新しいメッセージを読めません。参加した人には、参加後に送られたメッセージが見えます。それ以前のメッセージが自動で共有されることはありません。

## リンクした端末を確かめる

**アカウント** の **デバイス** で、自分の 2 つの端末のセキュリティコードを照合できます。一致しなければ、信用できないほうの端末を外してください。[端末と復元キー](/features/devices-and-recovery)をご覧ください。

## 限界

- チャットの誰でも、メッセージをコピー、保存、スクリーンショットできます。暗号化が守るのは送られる途中とサーバー上のメッセージで、誰かが読んだあとではありません。
- 検索の対象は、すでにあなたの端末にあるメッセージだけです。
- プッシュ通知にメッセージの本文が入ることはありません。
- 復元キーとリンクしたすべての端末をなくすと、あなたにも AChat チームにも履歴は戻せません。

全体のモデルは[セキュリティと暗号化](/concepts/security-and-encryption)にあります。
