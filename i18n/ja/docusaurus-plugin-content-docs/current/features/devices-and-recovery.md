# 端末と復元キー

**暗号化された履歴は、あなたが承認した端末の中にあります。取り戻せるのは復元キーか、リンクしたほかの端末です。Google ログインだけでは戻りません。** AChat はメッセージの鍵の写しを持っていないので、AChat チームが代わりに履歴を戻すことはできません。

## 端末をリンクする

1. 新しい端末で AChat を開き、**このデバイスをリンク** を選びます。コードが表示されます。
2. すでにログインしている端末で **アカウント** の **デバイス** を開き、そのコードを読み取ります。そのブラウザで読み取れなければ、英数字を入力します。
3. 承認します。承認すると、新しい端末は履歴を含めてチャットを読め、あなたとしてメッセージを送れます。手元にある端末だけを承認してください。

履歴は承認と一緒に移ります。新しい端末は、ほかの端末がすでに開いたり送ったりしたメッセージを移しているあいだ、**チャットを移しています** と表示します。履歴が届かなくても端末のリンクはできています。**アカウント** の **復元** で、復元キーを使って以前のメッセージを戻してください。

リンクを確かめるには、セキュリティコードを照合します。両方の端末に同じコードが表示されるはずです。違っていたら、信用できないほうの端末を外してください。

## 端末を外す

端末を外すとログアウトされ、新しいメッセージは届かなくなります。すでに端末に保存されたものは残り、AChat が取り戻すことはできないので、なくした端末は、できればその端末自体の設定でロックするか消去してください。

## 復元キー

- AChat が復元キーを表示するのは 1 回だけです。書き留めるか、この端末以外の、自分だけが手の届く場所に保存してください。
- すべての端末をなくしたら、新しい端末でログインして復元キーを入力すれば、履歴が戻ります。
- **アカウント** の **復元** で置き換えられます。新しいキーができた時点で、古いキーは使えなくなります。
- リンクした端末がまだあるうちにキーをなくしたら、すぐに置き換えてください。

復元キーもリンクした端末もなければ、AChat チームを含め、誰もメッセージの履歴を戻せません。

## ログアウト

ログアウトすると、その端末からチャットが消えます。そこでまた読むには、復元キーかリンクしたほかの端末が必要です。まだ送信待ちのメッセージは、ログアウトすると完全に消えます。
