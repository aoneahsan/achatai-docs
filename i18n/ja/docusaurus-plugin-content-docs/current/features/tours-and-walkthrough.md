# ページツアーと「AChat の仕組み」

**AChat から出ずに使い方を覚える方法は 2 つ。今いるページの短いツアーと、アプリ全体を 6 ステップで紹介するページです。**

## ページツアー

**このページのツアー** は、ヘッダーの 外観 のすぐ手前にある道しるべのボタンです。チャット、機能、プランと料金、コミュニティ、アカウント にあります。スマートフォンでは同じ上部のバーに、アカウント と コミュニティ ではページ見出しの末尾にあります。

これらのページを初めて開くと、短いメモがボタンを指します：*はじめてですか？このページを手短にご案内します。* ページごとに 1 回だけ表示され、その 1 回はアカウントに記録されるので、別の端末でまた表示されることはありません。数秒で自然に消えます。

ツアーはページの一部分ずつを強調し、何をする場所かを伝えます。

| 操作 | すること |
|---|---|
| **次へ**、**戻る** | 1 ステップ進む・戻る。矢印キーでも同じです |
| **すべてのステップ** | すべてのステップを一覧にし、どこへでも移れます |
| **ツアーをスキップ**、閉じるボタン、Esc | すぐにツアーを終えます |

スマートフォンでは、各ステップが画面の下から（強調する部分が下のほうにあるときは上から）シートとして開きます。末尾が `?tour=3` のツアーのリンクはステップ 3 を開きます。

## AChat の仕組み

[AChat の仕組み](https://achat.aoneahsan.com/ja/how-achat-works) は 6 ステップで、それぞれにその場面の画面が付いています：知っている人とのチャット、アカウントなしのルーム、グループとコミュニティ、ステータス、接続が切れたときに起きること、そしてプラン。**次へ** と **戻る**、矢印キー、スマートフォンならスワイプで移動でき、`?step=3` でステップ 3 が開きます。

公開ページの下にある **ヘルプ** の列、サイトマップ、**アカウント** の上部、ログイン前の チャット 画面から開けます。
