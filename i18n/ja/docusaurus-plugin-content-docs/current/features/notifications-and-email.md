# 通知とメール

**通知はあなたが許可するまでオフで、メッセージそのものを含むことはありません。**

## 通知

- **アカウント** の **設定** で **通知を許可** を選ぶとオンになります。AChat が端末に許可を求めるのは、これを選んだあとだけです。
- それぞれの通知にはチャット名か送り主の名前だけが入り、メッセージの本文は入りません。
- **通知をミュート** で 1 つのチャットを静かにできます。すべてミュートすると音と通知が止まりますが、メッセージは届きます。
- 許可と受信は別です。端末が通知を許可していてもまだ受け取れていなければ、AChat がそう伝え、もう一度試せるようにします。

## メール

AChat が Google のメールアドレスに送るのは、アカウントに関するメールだけです：

| メール | いつ |
|---|---|
| ようこそ | 登録したあと |
| 新しい端末をリンク | アカウントに端末がリンクされた |
| 復元キーを置き換え | 復元キーが置き換えられた |
| 保管ルームのお知らせ | 保管ルームの日付が近づいた |
| プランへの招待 | 誰かが Team / Family プランに招待した |
| 支払いの申請の受付、確認、未確認 | プランの支払いをしたあと |
| お問い合わせの受付 | お問い合わせページからメッセージを送ったあと |
| アカウント削除 | アカウントが削除されたあと |

匿名ルームからメールが送られることはありません。

## AChat が別のタブにあるとき

メッセージが届いたとき AChat のタブが表示されていなければ、メッセージの音が鳴り（通知設定で **サウンド** がオンで、チャットがミュートされていない場合）、戻るまでタブ名に新着の数が表示されます。チャット一覧はすぐに更新されます。
