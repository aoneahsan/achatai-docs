# 埋め込みウィジェット

**ルームかチャンネルを選び、見た目を選んで、コードをページにコピーします。** [ウィジェットのページ](https://achat.aoneahsan.com/ja/widget)で作れます。コピーする前に、デモのメッセージでプレビューが表示されます。

## 埋め込めるもの

| 対象 | 条件 |
|---|---|
| 匿名ルーム | どのルーム ID でも可：小文字、数字、ハイフンで 8〜20 文字。誰かが初めてウィジェットを開いたときに新しいルームが作られます |
| コミュニティのチャンネル | **匿名で参加可** のコミュニティにある、表示名で参加するチャンネルだけ |

プライベートグループと、アカウントが必要なチャンネルはほかのサイトに表示できません。

## レイアウトとオプション

- **ページの中：** コードを貼った場所に、決まった大きさでチャットを表示します。
- **チャットボタン：** 隅にボタンを置き、押すとパネルでチャットが開きます。
- **詰める**、**チャットのヘッダーを隠す**、**ログインを提供**（訪問者はログインしてルームを保管できます。チャットにログインは要らず、ログインは新しいタブで開きます）。

## 表示を許可するサイト

チャットを表示してよいサイトを 20 個まで登録できます。1 つも登録しないうちは、どのサイトでも表示できます。

- ルームの場合、リストを変えられるのはそのルームを保管している人だけです。誰かが保管するまでは、誰もルームを制限できません。
- チャンネルの場合、変えられるのはコミュニティの管理者だけです。

リストにないサイトでは、お知らせと、代わりに AChat でチャットを開くリンクが表示されます。

## 訪問者が知っておくこと

- ルームにパスワードがなければ、ウィジェットのあるページを訪れた誰もがルームを読み、書き込めます。メッセージはルーム自体の保存期間に従います。
- ほかのサイトの中では、ログイン、マイク、位置情報は使えません。位置を記録するチャットは AChat の中でしか開きません。
- サイト側のブラウザ設定によっては AChat が訪問者を覚えられないため、次回また表示名を選ぶ必要があるかもしれません。
