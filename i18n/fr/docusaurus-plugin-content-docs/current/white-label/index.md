# Marque blanche et licences

**AChat peut tourner sous le nom d'une autre organisation.** Avec une licence en marque blanche, l'équipe AChat héberge AChat, le déploie sur votre domaine et y met votre nom, votre logo et vos couleurs. Vous le proposez à vos propres utilisateurs. Si vous préférez posséder le code, vous pouvez aussi racheter AChat : le prix du rachat, plus une redevance de 7 % sur le chiffre d'affaires brut d'AChat tant qu'il en génère.

Les prix actuels figurent sur la [page des prix de licence](https://achat.aoneahsan.com/fr/white-label/pricing) et la [page du rachat](https://achat.aoneahsan.com/fr/white-label/buyout). Ils ne sont pas repris ici, pour n'être indiqués qu'à un seul endroit.

## Les deux voies

| | Licence en marque blanche | Rachat du code source |
|---|---|---|
| Qui le fait tourner | L'équipe AChat l'héberge et le déploie | Vous, à partir du code source |
| Code source | Non inclus | Tous les dépôts qui produisent l'app web et l'app Android |
| Exclusivité | Non : d'autres peuvent aussi obtenir une licence AChat | Oui : l'équipe AChat cesse de le vendre |
| Mises à jour | Six mois inclus, puis renouvellements | Six mois inclus, puis renouvellements |
| Après l'achat | Des renouvellements, si vous voulez d'autres mises à jour | Une redevance de 7 % sur le chiffre d'affaires brut d'AChat, chaque trimestre |
