# Apparence, langue et raccourcis

**Le thème, la couleur, la taille du texte et les animations sont dans un seul panneau Apparence : un changement s'affiche partout à la fois.**

## Apparence

Ouvre le panneau Apparence pour changer le thème, la couleur, la taille du texte ou les animations. Chaque choix s'applique sur toutes les pages.

## Langue

L'interface d'AChat existe en onze langues : anglais, chinois, hindi, espagnol, arabe, français, portugais, russe, japonais, ourdou et allemand. Choisis-la à la fin du panneau Apparence ; chaque langue s'affiche sous son propre nom. L'arabe et l'ourdou se lisent de droite à gauche, et le chinois, l'hindi, le japonais et l'ourdou ont chacun leur police.

## Raccourcis clavier

Appuie sur **?** n'importe où hors d'un champ de texte pour ouvrir la liste. Tu peux y changer la plupart des touches. Les raccourcis affichent **Ctrl**, ou **⌘** sur les appareils Apple. Le tableau donne les touches d'origine de chaque raccourci.

| Touches | Action |
|---|---|
| Ctrl+K | Trouver une discussion ou une page |
| Entrée | Envoyer |
| Maj+Entrée | Nouvelle ligne |
| ↑ dans une zone de message vide | Modifier ton dernier message |
| Ctrl+Maj+S | Marquer le texte sélectionné comme spoiler |
| Échap | Fermer un menu ou une boîte de dialogue, annuler une réponse ou une modification |
| Ctrl+Maj+F | Activer ou désactiver le mode concentration |
| Ctrl+Maj+H | Masquer l'écran maintenant |
| ↑ / ↓, Début / Fin | Se déplacer dans la liste des discussions |
| Alt+↑ / Alt+↓ | Discussion précédente ou suivante |
| Maj+F10 | Actions de la discussion |

### Changer une touche

Dans la liste, appuie sur **Modifier** à côté d'un raccourci, puis sur les nouvelles touches. **Échap** annule. **Réinitialiser** rend à un raccourci ses touches d'origine, et **Tout réinitialiser** les rend toutes, avec une annulation possible.

- Une combinaison de touches appartient à un seul raccourci. Si les touches sont prises, AChat nomme le raccourci qui les a et y renvoie.
- Échap, les flèches, Début, Fin et Maj+F10 sont des touches standard. Elles ne peuvent pas être changées, car les menus, les boîtes de dialogue et les listes en dépendent.
- Ton navigateur se réserve certaines combinaisons, comme Ctrl+W, qu'AChat ne peut donc pas utiliser.
- Quand ta session est ouverte, tes touches suivent ton compte sur chaque appareil où tu te connectes. Sans session, elles sont gardées dans ce navigateur seulement.

## Mode concentration

Active le **Mode concentration** depuis le menu d'une discussion ou avec Ctrl+Maj+F. Appuie sur **Échap** pour en sortir.

## Accessibilité

- Les raccourcis ci-dessus couvrent la liste des discussions, une discussion et la zone de message.
- Les changements, comme un message envoyé ou un brouillon restauré, sont annoncés aux lecteurs d'écran.
- La taille du texte et les animations viennent d'Apparence.
- [Lire à voix haute](/features/writing-messages#read-aloud) fait entendre un message avec une voix de l'appareil.

## Panneaux latéraux

Chaque panneau latéral de Discussions (un salon, les infos de la discussion, les médias partagés, la Corbeille, un fil, etc.) s'ouvre à 60 % de la zone de discussion. Fais glisser son bord, ou place le focus sur le bord et utilise les flèches ; un double-clic revient à 60 %. Chaque panneau garde sa largeur sur cet appareil et, si ta session est ouverte, sur ton compte.

## L'apparence en fichier

**Enregistrer dans un fichier** dans le panneau d'apparence garde tous tes choix d'apparence dans un petit fichier ; **Charger depuis un fichier** en applique un.

## Touches

Les touches 1 à 6 réagissent au message le plus récent avec les réactions rapides. **Touches façon Vim dans une discussion** (dans la boîte de dialogue des raccourcis) ajoute j et k pour défiler, G pour le message le plus récent et g g pour le plus ancien chargé. Chaque raccourci peut être changé.
