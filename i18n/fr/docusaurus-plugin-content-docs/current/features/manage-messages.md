# Gérer les messages

**Chaque action sur un message indique ce qu'elle change et pour qui avant que tu confirmes, et la plupart peuvent être annulées.**

## Actions sur un message

| Action | Ce qu'elle fait |
|---|---|
| Réagir | Ajoute une réaction emoji |
| Répondre / Fil | Cite un message, ou ouvre un [fil](/features/threads-and-replies) dessus |
| Modifier | Change ton propre message, y compris dans les discussions chiffrées |
| Transférer | Envoie une copie dans une autre discussion. Dans une discussion chiffrée, elle est chiffrée à nouveau pour la discussion de destination |
| Épingler | Épingle un message en haut de la discussion |
| Copier le lien | Un lien vers ce seul message, qui ne s'ouvre que pour les personnes de la discussion |

## Suppression et Corbeille

- **Supprimer pour moi** retire un message pour toi seul.
- **Supprimer pour tous** s'applique à tes propres messages et déplace le message dans la **Corbeille** de cette discussion.
- N'importe qui dans la discussion peut restaurer un message depuis la Corbeille, ou le supprimer définitivement.
- La Corbeille garde les éléments un nombre de jours défini, 30 par défaut, puis les supprime définitivement. Jamais plus longtemps que l'historique de la discussion elle-même, ni que le minuteur éphémère du message.

Dans une discussion chiffrée de bout en bout, un message supprimé pour tous disparaît aussi de la copie que chaque appareil a enregistrée pour la lecture hors ligne et la recherche, la prochaine fois que cet appareil charge la discussion. Il peut encore être restauré depuis la Corbeille. Une fois supprimé définitivement, la copie enregistrée part aussi, et elle ne revient pas quand tu associes un appareil ou restaures ton historique.

Une discussion supprimée attend aussi dans la Corbeille, pour que tu puisses la récupérer.

## Effacer les messages

- **Effacer pour moi** masque tous les messages d'une discussion pour toi seul. Les autres les gardent, et les nouveaux messages continuent d'arriver. Juste après l'effacement, **Annuler** fait revenir les messages. Cela ne marche qu'une fois, pendant un temps limité ; s'il n'est plus disponible, rien ne change et la discussion reste effacée pour toi.
- **Effacer pour tous** déplace tous les messages dans la Corbeille de la discussion en un seul lot, « Messages effacés », que n'importe qui dans la discussion peut restaurer avec **Tout restaurer**. Dans un groupe, seuls le propriétaire et les admins peuvent le faire.

Les copies que les gens ont déjà enregistrées, transférées ou capturées restent chez eux.

## Messages éphémères {#disappearing-messages}

Un réglage par discussion : **Désactivée**, **1 minute**, **1 heure** ou **1 jour**. Il s'applique aux nouveaux messages de tout le monde dans la discussion ; les messages déjà envoyés gardent leur propre minuteur. Une ligne dans la discussion indique quand quelqu'un le change, et chaque message affiche un compte à rebours.

N'importe qui dans la discussion peut encore copier, enregistrer ou capturer un message avant qu'il disparaisse.

## Vue unique

Active la **Vue unique** pour ton prochain message. Il reste masqué jusqu'à son ouverture, s'ouvre quelques secondes avec un compte à rebours, puis disparaît de cet appareil. Tu vois s'il a été ouvert. Pendant qu'il est ouvert, il peut encore être copié ou capturé. S'il ne s'ouvre pas à cause d'un problème de connexion, il n'est pas consommé : le cache reste et tu peux réessayer pendant un court moment.

## Sondages

Envoie un sondage et chacun vote dans la discussion. Un sondage montre combien de personnes ont choisi chaque option, pas qui, et chaque personne peut choisir une option. La personne qui l'a envoyé peut le clore : plus personne ne peut voter, les résultats restent et l'option en tête est marquée. Un sondage clos peut être rouvert.

## Archive et archive privée {#archive-and-private-archive}

- **Archiver** masque une discussion de ta liste sans la supprimer. Rien ne change pour les autres.
- **Archive un message ou une réponse** depuis son menu. Ton propre message est masqué pour tout le monde jusqu'à ce que tu le désarchives ; celui de quelqu'un d'autre n'est masqué que pour toi. Archiver un message principal emporte son fil. Si d'autres ont répondu à ton message, leurs réponses restent sous « Message archivé », et le fil n'accepte plus de nouvelles réponses tant que tu n'as pas désarchivé.
- **Sélectionne** plusieurs messages, réponses ou discussions (depuis un menu, ou par un appui long sur téléphone), puis archive-les ou désarchive-les ensemble. La barre indique qui cesse de les voir avant que tu n'appuies sur « Archiver ».
- Chaque niveau a sa vue : **Discussions archivées** dans ta liste, **Messages archivés** depuis le menu d'une discussion ou Infos de la discussion, et **Réponses archivées** depuis un fil. Rien n'y expire tout seul, et toi seul peux désarchiver ce que tu as archivé. Un message avec son propre minuteur éphémère part quand même à son échéance.
- **Archive privée** (salons anonymes, avec un compte) : dès lors, seul ton compte peut ouvrir le salon, même avec son lien ou son mot de passe, et il passe en lecture seule. Tu ne peux pas le faire pour un salon que quelqu'un d'autre conserve.

## Enregistrer une copie

Enregistre une copie d'une discussion en page web (.html) ou en Markdown (.md). Le fichier contient les messages que tu peux lire maintenant sur cet appareil, et quiconque reçoit le fichier peut le lire.

## Ajouter une étoile à un message

**Ajouter une étoile** marque un message sur cet appareil seulement ; rien n'est envoyé. Un message étoilé affiche une étoile, et **Chercher dans cette discussion** peut n'afficher que les messages étoilés.

## Signaler un message

**Signaler** envoie le message de quelqu'un d'autre aux modérateurs d'AChat avec un motif. Son auteur n'apprend pas qui l'a signalé. Dans une discussion chiffrée de bout en bout, le serveur d'AChat ne peut pas lire les messages : les mots affichés par ton appareil partent donc avec le signalement, et la boîte de dialogue le dit d'abord.

## Chercher dans cette discussion

**Chercher dans cette discussion** (Ctrl ou ⌘ + F, ou le menu Plus de la discussion) trouve des mots dans les messages que cet appareil a chargés, y compris ceux chiffrés de bout en bout, puisque la recherche tourne sur ton appareil. **Chercher dans les messages plus anciens** en charge davantage. Rien n'est envoyé nulle part.

## Enregistrer une copie depuis une discussion

**Enregistrer une copie** (Ctrl ou ⌘ + E, ou le menu Plus de la discussion) enregistre la discussion dans un fichier sur ton appareil.
