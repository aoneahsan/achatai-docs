# Fils et réponses

**Réponds dans un fil pour qu'un projet ne se perde pas pendant que les autres continuent de discuter.**

## Réponse ou fil

- **Répondre** cite un message dans la conversation principale.
- **Fil** ouvre une conversation annexe sur un message, dans un panneau à côté de la discussion. **Afficher dans la discussion** ramène au message d'où il est parti.

Les fils fonctionnent dans les discussions, les salons et les canaux de communauté.

## Supprimer dans un fil

- Supprime une seule réponse, et elle va dans la Corbeille de la discussion.
- Supprime le message d'où part un fil, et il va dans la Corbeille avec toutes ses réponses. N'importe qui dans la discussion peut les restaurer depuis la Corbeille.

Voir [Gérer les messages](/features/manage-messages) pour la Corbeille.
