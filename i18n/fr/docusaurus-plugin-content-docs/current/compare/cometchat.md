# Passer de CometChat à AChat

**CometChat est un chat pour développeurs, gratuit jusqu'à 100 utilisateurs avec son offre Build.** Si vos développeurs ajoutent le chat à votre propre app, restez dessus. AChat sert quand vous préférez coller un extrait et laisser les visiteurs discuter sans compte.

Dernière vérification le 2026-11-22. Côte à côte : [AChat et CometChat](https://achat.aoneahsan.com/fr/compare/cometchat).

## Au-delà de 100 utilisateurs

L'offre Build couvre jusqu'à 100 utilisateurs. Si ce que vous avez construit dessus est en réalité un salon public pour visiteurs, voici l'échange.

1. Séparez les deux usages. Le chat intégré entre vos propres utilisateurs reste sur CometChat.
2. Pour la partie publique, créez un salon ou choisissez un canal ouvert de communauté sur la [page du widget](https://achat.aoneahsan.com/fr/widget) ([widget intégrable](/features/embeddable-widget)).
3. Réglez la mise en page, puis copiez le code dans votre page.
4. Les visiteurs choisissent un nom affiché dans le salon. Personne n'a besoin de compte.
5. Si le salon doit rester privé pour un groupe, ajoutez un mot de passe et envoyez-le séparément.

## Les pages de CometChat

La page des tarifs de CometChat confirme une offre gratuite sans date de fin. Les pages consultées ne disaient pas s'il propose un chat prêt à ajouter à une page, ni s'il peut être hébergé sur vos serveurs : ces lignes ont donc été retirées.

| Fonctionnalité | AChat | CometChat |
|---|---|---|
| Offre gratuite sans date de fin | Oui | Oui (<a href="https://www.cometchat.com/pricing" target="_blank" rel="noopener noreferrer nofollow">leur page</a>) |

AChat ne fonctionne qu'en version hébergée. Son widget est un salon prêt à l'emploi, ni boîte de réception d'agents, ni SDK.
