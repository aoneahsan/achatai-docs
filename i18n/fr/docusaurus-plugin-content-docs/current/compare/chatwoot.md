# Passer de Chatwoot à AChat

**Chatwoot est une plateforme de support client open source, à héberger vous-même ou à payer par agent.** Faire tourner le support sur vos propres serveurs est une bonne raison de rester : AChat ne s'auto-héberge pas. Il sert quand vous ne voulez rien faire tourner, et que vos visiteurs se parlent entre eux plutôt qu'à des agents.

Vérifié le 2026-11-22. Voir [AChat et Chatwoot](https://achat.aoneahsan.com/fr/compare/chatwoot) pour la comparaison.

## Retirer une instance auto-hébergée

Si votre serveur Chatwoot accueille surtout les bavardages des visiteurs, l'entretien peut coûter plus que le salon ne vaut.

1. Exportez d'abord de Chatwoot tout ce dont vous avez besoin. Rien n'est importé dans AChat.
2. Créez un salon ou choisissez un canal ouvert de communauté sur la [page du widget](https://achat.aoneahsan.com/fr/widget) ([widget intégrable](/features/embeddable-widget)). Aucun serveur, aucune base de données ni mise à jour à surveiller.
3. Collez le code là où tournait le widget Chatwoot.
4. Gardez le salon avec un compte, pour qu'il dure au-delà de l'historique par défaut et que vous puissiez indiquer les sites autorisés à l'afficher.
5. N'arrêtez votre instance qu'une fois le nouveau salon en service depuis un moment.

## Côte à côte

| Fonctionnalité | AChat | Chatwoot |
|---|---|---|
| Offre gratuite sans date de fin | Oui | Oui (<a href="https://www.chatwoot.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">leur page</a>) |
| Chat prêt à ajouter à une page | Oui | Non précisé sur les pages consultées |
| Hébergement sur vos serveurs | Non | Oui (<a href="https://www.chatwoot.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">leur page</a>) |

Le widget d'AChat n'est pas une boîte de réception d'agents. Toute personne sur la page peut lire le salon, sauf s'il a un mot de passe.
