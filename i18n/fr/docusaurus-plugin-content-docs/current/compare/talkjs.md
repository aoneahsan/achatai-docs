# Passer de TalkJS à AChat

**TalkJS est une interface de chat prête à ajouter à votre produit, gratuite en mode développement.** Quand le chat fait partie de votre propre produit et qu'il est lié à vos propres comptes utilisateurs, TalkJS est plus adapté. AChat se met en ligne avec l'offre gratuite, et les visiteurs qui l'utilisent n'ont besoin d'aucun compte.

Vérifié le 2026-11-22. La page de comparaison est [AChat et TalkJS](https://achat.aoneahsan.com/fr/compare/talkjs).

## Du mode développement à un salon en ligne

TalkJS est gratuit tant que vous construisez en mode développement. Si votre prototype était un salon public plutôt qu'un chat entre vos utilisateurs, AChat peut le mettre en ligne avec son offre gratuite.

1. Vérifiez de quoi dépend votre prototype. Les conversations liées aux identifiants de vos utilisateurs restent sur TalkJS, car le widget d'AChat n'est pas un SDK pour développeurs et ne connaît pas vos utilisateurs.
2. Pour un salon ouvert, choisissez un identifiant de salon sur la [page du widget](https://achat.aoneahsan.com/fr/widget) ([widget intégrable](/features/embeddable-widget)). Les visiteurs entrent sous un nom affiché.
3. Choisissez **Dans la page** pour prendre la place de votre chat TalkJS, ou **Bouton de discussion** pour un panneau dans un coin.
4. Copiez le code dans la page.
5. Gardez le salon depuis un compte, puis indiquez les sites autorisés à l'afficher.

## Comparaison

| Fonctionnalité | AChat | TalkJS |
|---|---|---|
| Offre gratuite sans date de fin | Oui | En partie (<a href="https://talkjs.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">leur page</a>) |
| Chat prêt à ajouter à une page | Oui | Oui (<a href="https://talkjs.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">leur page</a>) |
| Hébergement sur vos serveurs | Non | Non précisé sur les pages consultées |

Le widget d'AChat affiche un salon anonyme ou un canal ouvert de communauté. Ce n'est pas un SDK pour développeurs, et toute personne sur la page peut lire le salon, sauf s'il a un mot de passe.
