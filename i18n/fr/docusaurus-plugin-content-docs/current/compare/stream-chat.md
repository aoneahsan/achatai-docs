# Passer de Stream Chat à AChat

**Stream Chat est un chat que les développeurs intègrent dans leurs apps, gratuit jusqu'à 1 000 utilisateurs actifs par mois.** Si vos développeurs intègrent le chat dans votre propre produit et veulent maîtriser chaque élément, Stream est le bon type d'outil. AChat fait le choix inverse : vous collez un extrait et obtenez un chat qui fonctionne, sans développeurs.

Vérifié le 2026-11-22. La comparaison côte à côte est sur [AChat et Stream Chat](https://achat.aoneahsan.com/fr/compare/stream-chat).

## Quand le SDK dépassait le besoin

Il arrive qu'une équipe adopte un SDK de chat pour ce qui s'avère être un seul salon public sur une seule page. Si c'est votre cas, cela prend quelques minutes au lieu d'un sprint.

1. Gardez Stream partout où le chat est lié à vos propres utilisateurs et données. Le widget d'AChat n'est pas un SDK pour développeurs : il ne se greffe pas sur vos propres comptes utilisateurs.
2. Pour le salon public, ouvrez la [page du widget](https://achat.aoneahsan.com/fr/widget) et choisissez un identifiant de salon ou un canal ouvert de communauté ([widget intégrable](/features/embeddable-widget)).
3. Choisissez la mise en page et les options ; la page du widget écrit le code pour vous.
4. Copiez l'extrait dans le modèle de votre page.
5. Une fois le salon gardé par quelqu'un, cette personne peut indiquer les domaines autorisés à l'afficher, jusqu'à 20.

## D'après la page des tarifs de Stream

La page des tarifs de Stream confirme une offre gratuite sans date de fin. Les pages consultées ne disaient pas si Stream fournit un chat prêt à ajouter à une page, ni s'il peut être hébergé sur vos serveurs : ces lignes ont donc été retirées.

| Fonctionnalité | AChat | Stream Chat |
|---|---|---|
| Offre gratuite sans date de fin | Oui | Oui (<a href="https://getstream.io/chat/pricing/" target="_blank" rel="noopener noreferrer nofollow">leur page</a>) |

Le widget d'AChat est un salon prêt à l'emploi, en version hébergée uniquement. Ce n'est pas un SDK pour développeurs, et toute personne sur la page peut lire le salon, sauf s'il a un mot de passe.
