# Passer de Snapdrop à AChat

**Snapdrop est un transfert de fichiers sans compte, stocké par LimeWire, jusqu'à 4 Go par transfert sans compte.** Les gros fichiers sans inscription sont son point fort. AChat sert quand vous voulez des messages en plus des fichiers, et un mot de passe sur le salon.

Vérifié le 2026-11-22. Comparaison sur [AChat et Snapdrop](https://achat.aoneahsan.com/fr/compare/snapdrop).

## Des fichiers, avec quelques mots à leur sujet

1. Avant de déplacer un gros transfert, vérifiez la taille de fichier que permet votre forfait AChat. AChat l'affiche avant que vous joigniez quoi que ce soit ([partage de fichiers](/features/file-sharing)). Au-delà, Snapdrop reste l'outil.
2. Ouvrez AChat sur la machine qui envoie et lancez un salon, sans compte ([salons anonymes](/features/anonymous-chats)).
3. Mettez-y un mot de passe ([mots de passe et chiffrement](/features/passwords-and-encryption)).
4. Envoyez les fichiers, et écrivez dans le même salon à quoi sert chacun.
5. La personne sur l'autre machine ouvre le lien, saisit le mot de passe, télécharge, et peut répondre s'il manque quelque chose.

## Comment ils se comparent

| Fonctionnalité | AChat | Snapdrop |
|---|---|---|
| Aucun compte requis | Oui | Oui (<a href="https://snapdrop.net/" target="_blank" rel="noopener noreferrer nofollow">leur page</a>) |
| Envoi de texte et de fichiers | Oui | En partie (<a href="https://snapdrop.net/" target="_blank" rel="noopener noreferrer nofollow">leur page</a>) |
| Protection par mot de passe | Oui | Non précisé sur les pages consultées |
| L'autre côté peut répondre | Oui | Non précisé sur les pages consultées |

Les messages AChat sont supprimés après le nombre de jours défini pour le salon, sauf si quelqu'un qui a un compte le garde. Anonyme signifie sans compte, pas invisible.
