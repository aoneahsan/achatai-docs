# Passer de Sendbird à AChat

**Sendbird est un chat intégré aux apps, facturé par utilisateurs actifs mensuels, avec un essai gratuit.** Si le chat fait partie de votre propre produit et que vous avez un budget pour cela, Sendbird est fait pour ça. AChat convient à un besoin plus modeste : un salon sur une page, quand vous préférez ne pas payer pour démarrer.

Dernière vérification le 2026-11-22. La comparaison complète est sur [AChat et Sendbird](https://achat.aoneahsan.com/fr/compare/sendbird).

## Avant que l'essai ne devienne une facture

Les forfaits Sendbird commencent à 349 $ par mois en facturation annuelle. Si votre essai a montré qu'il vous fallait seulement un endroit où les visiteurs se parlent, essayez d'abord ceci.

1. Notez à quoi servait l'essai. Si c'était la messagerie entre vos propres utilisateurs connectés, continuez d'évaluer Sendbird : le widget d'AChat n'est pas un SDK pour cela.
2. Si c'était un salon public, créez-en un sur la [page du widget](https://achat.aoneahsan.com/fr/widget) avec l'offre gratuite d'AChat ([widget intégrable](/features/embeddable-widget)).
3. Collez le code là où se trouvait le chat de l'essai.
4. Activez **Proposer la connexion** si les visiteurs doivent pouvoir garder le salon. La connexion s'ouvre dans un nouvel onglet, et discuter ne l'exige jamais.
5. Ajoutez un mot de passe si le salon doit rester entre les personnes que vous invitez.

## Sendbird, d'après sa page des tarifs

Leur page des tarifs indique qu'il n'y a pas d'offre gratuite sans date de fin. Les pages consultées ne disaient pas si Sendbird propose un chat prêt à ajouter à une page ou une version à héberger sur vos serveurs : ces lignes ne figurent donc pas ici.

| Fonctionnalité | AChat | Sendbird |
|---|---|---|
| Offre gratuite sans date de fin | Oui | Non (<a href="https://sendbird.com/pricing/chat" target="_blank" rel="noopener noreferrer nofollow">leur page</a>) |

AChat n'existe qu'en version hébergée, et son widget est un salon prêt à l'emploi, ni SDK, ni boîte de réception d'agents.
