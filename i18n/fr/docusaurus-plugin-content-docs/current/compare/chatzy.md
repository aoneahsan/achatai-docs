# Passer de Chatzy à AChat

**Chatzy propose des salons de discussion privés et gratuits pour les personnes que vous invitez, sans inscription.** Si vous comptez sur ses propres contrôles pour décider qui entre, continuez à les utiliser. La réponse d'AChat à « qui entre » est un mot de passe, et ce mot de passe chiffre aussi les messages du salon. Les salons AChat acceptent aussi les fichiers.

Vérifié le 2026-11-22. Comparaison sur [AChat et Chatzy](https://achat.aoneahsan.com/fr/compare/chatzy).

## Recréer un salon privé

1. Dans AChat, choisissez **Continuer anonymement**, puis **Créer un salon**. Personne n'a besoin de s'inscrire ([salons anonymes](/features/anonymous-chats)).
2. Définissez un mot de passe en le créant. Sans lui, personne ne peut entrer ni lire. Les messages sont chiffrés sur l'appareil de chacun avec ce mot de passe ([mots de passe et chiffrement](/features/passwords-and-encryption)).
3. Envoyez le lien dans un message et le mot de passe dans un autre, ou par un autre moyen.
4. Chaque personne choisit un nom affiché de 1 à 24 caractères, unique dans ce salon.
5. Partagez des fichiers dans le salon quand il le faut ([partage de fichiers](/features/file-sharing)).

Les messages disparaissent après un nombre de jours défini, 10 par défaut, sauf si quelqu'un qui a un compte [garde le salon](/features/keep-chats-and-accounts).
