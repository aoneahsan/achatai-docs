# Von Tidio zu AChat wechseln

**Tidio ist Kunden-Chat mit einem KI-Agenten namens Lyro, abgerechnet nach Unterhaltungen.** Willst du einen Agenten, der Kunden antwortet, ist das Tidio. AChat ist für Seiten, auf die Leute kommen, um miteinander zu reden, und wenn du keine Unterhaltungen zählen willst.

Zuletzt geprüft am 2026-11-22. Der ganze Vergleich: [AChat und Tidio](https://achat.aoneahsan.com/de/compare/tidio).

## Einen Antwort-Bot gegen einen Raum tauschen

Bei AChat antwortet niemand in deinem Namen. Besucher antworten einander, das funktioniert also nur dort, wo genau das der Sinn ist.

1. Such die Seiten aus, auf denen Besucher miteinander schreiben statt mit dir. Lass Tidio auf den übrigen.
2. Wähl auf der [Widget-Seite](https://achat.aoneahsan.com/de/widget) einen anonymen Raum oder einen offenen Community-Kanal, dann ein Layout ([einbettbares Widget](/features/embeddable-widget)).
3. Schalte **Kompakt** oder **Chat-Kopfzeile ausblenden** ein, wenn der Raum in einer schmalen Spalte sitzt.
4. Füg den Code in diese Seiten ein.
5. Gib dem Raum ein Passwort, wenn nur bestimmte Besucher ihn lesen sollen.
