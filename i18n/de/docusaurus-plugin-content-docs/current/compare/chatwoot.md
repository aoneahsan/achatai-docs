# Von Chatwoot zu AChat wechseln

**Chatwoot ist eine Open-Source-Plattform für Kundensupport, die du selbst hosten oder pro Agent bezahlen kannst.** Support auf eigenen Servern zu betreiben ist ein guter Grund zu bleiben; AChat lässt sich nicht selbst hosten. Es ist für den Fall, dass du nichts betreiben willst und deine Besucher miteinander statt mit Agenten reden.

Geprüft am 2026-11-22. Den Vergleich gibt es unter [AChat und Chatwoot](https://achat.aoneahsan.com/de/compare/chatwoot).

## Eine selbst gehostete Instanz abschalten

Trägt dein Chatwoot-Server vor allem Plaudereien von Besuchern, kostet die Pflege vielleicht mehr, als der Raum wert ist.

1. Exportier zuerst alles, was du aus Chatwoot brauchst. In AChat wird nichts importiert.
2. Bau einen Raum oder wähl einen offenen Community-Kanal auf der [Widget-Seite](https://achat.aoneahsan.com/de/widget) ([einbettbares Widget](/features/embeddable-widget)). Es gibt keinen Server, keine Datenbank und kein Update, um das du dich kümmern musst.
3. Füg den Code dort ein, wo das Chatwoot-Widget lief.
4. Behalte den Raum mit einem Konto, damit er über den Standardverlauf hinaus bleibt und du die Websites eintragen kannst, die ihn zeigen dürfen.
5. Schalte deine Instanz erst ab, wenn der neue Raum eine Weile läuft.

## Nebeneinander

| Funktion | AChat | Chatwoot |
|---|---|---|
| Kostenloser Tarif ohne Enddatum | Ja | Ja (<a href="https://www.chatwoot.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">ihre Seite</a>) |
| Fertiger Chat zum Einfügen in eine Seite | Ja | Auf den geprüften Seiten nicht angegeben |
| Auf eigenen Servern betreiben | Nein | Ja (<a href="https://www.chatwoot.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">ihre Seite</a>) |

Das Widget von AChat ist kein Agenten-Postfach. Ohne Passwort kann jeder auf der Seite den Raum lesen.
