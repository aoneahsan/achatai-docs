# Von Sendbird zu AChat wechseln

**Sendbird ist In-App-Chat, abgerechnet nach monatlich aktiven Nutzern, mit kostenloser Testphase.** Ist Chat Teil deines eigenen Produkts und hast du ein Budget dafür, ist Sendbird dafür gebaut. AChat passt zu einer kleineren Aufgabe: einem Raum auf einer Seite, wenn du für den Start lieber nichts zahlen willst.

Zuletzt geprüft am 2026-11-22. Der ganze Vergleich steht unter [AChat und Sendbird](https://achat.aoneahsan.com/de/compare/sendbird).

## Bevor die Testphase zur Rechnung wird

Die Tarife von Sendbird beginnen bei 349 $ pro Monat bei jährlicher Abrechnung. Hat deine Testphase gezeigt, dass du nur einen Ort brauchst, an dem Besucher reden können, probier zuerst das hier.

1. Schreib auf, wofür die Testphase war. Ging es um Nachrichten zwischen deinen eigenen angemeldeten Nutzern, prüf Sendbird weiter; das Widget von AChat ist dafür kein SDK.
2. War es ein öffentlicher Raum, bau einen auf der [Widget-Seite](https://achat.aoneahsan.com/de/widget) im kostenlosen Tarif von AChat ([einbettbares Widget](/features/embeddable-widget)).
3. Füg den Code dort ein, wo der Chat der Testphase saß.
4. Schalte **Anmeldung anbieten** ein, wenn Besucher den Raum behalten können sollen. Die Anmeldung öffnet sich in einem neuen Tab, und zum Chatten braucht es sie nie.
5. Setz ein Passwort, wenn der Raum unter den Leuten bleiben soll, die du einlädst.

## Sendbird laut seiner Preisseite

Ihre Preisseite sagt, dass es keinen kostenlosen Tarif ohne Enddatum gibt. Die geprüften Seiten sagten nicht, ob Sendbird einen fertigen Chat zum Einfügen in eine Seite oder eine Version für eigene Server anbietet, deshalb fehlen diese Zeilen.

| Funktion | AChat | Sendbird |
|---|---|---|
| Kostenloser Tarif ohne Enddatum | Ja | Nein (<a href="https://sendbird.com/pricing/chat" target="_blank" rel="noopener noreferrer nofollow">ihre Seite</a>) |

AChat gibt es nur gehostet, und sein Widget ist ein fertiger Raum, weder SDK noch Agenten-Postfach.
