# Von LiveChat zu AChat wechseln

**LiveChat ist Live-Chat mit Preisen pro Nutzer und einer 14-tägigen Testphase.** Er ist für Agenten gemacht, die Besuchern einzeln antworten. Läuft deine Website so, behalte ihn. AChat ist für etwas Kostenloses auf deiner Seite, schon heute, ohne Testphase, die abläuft.

Zuletzt geprüft am 2026-11-22. Die Vergleichsseite: [AChat und LiveChat](https://achat.aoneahsan.com/de/compare/livechat).

## Wenn deine Testphase bald endet

Vielleicht hast du eine LiveChat-Testphase begonnen und gemerkt, dass Besucher gar keinen Agenten brauchten. So steht ein Raum bereit, bevor die Testphase endet.

1. Öffne die [Widget-Seite](https://achat.aoneahsan.com/de/widget) und wähl einen anonymen Raum oder einen offenen Community-Kanal ([einbettbares Widget](/features/embeddable-widget)).
2. Probier beide Layouts in der Vorschau aus; sie füllt den Raum mit Beispielnachrichten, damit du die Größe beurteilen kannst.
3. Kopier den Code und ersetze damit das LiveChat-Snippet.
4. Besucher wählen einen Anzeigenamen und schreiben. Niemand wartet in einer Schlange, denn es gibt keine.
5. Ein Passwort sorgt dafür, dass nur die Leute den Raum lesen, denen du es gibst.

## Was die Seiten von LiveChat nicht sagten

Die LiveChat-Seiten, die wir gelesen haben, sagten nicht, ob es einen kostenlosen Tarif ohne Enddatum, einen fertigen Chat zum Einfügen in eine Seite oder eine Version für eigene Server gibt. Deshalb gibt es keine Funktionstabelle. Prüf es auf der <a href="https://www.livechat.com" target="_blank" rel="noopener noreferrer nofollow">Website von LiveChat</a>.

AChat hat einen kostenlosen Tarif und ein fertiges Widget, und es gibt es nur gehostet. Das Widget ist weder ein Agenten-Postfach noch ein Entwickler-SDK.
