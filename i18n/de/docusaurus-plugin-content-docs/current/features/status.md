# Status

**Ein Status ist eine Neuigkeit für deine angenommenen Kontakte, die nach 24 Stunden verschwindet.** Für Status brauchst du ein Konto.

## Wer ihn sieht

Standardmäßig deine angenommenen Kontakte. Vor dem Posten kannst du ihn nur mit einigen von ihnen teilen oder bestimmte Leute ausschließen. Was du auch wählst: Sehen können ihn nur Leute, die du als Kontakte angenommen hast.

## Aufrufe, Antworten und Löschen

- Du siehst, wer deinen Status angesehen hat.
- Eine Antwort auf einen Status landet in deinem persönlichen Chat mit dieser Person.
- Löschst du einen Status, verschwindet er sofort für alle. Wer ihn schon gesehen hat, hat ihn gesehen.

## Die Grenze

Status sind nicht Ende-zu-Ende-verschlüsselt, die Server von AChat können sie also lesen. Zugriffsregeln begrenzen, wer sonst jeden einzelnen sehen kann, auf das Publikum, das du gewählt hast.
