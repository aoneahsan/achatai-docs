# Einbettbares Widget

**Wähle einen Raum oder Kanal, wähle das Aussehen und kopiere dann den Code in deine Seite.** Bau es auf der [Widget-Seite](https://achat.aoneahsan.com/de/widget), die vor dem Kopieren eine Vorschau mit Demo-Nachrichten zeigt.

## Was du einbetten kannst

| Ziel | Bedingung |
|---|---|
| Anonymer Raum | Jede Raum-ID: 8–20 Kleinbuchstaben, Ziffern und Bindestriche. Beim ersten Öffnen des Widgets wird ein neuer Raum angelegt |
| Community-Kanal | Nur Kanäle mit Anzeigenamen in Communities mit der Kennzeichnung **Anonym erlaubt** |

Private Gruppen und Kanäle, die ein Konto brauchen, lassen sich nicht auf anderen Websites zeigen.

## Layout und Optionen

- **In der Seite:** der Chat in fester Größe dort, wo du den Code einfügst.
- **Chat-Button:** ein Button in einer Ecke, der den Chat in einem Bereich öffnet.
- **Kompakt**, **Chat-Kopfzeile ausblenden** und **Anmeldung anbieten** (Besucher können sich anmelden, um den Raum zu behalten; zum Chatten ist das nie nötig, und die Anmeldung öffnet sich in einem neuen Tab).

## Erlaubte Websites

Trag bis zu 20 Websites ein, die den Chat zeigen dürfen. Solange du keine einträgst, darf jede Website ihn zeigen.

- Bei einem Raum kann nur die Person, die ihn behält, die Liste ändern. Niemand kann einen Raum einschränken, bevor ihn jemand behält.
- Bei einem Kanal können das nur die Admins der Community.

Eine Website, die nicht auf der Liste steht, zeigt einen Hinweis und einen Link, um den Chat stattdessen in AChat zu öffnen.

## Was Besucher wissen sollten

- Jeder, der eine Seite mit dem Widget besucht, kann den Raum lesen und darin schreiben, es sei denn, der Raum hat ein Passwort. Nachrichten folgen dem Verlauf des Raums selbst.
- Anmeldung, Mikrofon und Standort funktionieren innerhalb einer anderen Website nicht. Ein Chat, der den Standort aufzeichnet, öffnet sich nur in AChat.
- Die Browsereinstellungen der Website können verhindern, dass AChat sich an Besucher erinnert, sodass sie beim nächsten Mal vielleicht wieder einen Anzeigenamen wählen müssen.
