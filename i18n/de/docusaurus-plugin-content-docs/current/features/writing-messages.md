# Nachrichten schreiben

**Das Nachrichtenfeld behält deinen Entwurf, formatiert Spoiler und Mathe und nimmt Diktat an. Übersetzung und Vorlesen laufen auf deinem Gerät.**

## Entwürfe

Ein ungesendeter Entwurf bleibt bei seinem Chat und erscheint in der Chatliste. Einen Entwurf zu verwerfen, lässt sich rückgängig machen.

## Formatierung

| Schreib | Du bekommst |
|---|---|
| `\|\|text\|\|` | Einen Spoiler, verborgen bis zum Antippen |
| `$formula$` | Mathe in einem Satz |
| `$$formula$$` | Mathe in einer eigenen Zeile |
| `@username` oder `@all` | Eine Erwähnung. Eine Erwähnung von dir ist umrandet, und **Erwähnungen von dir** listet sie auf |

Eine Formel, die sich nicht zeichnen lässt, erscheint so, wie sie getippt wurde.

## Die Formatierungsleiste

Über dem Nachrichtenfeld: **Fett**, **Kursiv**, **Durchgestrichen**, **Code**, **Link**, **Codeblock**, **Aufzählung**, **Nummerierte Liste** und **Zitat**. Auf einem breiten Bildschirm ist die Leiste von Anfang an da; auf dem Handy blendet **Formatierung** (Aa) sie ein oder aus. Eine Nachricht ohne Formatierung geht als reiner Text raus. Eingefügter Text behält nur diese Arten von Formatierung. Nachrichten aus dem Editor des alten AChat erscheinen ebenfalls mit ihrer Formatierung.

Ein Codeblock wird für gängige Sprachen beim Anzeigen hervorgehoben. Das Antwortfeld im Thread hat dieselben Werkzeuge wie das Feld im Chat.

## Vorschläge beim Tippen

Tipp `@` und den Anfang eines Namens, um jemanden aus dem Chat zu wählen, oder `@all`. Tipp `/` am Anfang eines leeren Felds für Befehle: `/shrug` fügt ¯\\_(ツ)_/¯ ein, `/clear` leert deinen Entwurf und `/export` öffnet **Kopie speichern**. Alles andere, das mit `/` beginnt, wird so gesendet, wie es getippt ist.

## Vollbild und lange Nachrichten

**Im Vollbild schreiben** gibt dem Nachrichtenfeld das ganze Fenster; Esc führt zurück. Eine lange Nachricht wird nach ein paar Zeilen eingeklappt, mit **Mehr anzeigen**.

## Links

Eine Webadresse in einer Nachricht ist ein Link, der sich in einem neuen Tab öffnet. **Linkvorschauen anzeigen** (Konto › Einstellungen › Dieses Gerät) fügt eine Karte mit Titel und Bild der Seite hinzu. Standardmäßig ist das aus. Ist es an, liest der eigene Server von AChat die Seite und reicht ihr Bild weiter, sodass die verlinkte Website dein Gerät nie sieht; in einem Ende-zu-Ende-verschlüsselten Chat heißt das, dass der Link dein Gerät verlässt.

## Sticker und Emoji

Sieben Sticker gehören zu AChat, also wird nichts heruntergeladen. Ein Sticker, den deine Version nicht kennt, erscheint als nicht verfügbar.

## Diktat

**Diktieren** macht aus Sprache Text im Nachrichtenfeld, über den Sprachdienst deines Browsers. Manche Browser schicken deine Stimme an ihren Anbieter, um sie in Text zu verwandeln, und AChat sagt dir das, bevor es zuhört. Wo Diktat nicht verfügbar ist, kannst du tippen oder eine Sprachnachricht aufnehmen.

## Übersetzung

**Übersetze** eine Nachricht auf deinem Gerät. Für manche Sprachen lädt dein Browser zuerst ein Sprachpaket herunter, das auf dem Gerät bleibt. Wo Übersetzung nicht verfügbar ist, wird die Nachricht nirgendwohin gesendet.

## Vorlesen

**Vorlesen** spielt eine Nachricht mit einer Stimme auf deinem Gerät ab. Ein Browser ohne Stimme auf dem Gerät bietet das nicht an. Es spielt auch in einem stummgeschalteten Chat.

## Ungelesene Nachrichten

Eine Trennlinie markiert, wo neue Nachrichten beginnen, und ein Button springt dorthin.
