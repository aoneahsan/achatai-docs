# Darstellung, Sprache und Tastenkürzel

**Design, Farbe, Textgröße und Bewegung liegen in einem Darstellungsbereich, also zeigt sich eine Änderung überall zugleich.**

## Darstellung

Öffne den Darstellungsbereich, um Design, Farbe, Textgröße oder Bewegung zu ändern. Jede Wahl gilt auf jeder Seite.

## Sprache

Die Oberfläche von AChat gibt es in elf Sprachen: Englisch, Chinesisch, Hindi, Spanisch, Arabisch, Französisch, Portugiesisch, Russisch, Japanisch, Urdu und Deutsch. Wähl sie am Ende des Darstellungsbereichs; jede Sprache erscheint unter ihrem eigenen Namen. Arabisch und Urdu liest man von rechts nach links, und Chinesisch, Hindi, Japanisch und Urdu bekommen jeweils eine eigene Schrift.

## Tastenkürzel

Drück **?** irgendwo außerhalb eines Textfelds, um die Liste zu öffnen. Die meisten Tasten kannst du dort ändern. Kürzel zeigen **Strg**, auf Apple-Geräten **⌘**. Die Tabelle zeigt die ursprünglichen Tasten jedes Kürzels.

| Tasten | Aktion |
|---|---|
| Strg+K | Chat oder Seite finden |
| Enter | Senden |
| Umschalt+Enter | Neue Zeile |
| ↑ in einem leeren Nachrichtenfeld | Deine letzte Nachricht bearbeiten |
| Strg+Umschalt+S | Markierten Text als Spoiler kennzeichnen |
| Esc | Menü oder Dialog schließen, Antwort oder Bearbeitung abbrechen |
| Strg+Umschalt+F | Fokusmodus ein oder aus |
| Strg+Umschalt+H | Bildschirm sofort verbergen |
| ↑ / ↓, Pos1 / Ende | Durch die Chatliste bewegen |
| Alt+↑ / Alt+↓ | Vorheriger oder nächster Chat |
| Umschalt+F10 | Chat-Aktionen |

### Eine Taste ändern

Drück in der Liste neben einem Kürzel auf **Ändern** und dann die neuen Tasten. **Esc** bricht ab. **Zurücksetzen** gibt einem Kürzel seine ursprünglichen Tasten zurück, und **Alle zurücksetzen** allen, mit Rückgängig.

- Eine Tastenkombination gehört genau einem Kürzel. Ist sie vergeben, nennt AChat das Kürzel, das sie hat, und verlinkt darauf.
- Esc, die Pfeiltasten, Pos1, Ende und Umschalt+F10 sind Standardtasten. Sie lassen sich nicht ändern, weil Menüs, Dialoge und Listen darauf angewiesen sind.
- Dein Browser hält manche Kombinationen für sich, etwa Strg+W, deshalb kann AChat sie nicht nutzen.
- Bist du angemeldet, folgen deine Tasten deinem Konto auf jedes Gerät, auf dem du dich anmeldest. Abgemeldet bleiben sie nur in diesem Browser gespeichert.

## Fokusmodus

Schalte den **Fokusmodus** über das Menü eines Chats oder mit Strg+Umschalt+F ein. Drück **Esc**, um ihn zu verlassen.

## Barrierefreiheit

- Die Kürzel oben decken Chatliste, Chat und Nachrichtenfeld ab.
- Änderungen wie eine gesendete Nachricht oder ein wiederhergestellter Entwurf werden Screenreadern angesagt.
- Textgröße und Bewegung kommen aus der Darstellung.
- [Vorlesen](/features/writing-messages#read-aloud) spielt eine Nachricht mit einer Stimme auf dem Gerät ab.

## Seitenbereiche

Jeder Seitenbereich in Chats (ein Raum, Chat-Info, geteilte Medien, Papierkorb, ein Thread und andere) öffnet sich mit 60 % des Chatbereichs. Zieh an seinem Rand oder fokussiere den Rand und nutze die Pfeiltasten; ein Doppelklick führt zurück auf 60 %. Jeder Bereich merkt sich seine Breite auf diesem Gerät und, wenn du angemeldet bist, in deinem Konto.

## Darstellung als Datei

**Als Datei speichern** im Darstellungsbereich legt jede Darstellungswahl in einer kleinen Datei ab; **Aus Datei laden** wendet eine an.

## Tasten

Die Tasten 1 bis 6 reagieren mit den Schnellreaktionen auf die neueste Nachricht. **Vim-Tasten im Chat** (im Kürzel-Dialog) fügt j und k zum Scrollen, G für die neueste Nachricht und g g für die älteste geladene hinzu. Jedes Kürzel lässt sich ändern.
