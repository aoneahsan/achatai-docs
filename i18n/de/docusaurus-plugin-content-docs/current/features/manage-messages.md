# Nachrichten verwalten

**Jede Aktion an einer Nachricht sagt vor dem Bestätigen, was sie für wen ändert, und die meisten lassen sich rückgängig machen.**

## Aktionen an einer Nachricht

| Aktion | Was sie tut |
|---|---|
| Reagieren | Fügt eine Emoji-Reaktion hinzu |
| Antworten / Thread | Zitiert eine Nachricht oder öffnet einen [Thread](/features/threads-and-replies) dazu |
| Bearbeiten | Ändert deine eigene Nachricht, auch in verschlüsselten Chats |
| Weiterleiten | Schickt eine Kopie in einen anderen Chat. In einem verschlüsselten Chat wird sie für den Zielchat neu verschlüsselt |
| Anheften | Heftet eine Nachricht oben im Chat an |
| Link kopieren | Ein Link auf genau diese Nachricht, der sich nur für Leute im Chat öffnet |

## Löschen und Papierkorb

- **Für mich löschen** entfernt eine Nachricht nur für dich.
- **Für alle löschen** gilt für deine eigenen Nachrichten und verschiebt die Nachricht in den **Papierkorb** dieses Chats.
- Jeder im Chat kann eine Nachricht aus dem Papierkorb wiederherstellen oder endgültig löschen.
- Der Papierkorb hält Dinge eine festgelegte Zahl von Tagen, standardmäßig 30, und löscht sie dann endgültig. Nie länger als der eigene Verlauf des Chats oder der eigene Timer der Nachricht.

In einem Ende-zu-Ende-verschlüsselten Chat verschwindet eine für alle gelöschte Nachricht auch aus der Kopie, die jedes Gerät zum Offline-Lesen und für die Suche gespeichert hat, sobald dieses Gerät den Chat das nächste Mal lädt. Aus dem Papierkorb lässt sie sich noch wiederherstellen. Ist sie endgültig gelöscht, geht auch die gespeicherte Kopie, und sie kommt nicht zurück, wenn du ein Gerät verknüpfst oder deinen Verlauf wiederherstellst.

Ein gelöschter Chat wartet ebenfalls im Papierkorb, damit du ihn zurückholen kannst.

## Nachrichten leeren

- **Für mich leeren** verbirgt alle Nachrichten eines Chats nur für dich. Alle anderen behalten sie, und neue Nachrichten kommen weiter an. Gleich nach dem Leeren holt **Rückgängig** die Nachrichten zurück. Das klappt einmal und nur eine begrenzte Zeit; ist es nicht mehr verfügbar, ändert sich nichts und der Chat bleibt für dich geleert.
- **Für alle leeren** verschiebt alle Nachrichten als einen Stapel in den Papierkorb des Chats, „Geleerte Nachrichten“, den jeder im Chat mit **Alle wiederherstellen** zurückholen kann. In einer Gruppe können das nur Inhaber und Admins.

Kopien, die Leute schon gespeichert, weitergeleitet oder abfotografiert haben, bleiben bei ihnen.

## Verschwindende Nachrichten {#disappearing-messages}

Eine Einstellung pro Chat: **Aus**, **1 Minute**, **1 Stunde** oder **1 Tag**. Sie gilt für neue Nachrichten aller im Chat; schon gesendete behalten ihren eigenen Timer. Eine Zeile im Chat sagt, wenn jemand sie ändert, und jede Nachricht zeigt einen Countdown.

Jeder im Chat kann eine Nachricht trotzdem kopieren, speichern oder einen Screenshot machen, bevor sie verschwindet.

## Einmal ansehen

Schalte **Einmal ansehen** für deine nächste Nachricht ein. Sie bleibt verdeckt, bis sie geöffnet wird, öffnet sich ein paar Sekunden mit Countdown und ist dann von diesem Gerät weg. Du siehst, ob sie geöffnet wurde. Solange sie offen ist, kann sie noch kopiert oder abfotografiert werden. Öffnet sie sich wegen eines Verbindungsproblems nicht, ist sie nicht verbraucht: Die Abdeckung bleibt, und du kannst es eine kurze Zeit erneut versuchen.

## Umfragen

Schick eine Umfrage, und die Leute stimmen im Chat ab. Eine Umfrage zeigt, wie viele Leute jede Option gewählt haben, nicht wer, und jede Person kann eine Option wählen. Wer sie geschickt hat, kann sie schließen: Danach kann niemand mehr abstimmen, die Ergebnisse bleiben und die führende Option wird markiert. Eine geschlossene Umfrage lässt sich wieder öffnen.

## Archiv und privates Archiv {#archive-and-private-archive}

- **Archivieren** blendet einen Chat aus deiner Liste aus, ohne ihn zu löschen. Für niemanden sonst ändert sich etwas.
- **Archiviere eine Nachricht oder Antwort** über ihr Menü. Deine eigene Nachricht ist für alle verborgen, bis du sie zurückholst; die von jemand anderem nur für dich. Eine Hauptnachricht zu archivieren, nimmt ihren Thread mit. Haben andere auf deine Nachricht geantwortet, bleiben ihre Antworten unter „Nachricht archiviert“, und der Thread nimmt keine neuen Antworten an, bis du sie zurückholst.
- **Wähle** mehrere Nachrichten, Antworten oder Chats **aus** (über ein Menü oder per langem Drücken auf dem Handy) und archiviere sie gemeinsam oder hol sie gemeinsam zurück. Die Leiste sagt, wer sie nicht mehr sieht, bevor du „Archivieren“ drückst.
- Jede Ebene hat ihre eigene Ansicht: **Archivierte Chats** in deiner Liste, **Archivierte Nachrichten** über das Menü eines Chats oder die Chat-Info und **Archivierte Antworten** aus einem Thread. Dort läuft nichts von selbst ab, und nur du kannst zurückholen, was du archiviert hast. Eine Nachricht mit eigenem Verschwinde-Timer geht trotzdem, wenn er abläuft.
- **Privates Archiv** (anonyme Räume, mit Konto): Ab dann kann nur dein Konto den Raum öffnen, selbst mit Link oder Passwort, und er wird schreibgeschützt. Bei einem Raum, den jemand anderes behält, geht das nicht.

## Eine Kopie speichern

Speichere eine Kopie eines Chats als Webseite (.html) oder Markdown (.md). Die Datei enthält die Nachrichten, die du jetzt auf diesem Gerät lesen kannst, und jeder, der die Datei bekommt, kann sie lesen.

## Eine Nachricht markieren

**Markieren** kennzeichnet eine Nachricht nur auf diesem Gerät; nichts wird gesendet. Eine markierte Nachricht zeigt einen Stern, und **In diesem Chat suchen** kann nur markierte Nachrichten zeigen.

## Eine Nachricht melden

**Melden** schickt die Nachricht von jemand anderem mit einem Grund an die Moderatoren von AChat. Wer sie geschrieben hat, erfährt nicht, wer gemeldet hat. In einem Ende-zu-Ende-verschlüsselten Chat kann der Server von AChat keine Nachrichten lesen, also gehen die Worte, die dein Gerät zeigt, mit der Meldung mit, und der Dialog sagt das vorher.

## In diesem Chat suchen

**In diesem Chat suchen** (Strg oder ⌘ + F, oder das Menü Mehr des Chats) findet Wörter in den Nachrichten, die dieses Gerät geladen hat, auch in Ende-zu-Ende-verschlüsselten, weil die Suche auf deinem Gerät läuft. **Ältere Nachrichten durchsuchen** lädt mehr. Nichts wird irgendwohin gesendet.

## Eine Kopie aus einem Chat speichern

**Kopie speichern** (Strg oder ⌘ + E, oder das Menü Mehr des Chats) speichert den Chat als Datei auf deinem Gerät.
