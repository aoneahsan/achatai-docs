# Threads und Antworten

**Antworte in einem Thread, damit ein Plan nicht untergeht, während alle anderen weiterchatten.**

## Antwort oder Thread

- **Antworten** zitiert eine Nachricht im Hauptgespräch.
- **Thread** öffnet ein Nebengespräch zu einer Nachricht, in einem Bereich neben dem Chat. **Im Chat zeigen** springt zurück zur Nachricht, mit der er begann.

Threads gibt es in Chats, Räumen und Community-Kanälen.

## Löschen in einem Thread

- Löschst du eine einzelne Antwort, landet sie im Papierkorb des Chats.
- Löschst du die Nachricht, mit der ein Thread beginnt, landet sie mit allen Antworten im Papierkorb. Jede Person im Chat kann sie aus dem Papierkorb wiederherstellen.

Zum Papierkorb siehe [Nachrichten verwalten](/features/manage-messages).
