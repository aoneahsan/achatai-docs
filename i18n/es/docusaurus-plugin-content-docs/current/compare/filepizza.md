# Pasarte de FilePizza a AChat

**FilePizza hace transferencias de archivos de igual a igual en tu navegador.** Cuando quieras que un archivo vaya directamente de un navegador a otro, úsalo. AChat es para cuando la otra parte no va a estar conectada en el mismo momento.

Última comprobación el 2026-11-22. La comparación completa: [AChat y FilePizza](https://achat.aoneahsan.com/es/compare/filepizza).

## Dejarlo para luego

Una transferencia de navegador a navegador necesita los dos extremos a la vez. Una sala de AChat guarda el archivo hasta que aparece la otra parte.

1. Abre una sala desde **Continuar de forma anónima** ([salas anónimas](/features/anonymous-chats)). Nadie se registra.
2. Ciérrala con contraseña ([contraseñas y cifrado](/features/passwords-and-encryption)).
3. Adjunta el archivo y cierra tu pestaña; se queda en la sala ([compartir archivos](/features/file-sharing)).
4. Envía el enlace y la contraseña. La otra persona lo recoge cuando se conecte, y puede dejarte una respuesta.
5. Se borra tras el número de días fijado para la sala. Bórralo antes si quieres.

## Lo que decía la página de FilePizza

La página de FilePizza confirma archivos, que hemos marcado «en parte» para texto y archivos. No decía si hace falta cuenta, si se puede poner contraseña ni si la otra parte puede responder, así que esas filas quedan fuera.

| Función | AChat | FilePizza |
|---|---|---|
| Enviar texto y archivos | Sí | En parte (<a href="https://github.com/kern/filepizza" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |

AChat cubre las tres cosas: sin cuenta, una contraseña opcional y respuestas. En una sala sin contraseña, cualquiera con el enlace puede leerla.
