# Pasarte de Yopass a AChat

**Yopass crea enlaces secretos de un solo uso, cifrados en tu navegador, de código abierto y gratis para alojar por tu cuenta.** Si el secreto debe destruirse tras verlo una vez, o quieres alojar la herramienta tú mismo, quédate con Yopass; AChat no se puede alojar por tu cuenta. AChat es para una conversación que sigue abierta hasta que terminas.

Comprobado el 2026-11-22. Consulta [AChat y Yopass](https://achat.aoneahsan.com/es/compare/yopass) para la comparación.

## Mantener la conversación abierta

Un enlace de Yopass se cierra después de leerlo. Si la otra persona vuelve con «no ha funcionado», empiezas de nuevo. En una sala de AChat, responde donde lo dejaste.

1. Elige **Continuar de forma anónima** y luego **Crear sala** ([salas anónimas](/features/anonymous-chats)).
2. Pon una contraseña. Los mensajes de una sala con contraseña se cifran en tu dispositivo con ella ([contraseñas y cifrado](/features/passwords-and-encryption)).
3. Envía lo que haga falta, texto o un archivo ([compartir archivos](/features/file-sharing)), y luego el enlace y la contraseña por separado.
4. Quédate hasta resolverlo. Después borra tus mensajes, o deja que caduquen tras el número de días fijado para la sala.

## Lo que decía la página de Yopass

La página de Yopass confirma que admite texto y archivos. No decía si hace falta cuenta, si se puede poner contraseña ni si la otra parte puede responder, así que esas filas quedan fuera.

| Función | AChat | Yopass |
|---|---|---|
| Enviar texto y archivos | Sí | Sí (<a href="https://yopass.se/" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |

Las salas de AChat no necesitan cuenta, admiten contraseña y dejan responder a la otra parte. Sin contraseña, cualquiera con el enlace puede leer la sala.
