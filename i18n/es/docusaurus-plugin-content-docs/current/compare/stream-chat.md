# Pasarte de Stream Chat a AChat

**Stream Chat es chat para que los desarrolladores lo integren en sus apps, gratis hasta 1.000 usuarios activos al mes.** Si tus desarrolladores están integrando chat en tu propio producto y quieren controlar cada parte, Stream es el tipo de herramienta adecuado. AChat es el intercambio opuesto: pegas un fragmento y tienes un chat funcionando, sin desarrolladores de por medio.

Comprobado el 2026-11-22. La comparación lado a lado está en [AChat y Stream Chat](https://achat.aoneahsan.com/es/compare/stream-chat).

## Cuando el SDK era más que el trabajo

A veces los equipos adoptan un SDK de chat para lo que acaba siendo una sala pública en una página. Si es tu caso, esto lleva minutos en lugar de un sprint.

1. Mantén Stream allí donde el chat esté ligado a tus propios usuarios y datos. El widget de AChat no es un SDK para desarrolladores, así que no se monta sobre tus propias cuentas de usuario.
2. Para la sala pública, abre la [página del widget](https://achat.aoneahsan.com/es/widget) y elige un ID de sala o un canal abierto de comunidad ([widget integrable](/features/embeddable-widget)).
3. Elige el diseño y las opciones; la página del widget te escribe el código.
4. Copia el fragmento en la plantilla de tu página.
5. Cuando alguien conserve la sala, podrá indicar los dominios autorizados a mostrarla, hasta 20.

## Según la página de precios de Stream

La página de precios de Stream confirma un plan gratuito sin fecha de fin. Las páginas que revisamos no decían si Stream te da un chat ya hecho para añadir a una página ni si puedes ejecutarlo en tus servidores, así que esas filas quedan fuera.

| Función | AChat | Stream Chat |
|---|---|---|
| Plan gratuito sin fecha de fin | Sí | Sí (<a href="https://getstream.io/chat/pricing/" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |

El widget de AChat es una sala ya hecha, alojada solo por nosotros. No es un SDK para desarrolladores, y cualquiera en la página puede leer la sala salvo que tenga contraseña.
