# Pasarte de LiveChat a AChat

**LiveChat es chat en vivo con precio por usuario y una prueba de 14 días.** Está hecho para agentes que atienden a los visitantes uno a uno. Si tu web funciona así, quédatelo. AChat es para tener algo gratis en tu página desde hoy, sin prueba que se acabe.

Última comprobación el 2026-11-22. La página lado a lado: [AChat y LiveChat](https://achat.aoneahsan.com/es/compare/livechat).

## Si tu prueba se está acabando

Quizá empezaste una prueba de LiveChat y viste que los visitantes no necesitaban ningún agente. Así puedes tener una sala lista antes de que termine la prueba.

1. Abre la [página del widget](https://achat.aoneahsan.com/es/widget) y elige una sala anónima o un canal abierto de comunidad ([widget integrable](/features/embeddable-widget)).
2. Prueba los dos diseños en la vista previa, que llena la sala de mensajes de demostración para que juzgues el tamaño.
3. Copia el código y sustituye el fragmento de LiveChat.
4. Los visitantes eligen un nombre visible y hablan. Nadie espera en una cola, porque no la hay.
5. Una contraseña hace que la sala solo la lean las personas a quienes se la des.

## Lo que no decían las páginas de LiveChat

Las páginas de LiveChat que leímos no indicaban si hay un plan gratuito sin fecha de fin, un chat ya hecho para añadir a una página o una versión para ejecutar en tus servidores. Por eso no hay tabla de funciones. Compruébalo en la <a href="https://www.livechat.com" target="_blank" rel="noopener noreferrer nofollow">web de LiveChat</a>.

AChat tiene plan gratuito y un widget ya hecho, y solo está alojado por nosotros. El widget no es una bandeja de agentes ni un SDK para desarrolladores.
