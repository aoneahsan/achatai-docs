# Pasarte de Chatwoot a AChat

**Chatwoot es una plataforma de atención al cliente de código abierto que puedes alojar por tu cuenta, o pagar por agente.** Llevar el soporte en tus propios servidores es una buena razón para quedarte; AChat no se puede alojar por tu cuenta. Es para cuando no quieres ejecutar nada, y tus visitantes hablan entre sí en lugar de con agentes.

Comprobado el 2026-11-22. Consulta [AChat y Chatwoot](https://achat.aoneahsan.com/es/compare/chatwoot) para la comparación.

## Retirar una instancia propia

Si tu servidor de Chatwoot aloja sobre todo charla entre visitantes, el mantenimiento puede costar más de lo que vale la sala.

1. Exporta primero de Chatwoot todo lo que necesites. No se importa nada a AChat.
2. Crea una sala o elige un canal abierto de comunidad en la [página del widget](https://achat.aoneahsan.com/es/widget) ([widget integrable](/features/embeddable-widget)). No hay servidor, base de datos ni actualizaciones que cuidar.
3. Pega el código donde funcionaba el widget de Chatwoot.
4. Conserva la sala con una cuenta, para que dure más allá del historial por defecto y puedas indicar las webs autorizadas a mostrarla.
5. Apaga tu instancia solo cuando la sala nueva lleve un tiempo funcionando.
