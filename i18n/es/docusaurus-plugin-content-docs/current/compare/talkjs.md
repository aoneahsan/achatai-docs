# Pasarte de TalkJS a AChat

**TalkJS es una interfaz de chat ya hecha para añadir a tu producto, gratis en modo de desarrollo.** Cuando el chat va dentro de tu propio producto y está ligado a tus propias cuentas de usuario, TalkJS encaja mejor. AChat se publica con el plan gratuito, y los visitantes que lo usan no necesitan cuenta en absoluto.

Comprobado el 2026-11-22. La página de comparación es [AChat y TalkJS](https://achat.aoneahsan.com/es/compare/talkjs).

## Del modo de desarrollo a una sala publicada

TalkJS es gratis mientras construyes en modo de desarrollo. Si lo que prototipaste era una sala pública y no chat entre tus usuarios, AChat puede publicarla con su plan gratuito.

1. Comprueba de qué depende tu prototipo. Las conversaciones ligadas a los ID de tus usuarios se quedan en TalkJS, porque el widget de AChat no es un SDK para desarrolladores y no conoce a tus usuarios.
2. Para una sala abierta, elige un ID de sala en la [página del widget](https://achat.aoneahsan.com/es/widget) ([widget integrable](/features/embeddable-widget)). Los visitantes entran con un nombre visible.
3. Elige **En la página** para ocupar el sitio de tu chat de TalkJS, o **Botón de chat** para un panel en una esquina.
4. Copia el código en la página.
5. Conserva la sala desde una cuenta y luego indica las webs autorizadas a mostrarla.
