# Widget para insertar

**Elige una sala o un canal, elige cómo se ve y copia el código en tu página.** Créalo en la [página del widget](https://achat.aoneahsan.com/es/widget), que muestra una vista previa con mensajes de demostración antes de copiar.

## Qué puedes insertar

| Destino | Condición |
|---|---|
| Sala anónima | Cualquier ID de sala: de 8 a 20 letras minúsculas, números y guiones. La primera vez que alguien abre el widget se crea una sala nueva |
| Canal de comunidad | Solo canales con nombre visible en comunidades marcadas como **Se permite el anonimato** |

Los grupos privados y los canales que necesitan cuenta no se pueden mostrar en otras webs.

## Diseño y opciones

- **En la página:** el chat con un tamaño fijo donde pegues el código.
- **Botón de chat:** un botón en una esquina que abre el chat en un panel.
- **Compacta**, **Ocultar el encabezado del chat** y **Ofrecer inicio de sesión** (los visitantes pueden iniciar sesión para conservar la sala; chatear nunca lo necesita, y el inicio de sesión se abre en una pestaña nueva).

## Webs permitidas

Indica hasta 20 webs que pueden mostrar el chat. Hasta que añadas una, cualquier web puede mostrarlo.

- En una sala, solo quien la conserva puede cambiar la lista. Nadie puede limitar una sala hasta que alguien la conserve.
- En un canal, solo los admins de la comunidad.

Una web que no está en la lista muestra un aviso y un enlace para abrir el chat en AChat.

## Lo que deben saber los visitantes

- Cualquiera que visite una página con el widget puede leer la sala y escribir en ella, salvo que la sala tenga contraseña. Los mensajes siguen el historial de la propia sala.
- El inicio de sesión, el micrófono y la ubicación no funcionan dentro de otra web. Un chat que registra la ubicación solo se abre en AChat.
- Los ajustes del navegador en esa web pueden impedir que AChat recuerde a un visitante, así que quizá tenga que volver a elegir un nombre visible la próxima vez.
