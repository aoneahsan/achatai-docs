# Do TalkJS para o AChat

**O TalkJS é uma interface de chat pronta para adicionar ao seu produto, grátis em modo de desenvolvimento.** Quando o chat pertence ao seu próprio produto e está ligado às suas próprias contas de usuário, o TalkJS encaixa melhor. O AChat entra no ar no plano grátis, e os visitantes que o usam não precisam de conta nenhuma.

Conferido em 2026-11-22. A página de comparação é [AChat e TalkJS](https://achat.aoneahsan.com/pt-BR/compare/talkjs).

## Do modo de desenvolvimento a uma sala no ar

O TalkJS é grátis enquanto você constrói em modo de desenvolvimento. Se o que você prototipou foi uma sala pública, e não chat entre os seus usuários, o AChat pode colocá-la no ar no plano grátis.

1. Veja do que o seu protótipo depende. Conversas ligadas aos IDs dos seus usuários ficam no TalkJS, porque o widget do AChat não é um SDK para desenvolvedores e não conhece os seus usuários.
2. Para uma sala aberta, escolha um ID de sala na [página do widget](https://achat.aoneahsan.com/pt-BR/widget) ([widget incorporável](/features/embeddable-widget)). Os visitantes entram com um nome de exibição.
3. Escolha **Dentro da página** para ficar onde estava o chat do TalkJS, ou **Botão de conversa** para um painel no canto.
4. Copie o código para a página.
5. Mantenha a sala com uma conta e depois liste os sites autorizados a mostrá-la.
