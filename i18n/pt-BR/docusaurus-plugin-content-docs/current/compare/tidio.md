# Do Tidio para o AChat

**O Tidio é chat com clientes com um agente de IA chamado Lyro, cobrado por conversas.** Se você quer um agente respondendo clientes, isso é o Tidio. O AChat é para páginas onde as pessoas vêm conversar entre si, e você não quer contar conversas.

Última conferência em 2026-11-22. Comparação completa: [AChat e Tidio](https://achat.aoneahsan.com/pt-BR/compare/tidio).

## Trocando um bot que responde por uma sala

Ninguém responde em nome do AChat. Os visitantes respondem uns aos outros, então isso só funciona onde essa é a ideia.

1. Escolha as páginas em que os visitantes conversam entre si, e não com você. Deixe o Tidio no resto.
2. Na [página do widget](https://achat.aoneahsan.com/pt-BR/widget), escolha uma sala anônima ou um canal aberto de comunidade, depois um layout ([widget incorporável](/features/embeddable-widget)).
3. Ligue **Compacto** ou **Ocultar o cabeçalho da conversa** se a sala ficar numa coluna estreita.
4. Cole o código nessas páginas.
5. Ponha uma senha na sala se só certos visitantes devem ler.
