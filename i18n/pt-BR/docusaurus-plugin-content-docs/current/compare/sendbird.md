# Do Sendbird para o AChat

**O Sendbird é chat dentro do app cobrado por usuários ativos mensais, com teste grátis.** Se o chat faz parte do seu próprio produto e você tem verba para isso, o Sendbird foi feito para isso. O AChat serve para um pedido menor: uma sala numa página, quando você prefere não pagar para começar.

Última conferência em 2026-11-22. A comparação completa está em [AChat e Sendbird](https://achat.aoneahsan.com/pt-BR/compare/sendbird).

## Antes de o teste virar conta

Os planos do Sendbird começam em US$ 349 por mês com cobrança anual. Se o seu teste mostrou que você só precisava de um lugar para os visitantes conversarem, experimente isto primeiro.

1. Anote para que era o teste. Se era para mensagens entre os seus próprios usuários logados, continue avaliando o Sendbird; o widget do AChat não é um SDK para isso.
2. Se era uma sala pública, monte uma na [página do widget](https://achat.aoneahsan.com/pt-BR/widget) no plano grátis do AChat ([widget incorporável](/features/embeddable-widget)).
3. Cole o código onde ficava o chat do teste.
4. Ligue **Oferecer login** se os visitantes devem poder manter a sala. O login abre numa nova aba, e conversar nunca precisa dele.
5. Ponha uma senha se a sala deve ficar entre as pessoas que você convida.

## O Sendbird, segundo a página de preços dele

A página de preços deles diz que não há plano grátis sem data para acabar. As páginas que conferimos não diziam se o Sendbird oferece um chat pronto para colocar em uma página ou uma versão para rodar nos seus próprios servidores, então essas linhas não aparecem.

| Recurso | AChat | Sendbird |
|---|---|---|
| Plano grátis sem data para acabar | Sim | Não (<a href="https://sendbird.com/pricing/chat" target="_blank" rel="noopener noreferrer nofollow">página deles</a>) |

O AChat é só hospedado, e o widget dele é uma sala pronta, não um SDK nem uma caixa de entrada de atendentes.
