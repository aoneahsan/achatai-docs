# Do tlk.io para o AChat

**O tlk.io é uma sala de chat na web num endereço, sem cadastro, que você pode incorporar no seu site.** Para uma sala descartável, sem nada para ler antes, é difícil de bater. As salas do AChat começam do mesmo jeito e vão além quando você precisa: senha, arquivos ou alguém mantendo a sala.

Última conferência em 2026-11-22. Lado a lado: [AChat e tlk.io](https://achat.aoneahsan.com/pt-BR/compare/tlk-io).

## O mesmo hábito, uma escolha a mais

Uma sala do tlk.io é um endereço que você espalha. Uma sala do AChat também.

1. Abra o AChat, escolha **Continuar anonimamente** e depois **Criar sala**. Você recebe a sala e o link para mandar ([salas anônimas](/features/anonymous-chats)).
2. Se a sala não é para qualquer um que adivinhe o link, defina uma senha ao criá-la. A senha também criptografa as mensagens da sala ([senhas e criptografia](/features/passwords-and-encryption)).
3. Mande arquivos para a sala além das mensagens ([compartilhamento de arquivos](/features/file-sharing)).
4. Cada mensagem é apagada depois de um número definido de dias, 10 por padrão. Se a sala deve durar, alguém com conta [a mantém](/features/keep-chats-and-accounts).
5. Tinha o tlk.io incorporado no seu site? A [página do widget](https://achat.aoneahsan.com/pt-BR/widget) faz o mesmo para uma sala do AChat.
