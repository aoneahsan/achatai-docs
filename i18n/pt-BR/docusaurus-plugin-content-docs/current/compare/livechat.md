# Do LiveChat para o AChat

**O LiveChat é chat ao vivo cobrado por usuário, com teste de 14 dias.** Ele foi feito para atendentes que respondem visitantes um a um. Se o seu site funciona assim, fique com ele. O AChat é para ter algo grátis na sua página hoje, sem teste para acabar.

Última conferência em 2026-11-22. A página lado a lado: [AChat e LiveChat](https://achat.aoneahsan.com/pt-BR/compare/livechat).

## Se o seu teste está acabando

Talvez você tenha começado um teste do LiveChat e visto que os visitantes nem precisavam de atendente. Veja como ter uma sala pronta antes de o teste acabar.

1. Abra a [página do widget](https://achat.aoneahsan.com/pt-BR/widget) e escolha uma sala anônima ou um canal aberto de comunidade ([widget incorporável](/features/embeddable-widget)).
2. Teste os dois layouts na prévia, que enche a sala de mensagens de demonstração para você avaliar o tamanho.
3. Copie o código e substitua o snippet do LiveChat.
4. Os visitantes escolhem um nome de exibição e conversam. Ninguém espera numa fila, porque não existe fila.
5. Uma senha deixa a sala legível só por quem você der a senha.

## O que as páginas do LiveChat não disseram

As páginas do LiveChat que lemos não diziam se existe plano grátis sem data para acabar, um chat pronto para colocar em uma página ou uma versão para rodar nos seus próprios servidores. Por isso não há tabela de recursos. Confira no <a href="https://www.livechat.com" target="_blank" rel="noopener noreferrer nofollow">site do LiveChat</a>.

O AChat tem plano grátis e um widget pronto, e é só hospedado. O widget não é caixa de entrada de atendentes nem SDK para desenvolvedores.
