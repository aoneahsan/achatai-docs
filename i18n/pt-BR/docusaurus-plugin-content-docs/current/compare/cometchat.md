# Do CometChat para o AChat

**O CometChat é chat para desenvolvedores, grátis para até 100 usuários no plano Build.** Se os seus desenvolvedores estão colocando chat no seu próprio app, fique com ele. O AChat é para quando você prefere colar um snippet e deixar os visitantes conversarem sem conta.

Última conferência em 2026-11-22. Lado a lado: [AChat e CometChat](https://achat.aoneahsan.com/pt-BR/compare/cometchat).

## Depois da marca de 100 usuários

O plano Build cobre até 100 usuários. Se o que você construiu nele é, na verdade, uma sala pública para visitantes, veja a troca.

1. Separe os dois usos. O chat dentro do app entre os seus próprios usuários fica no CometChat.
2. Para a parte pública, crie uma sala ou escolha um canal aberto de comunidade na [página do widget](https://achat.aoneahsan.com/pt-BR/widget) ([widget incorporável](/features/embeddable-widget)).
3. Defina o layout e depois copie o código para a sua página.
4. Os visitantes escolhem um nome de exibição na sala. Ninguém precisa de conta.
5. Se a sala deve ser privada para um grupo, ponha uma senha e mande-a separadamente.

## As páginas do CometChat

A página de preços do CometChat confirma um plano grátis sem data para acabar. As páginas que conferimos não diziam se ele oferece um chat pronto para colocar em uma página nem se dá para rodá-lo nos seus próprios servidores, então essas linhas ficaram de fora.

| Recurso | AChat | CometChat |
|---|---|---|
| Plano grátis sem data para acabar | Sim | Sim (<a href="https://www.cometchat.com/pricing" target="_blank" rel="noopener noreferrer nofollow">página deles</a>) |

O AChat roda só hospedado. O widget dele é uma sala pronta, não uma caixa de entrada de atendentes nem um SDK.
