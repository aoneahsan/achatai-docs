# Do Stream Chat para o AChat

**O Stream Chat é chat para desenvolvedores colocarem nos próprios apps, grátis até 1.000 usuários ativos por mês.** Se os seus desenvolvedores estão colocando chat no seu próprio produto e querem controlar cada parte, o Stream é o tipo certo de ferramenta. O AChat é a troca oposta: você cola um snippet e tem um chat funcionando, sem desenvolvedores envolvidos.

Conferido em 2026-11-22. O lado a lado está em [AChat e Stream Chat](https://achat.aoneahsan.com/pt-BR/compare/stream-chat).

## Quando o SDK era maior que o trabalho

Às vezes as equipes adotam um SDK de chat para o que acaba sendo uma sala pública numa página só. Se é o seu caso, isto leva minutos em vez de um sprint.

1. Mantenha o Stream onde o chat estiver ligado aos seus próprios usuários e dados. O widget do AChat não é um SDK para desenvolvedores, então não fica por cima das suas contas de usuário.
2. Para a sala pública, abra a [página do widget](https://achat.aoneahsan.com/pt-BR/widget) e escolha um ID de sala ou um canal aberto de comunidade ([widget incorporável](/features/embeddable-widget)).
3. Escolha o layout e as opções; a página do widget escreve o código para você.
4. Copie o snippet para o template da sua página.
5. Quando alguém mantiver a sala, poderá listar os domínios autorizados a mostrá-la, até 20.
