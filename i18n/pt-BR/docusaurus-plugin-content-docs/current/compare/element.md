# Do Element para o AChat

**O Element vende chat para organizações: uma edição Community gratuita, mais as opções Enterprise e Sovereign com preço por assento ou por implantação.** Se você administra o chat de uma organização e quer a sua própria implantação, esta página não é para você; o AChat não roda nos seus próprios servidores. Ela é para o outro caso, em que você usava o Element para falar com amigos e família e prefere começar no navegador sem configurar nada.

Conferido em 2026-11-22. A comparação completa está em [AChat e Element](https://achat.aoneahsan.com/pt-BR/compare/element).

## Mudando um círculo pessoal

1. Abra [achat.aoneahsan.com](https://achat.aoneahsan.com) em qualquer navegador atual e [entre](/getting-started/quick-start). Não há nada para configurar. Escolha um nome de usuário; nenhum número de telefone é pedido.
2. Salve a sua chave de recuperação ([aparelhos e chave de recuperação](/features/devices-and-recovery)). Ela aparece uma vez só.
3. Adicione as poucas pessoas com quem você mais conversa, por nome de usuário, link de convite ou QR code ([conversas pessoais e contatos](/features/personal-chats-and-contacts)).
4. Transforme cada sala pequena do Element num [grupo](/features/groups-and-communities) do AChat. Os grupos têm criptografia de ponta a ponta. Quem entra pelo link espera um admin aprovar.
5. Uma sala maior e aberta fica melhor como comunidade com canais. Comunidades não têm criptografia de ponta a ponta.

O histórico de mensagens do Element fica com o Element. O AChat não importa conversas de outros apps.

## O que diz a página de preços do Element

Lemos a página de preços do Element. Ela diz que dá para se cadastrar sem número de telefone. Não disse nada sobre criptografia de ponta a ponta nas conversas pessoais nem sobre recuperar o histórico num aparelho novo, então deixamos essas linhas de fora.

| Recurso | AChat | Element |
|---|---|---|
| Cadastro sem número de telefone | Sim | Sim (<a href="https://element.io/en/pricing" target="_blank" rel="noopener noreferrer nofollow">página deles</a>) |

No AChat, as conversas pessoais têm criptografia de ponta a ponta. Um aparelho vinculado ou a sua chave de recuperação traz o histórico de volta, e sem eles ninguém consegue restaurar, nem nós. Não há chamadas de voz nem de vídeo.
