# Do Chatwoot para o AChat

**O Chatwoot é uma plataforma de suporte ao cliente de código aberto que você pode hospedar por conta própria, ou pagar por atendente.** Rodar o suporte nos seus próprios servidores é um bom motivo para ficar; o AChat não pode ser auto-hospedado. Ele é para quando você não quer rodar nada, e os seus visitantes estão conversando entre si, e não com atendentes.

Conferido em 2026-11-22. Veja [AChat e Chatwoot](https://achat.aoneahsan.com/pt-BR/compare/chatwoot) para a comparação.

## Aposentando uma instância auto-hospedada

Se o seu servidor do Chatwoot hospeda principalmente conversa entre visitantes, a manutenção pode valer mais que a sala.

1. Exporte primeiro tudo o que precisar do Chatwoot. Nada é importado para o AChat.
2. Monte uma sala ou escolha um canal aberto de comunidade na [página do widget](https://achat.aoneahsan.com/pt-BR/widget) ([widget incorporável](/features/embeddable-widget)). Não há servidor, banco de dados nem atualização para você cuidar.
3. Cole o código onde rodava o widget do Chatwoot.
4. Mantenha a sala com uma conta, para ela durar além do histórico padrão e você poder listar os sites autorizados a mostrá-la.
5. Desligue a sua instância só depois que a sala nova estiver rodando há um tempo.
