# Supervisão dos admins

**O painel de admin do AChat mostra os detalhes das conversas, nunca as mensagens, exceto o que quem denunciou escolheu enviar com a denúncia.** Toda mudança de admin fica num registro de ações que ninguém pode editar ou apagar, nem os admins.

## O que os admins veem

- **Conversas:** só tamanho, datas e configurações. Uma conversa criptografada mostra só os detalhes.
- **Denúncias:** sobre pessoas, salas e comunidades. Os admins veem só o que quem denunciou escolheu enviar, nunca quem enviou.
- **Histórico de localização privado:** os admins não conseguem abrir.

## O que os admins podem fazer {#what-admins-can-do}

| Ação | Efeito |
|---|---|
| Remover mensagens denunciadas | Remove para todos na conversa. Só os admins do AChat conseguem restaurá-las |
| Restringir uma sala | Pessoas novas não conseguem abri-la por link nem entrar. Os membros que já estão nela continuam conversando |
| Suspender uma conta | A pessoa não consegue entrar nem enviar até um admin tirar a suspensão. As conversas dela são mantidas, e ela pode pedir uma revisão pela página de contato |
| Conceder um plano ou limite | Define um plano ou limites personalizados para uma conta, com data de término própria |
| Marcar uma sala para guardar para sempre | Deixa uma concessão de guardar para sempre limitada a salas marcadas cobrir aquela sala |
| Definir Guardar para sempre para uma pessoa | Escolhe se a pessoa pode guardar salas para sempre: **Não permitido**, **Só salas marcadas**, **Qualquer sala** ou **Toda sala, automaticamente**. É preciso um motivo, a não ser que a escolha seja Não permitido. Mudar isso nunca encurta uma sala que já está guardada para sempre |
| Marcar uma comunidade como Adulto | Muda a marca 18+ de uma comunidade |
| Excluir uma conta a pedido | Para quem não consegue entrar, a partir de um pedido feito pelo e-mail Google daquela conta |

Os admins também confirmam à mão os pagamentos por transferência bancária e respondem à caixa de contato.

Para [pagamentos com cartão](/features/plans-and-pricing#card), os admins podem abrir ou fechar novas vendas por cartão, ligar produtos da Polar a planos e períodos, definir o preço anual de um plano e quanto tempo um plano continua depois de uma renovação que falhou. Fechar as vendas por cartão não encerra as assinaturas que as pessoas já têm. Cada mudança fica no registro de ações.

## Limites que os admins definem

Os admins definem os limites do AChat no painel de admin, como quanto tempo a Lixeira guarda as coisas e quanto duram as mensagens das salas anônimas. Dois deles delimitam a [busca](/features/search-and-history) em cada dispositivo: **Conversas na busca**, o máximo de conversas que a busca cobre (fixadas primeiro, depois as mais recentes), e **Mensagens na busca**, o máximo de mensagens que ela cobre em cada conversa, das mais novas para trás. Cada campo aceita só um número inteiro dentro do intervalo permitido.

## Moderação dentro de grupos e comunidades

Quem cuida do espaço age primeiro. Admins de grupo podem remover membros e apagar qualquer mensagem; admins de comunidade cuidam das denúncias e dos banimentos. Veja [Grupos e comunidades](/features/groups-and-communities).

## O registro de ações

Toda mudança de admin aparece com quem fez e quando. Uma mudança em Guardar para sempre mostra a configuração antes e depois. Ninguém pode editar ou apagar um registro. O histórico de dispositivos e localização das conversas não faz parte deste registro.

## Revisões

Se você acha que uma suspensão ou um banimento está errado, peça uma revisão à equipe do AChat pela [página de contato](https://achat.aoneahsan.com/pt-BR/contact). A equipe toma a decisão final, e uma revisão não garante nenhum resultado.
