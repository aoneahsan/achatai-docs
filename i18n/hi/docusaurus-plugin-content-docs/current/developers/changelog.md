# डेवलपर चेंजलॉग

API, असिस्टेंट कनेक्शन, वेबहुक और दो-चरण साइन इन के बदलाव, सबसे नए पहले। API `v1` है।

## ओपन प्लैटफ़ॉर्म (2026-11-21)

- **[AChat API](./api.md)** `https://vhkerwyxmhaxfyjbvsha.supabase.co/functions/v1/api/v1` पर, अकाउंट › दूसरे ऐप में बनाई [एक्सेस की](./access-keys.md) (`achat_pat_…`) के साथ। आपकी प्रोफ़ाइल, सेटिंग, स्टेटस पोस्ट (टेक्स्ट) और ब्लॉक सूची पढ़ी और बदली जा सकती है; कॉन्टैक्ट, चैट, खुले रूम के मैसेज, कम्युनिटी और चैनल सिर्फ़ पढ़े जा सकते हैं। OpenAPI 3.1 दस्तावेज़ `/openapi.json` पर है।
- **[असिस्टेंट कनेक्शन](./assistants.md)** `https://vhkerwyxmhaxfyjbvsha.supabase.co/functions/v1/mcp` पर, Claude, ChatGPT, Claude Code और Cursor के लिए। हर एक को आप AChat पर मंज़ूरी देते हैं, और असिस्टेंट का हटाना `/developers/confirm` पर आपकी हाँ का इंतज़ार करता है।
- **[वेबहुक](./webhooks.md)** ग्यारह इवेंट के लिए, Standard Webhooks से हस्ताक्षरित, सिर्फ़ ID और समय के साथ।
- **[दो-चरण साइन इन](./two-step-sign-in.md)** ऑथेंटिकेटर ऐप, दस रिकवरी कोड और वैकल्पिक 7 दिन तक ब्राउज़र याद रखने के साथ। AChat की एडमिन स्क्रीन चलाने वाले अकाउंट के लिए ज़रूरी।
- एंड-टू-एंड एन्क्रिप्टेड चैट इन सबसे बाहर रहती हैं: बाहरी ऐप को चैट का नाम और सदस्य दिखते हैं, मैसेज कभी नहीं।
- कोई कैलेंडर फ़ीड नहीं: AChat के पास उसमें डालने लायक़ तारीख़ वाली कोई चीज़ नहीं।
