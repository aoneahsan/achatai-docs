# Claude, ChatGPT, Claude Code या Cursor जोड़ें

**AChat का असिस्टेंट पता अपने असिस्टेंट में पेस्ट करें, AChat पर मंज़ूरी दें, और वह आपका अकाउंट पढ़ सकता है और जो आपका है उसे बदल सकता है।** उसे सिर्फ़ वही दिखता है जो आप मंज़ूरी देते समय टिक करते हैं। वह एंड-टू-एंड एन्क्रिप्टेड मैसेज कभी नहीं पढ़ सकता, और AChat पर आपकी हाँ के बिना कुछ नहीं मिटा सकता।

AChat का असिस्टेंट पता:

```text
https://vhkerwyxmhaxfyjbvsha.supabase.co/functions/v1/mcp
```

यह Streamable HTTP पर चलने वाला रिमोट MCP सर्वर है। यह **खाता › दूसरे ऐप › असिस्टेंट जोड़ें** में भी **कॉपी करें** बटन के साथ मिलता है।

## Claude

1. Claude में **Settings**, फिर **Connectors** खोलें।
2. **Add custom connector** चुनें और AChat का पता पेस्ट करें।
3. Claude AChat खोलता है। देखें कि वह क्या माँगता है, और मंज़ूरी दें।

## ChatGPT

1. ChatGPT में **Settings**, फिर **Apps and Connectors** खोलें, और डेवलपर मोड चालू करें।
2. **Create** चुनें, नाम AChat रखें और पता पेस्ट करें।
3. ChatGPT AChat खोलता है। देखें कि वह क्या माँगता है, और मंज़ूरी दें।

## Claude Code

1. टर्मिनल में चलाएँ:

   ```bash
   claude mcp add --transport http achat https://vhkerwyxmhaxfyjbvsha.supabase.co/functions/v1/mcp
   ```

2. Claude Code में `/mcp` चलाएँ और **achat** चुनें।
3. आपका ब्राउज़र AChat खोलता है। देखें कि वह क्या माँगता है, और मंज़ूरी दें।

## Cursor

1. Cursor में **Settings**, फिर **MCP**, फिर **Add new MCP server** खोलें।
2. इसे `mcp.json` में पेस्ट करें:

   ```json
   { "mcpServers": { "achat": { "url": "https://vhkerwyxmhaxfyjbvsha.supabase.co/functions/v1/mcp" } } }
   ```

3. Cursor AChat खोलता है। देखें कि वह क्या माँगता है, और मंज़ूरी दें।

OAuth सपोर्ट करने वाले दूसरे MCP क्लाइंट भी ऐसे ही काम करते हैं: बिना टोकन वाले क्लाइंट को पता बताता है कि साइन इन कहाँ करना है, और क्लाइंट ख़ुद को रजिस्टर कर लेता है।

## आप क्या मंज़ूर करते हैं

AChat का सहमति पेज ऐप का नाम, वह पता जहाँ वह आपको वापस भेजता है, और उसकी माँगी हर अनुमति दिखाता है, [एक्सेस की](./access-keys.md#permissions) जैसे ही पढ़ें, बदलें और मिटाएँ टिक के साथ। कुछ भी माँगा जाए, साझा डेटा सिर्फ़ पढ़ने के लिए रहता है, और जो अनुमति AChat नहीं देता वह अनुरोध से हटा दी जाती है। जब तक आप **मंज़ूरी दें** नहीं चुनते, कुछ साझा नहीं होता।

- जो ऐप "AChat में ख़ुद रजिस्टर हुआ", उसे कौन चलाता है यह AChat ने नहीं जाँचा, इसलिए पढ़ें कि वह क्या माँगता है।
- अगर कनेक्शन चीज़ें बदल सकता है, तो मंज़ूरी के लिए पिछले 10 मिनट में साइन इन चाहिए, और [दो-चरण साइन इन](./two-step-sign-in.md) चालू हो तो कोड भी।
- आप कनेक्शन को नाम दे सकते हैं, ताकि बाद में दो को अलग पहचान सकें।

ऐप जुड़ने पर AChat आपको ईमेल करता है। आपका प्लान तय करता है कि एक साथ कितने जुड़ सकते हैं (Free पर डिफ़ॉल्ट 3; देखें [आपका प्लान क्या देता है](./index.md#what-your-plan-allows))। असिस्टेंट की कॉल API वाले उसी रोज़ के अनुरोध कोटे में गिनी जाती हैं।

## असिस्टेंट क्या कर सकता है

हर टूल को उसके बगल वाली अनुमति चाहिए, और असिस्टेंट की टूल सूची में सिर्फ़ वे टूल दिखते हैं जिनकी आपकी मंज़ूरी अभी अनुमति देती है।

| टूल | अनुमति |
|---|---|
| `list_profile`, `get_profile`, `update_profile` | `profile:read`, `profile:write` |
| `list_preferences`, `get_preferences`, `update_preferences` | `preferences:read`, `preferences:write` |
| `list_status`, `get_status`, `create_status`, `prepare_delete_status` | `status:read`, `status:write`, `status:delete` |
| `list_blocks`, `get_blocks`, `create_blocks`, `prepare_delete_blocks` | `blocks:read`, `blocks:write`, `blocks:delete` |
| `list_contacts`, `get_contacts` | `contacts:read` |
| `list_chats`, `get_chats`, `list_messages`, `get_messages` | `chats:read` |
| `list_communities`, `get_communities`, `list_channels`, `get_channels` | `communities:read` |

फ़ील्ड API वाले ही हैं; देखें [AChat API](./api.md)। सूचियाँ एक कॉल में 50 तक रिकॉर्ड लौटाती हैं, अगले पेज के कर्सर के साथ। मैसेज सिर्फ़ खुले रूम और चैनल से आते हैं। निजी चैट, ग्रुप या पासवर्ड वाला रूम अपना नाम और सदस्य दिखाता है, क्या कहा गया यह कभी नहीं।

## मिटाना आपका इंतज़ार करता है {#deletes-wait-for-you}

असिस्टेंट कभी नहीं मिटाता। जब आप उससे कोई स्टेटस पोस्ट हटाने या किसी को अनब्लॉक करने को कहते हैं, तो वह `prepare_delete_status` या `prepare_delete_blocks` कॉल करता है, और AChat `https://achat.aoneahsan.com/developers/confirm/…` का लिंक लौटाता है।

1. लिंक खोलें। AChat दिखाता है कि असिस्टेंट ने क्या माँगा और उसके साथ क्या जाएगा।
2. **मिटाएँ** (या **अनब्लॉक करें**), या **रहने दें** चुनें। आप AChat पर हैं, असिस्टेंट में नहीं, इसलिए वह ये बटन नहीं दबा सकता।
3. असिस्टेंट को बस इतना पता चलता है कि अनुरोध पूरा हुआ।

अनुरोध 10 मिनट बाद ख़त्म हो जाता है, और कुछ नहीं मिटता। पुष्टि के लिए पिछले 10 मिनट में साइन इन चाहिए, दो-चरण साइन इन चालू हो तो कोड के साथ। जो मिटाना अभी इंतज़ार में है वह **खाता › दूसरे ऐप › जुड़े ऐप** में दिखता है। मिटाने की अनुमति वाली [एक्सेस की](./access-keys.md) तुरंत मिटाती है, क्योंकि उसे चलाने वाले आप ख़ुद हैं।

## हटाएँ

**खाता › दूसरे ऐप › जुड़े ऐप** में, कनेक्शन पर **हटाएँ** चुनें। उसकी पहुँच तुरंत चली जाती है, बीच में चल रहे अनुरोध समेत। फिर इस्तेमाल करना हो तो फिर से जोड़ें। **नाम बदलें** सिर्फ़ वह नाम बदलता है जो आपको दिखता है।

## असिस्टेंट किन चीज़ों तक नहीं पहुँच सकता

- निजी चैट, ग्रुप और पासवर्ड वाले रूम के मैसेज, जिन्हें AChat ख़ुद नहीं पढ़ सकता।
- आपकी डिवाइस की, रिकवरी की, दो-चरण कोड, एक्सेस की और वेबहुक सीक्रेट।
- आपकी फ़ोटो, अटैचमेंट, रिएक्शन और पोल।
- किसी दूसरे अकाउंट की कोई भी चीज़।

असिस्टेंट AChat से जो टेक्स्ट पढ़ता है (कोई स्टेटस पोस्ट, किसी खुले रूम का मैसेज) वह उसे डेटा के रूप में लौटाया जाता है। दूसरों के लिखे शब्दों को उनके शब्द मानें, आपके असिस्टेंट के लिए निर्देश नहीं।
