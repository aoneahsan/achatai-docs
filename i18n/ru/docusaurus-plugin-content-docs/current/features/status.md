# Статусы

**Статус — это обновление для ваших принятых контактов, которое исчезает через 24 часа.** Для статусов нужен аккаунт.

## Кто его видит

По умолчанию ваши принятые контакты. Перед публикацией можно показать его только части из них или исключить конкретных людей. Что бы вы ни выбрали, увидеть его могут только люди, которых вы приняли в контакты.

## Просмотры, ответы и удаление

- Вы видите, кто посмотрел ваш статус.
- Ответ на статус приходит в ваш личный чат с этим человеком.
- Удалённый статус сразу исчезает у всех. Кто уже посмотрел — тот уже видел.

## Ограничение

Статусы не защищены сквозным шифрованием, поэтому серверы AChat могут их читать. Правила доступа ограничивают круг тех, кто ещё может видеть каждый статус, выбранной вами аудиторией.
