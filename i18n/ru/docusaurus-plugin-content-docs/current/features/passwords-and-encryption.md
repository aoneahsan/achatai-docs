# Пароли и шифрование

**Личные чаты, закрытые группы и их файлы защищены сквозным шифрованием, поэтому каждое сообщение можно прочитать только на устройствах участников.** Комната с паролем шифрует свои сообщения на вашем устройстве с помощью этого пароля.

## Что зашифровано

| Чат | Сквозное шифрование? |
|---|---|
| Личные чаты | Да, вместе с файлами |
| Закрытые группы | Да, вместе с файлами |
| Анонимные комнаты с паролем | Да, шифруются паролем комнаты |
| Открытые анонимные комнаты | Нет. Их может прочитать любой, у кого есть ссылка |
| Сообщества и их каналы | Нет |
| Статусы | Нет. Серверы AChat могут их читать; правила доступа ограничивают, кто ещё видит каждый |

AChat хранит сообщения со сквозным шифрованием в виде, который не могут прочитать ни его серверы, ни администраторы. AChat не хранит копию ключей ваших сообщений.

## Пароли комнат

- Чтобы войти в комнату и читать её, пароль нужен всем.
- Отправляйте пароль отдельно от ссылки.
- После слишком многих неверных попыток подряд придётся подождать несколько минут.
- Для новых паролей показывается индикатор надёжности. Проверка идёт на вашем устройстве, и пароль никуда не отправляется.

## Группы и смена участников

Когда состав группы меняется, группа получает новые ключи безопасности, поэтому вышедшие не могут читать новые сообщения. Новые участники видят сообщения, отправленные после их прихода; прежние сообщения автоматически не передаются.

## Проверка привязанного устройства

В разделе **Аккаунт** › **Устройства** можно сверить коды безопасности двух ваших устройств. Если они не совпадают, удалите устройство, которому не доверяете. См. [Устройства и ключ восстановления](/features/devices-and-recovery).

## Ограничения

- Любой участник чата может скопировать, сохранить сообщение или сделать снимок экрана. Шифрование защищает сообщения в пути и на сервере, но не после того, как их прочитали.
- Поиск смотрит только сообщения, которые уже есть на вашем устройстве.
- Push-уведомления никогда не содержат текст сообщения.
- Если потерять ключ восстановления и все привязанные устройства, историю не сможет восстановить ни вы, ни команда AChat.
