# Поиск и офлайн-история

**Поиск работает на вашем устройстве по сообщениям, которые на нём есть, поэтому ваши запросы остаются там же.**

## Поиск

- Откройте **Поиск**, чтобы искать по всем чатам. Результаты сгруппированы по чатам.
- Он охватывает сообщения, которые уже есть на этом устройстве. Корзина, архивированные чаты, группы, из которых вы вышли, и временно закрытые чаты не ищутся.
- Поиск охватывает до заданного числа чатов — сначала закреплённые, потом самые недавние — и заданное число новейших сообщений в каждом. Оба числа задают администраторы AChat, а страница поиска сообщает, сколько чатов она охватывает.
- **Ctrl+K** (или **⌘K**) находит чат или страницу.

## Офлайн

- Открытые вами чаты и файлы хранятся на устройстве, поэтому загружаются быстрее и открываются без сети.
- Сообщения, написанные офлайн, ждут в **Исходящих** с пометкой **Ожидает отправки** и отправляются по порядку, когда связь вернётся. Сообщение показывает **Отправлено**, только когда оно дошло.
- Если какие-то сообщения не отправляются, их можно отправить повторно или удалить те, что уже не нужны.
- Чат с включённой историей устройств и местоположения открывается только при наличии связи.

## Сохранённое на этом устройстве

**Аккаунт** › **Хранилище** показывает, что сохранено на устройстве. «Удалить сохранённые копии» убирает сохранённые чаты и файлы; при открытии онлайн они скачаются снова, а исходящие не затрагиваются.

Выход из аккаунта удаляет с устройства ваши чаты и сообщения, которые ещё ждут отправки. См. [Устройства и ключ восстановления](/features/devices-and-recovery).
