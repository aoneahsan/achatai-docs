# Встраиваемый виджет

**Выберите комнату или канал, выберите вид, затем скопируйте код на свою страницу.** Соберите его на [странице виджета](https://achat.aoneahsan.com/ru/widget) — перед копированием она покажет предпросмотр с демо-сообщениями.

## Что можно встроить

| Что | Условие |
|---|---|
| Анонимная комната | Любой ID комнаты: 8–20 строчных букв, цифр и дефисов. Новая комната создаётся, когда кто-то впервые открывает виджет |
| Канал сообщества | Только каналы с отображаемыми именами в сообществах с пометкой **Можно анонимно** |

Закрытые группы и каналы, где нужен аккаунт, на других сайтах показать нельзя.

## Вид и параметры

- **На странице:** чат фиксированного размера там, куда вы вставили код.
- **Кнопка чата:** кнопка в углу, открывающая чат на панели.
- **Плотная**, **Скрыть шапку чата** и **Предлагать вход** (посетители могут войти, чтобы сохранить комнату; для общения это не нужно, а вход открывается в новой вкладке).

## Разрешённые сайты

Укажите до 20 сайтов, которым можно показывать чат. Пока вы не добавили ни одного, показывать его может любой сайт.

- Для комнаты список может менять только тот, кто её сохраняет. Пока комнату никто не сохранил, ограничить её никто не может.
- Для канала — только администраторы сообщества.

Сайт, которого нет в списке, показывает уведомление и ссылку, чтобы открыть чат в AChat.

## Что стоит знать посетителям

- Любой, кто открыл страницу с виджетом, может читать комнату и писать в ней, если у комнаты нет пароля. Сообщения хранятся по правилам самой комнаты.
- Вход, микрофон и местоположение внутри чужого сайта не работают. Чат, записывающий местоположение, открывается только в AChat.
- Настройки браузера на сайте могут не дать AChat запомнить посетителя, поэтому в следующий раз ему, возможно, придётся снова выбрать отображаемое имя.
