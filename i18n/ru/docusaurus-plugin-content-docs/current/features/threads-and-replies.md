# Ветки и ответы

**Ответьте в ветке, чтобы договорённость не потерялась, пока остальные продолжают общаться.**

## Ответ или ветка

- **Ответить** цитирует сообщение в основном разговоре.
- **Ветка** открывает побочный разговор по одному сообщению в панели рядом с чатом. **Показать в чате** возвращает к сообщению, с которого она началась.

Ветки работают в чатах, комнатах и каналах сообществ.

## Удаление в ветке

- Удалите один ответ — он попадёт в корзину чата.
- Удалите сообщение, с которого началась ветка, — оно попадёт в корзину вместе со всеми ответами. Любой участник чата может восстановить их из корзины.

О корзине — в разделе [Управление сообщениями](/features/manage-messages).
