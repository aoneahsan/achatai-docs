# Переход из FilePizza в AChat

**FilePizza передаёт файлы напрямую между браузерами.** Когда нужно, чтобы файл шёл прямо из одного браузера в другой, пользуйтесь им. AChat — для случаев, когда другая сторона не будет в сети в тот же момент.

Последняя проверка 2026-11-22. Полное сравнение: [AChat и FilePizza](https://achat.aoneahsan.com/ru/compare/filepizza).

## Оставить на потом

Передаче из браузера в браузер нужно, чтобы обе стороны были на месте одновременно. Комната AChat держит файл, пока другая сторона не появится.

1. Откройте комнату через **Продолжить анонимно** ([анонимные комнаты](/features/anonymous-chats)). Никто не регистрируется.
2. Закройте её паролем ([пароли и шифрование](/features/passwords-and-encryption)).
3. Прикрепите файл и закройте вкладку; он останется в комнате ([обмен файлами](/features/file-sharing)).
4. Отправьте ссылку и пароль. Другой человек заберёт файл, когда будет в сети, и сможет оставить вам ответ.
5. Файл удаляется через заданное для комнаты число дней. Можно удалить и раньше.

## Что сказано на странице FilePizza

Страница FilePizza подтверждает передачу файлов, поэтому строку «текст и файлы» мы отметили как «частично». Нужен ли аккаунт, можно ли добавить пароль и может ли другая сторона ответить, там не сказано, поэтому эти строки убраны.

| Возможность | AChat | FilePizza |
|---|---|---|
| Можно отправлять и текст, и файлы | Да | Частично (<a href="https://github.com/kern/filepizza" target="_blank" rel="noopener noreferrer nofollow">их страница</a>) |

AChat даёт все три: без аккаунта, с необязательным паролем и с ответами. Комнату без пароля может читать любой, у кого есть ссылка.
