# Переход из CometChat в AChat

**CometChat — чат для разработчиков, бесплатный до 100 пользователей на тарифе Build.** Если ваши разработчики добавляют чат в ваше приложение, оставайтесь с ним. AChat — когда вы предпочли бы вставить фрагмент кода и дать посетителям общаться без аккаунта.

Последняя проверка 2026-11-22. Рядом: [AChat и CometChat](https://achat.aoneahsan.com/ru/compare/cometchat).

## За чертой в 100 пользователей

Тариф Build покрывает до 100 пользователей. Если то, что вы на нём построили, — на самом деле публичная комната для посетителей, вот как заменить.

1. Разделите два назначения. Чат внутри приложения между вашими пользователями остаётся в CometChat.
2. Для публичной части создайте комнату или выберите открытый канал сообщества на [странице виджета](https://achat.aoneahsan.com/ru/widget) ([встраиваемый виджет](/features/embeddable-widget)).
3. Задайте макет, затем скопируйте код на страницу.
4. Посетители выбирают отображаемое имя в комнате. Аккаунт не нужен никому.
5. Если комната должна быть закрытой для одной группы, задайте пароль и передайте его отдельно.
