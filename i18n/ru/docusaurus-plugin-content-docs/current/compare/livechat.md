# Переход из LiveChat в AChat

**LiveChat — онлайн-чат с оплатой за пользователя и 14-дневным пробным периодом.** Он сделан для операторов, которые отвечают посетителям по одному. Если ваш сайт работает так, оставьте его. AChat — когда нужно что-то бесплатное на странице уже сегодня, без пробного периода, который закончится.

Последняя проверка 2026-11-22. Страница сравнения: [AChat и LiveChat](https://achat.aoneahsan.com/ru/compare/livechat).

## Если пробный период подходит к концу

Возможно, вы начали пробный период LiveChat и поняли, что посетителям оператор вообще не нужен. Вот как подготовить комнату до конца пробного периода.

1. Откройте [страницу виджета](https://achat.aoneahsan.com/ru/widget) и выберите анонимную комнату или открытый канал сообщества ([встраиваемый виджет](/features/embeddable-widget)).
2. Попробуйте оба макета в превью: оно заполняет комнату демонстрационными сообщениями, чтобы можно было оценить размер.
3. Скопируйте код и замените им фрагмент LiveChat.
4. Посетители выбирают отображаемое имя и общаются. Никто не ждёт в очереди, потому что её нет.
5. Пароль оставляет комнату доступной только тем, кому вы его дали.

## Чего не сказано на страницах LiveChat

На прочитанных нами страницах LiveChat не сказано, есть ли бесплатный тариф без срока, готовый чат для страницы или версия для своих серверов. Поэтому таблицы возможностей нет. Проверьте на <a href="https://www.livechat.com" target="_blank" rel="noopener noreferrer nofollow">сайте LiveChat</a>.

У AChat есть бесплатный тариф и готовый виджет, и он работает только как сервис. Виджет — не ящик для операторов и не SDK для разработчиков.
