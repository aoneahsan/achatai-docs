# Переход из Discord в AChat

**Discord — это чат для сообществ, а Nitro — платное улучшение для вещей вроде больших загрузок.** Большому сообществу, которое живёт в голосовых каналах, место в Discord: в AChat нет голоса. AChat подходит сообществу, которое должно пускать гостей без аккаунта, или людям, которым нужно сквозное шифрование в личной переписке.

Последняя проверка 2026-11-22. Рядом: [AChat и Discord](https://achat.aoneahsan.com/ru/compare/discord).

## От сервера к сообществу

Сервер Discord довольно прямо ложится на сообщество AChat: в сообществе есть каналы, в каналах — ветки.

1. [Войдите](/getting-started/quick-start) и создайте сообщество в разделе **Сообщества** ([группы и сообщества](/features/groups-and-communities)). Выберите для него ID ссылки: 8–20 строчных букв, цифр и дефисов.
2. Выберите доступ. **Можно анонимно** пускает гостей под отображаемым именем без аккаунта. **Нужен аккаунт** оставляет его только для вошедших.
3. Пересоздайте текстовые каналы, которыми действительно пользуетесь. Сделайте канал закрытым, если читать его должны лишь некоторые участники.
4. Назначьте администраторов. Они создают каналы и разбирают жалобы и баны; кто станет администратором, решает только владелец.
5. Опубликуйте ссылку на сообщество в объявлениях Discord и дайте переезду время.
6. По желанию: поставьте на сайт канал с отображаемыми именами со [страницы виджета](https://achat.aoneahsan.com/ru/widget).

Сообщества не защищены сквозным шифрованием. Личные чаты ([личные чаты и контакты](/features/personal-chats-and-contacts)) и закрытые группы защищены, и их история возвращается только через привязанное устройство или ключ восстановления ([устройства и ключ восстановления](/features/devices-and-recovery)). История Discord не импортируется.
