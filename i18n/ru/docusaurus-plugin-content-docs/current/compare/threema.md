# Переход из Threema в AChat

**Threema не просит ни номера телефона, ни почты и отдельно сохраняет ваш ID и чаты.** Если вы выбрали его именно потому, что при регистрации не нужно отдавать личные данные, оставайтесь. Аккаунт AChat входит через Google, так что он не настолько «пустой». Что добавляет AChat — это комнаты, в которые любой может войти по ссылке, и чат, который можно поставить на сайт.

Проверено 2026-11-22. Сравнение рядом — на странице [AChat и Threema](https://achat.aoneahsan.com/ru/compare/threema).

## Два способа войти

Сначала решите, сколько вы хотите отдать AChat: от этого зависит, с чего начать.

**Совсем ничего.** Выберите **Продолжить анонимно** и создайте комнату ([анонимные комнаты](/features/anonymous-chats)). Вы выбираете отображаемое имя для этой комнаты и делитесь её ссылкой. Задайте пароль, если читать её должны только определённые люди.

**Аккаунт.** [Войдите через Google](/getting-started/quick-start) и выберите имя пользователя — по нему вас находят, почти как по Threema ID. Затем:

1. Сохраните ключ восстановления. Threema хранит резервную копию ID; в AChat историю возвращает ключ восстановления или другое привязанное устройство ([устройства и ключ восстановления](/features/devices-and-recovery)).
2. Отправьте контактам из Threema своё имя пользователя или ссылку-приглашение ([личные чаты и контакты](/features/personal-chats-and-contacts)).
3. Если у вас есть сайт, соберите для него комнату на [странице виджета](https://achat.aoneahsan.com/ru/widget).

Чаты из Threema не переносятся. AChat не импортирует чаты из других приложений.
