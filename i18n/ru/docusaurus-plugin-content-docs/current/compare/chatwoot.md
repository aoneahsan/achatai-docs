# Переход из Chatwoot в AChat

**Chatwoot — платформа поддержки клиентов с открытым кодом, которую можно развернуть у себя или оплачивать за каждого оператора.** Поддержка на собственных серверах — веская причина остаться: AChat нельзя развернуть у себя. Он для случая, когда вы не хотите ничего запускать, а посетители общаются друг с другом, а не с операторами.

Проверено 2026-11-22. Сравнение — на странице [AChat и Chatwoot](https://achat.aoneahsan.com/ru/compare/chatwoot).

## Отказ от собственного экземпляра

Если ваш сервер Chatwoot в основном держит болтовню посетителей, обслуживание может обходиться дороже, чем стоит сама комната.

1. Сначала выгрузите из Chatwoot всё нужное. В AChat ничего не импортируется.
2. Соберите комнату или выберите открытый канал сообщества на [странице виджета](https://achat.aoneahsan.com/ru/widget) ([встраиваемый виджет](/features/embeddable-widget)). Никакого сервера, базы данных или обновлений, за которыми надо следить.
3. Вставьте код туда, где работал виджет Chatwoot.
4. Закрепите комнату за аккаунтом, чтобы она пережила стандартный срок истории и вы могли указать сайты, которым разрешено её показывать.
5. Выключайте свой экземпляр только после того, как новая комната поработает какое-то время.
