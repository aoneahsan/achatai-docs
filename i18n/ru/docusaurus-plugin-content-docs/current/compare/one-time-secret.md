# Переход из One-Time Secret в AChat

**One-Time Secret даёт одноразовую ссылку на секрет, со сроком действия и необязательной парольной фразой.** Паролю, который должен исчезнуть после одного прочтения, место там. Берите AChat, когда нужно отправить больше одного или собеседнику нужно ответить.

Последняя проверка 2026-11-22. Полное сравнение: [AChat и One-Time Secret](https://achat.aoneahsan.com/ru/compare/one-time-secret).

## Когда одного прочтения мало

Типичный случай: вы настраиваете кому-то компьютер, и есть пароль, лицензионный ключ и вопрос, какой аккаунт использовать. Это либо по ссылке на каждый секрет, либо одна комната в AChat.

1. На компьютере с данными выберите **Продолжить анонимно**, затем **Создать комнату** ([анонимные комнаты](/features/anonymous-chats)).
2. Задайте комнате пароль, чтобы читать её мог только тот, кому вы его дадите ([пароли и шифрование](/features/passwords-and-encryption)). Пароль отправьте другим путём, чем ссылку.
3. Вставьте пароль, ключ и свой вопрос; можно приложить и файл ([обмен файлами](/features/file-sharing)). Ответить можно в той же комнате.
4. Когда закончите, удалите отправленное. Остальное удалится через заданное число дней, по умолчанию 10.

Страница One-Time Secret подтверждает возможность парольной фразы. Мы не нашли, нужен ли аккаунт, можно ли отправлять файлы вместе с текстом и может ли собеседник ответить, поэтому эти строки убраны.

| Возможность | AChat | One-Time Secret |
|---|---|---|
| Можно защитить паролем | Да | Да (<a href="https://onetimesecret.com/" target="_blank" rel="noopener noreferrer nofollow">их страница</a>) |

В AChat ничего из этого не требует аккаунта: в комнаты можно отправлять текст и файлы, а собеседник может ответить. Комнату без пароля может читать любой, у кого есть ссылка.
