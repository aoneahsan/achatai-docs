# Переход из tawk.to в AChat

**tawk.to — бесплатный онлайн-чат для сайтов; за плату убирается его брендинг.** Если ваша команда отвечает клиентам и хочет рядом центр помощи и тикеты, это делает tawk.to, а AChat — нет. Виджет AChat — это комната. Посетители общаются там друг с другом, не дожидаясь сотрудника поддержки.

Последняя проверка 2026-11-22. Сравнение рядом — на странице [AChat и tawk.to](https://achat.aoneahsan.com/ru/compare/tawk-to).

## Замена или второй виджет?

Обычно второй. На вопросы поддержки всё равно кто-то должен отвечать, так что оставьте tawk.to на страницах контактов или помощи. AChat ставьте туда, где посетители говорят между собой: на страницу мероприятия, курса, фан-сайта.

1. Откройте [страницу виджета](https://achat.aoneahsan.com/ru/widget) и выберите ID комнаты: 8–20 строчных букв, цифр и дефисов. Комната создаётся, когда кто-то впервые открывает виджет ([встраиваемый виджет](/features/embeddable-widget)).
2. Выберите **На странице** для чата фиксированного размера или **Кнопка чата** для кнопки в углу, открывающей чат на панели.
3. Посмотрите превью, затем скопируйте код на страницу.
4. Закрепите комнату за аккаунтом, затем укажите до 20 сайтов, которым разрешено её показывать. Пока ни один сайт не указан, вашу комнату может показывать любой сайт.
5. Задайте пароль, если комнату не должен читать каждый посетитель.
