# Переход из Tidio в AChat

**Tidio — чат с клиентами с ИИ-агентом Lyro и ценой по числу разговоров.** Если нужен агент, который отвечает клиентам, это Tidio. AChat — для страниц, куда люди приходят пообщаться друг с другом, и когда вы не хотите считать разговоры.

Последняя проверка 2026-11-22. Полное сравнение: [AChat и Tidio](https://achat.aoneahsan.com/ru/compare/tidio).

## Комната вместо бота-ответчика

В AChat никто не отвечает за вас. Посетители отвечают друг другу, так что это работает только там, где в этом и смысл.

1. Выберите страницы, где посетители общаются друг с другом, а не с вами. На остальных оставьте Tidio.
2. На [странице виджета](https://achat.aoneahsan.com/ru/widget) выберите анонимную комнату или открытый канал сообщества, затем макет ([встраиваемый виджет](/features/embeddable-widget)).
3. Включите **Компактный** или **Скрыть шапку чата**, если комната стоит в узкой колонке.
4. Вставьте код на эти страницы.
5. Задайте комнате пароль, если читать её должны только определённые посетители.
