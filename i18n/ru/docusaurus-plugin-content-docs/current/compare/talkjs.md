# Переход из TalkJS в AChat

**TalkJS — готовый интерфейс чата для вашего продукта, бесплатный в режиме разработки.** Когда чат живёт внутри вашего продукта и привязан к вашим пользовательским аккаунтам, TalkJS подходит лучше. AChat запускается на бесплатном тарифе, и посетителям, которые им пользуются, аккаунты не нужны вовсе.

Проверено 2026-11-22. Страница сравнения — [AChat и TalkJS](https://achat.aoneahsan.com/ru/compare/talkjs).

## От режима разработки к живой комнате

TalkJS бесплатен, пока вы строите в режиме разработки. Если ваш прототип — публичная комната, а не чат между вашими пользователями, AChat может запустить её на бесплатном тарифе.

1. Проверьте, от чего зависит прототип. Разговоры, привязанные к ID ваших пользователей, остаются в TalkJS: виджет AChat — не SDK для разработчиков и ваших пользователей не знает.
2. Для открытой комнаты выберите ID комнаты на [странице виджета](https://achat.aoneahsan.com/ru/widget) ([встраиваемый виджет](/features/embeddable-widget)). Посетители входят под отображаемым именем.
3. Выберите **На странице**, чтобы встать на место чата TalkJS, или **Кнопка чата** для панели в углу.
4. Скопируйте код на страницу.
5. Закрепите комнату за аккаунтом, затем укажите сайты, которым разрешено её показывать.
