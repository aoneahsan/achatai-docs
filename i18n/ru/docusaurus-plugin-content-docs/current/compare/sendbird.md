# Переход из Sendbird в AChat

**Sendbird — чат внутри приложения с ценой по числу активных пользователей в месяц и бесплатным пробным периодом.** Если чат — часть вашего продукта и на него есть бюджет, Sendbird для этого и сделан. AChat подходит для задачи поменьше: комната на странице, когда не хочется платить за старт.

Последняя проверка 2026-11-22. Полное сравнение — на странице [AChat и Sendbird](https://achat.aoneahsan.com/ru/compare/sendbird).

## Пока пробный период не стал счётом

Тарифы Sendbird начинаются от 349 $ в месяц при оплате за год. Если пробный период показал, что вам нужно лишь место, где посетители могут поговорить, сначала попробуйте это.

1. Запишите, для чего был пробный период. Если для переписки между вашими вошедшими пользователями, продолжайте оценивать Sendbird: виджет AChat — не SDK для этого.
2. Если для публичной комнаты, соберите её на [странице виджета](https://achat.aoneahsan.com/ru/widget) на бесплатном тарифе AChat ([встраиваемый виджет](/features/embeddable-widget)).
3. Вставьте код туда, где стоял чат из пробного периода.
4. Включите **Предлагать вход**, если посетители должны иметь возможность закрепить комнату. Вход открывается в новой вкладке, а для общения он не нужен никогда.
5. Добавьте пароль, если комната должна остаться среди приглашённых вами людей.
