# Переход из Stream Chat в AChat

**Stream Chat — чат для разработчиков, которые встраивают его в свои приложения, бесплатно до 1 000 активных пользователей в месяц.** Если ваши разработчики встраивают чат в ваш продукт и хотят управлять каждой частью, Stream — правильный тип инструмента. AChat — обратная сделка: вы вставляете фрагмент кода и получаете работающий чат без участия разработчиков.

Проверено 2026-11-22. Сравнение рядом — на странице [AChat и Stream Chat](https://achat.aoneahsan.com/ru/compare/stream-chat).

## Когда SDK был больше задачи

Команды иногда берут чат-SDK ради того, что в итоге оказывается одной публичной комнатой на одной странице. Если это ваш случай, это займёт минуты, а не спринт.

1. Оставьте Stream везде, где чат связан с вашими пользователями и данными. Виджет AChat — не SDK для разработчиков, поэтому поверх ваших пользовательских аккаунтов он не встанет.
2. Для публичной комнаты откройте [страницу виджета](https://achat.aoneahsan.com/ru/widget) и выберите ID комнаты или открытый канал сообщества ([встраиваемый виджет](/features/embeddable-widget)).
3. Выберите макет и параметры; страница виджета сама напишет код.
4. Скопируйте фрагмент в шаблон страницы.
5. Когда кто-то закрепит комнату, он сможет указать домены, которым разрешено её показывать, до 20.
