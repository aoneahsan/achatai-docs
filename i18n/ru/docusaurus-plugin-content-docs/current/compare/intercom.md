# Переход из Intercom в AChat

**Intercom — ПО для обслуживания клиентов с оплатой за место, а его ИИ-агент Fin оплачивается за результат.** Команде поддержки, которой нужно, чтобы первым отвечал ИИ, стоит остаться в Intercom. AChat ничего из этого не заменяет. Он предлагает комнату на странице — для случаев, когда служба поддержки вам вообще не была нужна.

Проверено 2026-11-22. Сравнение — на странице [AChat и Intercom](https://achat.aoneahsan.com/ru/compare/intercom).

## Где хватит комнаты

Честная проверка: читает ли кто-то в вашей команде разговоры в Intercom. Если да, продолжайте платить за места.

1. Перечислите страницы, где есть Intercom. Отметьте те, где посетители в основном общаются друг с другом или где никто из команды не отвечает.
2. Для них соберите комнату или открытый канал на [странице виджета](https://achat.aoneahsan.com/ru/widget) ([встраиваемый виджет](/features/embeddable-widget)).
3. Выберите **Кнопка чата**, если хотите, чтобы он открывался из угла страницы.
4. Вставьте код, а Intercom оставьте там, где работает ваша команда.
5. Пусть кто-то с аккаунтом закрепит комнату, чтобы можно было ограничить, какие сайты её показывают.

## Чего не сказано на страницах Intercom

Мы проверили на страницах Intercom бесплатный тариф без срока, готовый чат для страницы и запуск на своих серверах. Ничего из трёх не указано, поэтому таблицы возможностей нет. Возможно, ответ есть на <a href="https://www.intercom.com" target="_blank" rel="noopener noreferrer nofollow">сайте Intercom</a>.

С нашей стороны: у AChat есть бесплатный тариф и готовый виджет, а своего развёртывания нет. Виджет — не ящик для операторов, и без пароля комнату может читать любой на странице.
