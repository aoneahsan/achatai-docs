# Переход из tlk.io в AChat

**tlk.io — веб-комната для чата по адресу, без регистрации, которую можно встроить на свой сайт.** Для одной одноразовой комнаты, где ничего не нужно читать заранее, её трудно превзойти. Комнаты AChat начинаются так же и идут дальше, когда нужно: пароль, файлы или кто-то, кто закрепит комнату.

Последняя проверка 2026-11-22. Рядом: [AChat и tlk.io](https://achat.aoneahsan.com/ru/compare/tlk-io).

## Та же привычка, ещё один выбор

Комната tlk.io — это адрес, который вы рассылаете. Комната AChat — тоже.

1. Откройте AChat, выберите **Продолжить анонимно**, затем **Создать комнату**. Вы получите комнату и ссылку для отправки ([анонимные комнаты](/features/anonymous-chats)).
2. Если комната не для всех, кто может угадать ссылку, задайте пароль при создании. Пароль ещё и шифрует сообщения комнаты ([пароли и шифрование](/features/passwords-and-encryption)).
3. Бросайте в комнату файлы, а не только сообщения ([обмен файлами](/features/file-sharing)).
4. Каждое сообщение удаляется через заданное число дней, по умолчанию 10. Если комната должна остаться, кто-то с аккаунтом [закрепляет её](/features/keep-chats-and-accounts).
5. Встраивали tlk.io на сайт? [Страница виджета](https://achat.aoneahsan.com/ru/widget) делает то же для комнаты AChat.

Комнату без пароля может читать любой, у кого есть ссылка. Без аккаунта — не значит невидимо: ваше устройство всё равно подключается к серверам AChat.
