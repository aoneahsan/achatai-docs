# Переход из SimpleX Chat в AChat

**В SimpleX Chat вообще нет идентификаторов пользователей, даже случайных.** Если для вас смысл именно в этом, ничего здесь его не превзойдёт. AChat намеренно идёт другим путём: вас находят по имени пользователя. Сверху — анонимные комнаты, которыми можно делиться по ссылке или поставить на сайт.

Последняя проверка 2026-11-22. Полное сравнение: [AChat и SimpleX Chat](https://achat.aoneahsan.com/ru/compare/simplex-chat).

## Имя, по которому вас можно найти

В SimpleX каждый контакт начинается с одноразовой ссылки. В AChat вы раздаёте имя пользователя, так что подумайте над ним минуту.

1. [Войдите](/getting-started/quick-start) и выберите имя пользователя из 3–24 букв, цифр, точек или подчёркиваний. Его можно сменить в любой момент. После смены старое имя становится свободным для других.
2. Раздавайте его так, как привыкли: ссылкой-приглашением или QR-кодом ([личные чаты и контакты](/features/personal-chats-and-contacts)). Сообщения от тех, кого вы ещё не приняли, ждут в разделе **Запросы на переписку**.
3. Сохраните ключ восстановления ([устройства и ключ восстановления](/features/devices-and-recovery)). Если не осталось ни одного привязанного устройства, только он вернёт историю.
4. Для разговора, который не должен касаться вашего имени пользователя, используйте [анонимную комнату](/features/anonymous-chats). [Страница виджета](https://achat.aoneahsan.com/ru/widget) ставит её на ваш сайт.

Чаты остаются в SimpleX. AChat не импортирует из других приложений.

## Как заявлено

| Возможность | AChat | SimpleX Chat |
|---|---|---|
| Регистрация без номера телефона | Да | Да (<a href="https://simplex.chat/" target="_blank" rel="noopener noreferrer nofollow">их страница</a>) |
| Сквозное шифрование личных чатов | Да | Да (<a href="https://simplex.chat/faq/" target="_blank" rel="noopener noreferrer nofollow">их страница</a>) |
| История возвращается на новом устройстве | Частично | Да (<a href="https://simplex.chat/faq/" target="_blank" rel="noopener noreferrer nofollow">их страница</a>) |

В AChat история возвращается только через привязанное устройство или ключ восстановления, и без них её не восстановит никто, включая команду AChat. В AChat нет голосовых и видеозвонков.
