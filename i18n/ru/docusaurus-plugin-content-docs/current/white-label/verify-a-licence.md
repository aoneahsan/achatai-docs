# Проверить лицензию

**Любой может проверить копию AChat, работающую под другим именем.** Откройте [Проверить лицензию](https://achat.aoneahsan.com/ru/verify-license) и введите ключ лицензии копии или её домен. Проверку выполняет наш сервис лицензий.

## По домену

Каждая лицензированная копия отдаёт файл лицензии на своём домене, в `/.well-known/`. Проверка по домену читает этот файл и проверяет указанный в нём ключ.

| Ответ | Что значит |
|---|---|
| Лицензия действует | В файле указана лицензия для этого домена, и она действует |
| Другой домен | В файле указана лицензия, выданная для другого домена |
| Недействительная лицензия | Указанной в файле лицензии не существует |
| Нет файла лицензии | Домен его не отдаёт |
| Нет ответа | До домена не удалось достучаться |

## По ключу

Проверка по ключу отвечает, действует ли лицензия, ещё настраивается или отозвана, и показывает её открытые сведения: на кого она оформлена, её домены, платформы и даты. Адрес почты и цену она не показывает никогда.

## Копия с недействующей лицензией

Вместо приложения она показывает «Эта лицензия не действует» со ссылкой на эту проверку. Ничего в ней не удаляется.
