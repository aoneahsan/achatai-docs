# Настройка вашей копии

**После оплаты настройкой занимается команда AChat и пишет вам о каждом шаге.** С вашей стороны ничего устанавливать не нужно.

1. **Письмо с лицензией.** Ключ лицензии и сертификат приходят на адрес почты, с которого вы покупали. Сохраните оба: для продления нужен ключ.
2. **Ваш домен.** Сообщите команде AChat адрес, на котором должна работать ваша копия, например `chat.yourname.com`. Домен остаётся вашим, поэтому если для подключения нужна DNS-запись на вашей стороне, команда пришлёт вам точную запись, которую нужно добавить.
3. **Ваше название, логотип и цвета.** Пришлите их, и они появятся на каждом экране.
4. **Запуск.** Когда копия заработает на вашем домене, она будет отдавать свой файл лицензии, и любой сможет её [проверить](/white-label/verify-a-licence).

Оплата — банковским переводом на счёт Wise команды AChat; номер перевода вы отправляете со страницы оплаты. Лицензия выдаётся только после того, как команда AChat подтвердит перевод, и никогда — со страницы, на которую вы возвращаетесь.
