# Журнал изменений для разработчиков

Изменения API, подключения ассистентов, вебхуков и двухэтапного входа, новые сверху. Версия API — `v1`.

## Открытая платформа (2026-11-21)

- **[API AChat](./api.md)** по адресу `https://vhkerwyxmhaxfyjbvsha.supabase.co/functions/v1/api/v1`, с [ключами доступа](./access-keys.md) (`achat_pat_…`), которые создаются в разделе Аккаунт › Другие приложения. Профиль, настройки, статусы (текст) и список заблокированных можно читать и менять; контакты, чаты, сообщения открытых комнат, сообщества и каналы — только читать. Документ OpenAPI 3.1 лежит по адресу `/openapi.json`.
- **[Подключение ассистентов](./assistants.md)** по адресу `https://vhkerwyxmhaxfyjbvsha.supabase.co/functions/v1/mcp` для Claude, ChatGPT, Claude Code и Cursor. Каждое вы одобряете в AChat, а удаление, которое делает ассистент, ждёт вашего «да» на `/developers/confirm`.
- **[Вебхуки](./webhooks.md)** для одиннадцати событий, подписанные по Standard Webhooks, только с ID и временем.
- **[Двухэтапный вход](./two-step-sign-in.md)** с приложением-аутентификатором, десятью кодами восстановления и браузером, который можно по желанию запомнить на 7 дней. Обязателен для аккаунтов, ведущих админку AChat.
- Чаты со сквозным шифрованием во всём этом не участвуют: внешние приложения видят название и участников чата, но никогда — сообщения.
- Ленты для календаря нет: у AChat нет ничего датированного, что можно туда положить.
