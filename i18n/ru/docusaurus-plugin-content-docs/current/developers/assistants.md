# Подключение Claude, ChatGPT, Claude Code или Cursor

**Вставьте адрес ассистента AChat в своего ассистента, одобрите его в AChat — и он сможет читать ваш аккаунт и менять то, что принадлежит вам.** Он видит только то, что вы отметили при одобрении. Он никогда не прочитает сообщение со сквозным шифрованием и ничего не удалит без вашего «да» в AChat.

Адрес ассистента AChat:

```text
https://vhkerwyxmhaxfyjbvsha.supabase.co/functions/v1/mcp
```

Это удалённый MCP-сервер по Streamable HTTP. Он есть и в разделе **Аккаунт › Другие приложения › Подключить ассистента**, с кнопкой **Скопировать**.

## Claude

1. В Claude откройте **Settings**, затем **Connectors**.
2. Выберите **Add custom connector** и вставьте адрес AChat.
3. Claude откроет AChat. Проверьте, что он просит, и одобрите.

## ChatGPT

1. В ChatGPT откройте **Settings**, затем **Apps and Connectors** и включите режим разработчика.
2. Выберите **Create**, назовите его AChat и вставьте адрес.
3. ChatGPT откроет AChat. Проверьте, что он просит, и одобрите.

## Claude Code

1. В терминале выполните:

   ```bash
   claude mcp add --transport http achat https://vhkerwyxmhaxfyjbvsha.supabase.co/functions/v1/mcp
   ```

2. Выполните `/mcp` в Claude Code и выберите **achat**.
3. Браузер откроет AChat. Проверьте, что он просит, и одобрите.

## Cursor

1. В Cursor откройте **Settings**, затем **MCP**, затем **Add new MCP server**.
2. Вставьте это в `mcp.json`:

   ```json
   { "mcpServers": { "achat": { "url": "https://vhkerwyxmhaxfyjbvsha.supabase.co/functions/v1/mcp" } } }
   ```

3. Cursor откроет AChat. Проверьте, что он просит, и одобрите.

Другие MCP-клиенты с поддержкой OAuth работают так же: клиенту без токена адрес отвечает, где войти, и клиент регистрируется сам.

## Что вы одобряете

Страница согласия в AChat называет приложение, адрес, на который оно вас вернёт, и каждое запрошенное разрешение — с теми же отметками «Чтение», «Изменение» и «Удаление», что и у [ключа доступа](./access-keys.md#permissions). Общие данные остаются только для чтения, что бы ни запрашивалось, а разрешение, которого AChat не предлагает, убирается из запроса. Пока вы не выберете **Одобрить**, ничего не передаётся.

- Если приложение «зарегистрировалось в AChat само», AChat не проверял, кто за ним стоит, — внимательно прочитайте, что оно просит.
- Если подключение может что-то менять, для одобрения нужен вход за последние 10 минут, а при включённом [двухэтапном входе](./two-step-sign-in.md) — ещё и код.
- Подключению можно дать название, чтобы потом различать два подключения.

Когда приложение подключено, AChat присылает письмо. Сколько можно подключить одновременно, задаёт тариф (на Free по умолчанию 3; см. [что позволяет ваш тариф](./index.md#what-your-plan-allows)). Вызовы ассистента считаются в тот же дневной лимит запросов, что и API.

## Что может ассистент

Каждому инструменту нужно разрешение рядом с ним, и в списке инструментов ассистента видны только те, что сейчас позволяет ваше одобрение.

| Инструменты | Разрешение |
|---|---|
| `list_profile`, `get_profile`, `update_profile` | `profile:read`, `profile:write` |
| `list_preferences`, `get_preferences`, `update_preferences` | `preferences:read`, `preferences:write` |
| `list_status`, `get_status`, `create_status`, `prepare_delete_status` | `status:read`, `status:write`, `status:delete` |
| `list_blocks`, `get_blocks`, `create_blocks`, `prepare_delete_blocks` | `blocks:read`, `blocks:write`, `blocks:delete` |
| `list_contacts`, `get_contacts` | `contacts:read` |
| `list_chats`, `get_chats`, `list_messages`, `get_messages` | `chats:read` |
| `list_communities`, `get_communities`, `list_channels`, `get_channels` | `communities:read` |

Поля — те же, что в API; см. [API AChat](./api.md). Списки возвращают до 50 записей за вызов с курсором для следующей страницы. Сообщения приходят только из открытых комнат и каналов. Личный чат, группа или комната с паролем показывают название и участников, но никогда — что было сказано.

## Удаление ждёт вас {#deletes-wait-for-you}

Ассистент никогда не удаляет. Когда вы просите его убрать статус или разблокировать кого-то, он вызывает `prepare_delete_status` или `prepare_delete_blocks`, и AChat отвечает ссылкой на `https://achat.aoneahsan.com/developers/confirm/…`.

1. Откройте ссылку. AChat покажет, что попросил ассистент и что уйдёт вместе с этим.
2. Выберите **Удалить** (или **Разблокировать**) либо **Оставить**. Вы в AChat, а не в ассистенте, поэтому он не может нажать эти кнопки.
3. Ассистент узнаёт только то, что запрос завершён.

Запрос истекает через 10 минут, и ничего не удаляется. Для подтверждения нужен вход за последние 10 минут — с кодом, если включён двухэтапный вход. Удаления, которые ещё ждут, перечислены в **Аккаунт › Другие приложения › Подключённые приложения**. [Ключ доступа](./access-keys.md) с разрешением на удаление удаляет сразу, потому что запускаете его вы сами.

## Отключить

В разделе **Аккаунт › Другие приложения › Подключённые приложения** выберите **Удалить** у подключения. Оно сразу теряет доступ, включая запрос, который выполняет в этот момент. Чтобы пользоваться снова, подключите заново. **Переименовать** меняет только название, которое видите вы.

## Чего ассистентам не достать

- Сообщений в личных чатах, группах и комнатах с паролем — их не может прочитать и сам AChat.
- Ключей ваших устройств, ключа восстановления, кодов двухэтапного входа, ключей доступа и секретов вебхуков.
- Вашего фото, вложений, реакций и опросов.
- Ничего, что принадлежит другому аккаунту.

Текст, который ассистент читает в AChat (статус, сообщение в открытой комнате), передаётся ему как данные. Слова, написанные другими людьми, — это их слова, а не инструкции для вашего ассистента.
