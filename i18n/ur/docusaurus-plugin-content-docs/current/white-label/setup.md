# اپنی کاپی سیٹ کرنا

**ادائیگی کے بعد AChat ٹیم سیٹ اپ کرتی ہے اور ہر حصے کے بارے میں آپ کو لکھتی ہے۔** آپ کی طرف سے کچھ انسٹال نہیں کرنا۔

1. **لائسنس ای میل۔** آپ کی لائسنس کی اور سرٹیفکیٹ اس ای میل پتے پر آتے ہیں جس سے آپ نے خریدا۔ دونوں سنبھال کر رکھیں: تجدید میں کی مانگی جاتی ہے۔
2. **آپ کا ڈومین۔** AChat ٹیم کو وہ پتہ بتائیں جس پر آپ کی کاپی چلنی چاہیے، جیسے `chat.yourname.com`۔ ڈومین آپ کا ہی رہتا ہے، اس لیے اگر اسے جوڑنے کے لیے آپ کی طرف DNS ریکارڈ چاہیے، تو ٹیم آپ کو جوڑنے والا درست ریکارڈ بھیجتی ہے۔
3. **آپ کا نام، لوگو اور رنگ۔** انہیں بھیجیں، اور یہ ہر اسکرین پر لگ جاتے ہیں۔
4. **لائیو۔** جب آپ کی کاپی آپ کے ڈومین پر چلنے لگتی ہے، تو وہ اپنی لائسنس فائل دکھاتی ہے اور کوئی بھی اسے [جانچ](/white-label/verify-a-licence) سکتا ہے۔

آپ AChat ٹیم کے Wise اکاؤنٹ میں بینک ٹرانسفر سے ادائیگی کرتے ہیں اور ادائیگی کے صفحے سے ٹرانسفر کا حوالہ بھیجتے ہیں۔ لائسنس تب ہی جاری ہوتا ہے جب AChat ٹیم ٹرانسفر کی تصدیق کرتی ہے، اس صفحے سے کبھی نہیں جس پر آپ واپس آتے ہیں۔
