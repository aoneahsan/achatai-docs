# ہر پلیٹ فارم پر آپ کو کیا ملتا ہے

**لائسنس ان پلیٹ فارمز کا احاطہ کرتا ہے جن کی آپ ادائیگی کرتے ہیں، اور AChat آج دو دیتا ہے۔** ایکسٹینشن، ڈیسک ٹاپ ایپ یا پیکیج نہیں دیا جاتا، کیونکہ AChat خود ایسا کچھ نہیں دیتا۔

## ویب ایپ

آپ کے اپنے پتے پر براؤزر میں AChat: ذاتی چیٹس، گروپس، کمیونٹیز، اسٹیٹس اور گمنام رومز، ہر اسکرین پر آپ کا نام۔ یہ وہی ایپ ہے جو achat.aoneahsan.com پر چلتی ہے، اس سے الگ رکھی ہوئی: آپ کی کاپی استعمال کرنے والوں کو AChat اکاؤنٹس نہیں ملتے، اور ان کی چیٹس AChat کی چیٹس سے کبھی نہیں ملتیں۔

## موبائل ایپ (Android اور iOS)

آپ کے نام سے Android ایپ، آپ کے اپنے اسٹور اکاؤنٹ سے شائع۔ iOS بلڈ اسی ایپ سے بنتا ہے جب آپ Apple ڈویلپر اکاؤنٹ دیتے ہیں یا اس کا خرچ اٹھاتے ہیں۔ اسٹور ڈویلپر اکاؤنٹس آپ کا چنا ہوا خرچ ہیں، اس لیے وہ آپ کے ہیں۔

## ہر کاپی میں کیا ایک جیسا ہے

انکرپشن ویسے ہی کام کرتی ہے جیسے AChat میں۔ ذاتی چیٹس، پرائیویٹ گروپس اور پاس ورڈ والے رومز اینڈ ٹو اینڈ انکرپٹڈ ہیں؛ کمیونٹیز، کھلے رومز اور اسٹیٹس نہیں۔ یہ کس چیز کا احاطہ کرتی ہے اور کس کا نہیں، اس کے لیے دیکھیں [سیکیورٹی اور انکرپشن ماڈل](/concepts/security-and-encryption)۔

آپ کی کاپی پر آپ کا نام ہے، اس لیے اسے استعمال کرنے والے AChat کی نہیں، آپ کی پرائیویسی پالیسی اور شرائط پڑھتے ہیں۔
