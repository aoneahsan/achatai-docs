# ڈویلپر کی تبدیلیوں کا ریکارڈ

API، اسسٹنٹ کنکشن، ویب ہُکس اور دو مرحلہ سائن ان کی تبدیلیاں، سب سے نئی پہلے۔ API کا ورژن `v1` ہے۔

## اوپن پلیٹ فارم (2026-11-21)

- **[AChat API](./api.md)** `https://vhkerwyxmhaxfyjbvsha.supabase.co/functions/v1/api/v1` پر، اکاؤنٹ › دوسری ایپس میں بنائی گئی [ایکسیس کیز](./access-keys.md) (`achat_pat_…`) کے ساتھ۔ آپ کی پروفائل، سیٹنگز، اسٹیٹس پوسٹس (متن) اور بلاک فہرست پڑھی اور بدلی جا سکتی ہے؛ کانٹیکٹس، چیٹس، کھلے رومز کے پیغامات، کمیونٹیز اور چینلز صرف پڑھے جا سکتے ہیں۔ OpenAPI 3.1 دستاویز `/openapi.json` پر ہے۔
- **[اسسٹنٹ کنکشن](./assistants.md)** `https://vhkerwyxmhaxfyjbvsha.supabase.co/functions/v1/mcp` پر، Claude، ChatGPT، Claude Code اور Cursor کے لیے۔ ہر ایک کو آپ AChat پر منظور کرتے ہیں، اور اسسٹنٹ کا حذف کرنا `/developers/confirm` پر آپ کی ہاں کا انتظار کرتا ہے۔
- **[ویب ہُکس](./webhooks.md)** گیارہ ایونٹس کے لیے، Standard Webhooks سے دستخط شدہ، صرف IDs اور اوقات کے ساتھ۔
- **[دو مرحلہ سائن ان](./two-step-sign-in.md)** آتھنٹیکیٹر ایپ، دس ریکوری کوڈز اور اختیاری 7 دن تک براؤزر یاد رکھنے کے ساتھ۔ AChat کی ایڈمن اسکرینز چلانے والے اکاؤنٹس کے لیے ضروری۔
- اینڈ ٹو اینڈ انکرپٹڈ چیٹس ان سب سے باہر رہتی ہیں: باہر کی ایپس کو چیٹ کا نام اور اراکین نظر آتے ہیں، پیغامات کبھی نہیں۔
- کوئی کیلنڈر فیڈ نہیں: AChat کے پاس اس میں ڈالنے لائق تاریخ والی کوئی چیز نہیں۔
