# Claude، ChatGPT، Claude Code یا Cursor منسلک کریں

**AChat کا اسسٹنٹ پتا اپنے اسسٹنٹ میں پیسٹ کریں، AChat پر منظور کریں، اور وہ آپ کا اکاؤنٹ پڑھ سکتا ہے اور جو آپ کا ہے اسے بدل سکتا ہے۔** اسے صرف وہی نظر آتا ہے جو آپ منظوری کے وقت ٹک کرتے ہیں۔ وہ اینڈ ٹو اینڈ انکرپٹڈ پیغام کبھی نہیں پڑھ سکتا، اور AChat پر آپ کی ہاں کے بغیر کچھ حذف نہیں کر سکتا۔

AChat کا اسسٹنٹ پتا:

```text
https://vhkerwyxmhaxfyjbvsha.supabase.co/functions/v1/mcp
```

یہ Streamable HTTP پر چلنے والا ریموٹ MCP سرور ہے۔ یہ **اکاؤنٹ › دوسری ایپس › اسسٹنٹ منسلک کریں** میں بھی **کاپی کریں** بٹن کے ساتھ ملتا ہے۔

## Claude

1. Claude میں **Settings**، پھر **Connectors** کھولیں۔
2. **Add custom connector** چنیں اور AChat کا پتا پیسٹ کریں۔
3. Claude، AChat کھولتا ہے۔ دیکھیں کہ وہ کیا مانگتا ہے، اور منظور کریں۔

## ChatGPT

1. ChatGPT میں **Settings**، پھر **Apps and Connectors** کھولیں، اور ڈویلپر موڈ آن کریں۔
2. **Create** چنیں، نام AChat رکھیں اور پتا پیسٹ کریں۔
3. ChatGPT، AChat کھولتا ہے۔ دیکھیں کہ وہ کیا مانگتا ہے، اور منظور کریں۔

## Claude Code

1. ٹرمینل میں چلائیں:

   ```bash
   claude mcp add --transport http achat https://vhkerwyxmhaxfyjbvsha.supabase.co/functions/v1/mcp
   ```

2. Claude Code میں `/mcp` چلائیں اور **achat** چنیں۔
3. آپ کا براؤزر AChat کھولتا ہے۔ دیکھیں کہ وہ کیا مانگتا ہے، اور منظور کریں۔

## Cursor

1. Cursor میں **Settings**، پھر **MCP**، پھر **Add new MCP server** کھولیں۔
2. یہ `mcp.json` میں پیسٹ کریں:

   ```json
   { "mcpServers": { "achat": { "url": "https://vhkerwyxmhaxfyjbvsha.supabase.co/functions/v1/mcp" } } }
   ```

3. Cursor، AChat کھولتا ہے۔ دیکھیں کہ وہ کیا مانگتا ہے، اور منظور کریں۔

OAuth سپورٹ کرنے والے دوسرے MCP کلائنٹس بھی ایسے ہی کام کرتے ہیں: بغیر ٹوکن والے کلائنٹ کو پتا بتاتا ہے کہ سائن اِن کہاں کرنا ہے، اور کلائنٹ خود کو رجسٹر کر لیتا ہے۔

## آپ کیا منظور کرتے ہیں

AChat کا رضامندی کا صفحہ ایپ کا نام، وہ پتا جہاں وہ آپ کو واپس بھیجتی ہے، اور اس کی مانگی ہر اجازت دکھاتا ہے، [رسائی کی](./access-keys.md#permissions) جیسے ہی پڑھیں، بدلیں اور حذف کریں ٹک کے ساتھ۔ کچھ بھی مانگا جائے، مشترک ڈیٹا صرف پڑھنے کے لیے رہتا ہے، اور جو اجازت AChat نہیں دیتی وہ درخواست سے ہٹا دی جاتی ہے۔ جب تک آپ **منظور کریں** نہیں چنتے، کچھ شیئر نہیں ہوتا۔

- جو ایپ "AChat میں خود رجسٹر ہوئی"، اسے کون چلاتا ہے یہ AChat نے نہیں جانچا، اس لیے پڑھیں کہ وہ کیا مانگتی ہے۔
- اگر کنکشن چیزیں بدل سکتا ہے، تو منظوری کے لیے پچھلے 10 منٹ میں سائن اِن چاہیے، اور [دو مرحلہ سائن اِن](./two-step-sign-in.md) آن ہو تو کوڈ بھی۔
- آپ کنکشن کو نام دے سکتے ہیں، تاکہ بعد میں دو کو الگ پہچان سکیں۔

ایپ منسلک ہونے پر AChat آپ کو ای میل کرتی ہے۔ آپ کا پلان طے کرتا ہے کہ ایک ساتھ کتنی منسلک ہو سکتی ہیں (Free پر ڈیفالٹ 3؛ دیکھیں [آپ کا پلان کیا دیتا ہے](./index.md#what-your-plan-allows))۔ اسسٹنٹ کی کالز API والے اسی روزانہ درخواستوں کے کوٹے میں گنی جاتی ہیں۔

## اسسٹنٹ کیا کر سکتا ہے

ہر ٹول کو اس کے ساتھ والی اجازت چاہیے، اور اسسٹنٹ کی ٹول فہرست میں صرف وہ ٹول دکھتے ہیں جن کی آپ کی منظوری ابھی اجازت دیتی ہے۔

| ٹول | اجازت |
|---|---|
| `list_profile`, `get_profile`, `update_profile` | `profile:read`, `profile:write` |
| `list_preferences`, `get_preferences`, `update_preferences` | `preferences:read`, `preferences:write` |
| `list_status`, `get_status`, `create_status`, `prepare_delete_status` | `status:read`, `status:write`, `status:delete` |
| `list_blocks`, `get_blocks`, `create_blocks`, `prepare_delete_blocks` | `blocks:read`, `blocks:write`, `blocks:delete` |
| `list_contacts`, `get_contacts` | `contacts:read` |
| `list_chats`, `get_chats`, `list_messages`, `get_messages` | `chats:read` |
| `list_communities`, `get_communities`, `list_channels`, `get_channels` | `communities:read` |

فیلڈز API والے ہی ہیں؛ دیکھیں [AChat API](./api.md)۔ فہرستیں ایک کال میں 50 تک ریکارڈ لوٹاتی ہیں، اگلے صفحے کے کرسر کے ساتھ۔ پیغامات صرف کھلے رومز اور چینلز سے آتے ہیں۔ ذاتی چیٹ، گروپ یا پاس ورڈ والا روم اپنا نام اور اراکین دکھاتا ہے، کیا کہا گیا یہ کبھی نہیں۔

## حذف کرنا آپ کا انتظار کرتا ہے {#deletes-wait-for-you}

اسسٹنٹ کبھی حذف نہیں کرتا۔ جب آپ اس سے کوئی اسٹیٹس پوسٹ ہٹانے یا کسی کو ان بلاک کرنے کو کہتے ہیں، تو وہ `prepare_delete_status` یا `prepare_delete_blocks` کال کرتا ہے، اور AChat `https://achat.aoneahsan.com/developers/confirm/…` کا لنک لوٹاتی ہے۔

1. لنک کھولیں۔ AChat دکھاتی ہے کہ اسسٹنٹ نے کیا مانگا اور اس کے ساتھ کیا جائے گا۔
2. **حذف کریں** (یا **ان بلاک کریں**)، یا **رہنے دیں** چنیں۔ آپ AChat پر ہیں، اسسٹنٹ میں نہیں، اس لیے وہ یہ بٹن نہیں دبا سکتا۔
3. اسسٹنٹ کو بس اتنا پتا چلتا ہے کہ درخواست پوری ہوئی۔

درخواست 10 منٹ بعد ختم ہو جاتی ہے، اور کچھ حذف نہیں ہوتا۔ تصدیق کے لیے پچھلے 10 منٹ میں سائن اِن چاہیے، دو مرحلہ سائن اِن آن ہو تو کوڈ کے ساتھ۔ جو حذف ابھی انتظار میں ہیں وہ **اکاؤنٹ › دوسری ایپس › منسلک ایپس** میں دکھتے ہیں۔ حذف کی اجازت والی [رسائی کی](./access-keys.md) فوراً حذف کرتی ہے، کیونکہ اسے چلانے والے آپ خود ہیں۔

## الگ کریں

**اکاؤنٹ › دوسری ایپس › منسلک ایپس** میں، کنکشن پر **ہٹائیں** چنیں۔ اس کی رسائی فوراً ختم ہو جاتی ہے، بیچ میں چلتی درخواست سمیت۔ دوبارہ استعمال کرنا ہو تو دوبارہ منسلک کریں۔ **نام بدلیں** صرف وہ نام بدلتا ہے جو آپ کو نظر آتا ہے۔

## اسسٹنٹ کن چیزوں تک نہیں پہنچ سکتا

- ذاتی چیٹس، گروپس اور پاس ورڈ والے رومز کے پیغامات، جنہیں AChat خود نہیں پڑھ سکتی۔
- آپ کی ڈیوائس کیز، ریکوری کی، دو مرحلہ کوڈز، رسائی کیز اور ویب ہُک سیکرٹس۔
- آپ کی تصویر، اٹیچمنٹس، ری ایکشنز اور پولز۔
- کسی دوسرے اکاؤنٹ کی کوئی بھی چیز۔

اسسٹنٹ AChat سے جو متن پڑھتا ہے (کوئی اسٹیٹس پوسٹ، کسی کھلے روم کا پیغام) وہ اسے ڈیٹا کے طور پر لوٹایا جاتا ہے۔ دوسروں کے لکھے الفاظ کو ان کے الفاظ سمجھیں، آپ کے اسسٹنٹ کے لیے ہدایات نہیں۔
