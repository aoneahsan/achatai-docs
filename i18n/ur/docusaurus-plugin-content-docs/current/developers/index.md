# ڈویلپرز کے لیے AChat

**آپ کے AChat اکاؤنٹ تک ایپ کے باہر سے پہنچا جا سکتا ہے، آپ کے ذریعے، آپ کی شرائط پر۔** کوئی اسکرپٹ اسٹیٹس لگا سکتا ہے یا آپ کی بلاک فہرست ملا کر رکھ سکتا ہے، Claude بتا سکتا ہے کہ کن کھلے رومز میں نئے پیغامات آئے، اور آپ کا سرور اسی لمحے جان سکتا ہے جب کوئی آپ کو کانٹیکٹ کی درخواست بھیجے۔ یہ ہر پلان میں ہے، Free سمیت، اور ہر راستہ ایک ہی اکاؤنٹ تک پہنچتا ہے: آپ کا۔

## آپ کو کون سا چاہیے؟

| آپ چاہتے ہیں | استعمال کریں |
|---|---|
| آپ کا کوئی اسکرپٹ یا سروس آپ کا اکاؤنٹ پڑھے یا بدلے | [رسائی کی](./access-keys.md) اور [API](./api.md) |
| Claude، ChatGPT، Claude Code یا Cursor آپ کے اکاؤنٹ کے ساتھ کام کرے | [اسسٹنٹ کنکشن](./assistants.md) |
| کچھ بدلے تو آپ کے سرور کو بتایا جائے، ہر منٹ پوچھے بغیر | [ویب ہُکس](./webhooks.md) |
| Google سائن اِن کے بعد ایک کوڈ، تاکہ چوری شدہ Google اکاؤنٹ کافی نہ ہو | [دو مرحلہ سائن اِن](./two-step-sign-in.md) |

چاروں ایپ میں ہیں: کیز، منسلک ایپس اور ویب ہُکس **اکاؤنٹ › دوسری ایپس** میں، دو مرحلہ سائن اِن **اکاؤنٹ › سیکیورٹی** میں۔

## دوسری ایپس کن چیزوں تک پہنچ سکتی ہیں {#what-other-apps-can-reach}

کوئی ایپ صرف آپ کی بنائی کی یا آپ کے منظور کیے کنکشن سے اندر آتی ہے۔ دونوں میں تین اصول لاگو ہوتے ہیں۔

| | کیا | AChat کے باہر سے |
|---|---|---|
| **آپ کا** | آپ کی پروفائل، سیٹنگز، اسٹیٹس پوسٹس اور بلاک فہرست | پڑھنا اور بدلنا۔ حذف کرنا الگ اجازت ہے، جب تک آپ ٹک نہ کریں تب تک بند |
| **دوسروں کے ساتھ مشترک** | کانٹیکٹس، چیٹس، کھلے رومز کے پیغامات، کمیونٹیز اور چینلز | صرف پڑھنا۔ کوئی ایپ وہاں پوسٹ، ہٹا یا مدعو نہیں کر سکتی |
| **اینڈ ٹو اینڈ انکرپٹڈ** | ذاتی چیٹس، گروپس اور پاس ورڈ والے رومز | کبھی نہیں۔ ایپ کو چیٹ کا نام اور یہ نظر آتا ہے کہ آپ اس میں ہیں، پیغامات کبھی نہیں |

آخری اصول کوئی سیٹنگ نہیں۔ آپ کی ذاتی چیٹس، گروپس اور پاس ورڈ والے رومز کے پیغامات آپ کے ڈیوائسز پر بند رہتے ہیں، اور AChat کے سرورز انہیں نہیں پڑھ سکتے، اس لیے کوئی کی یا اسسٹنٹ بھی نہیں پڑھ سکتا۔ آپ کی ڈیوائس کیز، ریکوری کی اور دو مرحلہ کوڈز پر بھی یہی لاگو ہے۔ دیکھیں [سیکیورٹی اور انکرپشن](/concepts/security-and-encryption)۔

## آپ کا پلان کیا دیتا ہے {#what-your-plan-allows}

| | Free | Pro | Team / Family |
|---|---|---|---|
| ایک ساتھ رسائی کیز | 5 | 25 | 50 |
| روزانہ API اور اسسٹنٹ درخواستیں | 5,000 | 50,000 | 100,000 |
| ایک ساتھ ویب ہُک پتے | 3 | 20 | 40 |
| ایک ساتھ اسسٹنٹ کنکشن | 3 | 10 | 25 |

یہ آج کے ڈیفالٹ ہیں۔ ہر پلان کی تعداد AChat ٹیم طے کرتی ہے، اس لیے **اکاؤنٹ › دوسری ایپس › آپ کے پلان کے حساب سے استعمال** دکھاتا ہے کہ آپ پر کیا لاگو ہے، آج کی گنتی کے ساتھ۔ درخواستیں UTC آدھی رات سے گنی جاتی ہیں، اکاؤنٹ کی ہر کی اور اسسٹنٹ کو ملا کر۔ ہر کی یا کنکشن ہر پلان پر ایک منٹ میں 120 درخواستوں تک بھی محدود ہے، تاکہ بے قابو اسکرپٹ دن کا کوٹا ختم کرنے سے پہلے رک جائے۔

## کوئی کیلنڈر فیڈ نہیں

AChat میں ایسی کوئی تاریخ والی چیز نہیں جو کیلنڈر میں جائے، اس لیے سبسکرائب کرنے کو کوئی کیلنڈر فیڈ نہیں۔
