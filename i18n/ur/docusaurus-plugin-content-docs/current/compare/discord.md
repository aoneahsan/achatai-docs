# Discord سے AChat پر آنا

**Discord کمیونٹی چیٹ ہے، اور بڑے اپ لوڈز جیسی چیزوں کے لیے Nitro اس کا پیڈ اپ گریڈ ہے۔** وائس چینلز میں بسی بڑی کمیونٹی Discord پر ہی ٹھیک ہے؛ AChat میں وائس نہیں۔ AChat اس کمیونٹی کے لیے موزوں ہے جو مہمانوں کو بغیر اکاؤنٹ آنے دے، یا ان لوگوں کے لیے جو اپنی آمنے سامنے کی چیٹس اینڈ ٹو اینڈ انکرپٹڈ چاہتے ہیں۔

آخری بار 2026-11-22 کو جانچا گیا۔ آمنے سامنے: [AChat اور Discord](https://achat.aoneahsan.com/ur/compare/discord)۔

## سرور سے کمیونٹی

Discord سرور کافی سیدھا AChat کمیونٹی میں بدل جاتا ہے: کمیونٹی میں چینلز ہوتے ہیں، اور چینلز میں تھریڈز۔

1. [سائن اِن کریں](/getting-started/quick-start) اور **کمیونٹیز** سے ایک کمیونٹی بنائیں ([گروپس اور کمیونٹیز](/features/groups-and-communities))۔ اس کا لنک ID چنیں، 8 سے 20 چھوٹے حروف، اعداد اور ڈیش۔
2. اس تک رسائی چنیں۔ **گمنام کی اجازت** مہمانوں کو بغیر اکاؤنٹ ظاہری نام سے شامل ہونے دیتی ہے۔ **اکاؤنٹ ضروری** اسے سائن اِن کیے لوگوں تک رکھتا ہے۔
3. جو ٹیکسٹ چینلز آپ واقعی استعمال کرتے ہیں، انہیں دوبارہ بنائیں۔ جس چینل کو صرف کچھ اراکین کو پڑھنا چاہیے، اسے پرائیویٹ رکھیں۔
4. اپنے ایڈمن طے کریں۔ وہ چینلز بناتے ہیں اور رپورٹس اور پابندیاں سنبھالتے ہیں؛ کون ایڈمن ہو گا، یہ صرف مالک چنتا ہے۔
5. کمیونٹی کا لنک اپنے Discord اعلانات میں ڈالیں، اور منتقلی کو کچھ وقت دیں۔
6. اختیاری: [ویجیٹ کے صفحے](https://achat.aoneahsan.com/ur/widget) سے ظاہری نام والا ایک چینل اپنی ویب سائٹ پر لگائیں۔

کمیونٹیز اینڈ ٹو اینڈ انکرپٹڈ نہیں۔ ذاتی چیٹس ([ذاتی چیٹس اور کانٹیکٹس](/features/personal-chats-and-contacts)) اور پرائیویٹ گروپس ہیں، اور ان کی تاریخ صرف منسلک ڈیوائس یا آپ کی ریکوری کی سے لوٹتی ہے ([ڈیوائسز اور ریکوری کی](/features/devices-and-recovery))۔ Discord کی تاریخ امپورٹ نہیں ہوتی۔
