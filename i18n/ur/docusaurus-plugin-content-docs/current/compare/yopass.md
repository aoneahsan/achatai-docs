# Yopass سے AChat پر آنا

**Yopass ایک بار کے سیکرٹ لنک بناتا ہے، جو آپ کے براؤزر میں انکرپٹ ہوتے ہیں؛ یہ اوپن سورس ہے اور مفت میں سیلف ہوسٹ ہو سکتا ہے۔** اگر راز کو ایک بار دیکھنے کے بعد خود مٹ جانا چاہیے، یا آپ ٹول خود ہوسٹ کرنا چاہتے ہیں، تو Yopass پر رہیں؛ AChat سیلف ہوسٹ نہیں ہو سکتی۔ AChat ایسی گفتگو کے لیے ہے جو تب تک کھلی رہے جب تک آپ کا کام نہ ہو جائے۔

## گفتگو کھلی رکھنا

Yopass لنک پڑھے جانے کے بعد بند ہو جاتا ہے۔ اگر سامنے والا "یہ نہیں چلا" کہہ کر لوٹے، تو آپ کو دوبارہ شروع کرنا پڑتا ہے۔ AChat روم میں وہ وہیں جواب دیتے ہیں جہاں آپ نے چھوڑا تھا۔

1. **گمنام طور پر جاری رکھیں** چنیں، پھر **روم بنائیں** ([گمنام رومز](/features/anonymous-chats))۔
2. پاس ورڈ رکھیں۔ پاس ورڈ والے روم کے پیغامات اسی سے آپ کی ڈیوائس پر انکرپٹ ہوتے ہیں ([پاس ورڈ اور انکرپشن](/features/passwords-and-encryption))۔
3. جو چاہیے وہ بھیجیں، متن یا فائل ([فائل شیئرنگ](/features/file-sharing))، پھر لنک اور پاس ورڈ الگ الگ بھیجیں۔
4. معاملہ سلجھنے تک رکیں۔ پھر اپنے پیغامات مٹا دیں، یا انہیں روم کے مقررہ دنوں بعد ختم ہونے دیں۔
