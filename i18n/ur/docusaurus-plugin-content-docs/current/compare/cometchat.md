# CometChat سے AChat پر آنا

**CometChat ڈویلپرز کے لیے چیٹ ہے، اپنے Build پلان پر 100 یوزرز تک مفت۔** اگر آپ کے ڈویلپرز آپ کی اپنی ایپ میں چیٹ شامل کر رہے ہیں، تو اسی کے ساتھ رہیں۔ AChat تب کے لیے ہے جب آپ ایک اسنیپٹ چسپاں کرنا اور مہمانوں کو بغیر اکاؤنٹ بات کرنے دینا پسند کریں۔

آخری بار 2026-11-22 کو جانچا گیا۔ آمنے سامنے: [AChat اور CometChat](https://achat.aoneahsan.com/ur/compare/cometchat)۔

## 100 یوزرز کی حد کے بعد

Build پلان 100 یوزرز تک کے لیے ہے۔ اگر آپ نے اس پر جو بنایا وہ دراصل مہمانوں کے لیے ایک عوامی روم ہے، تو تبادلہ یوں کریں۔

1. دونوں استعمال الگ کریں۔ آپ کے اپنے یوزرز کے درمیان اِن ایپ چیٹ CometChat پر رہتی ہے۔
2. عوامی حصے کے لیے [ویجیٹ کے صفحے](https://achat.aoneahsan.com/ur/widget) پر ایک روم بنائیں یا کھلا کمیونٹی چینل چنیں ([ایمبیڈ ہونے والا ویجیٹ](/features/embeddable-widget))۔
3. لے آؤٹ طے کریں، پھر کوڈ اپنے صفحے میں کاپی کریں۔
4. مہمان روم میں ظاہری نام چنتے ہیں۔ کسی کو اکاؤنٹ کی ضرورت نہیں۔
5. اگر روم کسی ایک گروپ تک نجی رہنا چاہیے، تو پاس ورڈ رکھیں اور اسے الگ سے بھیجیں۔
