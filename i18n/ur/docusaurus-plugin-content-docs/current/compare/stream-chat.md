# Stream Chat سے AChat پر آنا

**Stream Chat ڈویلپرز کے لیے اپنی ایپس میں بنانے والی چیٹ ہے، 1,000 ماہانہ فعال یوزرز تک مفت۔** اگر آپ کے ڈویلپرز آپ کی اپنی پروڈکٹ میں چیٹ بنا رہے ہیں اور ہر حصے پر کنٹرول چاہتے ہیں، تو Stream صحیح قسم کا ٹول ہے۔ AChat الٹا سودا ہے: آپ ایک اسنیپٹ چسپاں کرتے ہیں اور چلتی ہوئی چیٹ مل جاتی ہے، کسی ڈویلپر کے بغیر۔

2026-11-22 کو جانچا گیا۔ آمنے سامنے کا موازنہ [AChat اور Stream Chat](https://achat.aoneahsan.com/ur/compare/stream-chat) پر ہے۔

## جب SDK کام سے بڑا تھا

ٹیمیں کبھی کبھی ایسے کام کے لیے چیٹ SDK اٹھا لیتی ہیں جو آخر میں ایک صفحے پر ایک عوامی روم نکلتا ہے۔ اگر آپ وہیں ہیں، تو یہ ایک اسپرنٹ کی جگہ چند منٹ لیتا ہے۔

1. جہاں چیٹ آپ کے اپنے یوزرز اور ڈیٹا سے جڑی ہے، وہاں Stream رکھیں۔ AChat کا ویجیٹ ڈویلپر SDK نہیں، اس لیے وہ آپ کے اپنے یوزر اکاؤنٹس کے اوپر نہیں بیٹھے گا۔
2. عوامی روم کے لیے [ویجیٹ کا صفحہ](https://achat.aoneahsan.com/ur/widget) کھولیں اور روم ID یا کھلا کمیونٹی چینل چنیں ([ایمبیڈ ہونے والا ویجیٹ](/features/embeddable-widget))۔
3. لے آؤٹ اور آپشنز چنیں؛ ویجیٹ کا صفحہ آپ کے لیے کوڈ لکھ دیتا ہے۔
4. اسنیپٹ اپنے صفحے کے ٹیمپلیٹ میں کاپی کریں۔
5. جب کوئی روم رکھ لے، تو وہ اسے دکھانے کی اجازت والے ڈومینز درج کر سکتا ہے، 20 تک۔
