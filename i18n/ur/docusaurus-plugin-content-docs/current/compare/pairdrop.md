# PairDrop سے AChat پر آنا

**PairDrop آپ کے لوکل نیٹ ورک پر پیئر ٹو پیئر فائلیں اور متن بھیجتا ہے، یا جوڑی گئی ڈیوائسز اور عارضی عوامی رومز کے ذریعے انٹرنیٹ پر۔** جب دونوں مشینیں ایک ساتھ چالو ہوں، تو یہی سیدھا راستہ ہے۔ AChat تب کام آتی ہے جب دوسری مشین بعد میں آن لائن آئے اور پیغام تب بھی وہاں ہونا چاہیے۔

آخری بار 2026-11-22 کو جانچا گیا۔ آمنے سامنے: [AChat اور PairDrop](https://achat.aoneahsan.com/ur/compare/pairdrop)۔

## جب دوسری مشین ابھی چالو نہ ہو

فرض کریں آپ کام سے نکل رہے ہیں اور آج رات گھر کے کمپیوٹر پر ایک فائل چاہیے۔ ابھی دوسری طرف کچھ انتظار نہیں کر رہا، اس لیے پیئر ٹو پیئر بھیجنا پہنچ نہیں سکتا۔

1. کام والی مشین پر AChat کھولیں، **گمنام طور پر جاری رکھیں**، اور ایک روم بنائیں ([گمنام رومز](/features/anonymous-chats))۔
2. پاس ورڈ شامل کریں، تاکہ بعد میں صرف آپ اسے کھول سکیں ([پاس ورڈ اور انکرپشن](/features/passwords-and-encryption))۔
3. فائل اور کوئی نوٹ ڈال دیں ([فائل شیئرنگ](/features/file-sharing))۔ روم کا لنک ایسی جگہ کاپی کریں جو گھر پر آپ کے پاس ہو۔
4. گھر پر لنک کھولیں، پاس ورڈ ڈالیں، اور فائل لے لیں۔
5. اسے مٹا دیں، یا رہنے دیں۔ پیغامات مقررہ دنوں بعد مٹ جاتے ہیں۔
