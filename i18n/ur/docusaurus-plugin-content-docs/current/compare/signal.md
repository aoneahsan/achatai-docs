# Signal سے AChat پر آنا

**Signal مفت ہے، اس میں اشتہار نہیں، وہ اینڈ ٹو اینڈ انکرپٹ کرتا ہے، اور فون اور ڈیسک ٹاپ پر چلتا ہے۔** اس کے پیچھے ایک غیر منافع بخش ادارہ ہے، اور اس میں آواز اور ویڈیو کالز ہیں، جو AChat میں نہیں۔ لوگ عام طور پر AChat کو دو دوسری وجوہات سے دیکھتے ہیں: یہ براؤزر میں کھلتی ہے، اور فون کھونے کے بعد ریکوری کی آپ کی تاریخ واپس لاتی ہے۔ Signal کہتا ہے کہ پرانی ڈیوائس کے بغیر بحالی کی سہولت نہیں۔

آخری بار 2026-11-22 کو جانچا گیا۔ پورا موازنہ: [AChat اور Signal](https://achat.aoneahsan.com/ur/compare/signal)۔

## Signal کے ساتھ سیٹ کرنا

آزمانے کے لیے Signal چھوڑنے کی ضرورت نہیں۔ زیادہ تر لوگ کچھ عرصہ دونوں چلاتے ہیں۔

1. اپنے کمپیوٹر کے براؤزر میں AChat کھولیں اور [سائن اِن کریں](/getting-started/quick-start)۔ کچھ انسٹال نہیں کرنا، اور پہلے کوئی فون جوڑنا نہیں پڑتا۔ یوزر نیم چنیں؛ کوئی فون نمبر نہیں مانگا جاتا۔
2. AChat جب ریکوری کی دکھائے، اسے لکھ لیں، کیونکہ وہ ایک ہی بار دکھتی ہے ([ڈیوائسز اور ریکوری کی](/features/devices-and-recovery))۔ یہی وہ حصہ ہے جو Signal آپ کو نہیں دے سکتا، اس لیے اسے گھر کی چابی کی طرح رکھیں۔
3. جب آپ Signal والے کسی کے ساتھ ہوں، تو ایک دوسرے کے QR کوڈ اسکین کریں۔ ورنہ اپنی Signal چیٹ میں اپنا دعوتی لنک بھیجیں ([ذاتی چیٹس اور کانٹیکٹس](/features/personal-chats-and-contacts))۔
4. اپنی دوسری ڈیوائس منسلک کرتے وقت سیکیورٹی کوڈ ملائیں۔ کوڈ میل کھائیں، تو وہی ڈیوائس ہے جسے آپ منسلک کرنا چاہتے تھے۔

کالز Signal پر رہتی ہیں۔ پرانے Signal پیغامات بھی وہیں رہتے ہیں، کیونکہ AChat دوسری ایپس سے چیٹس امپورٹ نہیں کرتی۔
