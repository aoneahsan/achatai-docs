# TalkJS سے AChat پر آنا

**TalkJS آپ کی پروڈکٹ میں شامل کرنے کے لیے تیار چیٹ UI ہے، ڈویلپمنٹ موڈ میں مفت۔** جب چیٹ آپ کی اپنی پروڈکٹ کے اندر ہو اور آپ کے اپنے یوزر اکاؤنٹس سے جڑی ہو، تو TalkJS زیادہ قریب بیٹھتا ہے۔ AChat مفت پلان پر لائیو ہوتی ہے، اور اسے استعمال کرنے والے مہمانوں کو اکاؤنٹ کی ضرورت ہی نہیں۔

2026-11-22 کو جانچا گیا۔ موازنے کا صفحہ [AChat اور TalkJS](https://achat.aoneahsan.com/ur/compare/talkjs) ہے۔

## ڈویلپمنٹ موڈ سے لائیو روم تک

ڈویلپمنٹ موڈ میں بناتے وقت TalkJS مفت ہے۔ اگر آپ نے جو پروٹوٹائپ بنایا وہ یوزرز کے درمیان چیٹ نہیں بلکہ ایک عوامی روم تھا، تو AChat اسے اپنے مفت پلان پر لائیو لے جا سکتی ہے۔

1. دیکھیں کہ آپ کا پروٹوٹائپ کس پر ٹکا ہے۔ آپ کے یوزر ID سے جڑی گفتگو TalkJS کے پاس رہتی ہے، کیونکہ AChat کا ویجیٹ ڈویلپر SDK نہیں اور آپ کے یوزرز کو نہیں جانتا۔
2. کھلے روم کے لیے [ویجیٹ کے صفحے](https://achat.aoneahsan.com/ur/widget) پر روم ID چنیں ([ایمبیڈ ہونے والا ویجیٹ](/features/embeddable-widget))۔ مہمان ظاہری نام سے شامل ہوتے ہیں۔
3. جہاں آپ کی TalkJS چیٹ تھی وہاں رکھنے کے لیے **صفحے کے اندر** چنیں، یا کونے کے پینل کے لیے **چیٹ بٹن**۔
4. کوڈ صفحے میں کاپی کریں۔
5. اکاؤنٹ سے روم رکھیں، پھر اسے دکھانے کی اجازت والی ویب سائٹس درج کریں۔
