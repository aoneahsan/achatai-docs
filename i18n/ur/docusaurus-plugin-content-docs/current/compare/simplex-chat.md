# SimpleX Chat سے AChat پر آنا

**SimpleX Chat میں کوئی یوزر شناخت ہوتی ہی نہیں، رینڈم بھی نہیں۔** اگر آپ کے لیے اصل بات یہی ہے، تو یہاں کچھ اس سے بہتر نہیں۔ AChat جان بوجھ کر الٹا راستہ لیتی ہے: لوگ آپ کو یوزر نیم سے ڈھونڈتے ہیں۔ اس کے اوپر گمنام رومز ہیں، جنہیں آپ لنک سے شیئر کر سکتے ہیں یا ویب سائٹ پر لگا سکتے ہیں۔

آخری بار 2026-11-22 کو جانچا گیا۔ پورا موازنہ: [AChat اور SimpleX Chat](https://achat.aoneahsan.com/ur/compare/simplex-chat)۔

## ایسا نام چننا جس سے ڈھونڈے جانے میں آپ کو مسئلہ نہ ہو

SimpleX پر ہر کانٹیکٹ ایک بار کے لنک سے شروع ہوتا ہے۔ AChat پر آپ اپنا یوزر نیم دیتے ہیں، اس لیے اس پر تھوڑا سوچیں۔

1. [سائن اِن کریں](/getting-started/quick-start) اور 3 سے 24 حروف کا یوزر نیم چنیں، جس میں حروف، اعداد، ڈاٹ یا انڈر اسکور ہوں۔ اسے کبھی بھی بدلا جا سکتا ہے۔ بدلنے پر پرانا نام کسی اور کے لیے کھل جاتا ہے۔
2. اسے ویسے ہی دیں جیسے آپ عادی ہیں: دعوتی لنک یا QR کوڈ کی صورت میں ([ذاتی چیٹس اور کانٹیکٹس](/features/personal-chats-and-contacts))۔ جنہیں آپ نے ابھی قبول نہیں کیا، ان کے پیغامات **پیغام کی درخواستیں** میں انتظار کرتے ہیں۔
3. ریکوری کی محفوظ کریں ([ڈیوائسز اور ریکوری کی](/features/devices-and-recovery))۔ کوئی منسلک ڈیوائس نہ بچے، تو تاریخ واپس آنے کا یہی ایک راستہ ہے۔
4. جس گفتگو میں آپ کا یوزر نیم نہیں آنا چاہیے، اس کے لیے [گمنام روم](/features/anonymous-chats) استعمال کریں۔ [ویجیٹ کا صفحہ](https://achat.aoneahsan.com/ur/widget) اسے آپ کی سائٹ پر لگا دیتا ہے۔

چیٹس SimpleX میں رہتی ہیں۔ AChat دوسری ایپس سے امپورٹ نہیں کرتی۔
