# Threema سے AChat پر آنا

**Threema نہ فون نمبر مانگتا ہے نہ ای میل، اور آپ کی ID اور چیٹس کا بیک اپ الگ الگ کرتا ہے۔** اگر سائن اپ پر کوئی ذاتی ڈیٹا نہ دینا ہی آپ کی پسند کی وجہ ہے، تو اسے رکھیں۔ AChat اکاؤنٹ Google سے سائن اِن کرتا ہے، اس لیے وہ اتنا خالی نہیں۔ AChat جو جوڑتی ہے، وہ ہیں ایسے رومز جن میں کوئی بھی لنک سے شامل ہو سکتا ہے، اور ایسی چیٹ جسے آپ ویب سائٹ پر لگا سکتے ہیں۔

2026-11-22 کو جانچا گیا۔ آمنے سامنے کے لیے [AChat اور Threema](https://achat.aoneahsan.com/ur/compare/threema) دیکھیں۔

## اندر آنے کے دو طریقے

پہلے طے کریں کہ AChat کو کتنا دینا چاہتے ہیں، کیونکہ اس سے بدلتا ہے کہ آغاز کہاں سے ہو۔

**کچھ بھی نہیں۔** **گمنام طور پر جاری رکھیں** چنیں اور ایک روم بنائیں ([گمنام رومز](/features/anonymous-chats))۔ اس روم کے لیے ظاہری نام چنیں اور اس کا لنک شیئر کریں۔ اگر صرف کچھ لوگوں کو پڑھنا چاہیے، تو پاس ورڈ رکھیں۔

**ایک اکاؤنٹ۔** [Google سے سائن اِن کریں](/getting-started/quick-start) اور یوزر نیم چنیں، جس سے لوگ آپ کو ڈھونڈتے ہیں، کافی حد تک Threema ID جیسا۔ پھر:

1. اپنی ریکوری کی محفوظ کریں۔ Threema ID کا بیک اپ رکھتا ہے؛ AChat پر آپ کی تاریخ ریکوری کی یا کوئی دوسری منسلک ڈیوائس واپس لاتی ہے ([ڈیوائسز اور ریکوری کی](/features/devices-and-recovery))۔
2. اپنے Threema کانٹیکٹس کو اپنا یوزر نیم یا دعوتی لنک بھیجیں ([ذاتی چیٹس اور کانٹیکٹس](/features/personal-chats-and-contacts))۔
3. اگر آپ کی ویب سائٹ ہے، تو [ویجیٹ کے صفحے](https://achat.aoneahsan.com/ur/widget) پر اس کے لیے ایک روم بنائیں۔

آپ کی Threema چیٹس ساتھ نہیں آتیں۔ AChat دوسری ایپس سے چیٹس امپورٹ نہیں کرتی۔
