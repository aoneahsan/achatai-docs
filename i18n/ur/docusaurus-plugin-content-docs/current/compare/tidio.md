# Tidio سے AChat پر آنا

**Tidio Lyro نامی AI ایجنٹ والی صارف چیٹ ہے، جس کی قیمت گفتگو کی گنتی سے لگتی ہے۔** اگر آپ صارفین کو جواب دینے والا ایجنٹ چاہتے ہیں، تو وہ Tidio ہے۔ AChat ان صفحات کے لیے ہے جہاں لوگ آپس میں بات کرنے آتے ہیں، اور آپ گفتگو گننا نہیں چاہتے۔

آخری بار 2026-11-22 کو جانچا گیا۔ پورا موازنہ: [AChat اور Tidio](https://achat.aoneahsan.com/ur/compare/tidio)۔

## جواب دینے والے بوٹ کی جگہ ایک روم

AChat پر آپ کی طرف سے کوئی جواب نہیں دیتا۔ مہمان ایک دوسرے کو جواب دیتے ہیں، اس لیے یہ وہیں چلتا ہے جہاں یہی مقصد ہو۔

1. وہ صفحات چنیں جہاں مہمان آپ سے نہیں، آپس میں بات کرتے ہیں۔ باقی پر Tidio رہنے دیں۔
2. [ویجیٹ کے صفحے](https://achat.aoneahsan.com/ur/widget) پر کوئی گمنام روم یا کھلا کمیونٹی چینل چنیں، پھر لے آؤٹ ([ایمبیڈ ہونے والا ویجیٹ](/features/embeddable-widget))۔
3. اگر روم کسی تنگ کالم میں ہے، تو **کمپیکٹ** یا **چیٹ ہیڈر چھپائیں** آن کریں۔
4. ان صفحات میں کوڈ چسپاں کریں۔
5. اگر صرف کچھ مہمانوں کو پڑھنا چاہیے، تو روم میں پاس ورڈ رکھیں۔
