# Element سے AChat پر آنا

**Element اداروں کو چیٹ بیچتا ہے: ایک مفت Community ایڈیشن، اور سیٹ یا ڈپلائمنٹ کے حساب سے قیمت والے Enterprise اور Sovereign آپشنز۔** اگر آپ کسی ادارے کے لیے چیٹ چلاتے ہیں اور اپنا ڈپلائمنٹ چاہتے ہیں، تو یہ صفحہ آپ کے لیے نہیں؛ AChat آپ کے اپنے سرورز پر نہیں چل سکتی۔ یہ دوسری صورت کے لیے ہے، جہاں آپ دوستوں اور گھر والوں سے رابطے کے لیے Element استعمال کرتے تھے اور بغیر کچھ سیٹ کیے براؤزر میں شروع کرنا چاہتے ہیں۔

2026-11-22 کو جانچا گیا۔ پورا موازنہ [AChat اور Element](https://achat.aoneahsan.com/ur/compare/element) پر ہے۔

## ایک ذاتی حلقہ لانا

1. کسی بھی نئے براؤزر میں [achat.aoneahsan.com](https://achat.aoneahsan.com) کھولیں اور [سائن اِن کریں](/getting-started/quick-start)۔ کچھ سیٹ نہیں کرنا۔ یوزر نیم چنیں؛ کوئی فون نمبر نہیں مانگا جاتا۔
2. اپنی ریکوری کی محفوظ کریں ([ڈیوائسز اور ریکوری کی](/features/devices-and-recovery))۔ یہ ایک ہی بار دکھتی ہے۔
3. جن گنے چنے لوگوں سے آپ سب سے زیادہ بات کرتے ہیں، انہیں یوزر نیم، دعوتی لنک یا QR کوڈ سے شامل کریں ([ذاتی چیٹس اور کانٹیکٹس](/features/personal-chats-and-contacts))۔
4. ہر چھوٹے Element روم کو ایک AChat [گروپ](/features/groups-and-communities) بنا دیں۔ گروپس اینڈ ٹو اینڈ انکرپٹڈ ہیں۔ لنک سے شامل ہونے والا ایڈمن کی منظوری کا انتظار کرتا ہے۔
5. بڑا، کھلا روم چینلز والی کمیونٹی کے طور پر زیادہ موزوں ہے۔ کمیونٹیز اینڈ ٹو اینڈ انکرپٹڈ نہیں۔

Element کی پیغامات کی تاریخ Element کے پاس رہتی ہے۔ AChat دوسری ایپس سے چیٹس امپورٹ نہیں کرتی۔
