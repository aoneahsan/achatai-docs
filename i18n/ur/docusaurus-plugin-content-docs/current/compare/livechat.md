## اگر آپ کا ٹرائل ختم ہونے والا ہے

ہو سکتا ہے آپ نے LiveChat ٹرائل شروع کیا اور دیکھا کہ مہمانوں کو ایجنٹ کی ضرورت ہی نہیں تھی۔ ٹرائل ختم ہونے سے پہلے روم تیار رکھنے کا طریقہ یہ ہے۔

1. [ویجیٹ کا صفحہ](https://achat.aoneahsan.com/ur/widget) کھولیں اور کوئی گمنام روم یا کھلا کمیونٹی چینل چنیں ([ایمبیڈ ہونے والا ویجیٹ](/features/embeddable-widget))۔
2. پیش منظر میں دونوں لے آؤٹ آزمائیں؛ پیش منظر روم کو ڈیمو پیغامات سے بھر دیتا ہے تاکہ آپ سائز پرکھ سکیں۔
3. کوڈ کاپی کریں اور LiveChat کا اسنیپٹ بدل دیں۔
4. مہمان ظاہری نام چن کر بات کرتے ہیں۔ کوئی قطار میں انتظار نہیں کرتا، کیونکہ قطار ہے ہی نہیں۔
5. پاس ورڈ رکھنے سے روم صرف وہی پڑھ پاتے ہیں جنہیں آپ وہ دیتے ہیں۔
