# انسٹالیشن اور رسائی

**کسی نئے براؤزر میں [achat.aoneahsan.com](https://achat.aoneahsan.com/ur) کھولیں، یا [Google Play](https://play.google.com/store/apps/details?id=com.aoneahsan.achat) سے Android ایپ انسٹال کریں۔** دونوں ایک ہی AChat ہیں، انہی چیٹس کے ساتھ۔

## ویب

AChat فون، ٹیبلٹ یا کمپیوٹر کے کسی بھی نئے براؤزر میں چلتی ہے۔ کچھ انسٹال نہیں کرنا۔

فون پر AChat کے صفحات ایپ کی طرح ترتیب دیے جاتے ہیں: اصل کام انگوٹھے کی پہنچ میں رہتا ہے، اور صفحات کے لنکس **مزید لنکس** کے نیچے ہوتے ہیں۔ کمپیوٹر پر، یا تنگ کی گئی براؤزر ونڈو میں، آپ کو ویب لے آؤٹ ملتا ہے۔

## Android

[Google Play](https://play.google.com/store/apps/details?id=com.aoneahsan.achat) سے حاصل کریں۔ AChat کیمرا (کوڈ اسکین کرنے)، مائیکروفون (وائس نوٹس اور بول کر لکھنے)، اطلاعات، یا لوکیشن (صرف اس چیٹ میں جس میں ڈیوائس اور لوکیشن ہسٹری چالو ہو) استعمال کرے، اس سے پہلے Android آپ سے پوچھتا ہے۔

## iPhone اور iPad

iOS ایپ نہیں ہے۔ Safari میں ویب پر AChat استعمال کریں۔

## شامل ہونے کے دو طریقے

| | گمنام روم | اکاؤنٹ |
|---|---|---|
| کیا چاہیے | ایک روم لنک اور ایک ڈسپلے نیم | ایک Google اکاؤنٹ اور ایک یوزر نیم |
| کیا ملتا ہے | وہ روم، آپ کے چنے ہوئے ڈسپلے نیم سے | ذاتی چیٹس، کانٹیکٹس، گروپس، کمیونٹیز، اسٹیٹس، رکھے گئے رومز، پلانز |
| فون نمبر | کبھی نہیں مانگا جاتا | کبھی نہیں مانگا جاتا |

یوزر نیم 3–24 حروف، اعداد، نقطوں یا انڈر اسکور کا ہوتا ہے، اور اسے بعد میں بدلا جا سکتا ہے۔ اگر آپ کا اکاؤنٹ ہے، تب بھی AChat آپ کے گمنام روم کے پیغامات اس سے نہیں جوڑتی۔

## کیا پہلے آزما سکتے ہیں؟

جی ہاں۔ [ڈیمو](https://achat.aoneahsan.com/ur/demo) فرضی لوگوں کے ساتھ چار مختصر کام کر کے دکھاتا ہے، اور وہاں آپ جو بھی ٹائپ کریں وہ صفحے سے باہر نہیں جاتا۔

## AChat کون استعمال کر سکتا ہے

آپ کی عمر 16 سال یا اس سے زیادہ ہونی چاہیے۔ اگر کوئی اکاؤنٹ اس سے کم عمر شخص کا پایا جائے، تو اسے بند کر دیا جاتا ہے۔
