# ذاتی چیٹس اور کانٹیکٹس

**ذاتی چیٹس ان لوگوں کے لیے ہیں جنہیں آپ نے کانٹیکٹ کے طور پر قبول کیا ہے، اور وہ اینڈ ٹو اینڈ انکرپٹڈ ہیں۔** ان کے لیے اکاؤنٹ چاہیے، کیونکہ دوست آپ کو آپ کے یوزر نیم سے ڈھونڈتے ہیں۔

## کانٹیکٹ شامل کریں

**رابطے** کھولیں اور کسی کو شامل کریں:

- **یوزر نیم**: اسے تلاش کریں۔
- **دعوتی لنک**: آپ کا لنک جس کے پاس ہے، وہ آپ کو کانٹیکٹ کی درخواست بھیج سکتا ہے۔
- **QR کوڈ**: اپنا کانٹیکٹ کوڈ دکھائیں، یا ان کا اسکین کریں۔

## پیغام کی درخواستیں

جو لوگ آپ کے کانٹیکٹ نہیں، ان کے پیغامات **پیغام کی درخواستیں** میں تب تک رکتے ہیں جب تک آپ نہ چنیں۔

- جسے آپ نے قبول نہیں کیا، وہ ایک پیغام بھیج سکتا ہے، اور اس کا بھیجا میڈیا آپ کے قبول کرنے تک چھپا رہتا ہے۔
- قبول کرنے پر وہ آپ کے کانٹیکٹس میں شامل ہو جاتا ہے۔ ڈیفالٹ طور پر کانٹیکٹس آپ کا اسٹیٹس اور آپ کو آخری بار کب دیکھا گیا، دیکھ سکتے ہیں۔
- آپ کوئی وجہ چن کر درخواست کی رپورٹ کر سکتے ہیں۔

## کسی کو بلاک کریں

بلاک کیا گیا شخص آپ کو پیغام یا درخواستیں نہیں بھیج سکتا، اور اسے بتایا نہیں جاتا۔ آپ رابطے میں اسے ان بلاک کر سکتے ہیں۔

## آن لائن اسٹیٹس اور پڑھنے کی رسیدیں

| سیٹنگ | اختیارات | ڈیفالٹ |
|---|---|---|
| آن لائن اسٹیٹس | سب، آپ کے کانٹیکٹس، یا کوئی نہیں | کانٹیکٹس |
| پڑھنے کی رسیدیں | آن یا بند | آن۔ بند کریں تو آپ بھی نہیں دیکھیں گے کہ دوسروں نے آپ کے پیغامات کب پڑھے |

## چیٹ فہرست

- چیٹ کے مینیو سے **پن کریں**، **بغیر پڑھی کریں** اور **اطلاعات میوٹ کریں**۔
- آپ کا بغیر پڑھا مینشن گنتی کے ساتھ **@** جوڑتا ہے۔
- نہ بھیجا گیا ڈرافٹ چیٹ فہرست میں دکھتا ہے۔
- فہرست صاف رکھنے کے لیے کوئی چیٹ **آرکائیو کریں**۔ اس میں موجود کسی اور کے لیے کچھ نہیں بدلتا۔

## ذاتی چیٹ کون پڑھ سکتا ہے

اس میں موجود لوگ۔ AChat کے ماڈریٹر کوئی پیغام تبھی دیکھتے ہیں جب چیٹ میں کوئی اس کی رپورٹ کرے۔ دیکھیں [پاس ورڈ اور انکرپشن](/features/passwords-and-encryption)۔

## کچھ نیا شروع کرنا

کوئی چیٹ کھلی نہ ہو، تو مرکزی حصہ **کسی کو پیغام بھیجیں**، **نیا گروپ**، **گمنام روم بنائیں** اور **روم میں شامل ہوں** (روم لنک یا ID پیسٹ کریں) دیتا ہے، اور آپ کی حالیہ چیٹس۔ چیٹ فہرست کے اوپر کا **+**، فون پر بٹن، اور Alt+N وہی اختیارات کھولتے ہیں۔

## دعوتی لنک یا QR کوڈ سے کانٹیکٹ شامل کرنا

**رابطہ شامل کریں** کے تین طریقے ہیں: **یوزر نیم**، **دعوتی لنک** اور **QR کوڈ**۔ آپ کے دعوتی لنک اور کوڈ میں `/invite/` اور آپ کا یوزر نیم ہوتا ہے؛ جو بھی اسے کھولتا یا اسکین کرتا ہے، وہ آپ کو **رابطہ شامل کریں** میں دیکھتا ہے اور آپ کو کانٹیکٹ کی درخواست بھیج سکتا ہے۔ جہاں آپ کا براؤزر کر سکتا ہے، **کوڈ اسکین کریں** آپ کے کیمرے سے کسی کا کوڈ پڑھتا ہے۔

## ٹائپ کرنا

ذاتی چیٹ یا گروپ میں، پیغام کے خانے کے اوپر ایک سطر دکھاتی ہے کہ کوئی ٹائپ کر رہا ہے۔ کچھ محفوظ نہیں ہوتا، اور گمنام رومز اسے کبھی نہیں دکھاتے۔ اگر آپ کی موجودگی **کوئی نہیں** پر ہے، تو دوسروں کو آپ کا ٹائپ کرنا نظر نہیں آتا۔
