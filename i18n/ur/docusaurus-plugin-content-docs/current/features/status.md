# اسٹیٹس

**اسٹیٹس آپ کے قبول کیے کانٹیکٹس کے لیے ایک اپ ڈیٹ ہے جو 24 گھنٹے بعد غائب ہو جاتی ہے۔** اسٹیٹس کے لیے اکاؤنٹ چاہیے۔

## کون دیکھتا ہے

ڈیفالٹ طور پر آپ کے قبول کیے کانٹیکٹس۔ لگانے سے پہلے آپ اسے ان میں سے کچھ کے ساتھ ہی شیئر کر سکتے ہیں، یا کچھ خاص لوگوں کو باہر رکھ سکتے ہیں۔ آپ جو بھی چنیں، صرف وہی لوگ دیکھ سکتے ہیں جنہیں آپ نے کانٹیکٹ کے طور پر قبول کیا ہے۔

## دیکھنا، جوابات اور حذف کرنا

- آپ دیکھ سکتے ہیں کہ آپ کا اسٹیٹس کس نے دیکھا۔
- اسٹیٹس کا جواب اس شخص کے ساتھ آپ کی ذاتی چیٹ میں آتا ہے۔
- اسٹیٹس حذف کرنے سے وہ فوراً سب کے لیے ہٹ جاتا ہے۔ جو پہلے دیکھ چکے، وہ دیکھ چکے۔

## حد

اسٹیٹس اینڈ ٹو اینڈ انکرپٹڈ نہیں ہوتے، اس لیے AChat کے سرورز انہیں پڑھ سکتے ہیں۔ رسائی کے اصول ہر اسٹیٹس کے دیکھنے والوں کو آپ کے چنے ہوئے دائرے تک محدود رکھتے ہیں۔
