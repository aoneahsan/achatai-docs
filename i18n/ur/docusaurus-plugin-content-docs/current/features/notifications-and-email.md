# اطلاعات اور ای میل

**جب تک آپ اجازت نہ دیں، اطلاعات بند رہتی ہیں، اور ان میں پیغام کبھی نہیں ہوتا۔**

## اطلاعات

- انہیں **اکاؤنٹ** میں **ترجیحات** کے اندر **اطلاعات کی اجازت دیں** سے آن کریں۔ AChat آپ کی ڈیوائس سے اجازت تبھی مانگتی ہے جب آپ یہ چنتے ہیں۔
- ہر اطلاع میں چیٹ یا بھیجنے والے کا نام ہوتا ہے، پیغام کا متن کبھی نہیں۔
- **اطلاعات میوٹ کریں** ایک چیٹ کو خاموش کر دیتا ہے۔ سب میوٹ کرنے سے آوازیں اور الرٹس رکتے ہیں؛ پیغامات پھر بھی آتے ہیں۔
- اجازت دینا اور پانا الگ ہیں: اگر آپ کی ڈیوائس اطلاعات کی اجازت دیتی ہے لیکن ابھی پا نہیں رہی، تو AChat یہ بتاتی ہے اور دوبارہ کوشش کرنے دیتی ہے۔

## ای میلز

AChat آپ کے Google ای میل پتے پر صرف آپ کے اکاؤنٹ کے بارے میں ای میل کرتی ہے:

| ای میل | کب |
|---|---|
| خوش آمدید | سائن اپ کرنے کے بعد |
| نئی ڈیوائس منسلک ہوئی | آپ کے اکاؤنٹ سے کوئی ڈیوائس منسلک کی گئی |
| ریکوری کی بدل دی گئی | آپ کی ریکوری کی بدل دی گئی |
| رکھے گئے روم کی یاد دہانی | کسی رکھے گئے روم کی تاریخ قریب آ رہی ہے |
| پلان کی دعوت | کوئی آپ کو Team / Family پلان میں بلاتا ہے |
| ادائیگی کی درخواست موصول، تصدیق ہوئی یا تصدیق نہیں ہوئی | کسی پلان کی ادائیگی کے بعد |
| رابطہ فارم کی رسید | رابطے کے صفحے سے پیغام بھیجنے کے بعد |
| اکاؤنٹ حذف ہو گیا | آپ کا اکاؤنٹ حذف ہونے کے بعد |

گمنام رومز کوئی ای میل نہیں بھیجتے۔

## جب AChat کسی دوسرے ٹیب میں ہو

جب کوئی پیغام آتا ہے اور AChat کا ٹیب سامنے نہیں ہوتا، تو آپ کو پیغام کی آواز سنائی دیتی ہے (اگر اطلاعات کی سیٹنگز میں **آواز** آن ہے اور چیٹ میوٹ نہیں)، اور ٹیب کا عنوان آپ کے لوٹنے تک نئے پیغامات گنتا ہے۔ چیٹ فہرست فوراً اپ ڈیٹ ہوتی ہے۔
