# تھریڈز اور جوابات

**تھریڈ میں جواب دیں، تاکہ باقی سب کی بات چیت چلتی رہے اور کوئی منصوبہ کھو نہ جائے۔**

## جواب یا تھریڈ

- **جواب دیں** مرکزی گفتگو میں کسی پیغام کا اقتباس دیتا ہے۔
- **تھریڈ** کسی ایک پیغام پر ضمنی گفتگو کھولتا ہے، چیٹ کے ساتھ والے پینل میں۔ **چیٹ میں دکھائیں** اس پیغام پر واپس لے جاتا ہے جہاں سے وہ شروع ہوا۔

تھریڈز چیٹس، رومز اور کمیونٹی چینلز میں کام کرتے ہیں۔

## تھریڈ میں حذف کرنا

- ایک جواب اکیلے حذف کریں، تو وہ چیٹ کے ٹریش میں جاتا ہے۔
- جس پیغام سے تھریڈ شروع ہوا اسے حذف کریں، تو وہ اپنے سارے جوابات کے ساتھ ٹریش میں جاتا ہے۔ چیٹ میں کوئی بھی انہیں ٹریش سے واپس لا سکتا ہے۔

ٹریش کے لیے دیکھیں [پیغامات کا انتظام](/features/manage-messages)۔
