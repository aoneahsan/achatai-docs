ڈویلپرز کے لیے AChat

آپ کے AChat اکاؤنٹ تک ایپ کے باہر سے پہنچا جا سکتا ہے، آپ کے ذریعے، آپ کی شرائط پر۔ کوئی اسکرپٹ اسٹیٹس لگا سکتا ہے یا آپ کی بلاک فہرست ملا کر رکھ سکتا ہے، Claude بتا سکتا ہے کہ کن کھلے رومز میں نئے پیغامات آئے، اور آپ کا سرور اسی لمحے جان سکتا ہے جب کوئی آپ کو کانٹیکٹ کی درخواست بھیجے۔ یہ ہر پلان میں ہے، Free سمیت، اور ہر راستہ ایک ہی اکاؤنٹ تک پہنچتا ہے: آپ کا۔

آپ کو کون سا چاہیے؟​

آپ چاہتے ہیںاستعمال کریں
آپ کا کوئی اسکرپٹ یا سروس آپ کا اکاؤنٹ پڑھے یا بدلےرسائی کی اور API
Claude، ChatGPT، Claude Code یا Cursor آپ کے اکاؤنٹ کے ساتھ کام کرےاسسٹنٹ کنکشن
کچھ بدلے تو آپ کے سرور کو بتایا جائے، ہر منٹ پوچھے بغیرویب ہُکس
Google سائن اِن کے بعد ایک کوڈ، تاکہ چوری شدہ Google اکاؤنٹ کافی نہ ہودو مرحلہ سائن اِن

چاروں ایپ میں ہیں: کیز، منسلک ایپس اور ویب ہُکس اکاؤنٹ › دوسری ایپس میں، دو مرحلہ سائن اِن اکاؤنٹ › سیکیورٹی میں۔

دوسری ایپس کن چیزوں تک پہنچ سکتی ہیں​

کوئی ایپ صرف آپ کی بنائی کی یا آپ کے منظور کیے کنکشن سے اندر آتی ہے۔ دونوں میں تین اصول لاگو ہوتے ہیں۔

کیاAChat کے باہر سے
آپ کاآپ کی پروفائل، سیٹنگز، اسٹیٹس پوسٹس اور بلاک فہرستپڑھنا اور بدلنا۔ حذف کرنا الگ اجازت ہے، جب تک آپ ٹک نہ کریں تب تک بند
دوسروں کے ساتھ مشترککانٹیکٹس، چیٹس، کھلے رومز کے پیغامات، کمیونٹیز اور چینلزصرف پڑھنا۔ کوئی ایپ وہاں پوسٹ، ہٹا یا مدعو نہیں کر سکتی
اینڈ ٹو اینڈ انکرپٹڈذاتی چیٹس، گروپس اور پاس ورڈ والے رومزکبھی نہیں۔ ایپ کو چیٹ کا نام اور یہ نظر آتا ہے کہ آپ اس میں ہیں، پیغامات کبھی نہیں

آخری اصول کوئی سیٹنگ نہیں۔ آپ کی ذاتی چیٹس، گروپس اور پاس ورڈ والے رومز کے پیغامات آپ کے ڈیوائسز پر بند رہتے ہیں، اور AChat کے سرورز انہیں نہیں پڑھ سکتے، اس لیے کوئی کی یا اسسٹنٹ بھی نہیں پڑھ سکتا۔ آپ کی ڈیوائس کیز، ریکوری کی اور دو مرحلہ کوڈز پر بھی یہی لاگو ہے۔ دیکھیں سیکیورٹی اور انکرپشن۔

کوئی کیلنڈر فیڈ نہیں​

AChat میں ایسی کوئی تاریخ والی چیز نہیں جو کیلنڈر میں جائے، اس لیے سبسکرائب کرنے کو کوئی کیلنڈر فیڈ نہیں۔
