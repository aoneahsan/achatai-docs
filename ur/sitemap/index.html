  • AChat API

    AChat کا REST API: بیس URL، Authorization ہیڈر، جواب کا ڈھانچہ، ایرر کوڈز، کرسر سے صفحات اور حدیں، پھر ہر ریسورس چلتی curl مثال کے ساتھ، آپ کی پروفائل اور اسٹیٹس پوسٹس سے کھلے روم کے پیغامات تک۔
