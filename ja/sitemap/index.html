AChat ドキュメントの全ページを、サイドバーと同じ分け方で並べています。検索エンジン、フィードリーダー、AI アシスタント向けには、sitemap.xml が全ページを、feed.xml が変更履歴を RSS で載せています。変更履歴フィード ページにも同じ項目があります。

概要

  • はじめに

    AChat は個人チャット、グループ、コミュニティ、匿名ルームのためのメッセージアプリで、ウェブと Android で使えます。できること、そして約束していないこと。

  • よくある質問

    AChat についての率直な答え：アカウント、暗号化、匿名ルーム、メッセージが残る期間、プラン、位置の記録、アカウントの削除、対応プラットフォーム。

  • 変更履歴

    AChat のリリースの歴史。個人チャット、グループ、コミュニティ、ステータスを加えた作り直しと、匿名チャットだったころの以前のリリース。

はじめに

  • インストールとアクセス

    AChat はブラウザで使うか、Google Play から Android アプリを入手できます。匿名ルームにはアカウント不要、個人チャットには Google ログインとユーザー名が必要です。

  • クイックスタート

    AChat で最初の会話を始めましょう。ユーザー名で友だちと、またはリンクで匿名ルームで。そして復元キーを保存します。

機能

  • 個人チャットと連絡先

    ユーザー名、招待リンク、QR コードで人を追加し、メッセージリクエストとブロックを扱い、オンライン表示の相手と既読を送るかどうかを選びます。

  • 端末と復元キー

    別の端末を AChat アカウントにリンクし、セキュリティコードを照合し、なくした端末を外し、復元キーで履歴を取り戻します。

  • 匿名ルーム

    AChat の匿名ルームがアカウントなしでどう動くか。ルーム ID、表示名、パスワード、メッセージの保存期間、そして匿名が意味しないこと。

  • パスワードと暗号化

    どの AChat のチャットがエンドツーエンド暗号化されているか、ルームのパスワードが何を守るか、そして限界。オープンなルーム、コミュニティ、ステータスはエンドツーエンド暗号化されていません。

  • グループとコミュニティ

    知り合い同士のための暗号化されたプライベートグループと、チャンネル、スレッド、役割、通報、追放のあるコミュニティ。どれにアカウントが必要か。

  • ステータス

    24 時間で消えるステータスを連絡先に投稿し、見る人を選べます。ステータスはエンドツーエンド暗号化されていないことも知っておいてください。

  • 保管ルームとアカウント

    AChat の匿名ルームを初期設定の履歴期間を越えて保管し、解除し、アカウントを管理します：ユーザー名、データの書き出し、アカウントの削除。

  • スレッドと返信

    メッセージに返信するか、スレッドで返信して、わき道の会話を 1 か所にまとめます。スレッドはチャット、グループ、ルーム、コミュニティのチャンネルで使えます。

  • ファイル、ボイスメモ、メディア

    AChat では、プランのファイル容量の範囲で、どんな種類のファイルでも、写真、動画、ボイスメモを共有でき、チャットのメディアがまとまる場所も見られます。

  • メッセージの管理

    AChat のメッセージの編集、削除、消去、転送、ピン留め、復元。チャットごとのゴミ箱、消えるメッセージと 1 回だけ表示、投票、チャット・メッセージ・返信のアーカイブ、チャットのコピーの保存。

  • メッセージを書く

    AChat の下書き、ネタバレ隠し、数式、メンション、スタンプ、音声入力、端末上の翻訳と読み上げ、そしてそのうちどれが端末の外に出るか。

  • 検索とオフラインの履歴

    AChat の検索は、端末にあるメッセージを対象に端末上で動きます。開いたチャットはオフラインでも読め、オフラインで書いたメッセージは送信トレイで待ちます。

  • 埋め込みウィジェット

    AChat の匿名ルームやコミュニティのチャンネルを、ページの中に、またはチャットボタンとして自分のサイトに置き、表示できるサイトを選べます。

  • 通知とメール

    AChat の通知はオプトインで、メッセージの本文を含むことはありません。AChat が Google のメールアドレスに送るメールと、その時期。

  • 外観、言語、ショートカット

    テーマ、色、文字サイズ、動きを 1 つの外観パネルで。アラビア語とウルドゥー語を含む 11 の表示言語、AChat のキーボードショートカットと集中モード。

  • この端末でのプライバシー

    共用や借りた端末を守る AChat の設定：プライバシー画面、目立たないタブ名、クリップボードの自動消去、このデバイスから消す。

  • 端末と位置の記録

    AChat のチャットには、端末と位置を記録するものがあります。何を記録し、誰が見られ、どれだけ保存し、入る前にどう確認するか。

  • プランと料金

    AChat の Free、Pro、Team / Family プラン、それぞれが変える 4 つの枠、カード払いと銀行振込の仕組み、紹介でプランの月数を得る方法。

  • ページツアーと「AChat の仕組み」

    チャット、機能、プランと料金、コミュニティ、アカウントにあるページツアーと、6 ステップの「AChat の仕組み」ページ。

  • 話して入力、下書きサポート、これまでの要約

    「話して入力」は録音をメッセージ欄のテキストに、「下書きサポート」は自分の下書きを書き直し、短くし、翻訳し、「これまでの要約」はオープンなルームをあなただけのために要約します。

コンセプト

  • AChat の仕組み

    AChat の 2 つの立場（アカウントと匿名の表示名）、チャットの種類、メッセージの置き場所、そしてそれぞれがどれくらい残るか。

  • セキュリティと暗号化のモデル

    AChat のエンドツーエンド暗号化が守るものと守らないもの、キー、リンクしたデバイス、復元キーの関係、そしてどんなアプリにも取り除けない限界。

  • 管理者による監督

    AChat の管理者に見えるもの、できること、できないこと。チャットの詳細は見えてもメッセージは見えない、報告、停止、ルームの制限、プランの付与、そして操作ログ。

  • データ、プライバシー、削除

    AChat が集めるもの、それを扱うサービス、データの種類ごとの保存期間、あなたが管理できること、そしてアカウント削除で消えるもの。

開発者向け

  • 開発者向けの AChat

    スクリプト、AI アシスタント、自分のサーバーから自分の AChat アカウントにアクセスします。アクセスキー付きの API、Claude と ChatGPT 向けのアシスタント接続、署名付きの Webhook、2 段階ログイン。暗号化されたチャットが AChat の外に出ることはありません。

  • アクセスキー

    アカウント › ほかのアプリ で AChat のアクセスキーを作り、読み取り、変更、削除できる範囲と、使えなくなる時期を選びます。キーを再表示できるとき、途切れなく差し替える方法、削除の方法。

  • AChat API

    AChat の REST API：ベース URL、Authorization ヘッダー、応答の形、エラーコード、カーソルによるページ送りと制限、そしてプロフィールやステータスからオープンなルームのメッセージまで、すべてのリソースを動く curl の例とともに。

  • Claude、ChatGPT、Claude Code、Cursor を接続

    AChat の MCP アドレスを通じて AI アシスタントを AChat アカウントに接続します。Claude、ChatGPT、Claude Code、Cursor の設定、承認する内容、削除がいつもあなたの承認を待つ理由、接続の解除。

  • Webhook

    AChat の Webhook：https のアドレスを追加し、イベントを選び、各配信の Standard Webhooks 署名を Node か Python で検証します。すべてのイベントとペイロード、再試行の予定、一時停止、アドレスがオフになる条件。

  • 2 段階ログイン

    AChat で Google ログインのあとに、認証アプリの 6 桁のコードを加えます。設定、10 個のリカバリーコード、ブラウザを 7 日間記憶、スマートフォンをなくしたとき、AChat チームにできることとできないこと。

  • 開発者向けの変更履歴

    AChat の API、アシスタント接続、Webhook、2 段階ログインの変更を新しい順に。2026-11-21 のオープンプラットフォームから。

ホワイトラベルとライセンス

  • ホワイトラベルとライセンス

    AChat チームがホストする AChat をあなた自身の名前で運用するか、ソースコードをまるごと買い取るか。それぞれに含まれるものと、料金の載っている場所。

  • プラットフォームごとに得られるもの

    AChat のホワイトラベルライセンスが現在対象とするプラットフォーム：ウェブアプリと、モバイルアプリ（Android、iOS はご要望に応じて）。

  • コピーのセットアップ

    AChat のホワイトラベルライセンスを買ったあとに起きること：ライセンスのメール、あなたのドメイン、名前、ロゴ、色、そして公開。

  • アップデートと更新

    AChat のホワイトラベルライセンスと買い取りには、どれも 6 か月分の AChat のアップデートが付きます。アップデートの範囲、更新しない場合、更新の方法。

  • ライセンスを確認

    別の名前で動いている AChat のコピーがライセンスを受けているかを、ライセンスキーかドメインで確認する方法と、それぞれの結果の意味。

  • ホワイトラベルのよくある質問

    AChat のホワイトラベルライセンスと買い取りについての回答：ソースコード、独占、カスタム開発、iOS、Wise での振込による支払い、買い取り後のロイヤリティ。
